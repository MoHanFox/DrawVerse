# 湿混双色贡献场性能验收

2026-10-17，Windows。对应[设计](brush-wet-field-performance-design.md)。主、第二角色均改为瓦片内一次覆盖计算，分别更新原几何/RGBA场和起收笔日记，再按变化像素并集重算。保留四独立场、原浮点积累公式和私有写入/COW；几何饱和仍混色，零覆盖只跳过无效颜色采样，不跳过载色准备、消耗或提交。无ABI/state/VBR变化，没有放宽工作预算。

## 固定输入Release测量

`cargo run --manifest-path core/Cargo.toml -p paint-core --example brush_wet_field_performance --release --locked`。192×128白底；主/副1%直径间距（主spacing内部为半径单位0.02）；40%整笔opacity、60%流量、真实湿度/拾色/混合/沉积/消耗；程序或含透明洞的8×8图片笔尖；8个原始8px输入包含弯曲，走Document分页。每组5次中位数，含Begin、绘画、End及单历史，不含初始化和摘要/Qt视口。前后相同基准源，全部最终像素与双载色65×65采样的浮点位摘要逐项一致，摘要不能代替下面逐像素/逐场回归。

## 对应回归

- 新3项通过。162组（27模式×2路径×3目标）使用测试专用原两遍color_field作为参考，逐输入比较完整四场、实际像素和每个载体格点的浮点位；包含图片洞/纹理、低流量、前后/溢出配置、蒙版、椭圆AA选区、偏移及透明锁。最终像素、真实历史、undo/redo保持；无像素变化的模式不制造历史。
- 起收笔在驻留1瓦片与正常驻留下对照原两遍，输入分页、活动尾恢复和取消均保持；另经64px原始输入与分页End完成后比较像素/双载色及undo/redo。
- 直接计数用例验证256个位置仅计算256次覆盖、128个非零位置采样128次，而旧两遍为512/256；持有旧瓦片及读取像素的快照时，后续更新采用COW，快照保持，结果与旧路径一致。没有用几何饱和跳过颜色更新。
- `paint-core --lib wet_` 18项通过（含上述3项，随后扩充的分页End部分再运行新3项通过），覆盖旧饱和继续混色、颜色动态、图片/起收笔、透明搬运、瓦片与历史写入失败整笔回滚、预算及零写入拾色等；筛选有交叉，不能再相加为互不重复测试。
- 新分页Actor既有6项、公开API既有9项通过，包括真实线程、64px三图片角色、准确准备修订及双载色/历史/交换。
- paint-core全目标Clippy `-D warnings`通过。
- Windows最终Release、生成头构建检查、4项C/C++ static/shared ABI通过。Qt现有两项湿混组合通过（含init/cleanup为4 passed）：64px单原始输入、三图片用途/新目录VBR交换重开、两色装载捕获与白色预览及历史；没有运行整体硬件验收或无关Qt全套。

首轮编译将新增方法留为子模块私有，修为父模块可用。新对照测试最初假定所有模式都会新增历史；白底上一些模式无像素修改，原算法也不生成历史，断言改为按实际像素变化并与旧路径历史对照，未修改生产历史规则。一次验证命令误写不存在的public_api测试目标，明确失败后改用实际async_session目标，9项通过。未隐藏失败或用缩短输入替代复现。

# 湿混双色 Engine 所有权

把已实现的 Document 湿混双色接入真实 Session 串行任务。配置开启湿混且有效双色时使用明确的双载色起笔入口，起笔借用工具租约的完整 WetInk；其余湿混保持旧单载体入口。End 使用完整 WetInk 结束，在 Document 像素/历史成功后才 commit_ink。单载体 End 仍按旧 commit 只采用主载体，保留工具内尚未使用的第二载色。

同一工具两个角色共用一份独占租约，跨文档冲突在选择目标前拒绝；重复起笔不破坏在途笔触。错误/队列取消/显式取消/New/stop/actor退出释放租约且不采用任一角色。Undo/Redo 只恢复像素，不回退工具载色。无像素拾色成功也必须采用两角色，不生成伪历史。

当前只接内部 typed Begin 任务，不绕过旧准备/包接口的湿混双色保护，不增加ABI或格式版本。下一阶段完整保存能力和原生准备修订才开放用户组合；本阶段不能以内部 Session 测试宣称公开 C ABI 已支持组合。

验收：真实串行队列两笔及完整像素剪贴字节对照 Document、两个载体完整采样/revision、跨会话共享工具/两种路径/起收笔/颜色动态/相对尺寸、捕获与undo/redo；双角色取消/输入预算/图层预算/New/stop与跨文档Busy和重复Begin，错误目标不改选择/载色；无像素拾色整对采用，切回单笔刷保留副载色。旧单载体 Actor/C ABI 与最小Qt回归、Windows Release。

# 切向压力动态

2026-10-18，新增预设级切向压力动态，模型为 `tangent-v1`。输入使用 `InputPoint::tangential_pressure` 的原始 -1..1 设备范围，映射为 `(value + 1) / 2` 后裁剪到 0..1；曲线横轴是该归一化值，纵轴为输出比例。零值对应曲线中点，负值和正值分别对应左右端。

参数包含启用开关和尺寸、流量、整笔不透明度三条独立曲线，每条 2–17 个严格递增节点、0–1 最低比例及可选 `smooth-pchip-v1`；默认关闭，三条曲线为恒等线性响应。曲线编辑和显示与速度动态共用 `SpeedCurveEditor`，但设置/重置回调指向 `tangent-v1`。

尺寸因子乘到主笔尖实际半径，并乘到配对第二笔尖的独立/相对跟随尺寸；相对固定边宽继续以已缩放的主尺寸为基准。流量因子乘到每个印章的流量，不透明度因子乘到压力/起收笔形成的整笔上限。速度、切向压力和压力曲线在同一次印章计算中相乘；随机序列、选区、蒙版、锁和历史边界不变。第二笔尖自身不支持切向压力动态，仍由主预设曲线统一驱动。

保存使用 state25、VBR1.31、behavior20 和 `tangent-dynamics` 能力。VBR `parameters.tangentDynamics` 完整保存 `model/enabled/size/flow/opacity`，关闭状态也保留；旧 state24/VBR1.30 不携带该对象，低版本夹带明确拒绝。预设复制、完整重置、导入导出和重启恢复使用同一对象。

Qt 输入层已从 `QTabletEvent` 读取 `tangentialPressure` 并传入 Rust；Windows 实体数位板是否提供非零该通道由设备/驱动决定，本阶段只验证模拟输入和代码路径。ABR 切向压力来源、任意来源到任意参数的动态矩阵、跨平台和硬件手感仍待后续。

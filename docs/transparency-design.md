# 透明画布背景

画布及导航原先以米白色矩形衬底，使完全透明或全部隐藏的图层看起来仍像有底色。本次改为白色/浅灰色正方形棋盘格，绘画和导出像素仍保留原有 alpha。

用一个可复用 QML 组件显示固定 24×24 PNG，Image.Tile 重复纹理；每格 12 个逻辑像素，缩放后仍保持便于辨认的大小，高 DPI 自动适配。图案定位在画布矩形内，只是显示背景。无逐像素 CPU 合成、无海量方块对象，不改 Rust 文档或文件 IO。

主画布及导航使用同一组件，位于 PaintCanvas 之下。隐藏所有图层时可完整看见棋盘格；局部透明也显示格子，不透明笔触遮住格子。验收包括 Qt 实际渲染像素截图、主画布/导航、隐藏/恢复图层、导出 alpha 不受影响和两倍 DPI。

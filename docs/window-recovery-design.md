# 窗口恢复与边缘吸附修复（2026-10-09）

仅修改 Qt/QML。主窗最小化时不重新裁剪原生区域；正常/最大化恢复后重建正确区域，保持无边框、菜单模糊、正常尺寸和画布内容。浮窗最小化期间不持久化临时几何。

图标临时面板全应用最多一个，窗口失去激活、外部鼠标/触控/数位笔按下或 Escape 后关闭；来源图标切换可继续打开当前目标，销毁旧窗不得清除新窗登记。空白关闭点击不绘画。

拖动工具窗靠近工具面板四边或主工作区左右边缘（内外统一 24px 范围）时选择最近边，显示窄发光边缘并在松手停靠。排除自身/同一正在移动的宿主；重叠目标优先当前可见的顶层窗口，避免隐藏窗或被遮挡面板抢占；主窗边缘仅在主窗可见处生效。工具面板中部只在标题标签区域接收合并，正文不再整个充当标签目标。画布与工具的接收限制保持。

单画布浮窗标题、空白尾部与窗口按钮共用 strip 颜色，hover 关闭按钮红色。图标侧栏背景与正常工具面板统一 surface 色，图标保持 text 色；删除工具条拖动说明提示。

验收：普通和最大化下重复最小化/任务栏恢复，Win32 客户区覆盖窗口且像素内容/几何正确；真实外部点击与跨列切换只有一个临时窗；鼠标/触控/数位笔和窗口切换均关闭；四边内外容差与中部无吸附、自身排除、遮挡选择、主左右归位及匹配发光提示；单画布标题背景与按钮一致；普通/两倍 DPI/Windows 实窗与完整 tools/check.py。

删除参考图布局预设及其自动初始化，双列停靠命名为“默认布局”；新启动采用默认双列，已保存自定义布局保留，菜单命令恢复默认。增加菜单入口与恢复/持久化回归。

补充标签拖动：鼠标在当前标签栏（含 8px 容差）内优先交换源/目标标签位置，松手提交并保留活动面板，不创建浮窗；越出标签栏才拆出面板。临时面板同样支持，拖动期间显示目标下沿提示，取消不改顺序。Qt Test 验证普通面板、图标临时面板、持久化及拖出边界。

# 笔刷目录分组与包组织

2026-10-17。完成VBR和笔刷库的分组、文件夹与显式顺序；分阶段接Rust目录、保存交换、原生及Qt，不用只有文件夹外观代替实际组织和往返。

## Rust目录阶段

新增不可变BrushOrganization：根有序条目、按稳定UUID标识的组记录，每组有名称与有序条目；条目明确区分Preset/Group，名称允许重复。组最多256、嵌套最多8层，沿用1024预设限制；组名80字符/去首尾空白/无NUL，组UUID规范且不可与预设冲突。所有预设和组必须恰好出现一次、全部可达，拒绝未知引用、孤立组、环、多父、重复条目和过深输入；构造先检查总条目边界，不递归无界遍历。

BrushCatalog的ids保持树的深度优先预设投影；现有平目录默认顺序不变。组织快照与BrushPreset/BrushProgram及资源分开，移动/重命名组不重编译笔刷或改变源图、载色及在途捕获；旧Arc组织和预设仍可读。完整组织替换、建组、改名、条目移动、解组/级联删除均先完整验证，成功仅推进一次revision，失败或无变化保留原状态及身份。移动位置按移除源条目后的目标兄弟列表解释。

解组把直接子项原位提升到父列表，保留深层组及预设顺序；级联删除删除整个子树，包含内置预设时整项拒绝。删除选中用户笔刷沿用回退第一个内置预设。普通批量导入仍追加根，显式组导入追加该组，复制选中预设追加同组（根目录仍追加根），不共享可变参数；ID/容量/资源预算失败不能半导入。删除单预设只移除该成员，允许留下空组。已有编辑/改名/来源操作保持组织。

旧状态编码尚无组字段时，有非空组记录必须明确拒绝，不能悄悄写成平目录；旧状态读入仍建立准确平组织。包接口当前从调用者显式JSON创建，旧解析器继续拒绝新增未知组织字段。此阶段不占state/VBR/ABI版本，不声称跨重启、包或界面分组已完成。

验收：默认/恢复平顺序、层级DFS投影与稳定身份、失败原子/无变化revision、环/多父/孤立/超深/数量/UUID/名称与引用边界、组内复制及批量导入/预算拒绝、解组/级联删除保护与选择回退、空组及删除成员、真实捕获笔画像素/历史不受组织改变影响。原目录/IO/准备与Qt最小回归、Windows Release/ABI；整体手感用户验收，跨平台后置。

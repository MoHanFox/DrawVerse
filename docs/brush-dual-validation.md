# 双笔尖覆盖核心验收

2026-10-14，ABI 保持1.42，无 Qt 新入口。DualBrush/SecondaryTip 配置不可变且共享；已接 paired-dab-v1 的六种覆盖组合、独立大小/流量压力曲线、设备角度/倾斜几何、程序/图片笔尖、第二散布及形状抖动。每个实际主子印章使用独立第二随机域；先组合覆盖再纹理/整笔不透明度/选区及写入。主轮廓限制第二区域，关闭配置不执行但保留资源与预算。

原地改变有效第二压力响应会更新普通写入，曲线输出不变时不增加印章；沿用整笔不透明度上限。工作预检包含最大第二数量和最坏图片采样成本，失败不推进随机序号、不修改像素/历史。第二图片与主图片/纹理源按身份共享预算，在途编译捕获资源。

## 1. 两种绘制方式

新增“双色绘制”功能，第二笔尖拥有颜色贡献和叠放顺序。现有模式名称不能被静默重新解释；双色其他混合模式若后续加入，需分别定义并验收颜色、覆盖和透明度语义。

扩展仍放在双重笔刷分类，复用主/第二笔尖、图片、动态、资源、路径、预览与历史系统，不另建Qt绘画引擎。既有独立路径/印章配对继续作为路径设置；没有把“前后”解释为沿路径的空间偏移。沿行进方向领先/落后若以后添加，使用独立的路径偏移参数。

## 2. 用户选项与尺寸单位

| 选项 | 确认规则 |
|---|---|
| 使用第二颜色 | 使用颜色面板保存的背景色。关闭时第二贡献使用前景色；开关保存于预设，实际两色属于工具颜色快照，不把用户当前颜色写成预设常量 |
| 独立尺寸 | 第二笔尖使用自己的像素直径，保留目前的独立尺寸与动态配置 |
| 相对尺寸 | 第二标称直径＝主标称直径＋像素偏移。滑条中点为0，左右为负/正；有可输入的像素值，直径单位与工具详情一致 |
| 允许溢出 | 关闭时第二贡献限制在主笔触覆盖范围内；开启时允许第二贡献出现在主覆盖外，仍受文档、选区、锁和目标蒙版约束 |
| 上层图层模式；下层图层模式 | 调整第一第二贡献者的图层 |
| 主笔刷前方／后方 | 表示第二贡献在主贡献上层／下层，分别产生不同的整笔合成结果 |
分隔渲染选项：不使每个印章依次往文档画“后方第二颜色→主颜色”：后来的第二印章会盖进前面已经画好的主线。更新时从已捕获的before快照重算受影响区域的整笔合成，不重复叠加上一帧预览。需要处理主覆盖增长时此前第二颜色的裁切变化，避免交叉/回笔/停顿出现杂边或残留。软覆盖裁切避免重复乘主覆盖使边缘额外变暗，具体算式在实施设计及像素测试中固定。

切换方式、尺寸模式或关闭模块，不清除另一模式已有的独立尺寸/相对偏移、动态、资源、第二颜色和叠放设置。有效尺寸受内核实际合法范围限制，显示最终有效尺寸；不得只在QML放宽范围，也不能产生负直径。具体滑条边界及超范围反馈在实施设计中与内核/预算同步确定。

## 3. 颜色捕获与整笔合成

起笔同时捕获前景、背景、模式、尺寸与两套定义。笔触中交换两色、选预设或改参数只影响下一笔。两色沿用线性预乘RGBA工作空间；若允许与颜色动态共用，需要明确各自的颜色来源和执行顺序，不能隐式借用第二颜色开关改变旧覆盖模式。

主/第二分别累积整笔覆盖与必要的颜色贡献，随后按叠放顺序生成一份复合笔触，应用整笔不透明度上限，再合成到起笔前的目标快照。整笔不透明度作用一次，不能先给两份贡献各套一次后重叠使透明度加深。流量、压力及颜色动态按各自真实定义执行。

两份贡献和快照采用现有有界瓦片/分页机制；实时预览与最终提交一致，取消和存储失败恢复全部，提交只有一条历史。撤销/重做恢复真实像素，不依赖当前颜色或预设。更大第二笔尖的脏区域、工作预算、光标边界和资源生命周期均需同步扩展。

## 4. 压感尺寸规则

- **跟随尺寸压感**：相对标称尺寸计算后，按相应尺寸动态缩放。描边预设同步主/第二尺寸响应时，主线与描边一起随压力变细。
- **固定描边宽度**：先算主笔尖实际压感/动态尺寸，再加直径偏移。该模式同步第二尺寸到主尺寸，避免再次套第二大小压感；原第二曲线保留并在界面说明当前不参与独立尺寸计算。

固定边宽的保证针对同路径、同形状、方向及尺寸动态同步的描边配置。第二笔尖独立散布、不同形状/角度或其他独立几何动态仍可用于复合效果，但不能承诺它们产生均匀外轮廓。与独立路径的主尺寸动态对应关系要在实施设计中明确，不能通过未经定义的主随机序号计算第二直径。

## 5. 自动描边预设

主贡献使用前景色，第二贡献使用背景色；双色正常模式，第二放在主后方，允许溢出，相对直径偏移+8px。同形状硬笔尖且主贡献完全覆盖时，外描边约4px，因为偏移单位是直径。提供跟随尺寸压感及固定边宽两规则。

描边预设同步两者路径印章、形状、方向和必要的尺寸动态，分别累积后统一合成，交叉与重叠处保留主贡献覆盖的内部区域。半透明主颜色会透出后方第二颜色，这是双色叠放本身的行为；若以后要求半透明主线也不透出描边，则另定义只绘外环的描边行为，不能静默修改正常合成。

新增对象/模型及能力显式版本化，Rust定义、state、VBR Schema、准备桥、原生包、Qt保存和真实预览完整接通后才展示入口。未支持的启用能力明确拒绝；关闭非默认配置也必须保留，旧读写器不能丢字段后宣称保存成功。ABR的现有覆盖双笔刷按旧模型导入，不把原文件未表达的双色扩展自动启用。

相对滑条居中、紧凑像素输入、通用复选框与1000ms提示；实际主/第二颜色和大小反映在预览中。光标区分主轮廓/复合作用范围，允许溢出时不能让用户误以为绘画受主轮廓限制。

真实像素覆盖独立/相对、正负/零偏移及边界；两色捕获/交换、前后顺序、溢出裁切与软边、六种旧覆盖模式保持；交叉、闭环、回笔与原地重叠的连续描边；整笔透明度不重复应用、两种压感边宽；图片/方向/散布与独立路径组合；选区/羽化/蒙版/锁/偏移/分页、预算和存储失败；取消/单条历史/撤销重做；状态/VBR关闭配置和源资源往返；Qt真实控件/窄列/DPR1/2/统一预览。

## 8. 重置预设按钮

2026-10-14用户补充：笔刷设置内提供“重置预设”按钮。它恢复当前预设的初始参数/资源/模块开关及关闭时保留值，不只重置当前子页；包括本扩展的两种尺寸、两种压力规则、第二颜色来源、溢出和叠放顺序。内置预设恢复出厂定义；保存副本以创建副本时的完整定义为基准；导入预设以导入成功后的可执行定义为基准，保留ABR原始来源。

基准需要独立持久保存并经过Rust资源/参数验证，不能把所有自定义笔刷重置成普通圆笔。旧自定义预设没有历史基准时，迁移时记录当前有效定义为基准并明确说明恢复范围。按钮不改变当前前景/背景色、预设身份与名称、全局光标、工具或画布历史；只影响下一笔，当前笔触使用捕获定义。重置发布原子修订、过期预览失效并生成真实新预览；失败保留当前定义。资源身份及来源基准保留和重开恢复列入验收。

# 固定白色笔刷预览

2026-10-16，用户明确要求任何设置下笔刷预览均为白色，替代此前双色/颜色动态/湿混有色缩略图策略；用户同时取消试画功能，未接入的试画代码、设计和构建更改已删除，不增加入口。

自动预览继续运行隔离Rust会话、捕获当前笔尖/动态/材质参数、固定正常工具混合模式。显示结果统一以白色呈现，保留实际渲染的每像素alpha；RGB取白色，不使用灰度转换或修改alpha，因而软边、低不透明度与孔洞保持。主画布、原生执行算法、工具前景/背景、预设参数、来源和VBR不变。

当前两色不再是自动预览请求或缓存身份的一部分，换色/交换两色不重新生成缩略图；预设参数变化仍通过原有token丢弃过期结果。湿混底样的内部取样仍属私有会话，输出同样统一白色，不展示彩色底样。固定尺寸240×60，白色转换在后台遍历这张小图，不访问主文档瓦片。

验收：主/第二贡献、双色、颜色动态和湿混预览所有alpha>0像素均RGB255，透明和半透明存在且保持；换色、交换及工具混合模式不改变预览缓存，笔尖参数变化仍使旧token失效；既有实际双色/湿混绘画像素与历史/载色隔离保持。Windows最小相关Qt、Release/ABI检查，无新格式或ABI。

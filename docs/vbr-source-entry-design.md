# VBR来源交换入口

ABI1.34/来源交换能力标志，既有library_package_read/write接1.2完整包。读取先校验整包和caller容量，再导入当前/基线PNG及分组来源，保留待准备使用的当前mask与来源凭据；基线mip不因仅有报告引用长期占预算。准确发布后交接释放。写入按sourceResource引用冷导出来源批次，收集当前/基线PNG后完整编译、原子保存，源文件损坏不能覆盖既有目标。

Qt的importPackage保留sourceResource并维持v4；冲突UUID副本共享来源身份，跨空仓库保存与恢复不依赖原文件。exportBrush/BrushLibrary.exportPackage增加显式includeSource参数；默认false对有来源预设明确拒绝。界面有来源时先打开紧凑选项，复选框“包含原始ABR包（可能包含其他预设和资源）”，默认未选，选中后再选择目标路径。无来源仍保持原保存流程。不是默认静默附带全部包，也不悄悄抹掉来源。

验收：原生size/错误无资源写入、source ID/原JSON完整交换、交接释放和当前/基线资源区别、损坏保存不覆盖、旧ABI C/C++回归；Qt显式范围选项、未选择不导出、整包导入v4、重导副本、改程序后保留基线/来源、跨目录/删除原ABR/重开报告与实际像素。只跑相关最小回归；当前实现不代表分组/高级动态/湿混完成。

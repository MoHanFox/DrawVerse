# ABR6/10采样分节

在 [ABR1/2读取](abr-sampled-design.md) 上复用有界reader/PackBits/覆盖预算，增加version6/10、subversion1/2和8BIM分节。依据上游 [GIMP加载器](https://raw.githubusercontent.com/GNOME/gimp/master/app/core/gimpbrush-load.c) 核对分节与47/301字节采样前缀；独立Rust实现，未移植源代码。16位的字节序/归一规则待真实语料核验，不据一个加载器实现推断所有文件，因此先明确拒绝。

样本前缀与记录剩余元数据原样保留，不编造名称/间距/样本UUID；描述符、纹理及其他分节保持有界原始来源数据，后续解析与转换报告使用。读取像素不代表解释desc参数，不提供用户成功导入入口。重复samp分节明确拒绝，其他重复未知分节保留顺序。

样本长度严格限制在samp分节内，记录间按4字节填充对齐且禁止跨界；所有分节在文件长度内验证。8位raw/PackBits共用原覆盖方向与128MiB整包mip预算，最多1024样本/4096分节/128MiB输入。整包错误/取消不返回部分结果。

验收：独立生成6/10×1/2、raw/RLE、非零填充、多样本/元数据与未知分节保留、真实孔洞像素；每处截断、跨界声明、错误签名、版本/位深、重复samp、尾随文件数据、取消拒绝。授权真实ABR与desc执行仍是后续门槛。

# 图标列与画布标题交互修复（2026-10-09）

后续更新：参考图布局预设已删除，默认布局为双列停靠；窗口恢复、统一边缘吸附和标签排序以 [window-recovery-design.md](window-recovery-design.md) 为准。
仅修改 Qt / QML UI，不改核心或 ABI。主工作区自身的左右边缘接收浮动工具面板，无论文档区域是否独占或为空；画布主体仍不接收工具停靠。边缘吸附包含靠近外边界的容差，且有实时预览。

工具列只保留展开内容与折叠图标两种状态，删除折叠为标签、展开面板组及重复按钮。旧布局中的标签折叠迁移为图标列。插入、上下拆分、返回工作区或新建自定义面板均继承接收列的图标状态；不因新增元素展开整列。单个图标可以直接拖出为正常浮动面板；整个图标列仍可整体拖动。

点击图标显示其当前活动面板，重复点击当前图标关闭，点击同组其他图标立即切换。临时面板为受管理的原生工具窗，点击空白或 Escape 关闭，并消费外部点击以免意外绘画；点击所属图标列允许切换而不吞掉图标点击。临时面板只能沿所属列侧边上下滑动，保持侧边关系和屏幕可见范围。展开列、拖出面板、隐藏来源或退出时销毁临时窗。

移除文档标签条的新建加号，文件菜单 / Ctrl+N 保留。单文档浮窗合并窗口标题与文档标签为一行，保留拖动、最小化与关闭；文档组合后恢复窗口标题行与标签行，标题始终显示此浮窗活动文档名，切换与编辑后立即更新。

验收：真实鼠标拖动在仅画布和无文档主区归位；图标列加入/拆分/恢复后仍为窄图标列；图标拖出和 Esc 还原；连续切换图层/历史/导航、空白关闭、侧边滑动；过时标签模式迁移；单/多文档标题切换与关闭后恢复单行；新建入口移除但菜单可用。普通/两倍 DPI、Windows 实窗以及完整 tools/check.py。

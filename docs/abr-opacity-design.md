# ABR 整笔不透明度转换

2026-10-15。内核已有整笔不透明度上限，ABR 基础转换器此前仍将 toolOptions.Opct 非100%报告为未执行。本阶段按已读取的0..100百分比映射真实整笔 opacity，覆盖程序/图片笔尖和密集往返，不能以降低流量或增大间距替代。保留严格类型/舍入前范围、整包失败/取消、逐字段支持报告与原始 ABR。

保留显式旧转换入口，旧来源的 drawverse.abr.basic converterVersion=1、基准和报告字节不重算。只有新导入且执行了非100% Opct 的记录使用 converterVersion=2；未使用新行为的输入保持旧版本，避免无关来源及包格式升级。转换结果显式携带版本，不根据用户后来修改的 opacity 推断来源版本。两版来源都只允许已有基础参数，尚不允许高级动态伪装为已支持。

来源记录结构仍为version1；旧来源仍可读、保存及原字节交换。VBR1.16允许包含converterVersion2来源；导出按全部记录的最高需求选择minor，解码拒绝把新来源夹带进旧minor。仅标注来源版本，不增加笔刷执行行为版本或额外必需能力。Schema公开两版来源、合法/非法样例。无C ABI布局变化，Qt现有不透明度和完整来源/基准接口直接复用；旧程序通过包minor或来源版本拒绝，不静默丢失。

验收：新旧转换对照、0/小数/100与错误类型/非有限/越界、真实程序/图片低opacity密集重叠上限、取消/undo/redo；ABR整包导入和来源基准版本、旧来源不重写、新旧混合VBR最高minor/降级拒绝/逐像素重开；相关来源IO/FFI/Qt导入回归。非零角度PS方向、完整动态/纹理/双笔刷映射、16位采样和授权PS语料等继续后续，不宣称完整ABR或整个笔刷系统完成。

字段语义参考[ag-psd ABR读取器](https://github.com/Agamnentzar/ag-psd/blob/master/src/abr.ts)：toolOptions.Opct为数值，缺失默认100。该源码用于核对字段，不作为PS逐像素等价证据；实现仍使用既有独立Rust描述符读取。

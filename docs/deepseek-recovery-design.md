# 遗留功能修复（2026-10-11）

本轮按用户确认先交付修复；GPU、液化、.vbr 和图层复制/合并另立模块。保留已删除功能的禁用状态、既有文档格式、ABI 1.12 和历史 20ms 回放。

## 修复边界

- FFI caller-memory 长度同时满足 usize 和 isize 范围，恢复被删除的缓冲区校验；失败输出和像素仍原子。
- 选框槽位显示记住的矩形/椭圆；所有实际工具入口（含快捷键）保持互斥，切换不丢形状。
- 取色十字由共享 CanvasPane 渲染，跟随鼠标及数位笔；Alt 仅在绘画工具生效，不干扰选区的减去操作。松开或失焦清理。
- 吸色同时作为工具栏独立槽位（I），与画笔/橡皮/移动/选框互斥；独立吸色无需按 Alt，顶部显示采样说明，底栏显示真实工具名称。
- 核心按渲染视口的实际区域和输出尺寸转换吸色坐标，包含分数原点、缩放、LOD 与设备 DPI；极端整数输入仍夹到边缘，不能因整数减法溢出而失败。
- 最大化恢复拖动交给全局 WindowDrag 延续，窗口重建鼠标抓取时不丢第二次移动；恢复后的按钮测试等待布局与事件派发完成。
- 重排/重挂时剪贴层若失去原基底或因重排/更换父级而改用不同基底，释放剪贴；原位置受影响的链同样释放。插入现有剪贴链的新像素层继承剪贴。修改与排序/插入属于同一历史操作。
- 从纵向停靠链关闭/移出一组时，剩余组保留原高度，多出的空间显示面板背板；工具条继续占据整列。正常窗口调整及分割线拖动仍分配可用空间，保存/恢复保留长度。
- 缩略图通过独立通知更新，不能为了一个缩略图重新发布全部历史、图层并重建 QML ListView。保留后台编码和 48px 限制，打开缓存面板不重新编码。
- 校正稀疏历史枚举的名称映射，文档记录实际验证结果；修复资源依赖与部署规则时以当前 CMake 内容为准。

Rust 验证剪贴链插入、不同基底间移动、原基底移走、跨父级和撤销/重做；FFI 验证 isize 边界及不写失败像素。Qt 验证真实快捷键、选框切走仍显示椭圆、取色十字鼠标/数位板位置、选区减去不显示取色器、缩略图更新不销毁行、不触发层结构通知、面板关闭高度与工具条整列覆盖、保存恢复。先运行失败基线，再完整运行 tools/check.py 和原生窗口相关用例，记录日志后 commit/push/deploy。

# 笔刷系统剩余功能与用途

2026-10-18，笔触距离动态阶段更新。已完成统一定义/资源目录、程序与图片笔尖、压力曲线/独立流量和整笔不透明度、形状/散布/颜色/纹理、覆盖与双色双笔刷、可选复合轮廓/半透明基础图片光标、平滑/起收笔、二维湿混/单色涂抹、ABR基础及部分动态、VBR1.32速度/切向压力/距离交换和PS分类设置；完成范围以各阶段验收为准，不能据此宣称整体已达Procreate或完全兼容PS。

| 剩余项 | 功能与实际用途 | 当前边界/证据 |
|---|---|---|
| 密集/大笔刷进一步性能优化 | 在有界分页基础上测量并优化重印章、采样及像素开销，降低大笔刷延迟 | Document/Actor已接通原始输入续页、End/Cancel顺序和安全发布，原64px公开API与Qt通过；单印章8M及总输入512M/131072等预算仍保留，湿混双色覆盖遍历优化已完成8组局部测量，更广泛大笔刷测量优化仍待做。见brush-input-paging-actor-validation.md及brush-wet-field-performance-validation.md |
| ABR高级兼容与16位样本 | 更完整还原PS笔刷中的纹理、双笔刷、其他设备/渐隐控制；读取更多高位深笔尖来源 | 基础、压力/散布/颜色/形状/部分设备及有界8/16位纹理图案/八种覆盖模式（含`CBrn`）/亮度对比度/最低深度与深度动态/纹理来源快照与恢复已接，见abr-texture-validation.md；其他未定义纹理模式及其他启用能力仍未执行。16位笔尖raw/RLE和字节序/量化证据未齐，当前明确拒绝，见abr-16bit-investigation.md |
| 扩展动态控制 | 用切向压力等驱动更多尺寸/流量/透明度通道 | 速度、切向压力和笔触距离动态已分别接入state24/25/26、VBR1.30/1.31/1.32及Qt曲线，基础压力、方向/旋转/倾斜、随机、距离起收笔及时间喷枪也已接；任意来源到任意参数的通用矩阵仍未接 |
| VBR分组与笔刷包组织 | 导入导出保留文件夹、分组和顺序，方便管理大笔刷包 | Rust组织树/目录、state20/VBR1.24及整树副本映射、资源发布/目标目录原子合并、ABI1.54准备及1.55完整包读写交接已接；Qt state20 镜像、树显示、复制/删除组织保持、重启恢复、上下文菜单、拖放排序、完整范围导出及分组包副本树导入已接，见brush-groups-import-validation.md。旧入口有组明确拒绝。 |
| Windows整体验收与输入问题 | 实测数位板手感、设备/高DPI、密集参数和模块组合，定位偶发输入错误 | 用户自行测试，无需agent测试 |
| 后续wgpu加速 | 通过GPU执行绘画/混色等重像素工作，复用核心参数与调度语义 | 当前CPU为参考；GPU仍是后续路线，尚无完整笔刷GPU后端。不是本轮已交付能力 |

用户已取消可交互试画，不能把它算作待补功能。自动预览固定白色/正常模式的要求继续保持。ABR导出、物理高度/光照颜料模型不属于当前首期承诺；Python插件排最后。

双色湿混的涂抹与橡皮已由用户确认没有实际意义，明确保持拒绝，不列入剩余功能。

非分隔双笔刷已以 `interleaved-stamp-v1` 接入核心、state22、VBR1.28 和 Qt，见[设计](brush-dual-stamp-design.md)及[验收](brush-dual-stamp-validation.md)；它要求配对笔尖，独立路径拒绝，橡皮/普通涂抹忽略颜色，手指绘画涂抹使用双色，湿混下的涂抹/橡皮不处理。

时间喷枪已以 `time-interval-v1` 接入核心、state23、VBR1.29、ABI1.57 和 Qt，见[设计](brush-airbrush-design.md)及[验收](brush-airbrush-validation.md)；只支持干画笔和橡皮。

用户已发令继续推进；此清单记录当前剩余范围，具体实施及验收见各阶段文档。整体Windows设备手感由用户自行验收。

纹理已增加 Photoshop 风格的 `normal`、正片叠底、变暗、变亮、减去、差值、滤色、颜色加深组合模式及亮度/对比度调整，旧纹理缺省为 normal/0；ABR 的 `patt` 图案、`Txtr` 参数和上述八种模式/调整已接入实际执行，来源报告和资源往返已验。其余未定义 Photoshop 纹理模式仍属于高级 ABR 未完成范围。

半透明基础图片光标已完成Qt入口，默认关闭/25%不透明度，实际身份捕获及全局保存见brush-cursor-image-ui-validation.md；不等于随机/纹理/最终混色印章预演，也不恢复被取消的试画。

速度动态已以`speed-v1`接入核心、state24、VBR1.30、behavior19和Qt“传递”页，见[设计](brush-speed-design.md)及[验收](brush-speed-validation.md)。它以文档像素/秒统一驱动主/配对第二笔尖尺寸、流量和整笔不透明度上限；ABR速度来源、任意动态矩阵、实体设备手感、跨平台和GPU仍属于后续范围。

切向压力动态已以`tangent-v1`接入核心、state25、VBR1.31、behavior20和Qt“传递”页，见[设计](brush-tangent-design.md)及[验收](brush-tangent-validation.md)。它使用设备-1..1切向压力归一化曲线；实体数位板是否输出非零切向压力由设备/驱动决定，尚未做硬件认证。

笔触距离动态已以`distance-v1`接入核心、state26、VBR1.32、behavior21和Qt“传递”页，见[设计](brush-distance-design.md)及[验收](brush-distance-validation.md)。它按活动笔触累计文档距离驱动三条曲线；ABR距离/渐隐来源和任意动态矩阵仍待后续。

# 笔刷系统剩余功能与用途

| 剩余项 | 功能与实际用途 | 当前边界/证据 |
|---|---|---|
| 密集/大笔刷进一步性能优化 | 在有界分页基础上测量并优化重印章、采样及像素开销，降低大笔刷延迟 | Document/Actor已接通原始输入续页、End/Cancel顺序和安全发布，原64px公开API与Qt通过；单印章8M及总输入512M/131072等预算仍保留，湿混双色覆盖遍历优化已完成8组局部测量，更广泛大笔刷测量优化仍待做。见brush-input-paging-actor-validation.md及brush-wet-field-performance-validation.md |
| 湿混与其他工具的完整组合 | 让双色贡献用于涂抹/擦除时有明确搬运、透明度及双角色规则 | 画笔湿混双色已接；单载色湿混涂抹已接；双色涂抹/湿混橡皮仍拒绝。须先定义符合工具含义的行为，不能简单复用着色 |
| 非分隔双笔刷模型 | 主副笔尖按印章顺序即时参与同一笔迹混合，提供区别于现有整笔分开累积合成的叠加效果 | 现有覆盖模型、独立路径及整笔隔离双色已实现；非分隔逐印章模型仍未实现 |
| ABR高级兼容与16位样本 | 更完整还原PS笔刷中的纹理、双笔刷、其他设备/渐隐控制；读取更多高位深笔尖来源 | 基础及压力/散布/颜色/形状/部分设备已接，近似项有报告；其他启用能力未执行。16位raw/RLE字节序/量化证据未齐，当前明确拒绝，见abr-16bit-investigation.md |
| 扩展动态控制与时间喷枪 | 用速度、切向压力等驱动更多尺寸/流量/透明度通道；喷枪可在停留时按时间持续沉积 | 基础压力、方向/旋转/倾斜、随机、距离起收笔已接，尚非任意来源到任意参数；按时间喷枪仍为后续可选模式 |
| VBR分组与笔刷包组织 | 导入导出保留文件夹、分组和顺序，方便管理大笔刷包 | Rust组织树/目录操作、state20及VBR1.24组织清单/整树副本映射已实现，资源/来源与真实绘画保持；目标库原子合并、完整原生交接/Qt仍待接，旧入口有组明确拒绝，见brush-groups-vbr-validation.md |
| Windows整体验收与输入问题 | 实测数位板手感、设备/高DPI、密集参数和模块组合，定位偶发输入错误 | 用户自行测试，无需agent测试 |
| 后续wgpu加速 | 通过GPU执行绘画/混色等重像素工作，复用核心参数与调度语义 | 当前CPU为参考；GPU仍是后续路线，尚无完整笔刷GPU后端。不是本轮已交付能力 |

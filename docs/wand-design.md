# 魔棒（2026-10-12）

按参考图实现独立魔棒工具（W）：新建/添加/减去/交叉四种选区组合；取样点及 3、5、11、31、51、101 像素方形平均；容差默认 10（0–255）；消除锯齿、连续默认开启，所有图层取样默认关闭。Shift 添加、Alt 减去、Shift+Alt 交叉；按下只选一次，鼠标/数位板及浮动画布共用。取样平均仅用于种子参考色，边界裁切按实际样本数量平均；候选像素逐点比较。前景色、不透明度、图层锁不影响选区。

共用油漆桶的直通 sRGB/alpha 最大通道差、四邻接访问位图及一色阶 AA 过渡。默认取样活动像素层（含偏移）；所有图层使用填充前可见合成。已有选区不限制发现，结果交给共用组合规则。输出有界灰度掩码，保存、撤销重做和画笔/橡皮限制使用同一覆盖；轮廓由实际掩码半覆盖边界产生，不能以包围框冒充。完全无匹配区域使用空选区组合规则。发现/资源/历史失败不改变像素和选区。

工作集沿用 4096 访问瓦片及 16Mi 像素扫描/包围掩码上限；编码还必须满足现有选区文本 1MiB 限制。灰度掩码以带 g 前缀的 RLE 保存，旧二值编码仍读取；旧版本对新灰度编码明确拒绝。ABI 1.17 新增 sized 魔棒请求和按 publication 读取掩码覆盖的导出，不修改旧 DTO。核心不依赖 Qt，UI 只通过 PaintCoreClient/C ABI。

最小验收：Rust 定向魔棒/既有桶和选区回归，覆盖平均取样、连续/全局、组合、AA/容差、合成取样、偏移、持久化及撤销；FFI 定向请求复制/拒绝/掩码查询/真实历史；生成头严格检查和 Release 构建；Qt 仅魔棒真实参数/鼠标/数位板/浮窗/真实非矩形轮廓用例普通与两倍 DPI。不跑完整仓库测试，不把最小验证称为完整验证。

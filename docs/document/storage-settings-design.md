# 暂存盘设置与清扫：设计（ABI 1.3）

本轮新增 paint-storage，统一管理文档分页与磁盘历史的路径、空闲空间检查和异常残留；Rust 不依赖 Qt。已有文件保存的同目录原子替换不改为暂存盘保存。

方案比较：在线搬迁会涉及活动笔触、历史和后台快照，失败时还需要双盘事务；本轮采用保存设置、重启生效。UI 明确展示当前运行设置和下次启动设置，不清空当前文档或历史。路径可选择现有目录，留空使用系统临时目录；内存默认 256MiB、瓦片暂存预算默认 8GiB、保留空闲空间默认 512MiB，磁盘历史 4GiB / 100 条仍独立。

目录边界：选定目录下仅使用 `.drawverse-scratch-v1` 命名空间，校验固定标记与普通文件/目录类型；每个运行实例创建随机 `run-*` 目录，并持续持有带固定标记的 `.lease` 文件独占 OS 锁。初始化、建目录和清扫在维护锁下串行，锁争用返回可重试错误。只删除通过标记、命名、文件类型及路径边界验证、且能够独占锁定的废弃 run。遇到未知文件、子目录、链接或仍被锁定的目录跳过，不递归删除。正常释放先释放临时文件，再删除 lease 和空 run；活动快照/历史继续持有管理器，保持暂存文件可读。旧版散落在系统 Temp 的文件不会仅凭前缀被删除。

空间检查使用平台可用空间；增长写入前检查保留值，并在每 1MiB 或 1 秒刷新，控制热路径开销。容量预算不预分配整盘空间，也无法阻止其他程序同时消耗磁盘；真实写失败仍由现有事务保护原文档/历史。所有探测、清扫和设置检查在 C++ 后台线程调用 Rust，不阻塞 UI。

新增 C ABI DTO `PaintStorageOptions` / `PaintStorageInfo` 与 create-with-storage、inspect 函数；现有结构/函数不变，minor 升 1.3，UTF-8 + 长度、错误码、调用者缓冲契约不变。配置从 core 传入每个新建/加载文档与历史后备；QSettings 只在检查成功后保存，坏设置启动报错并可在设置面板修正，不悄悄切换别的盘。

验收：Unicode 路径、坏配置/不可写/空间不足、低预算分页和磁盘历史正确落盘、旧版本持有文件寿命、正常清理、子进程被终止后清扫、活动多进程不误删、陌生内容/链接跳过、ABI 新旧调用兼容、Qt/QML 保存/重启生效/失败保留原配置，完整 check 和原生绘画基准。

依赖依据：[fs2 可用空间](https://docs.rs/fs2/0.4.3/fs2/fn.available_space.html)、[跨平台文件锁约束](https://docs.rs/fs2/0.4.3/fs2/trait.FileExt.html)。锁采用独立文件句柄，避免复制同一锁句柄。

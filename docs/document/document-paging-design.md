# 文档瓦片分页：设计与验收

本轮解除默认 4096 个 live 瓦片（约 256MiB）导致的绘画硬门槛，将它改为驻留缓存预算。逻辑瓦片仍有独立有限上限，暂存文件也受容量限制，不声称任意百万尺寸画布可无限填满。

方案比较：提高固定 RAM 限制只会推迟耗尽；直接把冷瓦片丢掉会损坏画面；逐像素磁盘读取会毁掉交互延迟。本轮采用不可变 Arc<Tile> 身份、按瓦片驻留缓存和无损磁盘后备。图层/快照/历史保存句柄，像素 pin 返回共享只读数组；磁盘化不改变身份或修订，绘画改变像素才生成新身份。已有渲染缓存继续复用。Tile 的内部缓存可用 Mutex，Rust 不依赖 Qt。

每文档 PagePool 默认驻留 4096 个瓦片、逻辑最多 1,000,000 个、暂存文件最大 8GiB。冷瓦片按 LRU 淘汰，重复/原始浮点位模式无损编码；磁盘区段分桶重用，旧版本被快照/历史引用时不得复用其区段。读取时检查长度、校验码和像素合法性。后备文件采用独占临时文件，正常释放自动清理。工作中的读 pin 允许短暂超过缓存预算，快照本身不固定像素 RAM；渲染、编码与 IO 必须及时释放 pin。

笔刷每次 dab 按相交瓦片计算，一次 pin、一次局部修改和提交，保持原覆盖/压力/距离采样结果。真正有像素差异才创建新句柄；发生 IO/容量错误时依照现有事务恢复整笔。缓存锁持有时不获取瓦片锁；淘汰发布采用瓦片状态 → 缓存登记的固定顺序，禁止反向嵌套。耗时读写不持有 UI/文档注册表锁，瓦片状态锁仅保护单瓦片转换。

只读 pin 使用 Arc<Box<[Pixel]>>：Box 固定 4096 个像素，Arc 仅包裹指针，避免 Vec 转 Arc 切片时再次复制 64KiB。已捕获笔前状态、仅文档持有、没有后备页的私有笔触瓦片，可在释放读 pin 后复用像素缓冲；先注销缓存登记并用 Arc::make_mut 使旧 Weak 身份失效，再修改/重新登记。存在共享快照或后备页时使用完整不可变复制；并发淘汰或 Weak 读者获得额外引用时 make_mut 继续保护原内容，并重新登记被保留的原版本。Owned Tile 克隆独立像素数组，导入冷克隆后脱离源后备文件，使目标文档预算包含自己的存储。

渲染在快照上按瓦片 pin，缓存命中不读取像素；扩大可见稀疏坐标数量以支持 8K 等大画布概览，输出/工作预算继续有效。历史解码按块登记到 PagePool，避免撤销先还原整份像素进 RAM；全部读验成功后再改图层/栈。生产读取使用可失败接口，错误向 C ABI 返回 IO_ERROR，不替换为透明像素。

文件模块继续后台处理，保存必须经可失败快照读取并保留原子替换。格式尺寸/解码工作区预算和文档驻留预算分开说明；本轮不宣称解码器实现完全流式，也不宣称整进程 RAM 等于缓存限额。暂存盘配置和异常退出清扫另行完善，默认使用系统临时目录。

验收：低驻留预算下多图层绘画/快照/取消/整笔撤销重做精确；冷页读取与缓存淘汰、后备损坏与写失败原子性、区段复用与文件释放；默认预算下超过 4096 瓦片的全幅绘画和大画布概览；分页画面与原 CPU 金图一致；分页数据保存/重开；Qt/C ABI 实际绘画路径与完整 check，通过后更新 build/qt 并复测小画布性能。

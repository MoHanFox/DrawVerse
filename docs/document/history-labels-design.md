# 真实历史名称与初始状态边界（2026-10-10）

历史列表使用 Rust 已提交历史记录的操作类型，不按撤销数量猜测“操作 X”。每笔显示画笔/橡皮擦及相应工具图标，选区显示全选、框选、取消选区或反选；图层操作显示对应名称与图标。无变化、失败、取消的操作不生成记录。撤销/重做保留原标签，新分支丢弃被替代的重做标签。

历史裁剪时记录初始状态已不可到达，列表不再显示“初始状态”。可点击记录仍指向保留历史的真实深度，不以新序号伪装初始状态。条目类型与命令一起保留，包括磁盘编码历史，但不改变既有磁盘命令格式，也不为显示而解码像素。

ABI 1.10 添加固定 16 字节 PaintHistoryEntry 和 exact-publication 的 paint_session_history_entry 查询。边界深度 0 表示初始状态或已裁剪的边界；深度 1 到 undo_depth+redo_depth 按时间排序返回真实操作类型。Qt 后台枚举小元数据，QML 共用历史内容渲染，仅在初始状态确实保留时显示深度 0。历史跳转现使用 ABI1.73 的一次异步指定深度请求，替代早期 20ms 逐条回放；直接跳转的实现与失败边界见下文。

验收覆盖 Rust 裁剪超过 100 条、撤销重做/分支、画笔和擦除、选区、磁盘编码元数据；FFI DTO 布局、世代/发布查询及清零失败；Qt 150 笔后无伪初始状态、正确名称/图标和点击真实深度。完整检查与原生窗口回归通过后提交推送。


## 2026-10-20：一次发布的直接跳转

参考 PhotoCraft `crates/engine/src/history_select_cmds.rs`（本地 d95fdf3181c01ad41e95456091a394b105a9afb2）的私有游标、一次恢复与一次 damage。DrawVerse 保留现有瓦片与压缩历史，`Document::select_history` 仅复制图层元数据/共享瓦片身份，逐条物化命令并在私有工作态应用；全部成功后移动历史栈，修订只增加一次。读取失败恢复层、选区、活动层和脏区，历史栈不变。不会向 Qt 发布中间状态，也不逐步请求视图合成。

自由变换按目标深度直接取得最终几何，仅调用一次 update_transform，软件/选区回退也只物化最终预览；液化按已保存的场与瓦片历史恢复，失败恢复整个会话状态。拖动、未结束笔触和异步工作期间不允许点击跳转。保留的深度边界与 redo 语义不变。

ABI1.73 `PaintHistorySelect` 携带文档 generation、revision、scope 和深度，actor 拒绝过期/错误历史域请求；客户端从当前发布状态发一次请求，历史面板等待完成后显示目标。序列完成与视图屏障沿用既有异步协议。state44、VBR1.0 和历史磁盘编码不变。

计算量仍与跨越命令及冷页读取有关；这项优化消除中间发布/合成和变换重复物化，不保证所有大历史跳转恒定耗时。验收见[用户清单验收](../validations/planning/2026-10-20-bugfix-validation.md)。

## 2026-10-21 翻转标签

图像水平/垂直翻转各自记录操作。自由变换会话的相邻已确认几何若为纯水平/垂直反射，局部历史显示对应名称；确认后的永久历史按最终几何与原始几何判定。撤销/重做只移动既有几何，不依赖UI临时名称。复合变形保留自由变换标签。C ABI1.76增加39/40，旧kind不重排。

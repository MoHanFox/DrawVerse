# 纹理溶解模式设计

2026-10-18。纹理模式新增 `dissolve`：先用纹理深度/亮度/对比度/反相/深度动态得到连续覆盖率，再用文档像素坐标与当前印章位置派生的确定性哈希做二值抖动。输出为 0 或 1，区域平均覆盖率仍接近 `base * texture`，不改变笔尖、流量、整笔不透明度、选区、蒙版、历史或随机序列。

这是覆盖率溶解的近似实现，不是 Photoshop 颜色空间中的 Dissolve 图层混合。`coverage()` 继续保持连续采样，供文档纸纹路径使用；只有印章 `apply()` 使用二值抖动。哈希只依赖像素和印章位置，因此同一输入可重复，不把随机状态写入历史。

非默认 `dissolve` 写入 state33/VBR1.39，低版本 state/VBR 明确拒绝；ABR `BlnM` 的 `Dslv`/`dissolve` 映射到该模式。Qt 纹理下拉增加“溶解”，预览状态版本同步为 33。Hue/Saturation/Color/Luminosity 仍需要颜色感知的纹理合成，本阶段不把它们伪装成标量覆盖率模式。

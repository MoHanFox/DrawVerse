# 图片笔尖覆盖轮廓

Rust从不可变基础覆盖提取0.5等值线，采用线性边插值和双线性鞍点判定的marching squares；保留孔洞、分离区域。外缘重复边界样本并用零宽外带闭合，使满覆盖矩形准确落在图片边界，兼容绘画的边界内夹取样。坐标归一到标称直径的单位正方形，保持原始宽高比；Qt仅缩放/圆度/旋转路径。

轮廓是覆盖网格的分段线性等值线，未按显示尺寸丢弃小孔洞；不是每个像素印章的最终混合结果。采用固定0.5阈值，完全透明/低于阈值允许空轮廓。单轮廓最多65536线段；超出明确返回资源限制，UI临时简化轮廓并显示说明，绘画资源不受影响。后续屏幕误差受控简化可提高复杂纹理覆盖范围，不能截断路径后声称精确。

资源仓库按内容ID缓存SVG路径（标准几何传输，不包含文件路径）。最多8项/16MiB，后台提取且不持有全局句柄锁。Qt只保持当前预设请求，过期结果不能替换新笔尖；指针移动不重新提取，参数变化只变换路径。使用继承自Path的scale属性保持ShapePath线宽为屏幕单位，外宽线+内窄线形成双色描边。

参考Qt官方Path scale文档：https://doc.qt.io/qt-6/qml-qtquick-path.html#scale-prop 。最低Qt6.5可用，避免依赖新版cosmeticStroke。

验收：矩形/非方形准确边界、孔洞/多区域闭合、阈值插值、鞍点方向、透明空路径、复杂度拒绝无部分结果；缓存身份/预算；ABI缓冲/无资源拒绝；Qt当前身份/旋转比例/线宽/悬停/简化优先级、真实图片像素与光标不改历史。

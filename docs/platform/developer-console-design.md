# 开发者控制台

2026-10-19：Windows应用显式使用GUI子系统，正常启动不创建CMD窗口。首选项→界面提供“开发者控制台”，默认关闭，保存到工作区设置的独立`developer/console`键，与布局重置无关。

开关立即生效，启动时恢复；开启时由应用分配UTF-8控制台并连接标准输出和错误输出。拥有控制台期间安装Qt日志转发，避免启动早期已有日志导致后续日志不进入新窗口；关闭时恢复先前处理器。关闭仅释放应用自己创建的控制台，不隐藏启动者的终端。控制台标题栏关闭命令禁用，避免误关控制台导致整个应用退出。

最小验收：设置默认值/开关/重开与布局重置保持，实际QML控件回写，Release PE子系统检查，独立Windows进程开关和日志输出。记录见[本轮验收](../validations/planning/brush-feedback-execution-validation.md)。

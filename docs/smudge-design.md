# 涂抹工具（2026-10-12）

涂抹是独立工具（R），复用当前 BrushLibrary 预设、笔刷大小/间隔、圆形笔尖覆盖、笔触插值、数位板采集、选区覆盖、瓦片分页和笔触历史；不建立第二套笔刷引擎。参数：强度默认 50%（0–100）、强度压感默认开启、对所有图层取样默认关闭、手指绘画默认关闭。预设不透明度乘涂抹强度，压力继续控制笔尖大小；强度压感开启时还乘压力。切换工具保留涂抹参数。

无手指绘画时按下不注入前景色：移动笔尖把上一 dab 位置的像素按位移搬向当前位置，读取本 dab 写入前状态，双线性采样线性预乘 RGBA，再按笔尖/强度/选区覆盖插值目标。背景透明度可以被拖动；透明锁保留目标 alpha。手指绘画只在每条笔触第一次有效 dab 混入前景色，之后继续搬运；蒙版使用既有黑白灰转换。默认读取活动层原始像素，所有图层读取可见合成但只写活动层；蒙版目标明确拒绝所有图层取样。组和祖先完全锁仍拒绝，选区限制写入而不修改取样内容。

每个 dab 只暂存其有界源 patch（最大约 515×515 Pixel），不得复制整文档或逐像素原位读取反馈。共用既有瓦片 COW/dirty/恢复规则；读取和写入失败取消整笔触，取消与撤销恢复原像素，单笔历史标为“涂抹”。搬运额外取样工作计入既有段预算。首点/静止且关闭手指绘画没有变化时不产生历史。

ABI 1.18 新增 88 字节 PaintSmudgeStrokeDesc 和异步 paint_session_begin_smudge，嵌套复用 PaintStrokeDesc，strength 独立；输入 point 与旧采集 DTO 相同。入队后仍是 Operation::Begin，move/end/cancel/队列合并全部复用。旧 stroke DTO/导出和 reserved 规则保持。历史 26、feature bit 32768。UI 独立按钮、参数栏与轮廓共用画笔，并能选择现有笔刷。

笔刷间隔按直径百分比显示，1% 对应引擎 radius 比例 0.02；同时修改 Rust 校验、库设置/持久化校验和滑块，不只降低 UI 下限。

最小验收：核心真实搬色、首点无变化、方向/压感/强度、全层只写当前层、透明/选区/偏移/蒙版/锁、取消/撤销重做及 1% 间隔；FFI 请求复制/拒绝与单条历史；Qt 独立工具、参数与预设复用、1% 间隔保存/恢复、鼠标和数位板真实帧/历史。只运行直接相关定向回归、fmt/clippy、头检查及 Release 构建，记录未跑全量测试。

## 参数说明

工具参数复选框提供中文说明，鼠标停留 1000ms 后显示，移开隐藏；说明内容覆盖 AA、连续区域、合成取样、压感强度、手指绘画、容差、取样范围和间距。已有图标与图层说明统一为同样延迟。提示不接管点击和笔输入。

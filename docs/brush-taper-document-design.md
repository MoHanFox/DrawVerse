# 起收笔 Document 执行与像素检查点

2026-10-16。在已验证的distance-envelope-v1上接真实Document执行；本阶段提供Rust明确起笔入口，尚不加入无法完整保存的BrushSettings字段，也不增加C ABI或Qt入口。后续IO阶段再统一预设、基准及交换。

每个滤波后路径段仍由原调度器生成主/第二流印章，记录原设备通道、累计弧长、顺序和方向。TaperBuffer决定冻结前缀与活动笔尾，重绘直接调用原dab/secondary_dab，不重新进行路径插值或随机调度。尺寸因子乘压力/形状/相对尺寸计算后的实际半径；第二固定边宽也在最后统一缩放。opacity因子与原压感上限相乘，使用原整笔贡献场，不改成逐印章flow；涂抹按工具强度乘opacity因子。

检查点分两部分：固定大小的执行标量（随机序号、设备方向、前印章/涂抹位置、形状颜色、工具翻转、蒙版灰度、湿混载体）和仅活动尾部涉及瓦片的首次写入日志（实际图层/主贡献/第二贡献）。不复制整笔before或整份贡献场映射；它们继续由原分页存储和整笔历史管理。日志持有不可变Arc，原私有写入自然变成COW，重算恢复日志对应瓦片后再渲染。冻结前缀不记录日志，越过冻结边界捕获新标量检查点，之后只记录新活动尾部。

日志每一类至多max_document_tiles项；印章记录至多65536，重算工作仍受原单段印章/像素/湿混预算限制。每段先准备完整计划和预算，再恢复/执行；执行或预算失败整笔回滚，不能留下半次笔尾或半份贡献。历史成功时依旧只产生一条笔触；取消恢复起笔before，湿混返回的载体与最终可见笔触同源。新逻辑只在明确启用的入口运行，关闭时保留既有路径。

起笔/逐段/结束都使用同一执行器，结束仅冻结已显示笔尾，不补鼠标原始终点。正常调度所需的最后印章仍在当前滤波末端；不虚构压力或抬笔轨迹。选区/蒙版/偏移/透明锁、灰度和双色双路径、散布/颜色/图片纹理、湿混/涂抹沿用原算子。

验收需要真实像素：与一次性已知最终端点的参考执行逐像素对照、分段与重算确定性、透明度上限与半径、尾部移动后旧像素清理、单双流/随机/图片/纹理/选区/蒙版/锁/偏移、湿混载体和涂抹、取消/撤销/重做/分页及预算失败回滚；同时运行相关旧绘画回归。不以命令调度测试代替像素测试。无用户界面发布或跨平台验收声明。

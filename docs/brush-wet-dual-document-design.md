# 湿混双色 Document 执行

在双载色事务基础上，新增明确的 Rust Document 起笔/结束接口，捕获前景/第二颜色、完整 WetInk 与双色定义。既有单载体入口继续拒绝双色，避免结束时丢失第二载体；旧预设编译/IO/ABI/Qt保护保持，后续再发布组合能力。

两流使用各自二维载体，按真实印章顺序拾色、写入和提交。配对印章先主后第二，独立路径沿现有调度顺序；下一个印章读取此前可见结果。主动态在沉积上变色，不改原始载体，第二载色不套主颜色动态。0半径重置对应路径，0流量/opacity仍允许拾色。全图层取样、选区/蒙版、偏移、锁沿用已有规则。

主/第二各保留独立分页几何场与预乘RGBA贡献场。几何场用于不溢出时 min 软裁切，不以载色alpha替代几何；RGBA按现有湿混贡献公式更新，允许覆盖饱和后颜色继续改变。第二贡献按几何裁切比例缩放，再沿既有27模式及前后顺序隔离合成，整笔opacity/选区/纸纹只应用一次，与before合成。原干双色数值路径保持。

活动尾检查点捕获两个载体；新增两张RGBA场采用首次写入瓦片日志恢复，不能克隆增长中的整场。预算涵盖两个载体采样及新增场更新，事务/历史/取消/失败恢复整笔原图；成功结束返回完整双载色。后续 Engine 必须在历史成功后整对采用。

验收包含实际双色拾色/透明载色贡献、两路径/软边/前后及溢出、低整笔opacity/回笔、主动态和原始载体隔离、分页/蒙版/锁/选区、起收笔对照一次执行参考、预算与暂存失败回滚及旧单载体/干双色回归。仅Windows；本阶段不宣称Qt组合已开放，双色涂抹和橡皮不在本模型中冒充绘画。

# 起收笔 Qt 接入

在既有距离包络内核及 ABI1.51 上完成 Qt 镜像与设置，不增加 UI 绘画算法。当前预设拥有完整 strokeTaper（包括关闭后的配置），目录 state18、VBR1.22 与重置基准使用同一对象；默认对象省略，旧数据不主动升级。预览和真实笔触均通过新的 taper 准备入口捕获准确修订，包读写使用对应新入口。最低 ABI1.51。

PS 风格左侧分类增加“起收笔”，右侧总开关、起笔/收笔选择、文档像素长度 0–4096，以及尺寸、不透明度的独立平滑曲线和最低比例。长度 0 无影响，最低比例 100% 可关闭该通道效果。编辑自动 PCHIP，原导入 linear 保留；曲线固定 (0,0)/(1,1)，保持严格顺序和 f32 可分辨性。共用压力曲线编辑器的图形交互，但明确横轴为归一化距离，不混淆压力语义。

自动预览保持白色/正常模式；抬笔保留当前平滑末端，不追指针补线。起收笔与两流、双色、湿混、涂抹的实际执行复用原内核。

验收：合法非法和关闭配置、默认旧版本、目录最高版本、复制/重置基准/保存重开及 VBR 新目录交换；真实 Qt 控件和平滑编辑、白色预览、准确捕获/实际笔触像素/历史撤销重做。最小 Windows Release/Qt 验证，不宣称完整 ABR、非分隔双笔刷或全系统验收完成。

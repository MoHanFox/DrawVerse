# 可选复合光标Qt接入

2026-10-15，消费ABI1.49复合姿态。光标与预览页新增通用“复合光标”复选框，默认关闭，1000ms提示；应用级cursor.composite布尔，严格验证/缺失默认false，不进入预设/resetState/VBR，切换不改变画布/预设/真实预览。共享偏好沿用已有同步。

主光标行为保持。开关打开、双色溢出有效且已有准确原生姿态时，在主轮廓后显示第二基础笔尖黑白双线；灰度/裁切/关闭第二模块不显示外圈。简化模式两者为标称圆；实际模式分别应用Rust返回的大小/角度/圆度和各自图片轮廓。未知悬停压力使用标称，落笔用压力，描边固定宽度由Rust计算。随机散布/形状抖动和时间平滑印章队列不预演。

当前与在途各自保留主/第二图片资源和轮廓；参数切换只改变下一笔的几何/资源。后台轮廓请求改为最多4个去重身份（当前主/第二与在途主/第二），每次只保留实际待取身份，结果按身份更新对应槽，不覆盖另一角色；Busy轮转重试，其余失败显示简化圆。图片算法仍仅Rust，Qt只显示归一化路径。液化、吸色、平移、CapsLock、Ctrl/变换和仅悬停偏好继续优先。

验收：默认/严格布尔/旧配置/关闭重开/副本及VBR无污染，不发预览或历史；真实QML开关、双圈尺寸/两规则压力/方向设备、在途切换与主第二不同图片路径、灰度/裁切和关闭隐藏、简化/缩放/DPR1/2/工具优先，原单笔尖/图片回归；Release构建和相关最小Qt测试。

默认关闭时继续读取既有单笔尖姿态，开启才读取复合几何。数位笔设备的伴随Hover事件不再被按鼠标样本覆盖，由Tablet事件保留压力/角度/倾斜；真正的鼠标Hover保持原行为。单个资源已明确失败时，不因反复调整大小而重新生成同一复杂轮廓。

关闭选项时不请求第二图片轮廓；打开时按现有资源身份补取，关闭保留已完成的有界轮廓缓存。第二轮廓不在双色橡皮/涂抹等未定义工具中显示。

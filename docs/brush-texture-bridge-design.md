# 原生纹理资源准备与生命周期

原生 PreparedCatalog 的 state11 准备已调用资源 IO，但导入交接与闲置修订释放仍仅识别笔尖图片。本阶段把纹理源纳入相同生命周期：导入包仅持有实际被当前笔尖或纹理引用的覆盖资源；关闭纹理仍拥有资源，准备发布后按资源身份采用交接；闲置纹理修订释放编译目录和周期 mip，保留准确 JSON 配方。正在使用的不可变目录继续持有纹理，重新准备从持久 PNG 验证身份。

不改变 ABI 和公开包能力；旧 Qt 尚不能保留 texture 对象，package 临时拒绝继续保留。不得因此声称界面、VBR 用户入口已完成。源 ABR 基线独立，不参与当前纹理采用。

验收：纹理独占以及与笔尖共用 PNG 的导入交接；启用和关闭都采用；不含纹理的目录不能误采用交接；未采用的资源仍保留；在途目录不被释放；切换后闲置纹理源和 mip 释放，准确配方重建产生相同真实像素与历史；错误资源引用不替换当前目录。现有笔尖和来源生命周期回归不得退化。

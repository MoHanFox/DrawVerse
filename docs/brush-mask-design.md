# 图片笔尖资源内核

图片笔尖使用不可变 `BrushMask`：灰度覆盖8位，不做显示色彩转换。最大4096×4096、16MiB原图；生成有界 box mip（最长边逐层取半），与笔触捕获的 `Arc` 一起保持生命周期。原图只读，预设更换或资源删除不改变已开始笔触。

`BrushDefinition` 引用可选覆盖资源，`BrushProgram` 预计算方向、长短轴与边界。笔刷直径对应资源最长边，原图长宽比保持，roundness 进一步压缩Y轴；angle 正值在文档Y向下坐标内顺时针。采样使用最近合适 mip 和双线性插值，外围几何边界有1屏幕像素的覆盖过渡；原资源孔洞不套圆形裁剪。图片的软边由资源覆盖决定，不执行程序圆笔硬度。

印章外包围盒考虑旋转矩形角点，不沿用圆半径造成裁切。事务、选区、擦除、蒙版、涂抹继续共用覆盖；普通程序笔尖保留独立 const 热路径，不增加资源采样分支。图像模式像素预算使用旋转矩形最大边，避免绕过原输入预算。

本阶段先验证资源与执行内核，下一阶段接 VBR PNG/SHA256、资源 ABI、UI 导入和真实图片轮廓。内核阶段不在 UI 宣称已能导入图片笔刷。

验收：非法尺寸/长度在 mip 分配前拒绝；孔洞、非方形、旋转角点、缩小覆盖、旧圆笔一致；笔触捕获资源、共享资源不被写入；擦除/选区/蒙版/涂抹与撤销取消保持正确；单笔事务与像素预算不变。

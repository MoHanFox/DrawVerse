# 平滑跟随、画布缩放与色轮保存

2026-10-16，用户反馈高平滑跟随延迟和抬笔直线补尾，要求Ctrl++/Ctrl+-缩放及当前/历史颜色重启保持。先沿用现有Rust路径滤波、CanvasItem视口变换和共享笔刷偏好保存链路，不建立另一套Qt绘画算法。

画布快捷键由各CanvasItem接收所属窗口的输入，通过可见、当前窗口、文本焦点和绘画状态判定；Ctrl++、Ctrl+=（主键盘不按Shift）和Ctrl+-都围绕画布中心缩放，兼容Shift和小键盘。文字输入时不抢键，浮动画布只改变自己的视图，不修改像素和历史。原生窗口输入只消费一次，避免快捷键解析对加号与等号的别名重复触发。

前景/背景色放入BrushLibrary偏好快照的可选colorState，严格验证两个颜色字符串后原子采用。旧快照没有该字段时保留当前默认值。PaintCoreClient颜色和预览跟随同一状态，交换颜色一次保存，多文档沿既有单写入者同步；不进入原生目录、预设重置、VBR或画布历史。历史颜色沿用recentColors及成功绘画后的使用规则，完整顺序和alpha经同一偏好持久化恢复。正常shutdown等待已排队保存，验证关闭后重建客户端而非只比对内存。

用户确认平滑收尾：保留拖绳距离，抬笔停在当前笔画末端，不补线。Rust结束笔触不再向PathFilter合成最多512个追赶步进，也不接原始终点；保留已处理路径最后一点的压力和设备通道，只按现有印章间隔规则完成该点的末印章。无新定时器，不在暂停指针时偷偷释放稳定距离。取消/失败/历史和四类写入仍共用Document事务。已有保存参数、ABI、格式与预设模型不变，已提交历史像素不重算。该明确用户指令更新旧平滑阶段“抬笔补齐终点”的规则。

验收：高参数折线抬笔不新增追赶像素/压力，Rust写入算子与真实鼠标/笔入口、取消和历史；真实键盘主窗/浮窗及文字输入保护、缩放中心和文档像素/历史不变；当前两色和历史顺序/透明度保存重启、多文档同步、旧配置迁移、非法字段原子拒绝和VBR不含全局颜色。

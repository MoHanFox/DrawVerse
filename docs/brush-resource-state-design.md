# 图片笔尖身份与持久状态

图片覆盖资源携带可选、不可变的完整PNG SHA身份。直接内核覆盖可以没有文件身份，但这种预设不能假装已可持久化；状态编码必须明确拒绝。

笔刷状态v3在预设行增加maskResource，保存纯64位SHA，不存外部源路径。读写仍支持v1/v2程序预设；v2不能偷偷接受图片字段。v3资源由Rust ResourceStore解析、验证/加载并捕获Arc，再整批创建编译目录；任何资源缺失、损坏、预算或参数错误导致整个状态失败。

规范化后的v3保持资源身份、名称、顺序和选择；临时工具尺寸/前景色/光标不进入状态。恢复不访问原始导入图片，引用不执行外部路径。下一段接原生库的共享资源目录与Qt镜像、VBR资源包。

验收：带孔洞实际绘画、状态/目录往返、源图片删除后仍加载、非法/缺失/错误哈希/预算整体失败、程序旧状态不变、无身份图片拒绝持久化。

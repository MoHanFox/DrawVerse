# 图层组：设计与验收

本轮交付图层组的完整链路，蒙版作为下一独立模块。插件仍最后实施。

## 模型选择

递归树会改变现有平面图层、分页、历史和 ABI 读取路径；平面数组加父 ID 可以保留普通图层快路径。因此使用后序数组（底到顶，子树连续，组节点在子节点之后），根父 ID 为 0。组不持有像素，嵌套最多 16 层，总节点最多 4096。

组采用隔离合成：子节点先在透明背景合成，组的混合模式、opacity 和 fill 再应用一次。暂不提供 PS 的“穿透”模式。组的透明像素锁不可用；位置锁和完全锁对后代生效。可见性与透明度同样影响整个子树。

像素图层位置始终是文档坐标；组位置固定为零。移动组用一个原子历史命令调整全部后代像素图层的整数位置，任何后代位置锁、坐标越界或历史写失败都拒绝整个操作。重新归组保持像素位置，改变合成上下文。解组移除组的合成属性，不烘焙像素；删除组则删除整个子树。最后一个像素图层不能删除。

分组、解组、重新归组使用只含元数据的结构历史，不复制或编码整张画布；删除子树才保存其不可变瓦片引用，超预算依照已有磁盘历史机制处理。撤销/重做恢复层级和顺序。选择组时不能绘画；新建图层进入所选组，选中像素层则在同级上方插入。

## 渲染与接口

无组文档保留现有缓存和普通 Normal 合成循环。有组文档通过逐行隔离合成，缓存依赖实际可见的像素瓦片及组元数据；隐藏/零透明度的祖先不得读取冷页。缩略图预览组内合成，忽略所选组自身的隐藏和透明度，保留子节点属性。

ABI 1.5 新增独立层级 DTO 和异步组操作；现有结构大小、函数签名及混合模式编号不变。GUI 只提交小命令，后台 actor 修改文档。QML 显示缩进、文件夹、展开折叠，提供分组、解组、移入组及移出组。浮动面板使用相同组件。

ORA 使用标准嵌套 stack 且明确 isolation="isolate"，依据 [OpenRaster 0.0.6 图层结构规范](https://www.openraster.org/baseline/layer-stack-spec.html)。保存保留嵌套、组属性、选中节点及现有 dv 扩展；加载重新分配层 ID，父子关系按节点映射恢复，溶解种子独立保存。导入拒绝无法准确解释的穿透组、非零组位置、超深层级和未知扩展；不静默扁平化。PNG/JPEG/WebP 继续导出合成结果。

## 验收

- 核心：嵌套顺序、循环/深度拒绝、组混合只应用一次、锁继承、移动原子性、删除和结构撤销、冷页/磁盘历史。
- 渲染：与核心逐像素参考一致、组属性及成员变化使缓存失效、隐藏祖先无冷页读取、普通绘画快路径性能回归。
- IO：嵌套 ORA 回环、外部隔离组导入、穿透及恶意层级拒绝。
- ABI：新 DTO 大小、版本能力、异步操作、旧 C/C++ 客户端兼容。
- Qt：展开/折叠、分组/解组、组内新增/移入移出、浮窗、高 DPI；完整 tools/check.py 和原生绘画性能基准。

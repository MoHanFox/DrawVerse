# 纹理覆盖内核

不可变TextureSettings：Document/Tip坐标、scale（每源像素对应文档像素，0.01–100）、angle（±180度）、depth（0–1）、invert、offsetX/Y（±1M文档像素）。Document固定文档坐标，不随图层偏移或视口改变；Tip以实际印章中心定位，旋转叠加当前设备/随机笔尖角度，偏移仍为画布像素。周期线性因子为(1-depth×(1-pattern))。Document作为整笔覆盖后的固定纸纹，100%不透明度也受纸纹上限限制，不因密集间距填平灰度纹理；Tip作为逐印章覆盖乘子，随重叠逐渐累积。不扩大边界、间距或数量。

TextureResource共享原始BrushMask，另建周期mip（奇数边缘按原面积加权，8位逐级量化），不会改变旧图片笔尖clamp取样。编译缓存纹理变换及每实际印章LOD/取样计划；无每像素分配。恒白或反相恒黑的恒等纹理在编译时折叠，预算不虚增；其他纹理按最多8次周期取样计入段预算，拒绝不丢输入。文档执行新增TEXTURED泛型路径，关闭纹理不增加普通笔尖逐像素分支。程序与图片、颜色/流量、选区和四类写入共用覆盖。

BrushTexture持有启用/设置/可选不可变资源。启用即要求资源，即使depth=0；关闭保留配置/资源。起笔捕获资源，编辑/释放调用方不影响在途；目录预算分别去重源Mask与周期mip，关闭资源也计入，不漏算同源笔尖/纹理。未接IO时明确拒绝非默认纹理保存。

验收：参数和缺资源拒绝、周期缝/负坐标/奇数能量/缩小LOD、实际纹理开孔与深度/反相/旋转/两坐标；偏移层、图片、选区、绘画/擦除/蒙版/涂抹和透明度上限；资源快照/共享预算、取消/历史/分段一致与失败原子性。此阶段无ABI/UI入口，不宣称PS所有纹理组合兼容，资源IO/VBR/原生Qt及其余全系统范围后续接入。

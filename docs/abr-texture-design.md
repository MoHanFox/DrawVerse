# ABR 纹理导入

状态：2026-10-18 基础导入已实现，验收见 [ABR 纹理验收](abr-texture-validation.md)。ABR 的来源原字节仍完整保留；已映射的图案资源、深度、缩放、坐标空间、反相和八种纹理覆盖模式进入真实执行，其他 Photoshop 纹理字段继续逐项报告为未执行。

## 目标

将 Photoshop ABR 中启用的笔刷纹理转换成 DrawVerse 已有的纹理覆盖执行对象，并让真实图案资源随导入、预设状态、VBR、来源快照及重新打开完整往返。继续使用统一笔刷引擎，不在 ABR 专设渲染分支。

ABR 纹理包含两个独立输入：预设描述符中的 `useTexture`、`Txtr/Ptrn/Idnt` 与参数，以及 `patt` 分节中按 ID 存储的图案像素。只有参数、资源和执行模式均可解析时才启用纹理；任一必需项缺失或非法，整批导入失败，不能发布缺图案的半成品。

## 解析与资源

- 继续使用仓库有界描述符解析器读取 `desc` 和保留原始 ABR；单独评估 `brushkit-abr` 的 `patt` 解码能力，集成前验证其版本覆盖、尺寸/像素总量上限、取消响应和畸形输入行为。不得让二次解析绕过现有 128 MiB 文件、1024 预设、目录像素预算和取消限制。
- 按 `Txtr/Ptrn/Idnt` 精确关联图案 ID，不按名称或次序猜测。缺少引用、重复 ID、引用不存在或图案损坏时返回有界错误并保持原库不变。
- 首批仅接受已经核验且能确定性转成灰度覆盖的 8 位灰度、索引色和 RGB 图案；RGB 使用记录的 Rec.601 亮度转换。16 位或其他模式明确报告不支持，不静默量化。
- 转成 `BrushMask` 后采用 PNG 内容哈希作为纹理资源 ID，复用当前资源库、容量预检和原子导入路径。重复图案共享资源；图案不能因超过 4096 边长、像素预算、资源预算或编码预算而部分导入。
- `textureEachTip` 映射到笔尖局部/文档固定空间；`textureScale` 百分比换算为比例；`textureDepth` 换算为 0..1；`InvT` 映射反相。每个字段均执行类型、单位、有限值、舍入前范围校验。

## 混合模式与近似

- ABR `textureBlendMode` 的枚举 ID 必须使用真实描述符样本和许可语料逐项确认，不从显示名称猜测。先映射到 DrawVerse 已实现且公式语义一致的纹理覆盖模式；未知或不可等价的模式保留来源并列为未执行，不可伪装成 `normal`。
- Photoshop 的纹理模式列表若包含当前核心尚未支持的模式，应扩展 `TextureMode`、核心覆盖公式、序列化校验、Schema、Qt 下拉和真实像素测试。不得只增加界面选项。已有七种模式的旧 state/VBR 缺省行为与字节兼容。
- `textureBrightness`、`textureContrast`、`minimumDepth`、`textureDepthDynamics` 等当前执行模型没有对应行为时，逐字段标记未执行；可执行的纹理基础部分仍可导入，但来源报告必须保留部分转换状态。禁止把 `height` 等特殊模式冒充普通混合模式。
- 纹理覆盖模式作用于笔尖覆盖率和图案值，不改变画布颜色混合，也不声称 Photoshop 逐像素等价。实际语义差异需在报告和验收文档中明确。

## 数据交换与兼容

- ABR handoff 增加纹理参数与纹理资源身份，增加对应 handoff 版本；Qt 端严格按版本读取，旧版本仍按原规则导入，新字段缺失/资源 ID 不匹配时整批拒绝。
- ABR 来源转换器升至新版本，旧 v1..v7 转换入口、来源记录 JSON 字节、报告和原始 ABR 不重算。新版本来源基准需记录完整纹理参数及资源 ID，使“重置预设”可恢复导入时纹理；关闭状态、资源引用和当前编辑值不能混淆。
- 更新来源 JSON Schema、合法/非法样例、VBR 最高 minor 选择及低版本夹带拒绝。纹理资源加入包资源并集与容量预检；旧包读取和旧状态字节保持。若扩展纹理模式枚举，需要单独升级 VBR minor 并验证 Qt/原生边界，不改动不相关 ABI。
- 真实 ABR 的未知块仍由完整原始文件保留；来源保留只用于审阅和重置，不作为执行数据。

## 验收

1. 用生成的 `desc` + `patt` 文件验证精确 ID 关联、灰度/索引/RGB 解码、已支持模式、深度/缩放/反相/坐标空间及逐字段兼容报告；另用获得许可的真实纹理 ABR 样本核对结构和像素。
2. 以导入后的真实 BrushDefinition 绘制纹理，逐像素验证每种模式和对照样本；覆盖程序/图片笔尖、文档/笔尖坐标、低深度、反相、历史撤销重做。
3. 验证重复资源去重、ABR handoff 到 Qt 预设库、来源基准重置、纹理资源持久化、VBR 导出/导入和新目录重开后实际笔触一致。
4. 覆盖缺 ID、未知模式、无效数值、损坏图案、超大维度、资源/字节预算、取消、容量不足和末项失败；所有失败均不发布部分预设。
5. Windows 最小相关 Rust/原生/Qt 测试与 Release 构建通过后独立提交推送。真实 Photoshop 完整笔触对照需有许可样本；未验证项明确记录，不宣称全面 ABR 兼容。

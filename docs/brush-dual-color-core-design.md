# 双色双笔刷整笔合成内核

2026-10-15：在已完成的相对尺寸基础上执行separated-stroke-v1。DualColor设置保留启用、使用背景色、允许溢出、第二在前/后、两贡献的颜色混合模式；六种旧灰度覆盖模式保留并不重新解释。默认关闭。此阶段不公布ABI/UI，旧IO对任何非默认新配置明确拒绝，关闭值也不能丢失。

仅绘画执行双色，橡皮/涂抹及数位笔橡皮输入明确拒绝；颜色与两笔定义起笔不可变捕获。主颜色动态先作用于前景/背景，再累积直色矩；第二取背景或原前景，保留其alpha，独立颜色动态未定义且不启用。主与第二分别按流量和主不透明度压力上限累积coverage，配对和独立路径都生成真实第二场；固定宽度沿已验证的主实际尺寸映射。

第二不溢出时有效coverage=min(第二coverage,主coverage)，不用相乘二次降低软边。按前后顺序在透明隔离笔触内应用各贡献混合模式，再乘整笔opacity一次，最后使用工具模式合成到起笔before。底部贡献模式在透明底上通常等效正常，溶解例外；模式交换位置后自然改变内部混合。透明主颜色正常透出后方第二色。第二贡献始终保留未裁切场，主覆盖后来增长时重算受影响瓦片，回笔/交叉不会将后来的第二印章直接叠到已绘主线。

主局部纹理只调制主印章；文档纸纹在最终复合贡献上作用一次，避免反复积累吃掉纸纹。选区/羽化在复合贡献上作用一次；蒙版使用复合颜色的现有可见灰度，透明锁保持before精确alpha，偏移用图层局部瓦片和文档坐标。双场和before使用页池，不建整图缓存；真实脏瓦片/取消/整笔历史共用事务，预算包含第二更大边界和整瓦片重算，存储失败原子回滚。

验收：真实双色前后/溢出/不溢出软裁切、回笔交叉内部不串色、透明度只作用一次/主透明色、起笔捕获、动态与两种路径/相对压力；选区/蒙版/透明锁/偏移、分页/预算/取消与撤销重做、旧六模式/IO拒绝。此阶段不声称完成自动描边预设或设置界面，非分隔的逐印章模式需后续另定义，不能假装支持。

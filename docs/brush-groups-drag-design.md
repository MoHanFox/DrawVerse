# 画笔组拖放排序

2026-10-18，在既有 state20/VBR1.24 有序组织树上增加 Qt 拖放排序入口。组织模型不变：根目录和每个组仍以有序 `items` 保存预设与子组，`applyOrganization` 继续负责完整投影和规范化。

`BrushLibrary` 新增 `movePresetToGroupAt`/`moveGroupToGroupAt`：先移除源项，再按目标父组和位置插入。位置限制在目标数组范围内；同父移动时，源索引小于目标索引会先减一，避免拖到下一项时错位。目标组不存在、源项不存在、把组拖入自身或后代、以及原有非法移动全部原子拒绝并保留原快照。原有不带位置的入口继续表示追加到目标末尾。

画笔库面板的每一行同时候选拖拽源和放置目标。拖到预设或组的上下半区表示在其前/后插入；拖到组的中段表示移入该组末尾；列表底部的“拖到这里移到画笔库根目录”区域提供根目录目标。图表使用焦点的边框/插入线，不改变选择与预览；搜索过滤只影响显示，实际拖放使用原始组织 ID 与父组。

该阶段不改变 state20、VBR1.24、ABI1.55 或保存格式；Qt 只改变组织顺序和父组，资源、来源、预览和选中预设继续走既有持久化。

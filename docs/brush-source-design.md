# 笔刷来源与导入报告资源

完整原始ABR作为非执行来源文件按SHA256保存，与每个预设的小型来源记录分离；同一包的预设共享原始文件，不额外记录导入时文件路径（原始字节中已有内容保持不变）。记录包含文件版本/子版本、预设序号、导入时名称、转换器版本、导入时基础参数/图片身份、逐字段状态/原因。未解释desc/patt/未知数据由完整原始文件保留，不能用有限JSON字段假装保留完整来源。

来源记录是导入时快照，不是当前用户编辑后的参数，也不作为可信执行指令或PS兼容证明。当前执行仍仅使用BrushSettings。先完成Rust资源存取，后续原生预设只保存来源记录ID，再接状态与VBR来源资产；本阶段不宣称UI来源查看已经可用。

文件命名固定hash.abr/hash.json；原始文件128MiB、记录2MiB、报告4096项/1MiB路径；共享仓库实例写入串行，最多4096持久条目。校验hash/记录结构/版本/原始头对应关系（不把来源记录当作完整ABR语义验证），拒绝符号链接和无效ID；同目录temp+sync+不覆盖原子保存，损坏现有文件不能覆盖。先保存原始文件、再记录；后者失败可留下孤立原始文件，不返回成功记录ID，不宣称两文件事务。已存在记录导入/导出按完整JSON字节保存身份，不用重编码替换引用。

本地保留完整来源包不等于导出单个预设时默认复制其中其他预设；VBR来源阶段须明确导出范围，或提供只附所选预设来源的表示，不隐式扩大用户导出内容。

恢复完整读取并校验原始文件，不改变已捕获的immutable来源对象。取消/校验失败不发布记录。验收：完整未知字节往返/共享原文件/原路径删除、报告/导入基线、篡改/坏hash/路径/符号链接、版本/预算/取消、并发相同内容不覆盖。真实外部资产不分发；测试使用独立生成字节。

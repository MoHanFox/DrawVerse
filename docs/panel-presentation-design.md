# 面板状态与紧凑信息栏（2026-10-10）

本次用户要求取代常驻图标面板“再次点击只置顶”的行为：点击图标打开，再次点击关闭该面板，不影响同列其他已打开面板，空白/失焦仍不关闭。面板宽高与相对来源列的侧边导航偏移按面板 ID 保存，收回/再次打开、移动组、保存布局/恢复时继承；位置超出新屏幕可见范围时重新约束。布局 v6 增加可选 panelViews，不改变核心/ABI，旧 v6 没有此字段时正常恢复，非法可选状态忽略而不重置工具布局。不同面板状态独立，显式默认布局清空这些状态。

UI 控件与面板描边统一 #1B1C1F（包括焦点/选中边框，选择仍由填充/文字表达）；灰黑分隔同色，拖放发光和几何选区属于交互提示，保留其可见反馈。普通工具标签上方圆角从 6px 减为 3px。面板顶部拖动栏与标签栏的背景 #05080A，停靠不透明，独立工具窗/图标展开窗背景 alpha=.75；只改变背景透明度，文字与正文保持不透明。原生窗与面板根背景不垫一层不透明色，避免假透明；独立图标列空白仍为 #1C1E21。

主窗底部改为紧凑信息栏：左侧实时显示当前工具、活动画笔名、文档尺寸、非蒙版图层数量，右侧缩小、单小数缩放百分比、放大、适配。无活动文档显示占位并禁用视口操作。取消文件任务与文件/错误状态保持可达。工具条删除适合窗口按钮，视图菜单及 F 保留；底栏适配调用当前画布 fitToView，缩放围绕画布中心，沿用滚轮缩放范围，不改变文档像素/历史。

验收：同图标开关与其他面板保持；缩放/侧边滑动后再次打开和布局恢复继承独立状态，非法状态不污染布局；主窗/浮窗描边、圆角与真实顶部背景 alpha 像素，正文/列空白保持不透明；底栏工具/画笔/尺寸/图层/缩放随真实状态与多文档活动对象切换，放大/缩小中心不漂移、适配有效且不绘画，原工具条按钮移除。普通/高 DPI Qt Test、Windows 实窗与完整 tools/check.py；验证后 commit/push origin/master。

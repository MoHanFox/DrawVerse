# 形状抖动原生Qt入口

ABI1.40新增SHAPE_JITTER能力，无DTO变化。Qt接受state9/VBR1.7/behavior6/shape-jitter，解除临时package边界；启动至少需要ABI1.40避免旧核心丢参数。每预设独立shapeJitter对象，完整seed保留字符串，关闭配置和复制保持，目录及批量导入始终取最高状态版本。

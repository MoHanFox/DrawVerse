# 菜单悬停与多选新建组修复

混合模式列表由同一个指针位置决定预览目标，进入和离开相邻行不能互相覆盖。首次进入、行间移动以及滚动后的静止指针都立即请求预览；关闭列表恢复正式效果，提交只产生一次历史。回归须保持真实 CanvasItem 连接，同时覆盖相邻行切换，不能用滚轮触发首次更新。

新建组统一使用所选图层，Rust 原子完成。选择按原堆叠顺序归一化，祖先与后代去重，蒙版跟随所有者。新组位于各选中根的最近公共父组内、最高选中分支原位置；根之间保持顺序，未选节点保持原父级和顺序。拒绝单独蒙版、锁定、无效 ID、层数和深度溢出时不得改变文档或历史。一次撤销恢复整个结构，单层旧接口兼容。新增 ABI 1.14 批量建组入口，输入 ID 和名称在调用内复制。

分类子菜单从第一行向侧边移动时须保持同一菜单链。定位和输入路由以真实窗口全局坐标为准，避免子菜单第一行与菜单栏重叠或把子菜单坐标用于主菜单栏。保留鼠标切换其他分类、Escape 和外部点击关闭，以及浮窗置顶。验证第一行和后续行、实际逐像素跨边移动，兼容原生 Popup.Window 和侧边窗口回退、普通及 2 倍缩放。

验收：Rust 检查多选/跨父级/祖先去重/蒙版/剪贴/失败原子性及撤销重做，FFI 检查复制输入和单次历史，Qt 检查两处建组入口、真实画布悬停预览及第一行菜单跨边移动。完整运行 tools/check.py，构建部署，验证后提交并推送 origin/master。

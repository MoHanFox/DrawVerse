# 图像菜单：调整、画布大小与画布旋转（2026-10-10）

用户要求在"图像"菜单下提供：调整（曲线 / 色阶 / 色相饱和度明度）、画布大小、画布旋转（顺时针 90°、逆时针 90°、垂直翻转、水平翻转）。

## 现状与差距

- 图像菜单目前只有占位项（全部"待支持"）。
- 内核有 `move_layer(id, dx, dy)`（整数平移，单图层），**没有**画布/图层的旋转、翻转或重采样原语；`paint-ffi` 也没有对应入口。
- `Document::from_import*` 只能"构造"，不是可撤销的编辑操作；用它实现旋转会绕过历史、丢掉图层结构与身份，因此不可用。

## 设计

### 画布旋转与翻转（真实可用）

1. **核心原语**：新增 `Document::transform_all(AffineKind)`，对**所有图层**（含组内图层）应用同一个正交变换：
   - `Rotate90Cw` / `Rotate90Ccw` / `Rotate180`：宽高互换（180° 不换），逐图层重映射像素并重算尺寸与位置；
   - `FlipHorizontal` / `FlipVertical`：尺寸不变，镜像采样。
   - 采样规则：正交变换下每个目标像素精确对应一个源像素（无插值），因此是**无损整数重映射**；实现在瓦片层做一次遍历，保持稀疏瓦片与分页缓存语义。
   - 画布尺寸随旋转更新（90/270 交换宽高），选区和历史的选择步骤坐标同步变换或按规则清空（与 PS 一致：旋转后选区跟随变换）。
   - 一次操作 = **一条历史记录**，新 `HistoryAction::TransformCanvas`（显示"画布旋转"/"翻转画布"），可完整撤销；旋转后文档 `modified=true`。
2. **ABI 1.13**：新增 `paint_session_transform_canvas(core, session, kind: u32, out_sequence)`（只新增符号，不改既有 DTO）。
3. **Qt**：`PaintCoreClient::rotateCanvas(kind)` / `flipCanvas(kind)`，QML 菜单项直接调用；画布与导航器通过既有帧刷新自动更新。

### 画布大小（真实可用）

`Document::resize_canvas(width, height, anchor: u32)`：保持像素内容相对锚点（默认居中）裁剪或扩展，扩展区域透明；组、蒙版、剪贴关系与图层结构不变；一次历史记录（`HistoryAction::ResizeCanvas`），ABI 同批新增。QML 用一个小对话框输入宽高并选择锚点。

### 调整：曲线 / 色阶 / 色相饱和度明度（分步）

三者都是**像素级重映射**，需要新的内核原语与可交互预览，工作量明显大于上面两项，因此单独排期：

1. 核心：`Document::apply_adjustment(Adjustment)`，参数化为 `Curves(控制点) | Levels(黑场/白场/伽马/输出范围) | Hsv(色相偏移, 饱和度系数, 明度系数)`，作用于活动图层（可选"影响全部图层"），一次历史记录；
2. 预览：沿既有混合预览机制（`paint_session_set_blend_preview` 的槽位/世代/取消模型）做**不写历史、不改文档**的实时预览；
3. QML：曲线编辑器（可拖控制点）、色阶直方图 + 三滑块、HSB 三滑块对话框，均带"预览 / 取消 / 确定"。

在新的内核原语就绪前，这三项在菜单里保持 `enabled: false` 且文案标"待支持"，不做点了没反应的假项。

## 验收

- Rust：旋转 90°×4 回到原图（逐像素等值）、翻转两次回到原图、宽高交换、组/蒙版/剪贴关系保持、稀疏瓦片不丢内容、撤销重做恢复、画布大小裁剪与扩展的像素与结构断言。
- FFI：非法 kind、超大画布、非正交参数拒绝；失败不产生半成品状态。
- Qt：菜单项触发后画布与导航同步、`modified` 置位、Ctrl+Z 一步恢复；画布大小对话框边界校验。
- 完整 `python tools/check.py`、两倍 DPI、构建部署。

## 分步实施

1. 菜单结构上线（本次）：图像菜单按用户给的结构列出条目，可实现的接内核，未实现的明确禁用标注；
2. 内核 `transform_all` + `resize_canvas` + ABI 1.13 + Rust/Qt 回归；
3. 调整三件套的内核原语与预览；
4. 曲线/色阶/HSB 对话框与交互；
5. 完整检查与部署。

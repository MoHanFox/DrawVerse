# 面板尺寸、颜色交互与图层悬停预览（2026-10-10）

浮动分割树移走叶面板时，按移走前剩余叶的占用矩形缩小宿主窗口并调整位置，保留剩余面板的实际尺寸与屏幕位置。主工作区仍占用主窗，不留下空分支。取消拖动恢复原布局与窗口几何。

共享 PanelContent 的颜色块单击立即交换颜色，删除双击 HEX 输入与相关提示；工具详情栏删除颜色块。HSB 渐变条下方用向上的白色三角指示。图层百分比下拉控件整体缩小 25%，使用深色背景与统一描边。组合框统一紧凑深色条目，图层混合模式悬停预览真实合成结果。

悬停预览不修改文档、历史、保存内容或元数据。ABI 1.9 增加 paint_session_set_blend_preview，以既有视口 DTO、显式图层和混合模式请求完整合成帧；仅槽 0/1，保留已有请求号/世代/取消机制。渲染前仅修改不可变快照的副本，瓦片仍共享。普通 set_viewport 清除该槽的覆盖。Qt 同时刷新画布和导航，关闭菜单恢复实际合成，点击只提交一次正式图层修改；切换图层、文档、绘画和编辑取消预览。

主窗外描边沿用 #63666B、50% 不透明，在独立非交互透明窗口中向外绘制 1px，不侵占正文。跟随普通窗口位置/大小，最小化、隐藏、最大化和全屏时隐藏。画布标签左侧留 8px 间距，页头底色与工具详情栏一致。

用户追加：折叠图标列类别之间的居中横线使用 #3B3D42，调亮以便分辨类别；普通控件描边仍为 #1B1C1F。

数位板笔刷轮廓同时处理窗口与 QQuickItem 的 TabletMove 路径，以全局位置换算到画布局部，防止两条路径坐标含义不同；悬停接受数位板事件避免合成鼠标覆盖位置，离开画布/数位板感应范围隐藏轮廓。大写精确十字模式沿用。

验收：Rust 检查快照预览像素不同但原快照不变；FFI 检查完整合成、历史与修订不变、非法参数、请求替换及取消恢复。Qt 检查浮窗并列/上下拆分及取消、立即交换且无 HEX 输入、菜单紧凑深色与悬停/提交/关闭恢复、下拉尺寸、HSB 三角位置、外描边原生几何/透明度/最大化隐藏、标签间距和颜色。完整 tools/check.py 与 Windows 实窗回归通过后提交推送 origin/master，并部署应用。

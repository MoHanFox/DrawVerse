# 允许空图层栈

用户要求删除所有图层后仅显示灰白透明棋盘格。Document 允许零图层，active_layer=0 表示没有活动目标；只含空组的层级也合法。不创建替代图层或背景。单层、组子树、多选删除共用现有原子历史/锁校验；撤销恢复原内容，重做恢复空栈，随后可新建图层或粘贴内容。无图层绘画返回无目标错误，不产生像素或伪历史。

Qt 删除按钮及菜单允许最后一个图层删除，空栈时删除禁用，活动选择清空；渲染继续输出透明，由既有棋盘格呈现。保存 ORA 保留零图层（完整合法空 stack），导入不补层并避免活动索引下溢；透明 PNG 导出沿用合成。

验收：Rust 单/组/批量删除、透明合成/快照、active=0、新建/历史恢复与无目标绘画；ORA 空栈及仅组往返；Qt 真实删除键/按钮、透明画布、撤销重做及重新新建。Windows 最小相关检查，无 ABI 布局变化。

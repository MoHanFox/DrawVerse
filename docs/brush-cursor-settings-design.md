# 笔尖光标偏好

程序笔尖阶段已提供跟随圆度/角度/缩放的双线轮廓。本阶段补全实际可用的全局偏好：轮廓显示、中心十字、仅悬停显示、线宽1–3像素。设置位于笔刷设置第三项“光标与预览”，使用共享紧凑控件和1秒参数提示。

另提供简化圆形和内外轮廓颜色（不透明颜色，默认为黑/白）。图片叠加预览将在实际图片笔尖资源模块中接入，不提前显示无效控件。

这些参数属于应用绘画偏好，写入预设状态根的 cursor 对象，不进入单个预设或 VBR。改动不使真实笔触预览失效，不改变文档/笔触历史；保存失败/非法恢复不改动现有状态。缺失 cursor 的旧配置使用原双线默认值。

DocumentManager 将笔刷偏好变更原子同步给所有文档的 UI 镜像；新文档就绪时继承当前状态，避免同一配置文件被不同文档的旧副本覆盖。同步通过 restore 发布，不再次请求保存；每个文档的像素/事务、当前工具模式与预览任务仍独立。

共享笔刷状态只由初始客户端的后台 worker 顺序保存，其他文档的改动路由到这个写入者，避免多个 worker 的保存顺序逆转。独立使用 PaintCoreClient 的测试/宿主仍自行保存。

写入者关闭时先等 stopped（旧保存队列已排空），再移交给存活客户端并保存最近状态；关闭间隙的修改由管理器保留。新文档继承最近快照，不从已关闭初始文档取过时参数。

绘画中仅悬停选项隐藏轮廓与中心；关闭两者使用系统精确十字。CapsLock、吸色、平移、Ctrl 选层、自由变换继续优先；液化始终显示其原圆形轮廓，不受普通笔刷选项影响。

验收：原生窗口下修改偏好后光标可见性/形状即时更新，开始/结束笔触正确隐藏恢复，CapsLock 和工具切换优先，旧配置/无效配置/副本/VBR 保存保持语义；修改不发出笔触预览请求，不产生文档历史。

# 液化性能与工具条统一

保持 ABI 1.21、原始像素双线性采样、工具公式、路径插值、压力/时间和选区覆盖坐标不变。预览 dab 不再提高渲染版本屏障，允许连续操作显示有效中间帧；开始、重置、取消、确认和专注切换保持屏障，防止旧会话结果显示。

CPU 按瓦片访问工作缓冲，取消内层逐像素工作树查询；位移场读取使用相邻瓦片快速缓存，原像素读取缓存跨插值步骤保留且使用最近瓦片快速路径；选区使用有界覆盖缓存，保留液化原来的整数采样坐标。瓦片驻留修剪移到步骤末，失败仍不提交部分结果。

不丢弃或粗暴合并输入，不改路径与累计变形结果；本轮不引入 GPU 或低分辨率近似预览。原始层与临时位移场克隆仍保持错误回滚。分析报告中的剩余输入积压、索引克隆和整帧传输开销保留为后续工作。

工具条标题与工具之间增加 1px 分隔。抽取 CompactCheckBox，统一选区、油漆桶、魔棒、涂抹、液化工具条的 13px 指示框和 1 秒说明。

验收：液化已有核心事务/压力/选区/错误回滚测试及固定像素校验；同场景 Release 性能对比（不以固定时限判定测试）；FFI 验证 dab 非屏障、控制操作仍是屏障；Qt 验证分隔线、共用 13px 指示框和液化原有交互。仅运行相关最小用例。

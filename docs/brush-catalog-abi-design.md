# 原生笔刷库 ABI

ABI 1.27 新增独立生命周期的 PaintBrushLibrary 句柄。它不属于任何文档/core；关闭创建时的文档不会释放库，调用者显式销毁。注册表保留失效地址，拒绝伪造/重复销毁句柄；在途笔触已经捕获不可变定义，销毁库不影响该笔触。

提供默认库创建、元数据/身份/名称读取、选择、参数编辑、改名、副本和删除。读取以库 revision 为一致性屏障，过期返回 BUSY；修改先经过 Rust Catalog 验证再原子发布。所有同步目录操作由后台线程调用；GUI 后续通过 PaintCoreClient 的后台服务接入，不直接执行 IO 或图片编译。

PaintBrushSettings 是64字节（结构头/保留字段/直径/不透明度/直径比例间距/保留字段、40字节笔尖）；目录预设信息64字节，目录信息32字节。读取名称/ID用有界 caller-buffer。工具状态独立的 PaintBrushToolDesc 为56字节，包含操作、目标层、临时半径、涂抹强度、前景色及涂抹开关。

paint_session_begin_preset 在返回前捕获指定库预设的定义与资源，复用异步 Begin/Move/End/Cancel 队列；临时工具尺寸/颜色/操作不写回预设。库修改、删除、销毁不影响笔触。旧 ABI 导出和旧 DTO 保持不变。

本模块接通可调用的原生库和真实笔触入口。Qt 镜像迁移、持久 PNG/SHA256、资源导入和 ABR 为下一段接入，未完成前不把原生库接口当作整套图片工具已完成。

验收：DTO 大小/偏移及生成头、独立句柄生命周期与过期读取、原子参数/名称/身份失败、内置删除保护、副本与选择；实际异步绘画在编辑/删除/销毁库后仍使用捕获定义，保持单条历史/撤销重做；错误参数不改变目录或文档。

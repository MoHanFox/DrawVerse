# 画笔系统：.vbr 格式与 Procreate 式行为（2026-10-10）

用户反馈三件事：

1. 画笔库顶部那排 `6 / 12 / 24 / 48` 加圆点的按钮**不是预设**，应当是"用户刚用过的笔刷 + 其大小"的预览，而且圆点渲染要**居中**；
2. 画笔列表与画笔设置要还原 Procreate 的组织方式，并建立本项目自己的笔刷格式 **.vbr**；
3. 每个笔刷、以及每个需要使用笔刷的系统（画笔、橡皮、涂抹）都要有**独立的像素大小**。

## 现状

- `BrushLibrary` 把 4 个内置预设写成固定 id（`round-pressure`/`round-fine`/`round-translucent`/`round-wide`），只有 `radius/opacity/spacing` 三个参数，没有笔尖形状、纹理、压感曲线等 Procreate 概念。
- 顶部四个按钮是硬编码 `[6,12,24,48]`，点击直接把 `library.radius` 设成对应值——既不是预设也不是历史，属于误导性控件。
- 工具大小只有两个槽（画笔、橡皮，`toolRadii[2]`）；涂抹工具尚未存在，因此没有第三槽。
- 设置随 `brushes/state`（JSON v1）持久化，`restore()` 对版本与字段做严格校验。

## .vbr 格式（设计）

`.vbr` 是**单文件笔刷包**，UTF-8 JSON 正文 + 可选 base64 附加数据，文件名即笔刷名（可中文）。版本化、向后兼容：

```
{
  "format": "drawverse.vbr",
  "version": 1,
  "id": "<uuid>",
  "name": "压感圆笔",
  "engine": "round" | "smudge",
  "shape": { "kind": "round" | "square" | "stamp", "roundness": 1.0, "angle": 0.0,
             "texture": "<base64 png，可省略：省略即纯色笔尖>" },
  "dynamics": {
    "size":   { "pressure": 1.0, "tilt": 0.0, "speed": 0.0 },
    "opacity":{ "pressure": 1.0 },
    "flow":   { "pressure": 0.5 },
    "jitter": 0.0,
    "scatter": 0.0
  },
  "spacing": 0.15,
  "blend": "normal",
  "wet": { "density": 0.5, "pull": 0.5 }        // smudge 专用
}
```

校验规则：`format` 必须匹配；`version` 只接受 1；`id` 为合法 UUID 且不与现有冲突；`name` 1–80 字符；所有数值有限且落在各自范围（`roundness 0–1`、`angle 0–360`、`dynamics 0–1`、`spacing 0.05–1`、`jitter/scatter 0–1`、`wet 0–1`）；`texture` 解码后 ≤ 512×512 PNG 且 ≤ 1 MiB。任何一项不合法整体拒绝，不做部分导入。

导入/导出：画笔面板支持"导入 .vbr"（文件对话框，多选）与"导出 .vbr"（单个或全部）；导入的笔刷与内置笔刷同级，`builtin=false`，可重命名与删除。内置笔刷也能导出，作为格式示例。

## Procreate 式组织

- 左侧/上方为**笔刷列表**（名称 + 真实引擎预览 + 收藏标记），下面是分类（基础、自定、导入）。
- 右侧/下方为**画笔设置**面板，分为 Procreate 的几组：笔尖形状（形状/圆度/角度/纹理）、动态（大小/不透明度/流量对压感·倾斜·速度的响应、抖动、散布）、间距、湿边（仅 smudge）。
- 参数改动实时写入当前笔刷并**后台异步**刷新列表预览；预览失败显示原因，不伪装成功。
- 现有 `BrushLibrary` 扩展为承载 `.vbr` 字段的模型，设置 JSON 升到 v2（v1 可读：缺字段取默认值并标记迁移）。

## 工具尺寸独立性

- 尺寸槽从 `toolRadii[2]` 扩为三个：**画笔 / 橡皮 / 涂抹**，各自独立，互不影响；切换工具或切换笔刷都保留各自的值。
- 每个笔刷也保存"上次使用的大小"（`lastSize` 随 `.vbr` 不写入文件，属于本机偏好），因此"同一笔刷在不同工具下"各自记住上次大小。
- `[` / `]` 调整的是**当前工具**的尺寸，与笔刷列表预览无关（列表预览始终用固定适中大小渲染，不随当前像素大小变化）。

## 顶部"最近使用"条（替换误导性的 6/12/24/48）

- 语义改为**最近用过的笔刷 + 其大小**：每项显示该笔刷的缩略预览与大小数字，点击即选中该笔刷并恢复其大小。
- 由 `BrushLibrary` 维护最近使用队列（去重、最多 12 项、最近在前），真实用笔（提交笔触）才入队——与"最近颜色"同一原则。
- 每项内部的圆点/预览必须**居中**：用固定尺寸的正方形画布按 `PreserveAspectFit` + 居中锚点绘制，不随容器宽度拉伸。

## 验收

- Rust/Qt：`.vbr` 往返（导出→导入逐字段等值）、非法字段逐项拒绝（版本、UUID、名称长度、越界数值、超大纹理）、v1 设置迁移、最近使用队列去重与上限、三工具尺寸互不影响、顶部条点击恢复笔刷与大小、预览居中（像素断言：预览图形重心与容器中心偏差 < 1px）。
- 绘画效果：既有画笔/橡皮的金图（`painting-performance` 与画笔库回归）在笔刷模型变更后仍通过；新增笔尖形状与动态参数至少各一条像素回归。
- 性能：沿用 `PaintingBenchmark` 的固定压感输入，比较改动前后每笔耗时与帧间隔，回归记录写入验收文档；不达标不合并。

# 参数与资源布局验收

2026-10-19 Windows Release，对应[设计](../../../brush/ui/brush-settings-resource-layout-design.md)。

公共`ParameterSlider`已用于双重笔刷、相对百分比、纹理、笔尖、传递、湿混、平滑和描边。标题/减号输入框加号同排、滑条下一排；支持小数，百分比输入仍保留比滑条更大的范围。窄面板首次测试发现输入框溢出，限制行最小宽度并恢复66px输入宽度后通过。

资源选择复用`BrushResourcePicker`，笔尖/纹理/双重笔刷页首显示64px方形缩略图、展开箭头与右侧加减图标。展开后为可滚动方阵，使用GridView可视委托，收起不创建资源网格，不显示图片编号。重命名/保存笔刷、新建/重命名组使用共享`PanelDialog`与`Popup.Window`，按屏幕空间置于面板左右，避免面板裁剪。

Release构建通过；8项Qt专项通过，记录`artifacts/resource-layout-qt.txt`：同排几何及资源入口优先、独立弹窗的实际窗口身份与面板旁落点、已有笔刷小数、相对百分比、实际资源缩略图/选择/新目录像素、双击改名、纹理键盘输入/预览/交换、分类延迟创建，以及整笔描边回归。相关用例无QML警告。未运行全量check、跨平台、实体设备或GPU。

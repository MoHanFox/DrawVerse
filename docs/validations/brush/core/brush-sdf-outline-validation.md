- 旧核心描边13项通过（参数4、文档7、已有笔刷1、分页预览1）：距离带与独立穷举参考、画布外形状、纹理/位移/选区/透明锁、同色绘画、单历史、取消、尾部重放、分页与资源错误回滚。旧建路径移除重复EDT，使用共用的列→行变换。

- Windows Release旧描边Qt三项通过（另含初始化/清理共5通过）：真实预览/颜色像素/历史/保存重开、资源进入新目录、state41/复制/重置及非法参数原子拒绝。格式与生成头检查通过，完整Release与QtUI目标重建通过，产物 `build/qt/bin/Release`；ABI1.69、state41与VBR1.0不变。

此步只提供CPU算子并接入旧描边距离计算；新SDF尚无设置入口，不代表新算法实际笔触、独立自身纹理或GPU完成。未跑全量/跨平台/实体输入。

## 第二步：自身描边独立纹理

- 现有建路径已支持自身来源的独立纹理，主笔刷texture不改；资源选择/导入、空间、深度、独立开关和移除已接入。异步角色4捕获目标和自身来源，角色3仍为原纹理来源，完成时不根据当前选中预设或来源猜测。
- IO描边4项通过（新增1项、资源往返旧用例扩展自身来源）：state42/旧state41拒绝、旧编码保持、启用与关闭参数、资源新目录、VBR实际像素及旧行为元数据规范化。黑色纹理擦除蓝色描边而主红色像素保持，纹理禁用恢复原描边。
- Windows Release Qt新增2项及旧入口1项通过：实际QML角色、白色预览、两色真实像素、单历史撤销重做、VBR导入新资源目录、最近快照、重启恢复、非法旧state原子拒绝；异步切换来源/预设仍回填捕获目标，已有资源重选及移除。另含初始化/清理共5通过。
- 原生描边2项、严格Clippy（ops/core/IO/FFI）、格式和生成头检查通过。ABI1.70支持state42，VBR1.0/behavior34与`outline-self-texture`；原模式仍state41/behavior33，没有新增GPU计算。
- 工作流整组30通过、软件后端GPU专项1跳过，无失败；四C/C++静态/共享ABI消费者通过，完整Release重建通过，产物 `build/qt/bin/Release`。未跑全量、跨平台或实体连续输入。

新SDF算法仍仅完成算子，尚未接入实际笔触/缓存/算法选择；最终笔刷GPU覆盖文档将在该算法接入后更新。

## 第三步：实际 CPU 笔触与缓存（2026-10-20）

核心新增 OutlineAlgorithm::Sdf，独立执行 A→SDF→等距线→max 印章→位置遮罩→一次预乘着色。灰度瓦片 max 保形，缓存 A/场/遮罩，覆盖变化及起收笔回放失效。自身/已有图片笔尖和独立纹理复用既有采样，旧 Path 默认不变。

新增实际笔触两项验证三位置、AA、半透明重叠不上色加深、单历史/撤销重做/取消及独立图片/纹理；新增缓存单元验证灰度保留、身份复用、形状增长失效和取消释放。起收笔分页比较扩展到两算法。核心描边4+9+1+1及内部3项通过；新采样调整后两项复跑通过，严格 Clippy 与格式检查通过。该提交只接核心，设置、交换版本及 Release 将在下一小项验证；无新增 GPU 计算。

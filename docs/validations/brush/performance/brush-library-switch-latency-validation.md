# 大目录切换与起笔延迟验收

2026-10-19，Windows Release。设计见[大目录切换与起笔延迟](../../../../brush/performance/brush-library-switch-latency-design.md)。

Qt 使用公开许可的148项ABR样本导入三次，含默认项共448项，真实Main窗口、后台执行和心跳计时；不是用户约32MB/400项的原包。

| 两轮各8次 | 修改前 | 修改后 |
| --- | --- | --- |
| 总时长 | 406/412ms | 330/331ms |
| 最长同步起笔调用 | 24.404/24.430ms | 14.267/13.403ms |
| 最长选择调用 | 1.530/4.323ms | 1.530/4.769ms |
| 最长GUI心跳间隔 | 35/38ms | 27/32ms |

切换本身没有稳定改善；本样本未复现严重卡顿。起笔减少重复JSON构造/解析；后台仅选择变更复用成功目录预设，资源量较大的原包收益仍待实机复核。

最小验证：Qt上述448项切换/真实起笔、3x148导入/滚动、整笔描边实际像素与新目录交换、闲置资源重新选择、512项参数连续修改、多文档创建/退出保存、重开重置与在途捕获，共7项通过。原生新增1项确认预设Arc相同、参数编辑重编译、无效选择与重复JSON字段拒绝、失败后恢复；原生既有66项含图片/来源回收及冷重建均通过。Release Qt构建和自动生成ABI头检查通过。

未跑全量check、实体设备、跨平台或GPU；用户原包的短时强卡顿尚不能宣称完全解决。

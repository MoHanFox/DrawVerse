# 笔刷分组Rust目录验收

2026-10-17，Windows。对应[设计](../../../brush/library/brush-groups-design.md)。本阶段完成不可变组织模型和真实BrushCatalog操作，未接有组状态的保存交换、原生操作和Qt文件夹界面，不宣称分组已可跨重启或VBR往返。

BrushOrganization持有有序根/组子项及深度优先预设投影，BrushCatalog.ids与其同步。组UUID/名称、唯一成员和可达性/层级/数量限制均在发布前验证；编辑组织不重建BrushPreset、程序或资源。已有平目录默认与恢复顺序保持。组内复制/批量导入、成员移位、解组和级联删除通过候选状态原子采用，成功仅推进一次revision，无变化保持原Arc与revision；内置预设子树保护和选中删除回退沿用既有语义。

实际结果：

- 新组织集成6项通过：混合根/子组的DFS顺序、组移动与成员提升后的实际ids、快照保留、同名组/重命名无变化；环/自身/后代移动、多父/重复/孤立/未知引用、身份冲突、非法位置/名称/UUID及不完整成员集合均拒绝且原状态/Arc保持。
- 准确边界：8层组可含预设，第9层拒绝；256组加1024预设/1280条目可用，再增组或预设拒绝；非法原始组织超条目及81字符组名拒绝，80个Unicode字符接受。树遍历使用有界迭代栈。
- 复制追加选中预设所属组并保留来源/共享不可变资源；普通导入仍追加根、显式导入追加组，重复/组ID冲突/未知目标和资源预算失败均不半导入。删除单成员保留空组，解组原位提升子项/保留顺序，级联含内置成员整项拒绝。真实图像笔尖在途捕获在用户子树被删除后仍完成，完整像素/单历史及undo/redo与参考保持。
- 新修订边界单元1项通过：revision耗尽时复制、移动、删除成员和整个子树在候选修改后仍不发布；真正无变化的组织替换和组名规范化可成功而不推进修订。
- 原目录集成5项通过，覆盖参数/来源/捕获、原子导入/复制/删除、1024容量和共享资源预算；默认平目录行为保持。
- 旧状态IO共5项通过（新保护1/旧4）：有组（包括空组）编码明确Unsupported，旧未知groups字段拒绝；解组后原始平目录字节完全相同，平根重排可准确保存/恢复且不升级格式。唯一接收BrushCatalog的旧序列化入口已保护；既有显式包JSON解析边界保持。本阶段没有新增任何可读的分组JSON字段或包能力。
- 既有公开原生目录2项通过；paint-core/paint-io/paint-ffi全目标Clippy `-D warnings`通过。最终Windows Release/生成头字节检查及4项C/C++ static/shared ABI通过，无ABI/state/VBR版本变化。
- 既有Qt程序预设/真实预览/光标/像素持久化及图片导入/在途捕获2项通过（含init/cleanup为4 passed）；它们仍使用平目录，不是分组界面验收。未跑无关全仓、跨平台或整体硬件手感；后者由用户自行进行。

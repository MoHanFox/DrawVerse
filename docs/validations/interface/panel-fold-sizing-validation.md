# 面板折叠尺寸验收（2026-10-11）

设计见 [尺寸保持](../../interface/panel-fold-sizing-design.md)。

## 问题与修复

- 真实回归基线：工具栏与画笔列同处浮窗，收起画笔列后，工具栏从 36px 膨大为 389px。紧凑图标列分配覆盖了工具栏的固定宽度。
- 工具栏宽度最终优先应用，仍受 36–72px 用户宽度约束；收起前共享布局记录相邻面板尺寸，浮窗按新内容宽度收窄，保持位置和高度。展开恢复原宽度，纵向余量不分给其他面板。
- 保存/恢复浮窗的通用几何函数曾强制最小 150px，导致 67px 的工具栏/图标列组合恢复后变宽；读取已验证浮窗几何时允许 36px 下限，实际窗口仍按内容最小值限制。
- 布局 v6 的可选 retainedWidths 与既有 retainedHeights 配合；未知/越界尺寸忽略，旧布局不要求这些字段。取消拖动恢复尺寸快照。用户主动调整窗口或分割线解除对应方向的尺寸保持；工具栏和图标列仍保持自身规则。
- 旧的已折叠布局从保存的展开宿主宽度重建缺失尺寸，加载时就将膨大的组合窗收窄；已有展开尺寸不覆盖。收起状态下调整工具栏宽度，宿主同步改变，图标列保留空间。
- 新 Qt 用例覆盖三种工具栏宽度、反复收起/展开、窄窗保存恢复、独立并列面板宽高保持、两个列依次收起与展开、手动调整后展开保持新尺寸。原生窗口为整数尺寸，分割比例的亚像素尺寸允许小于 1px 的舍入差。

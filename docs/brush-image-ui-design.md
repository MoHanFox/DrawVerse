# 图片笔尖 Qt 接入

沿用独立共享原生库与准确修订，不在Qt解码覆盖或执行绘画。后端启动把资源目录绑定到实际QSettings文件旁的brush-resources；隔离预览库共享同一资源仓库。PNG导入在后端执行，UI只提交本地路径和覆盖解释。参数选项为灰度覆盖、透明度、反向亮度；16位输入成功时说明已量化。

导入捕获目标预设ID；完成时即使切换预设也只修改原目标，原目标已删除则失败。库草稿/多文档同步/保存使用v3 maskResource；资源文件由Rust内容寻址持久化。图片笔尖可恢复为程序笔尖，硬度控件禁用并说明来自图片；圆度/角度/流量/压感仍共用。VBR程序导出对图片明确拒绝，待资源归档阶段接入。

预览以独立库准备包含该笔尖的完整小状态，Rust等待准确修订，避免预览修改画布参数。恢复v1/v2保留兼容；v3缺失资源不得覆盖原配置。图片实际轮廓另作原生轮廓接口阶段，此阶段UI不宣称具有图片轮廓。

验收：导入孔洞PNG后真实笔触/预览、删原图再启动恢复、切换预设不串写、多文档共享、图片副本/参数修改保留ID、程序恢复与VBR拒绝无文件、旧预览/保存最小回归。

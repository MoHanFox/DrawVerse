# 自动描边预设

2026-10-15。基于已完成的paired-dab-v1、relative-size-v1与separated-stroke-v1，不增加绘画算法、ABI或交换字段。双重笔刷/双色绘制页提供“创建描边：跟随压感”和“创建描边：固定边宽”。每次创建新的用户UUID并选择它，不覆盖当前预设，不改变工具混合模式、两色、光标或文档历史；库满1024原子拒绝并显示原因。用户预设可修改/改名/删除/交换，创建时完整定义成为持久resetState基准。

两个模板为24px主直径、硬圆/100%流量/整笔不透明度、10%主间距、大小压感开/流量压感关，第二同路径配对、同形状/线性大小压感、流量压感关，相对直径+8px、第二背景色/正常贡献/主后方/允许溢出。固定边宽用fixed-width；跟随用follow-pressure。资源、散布、形状抖动、色彩动态、纹理和时间平滑均为空，避免沿用当前笔刷破坏均匀边宽。默认有约4px硬外边；跟随模式宽度随压力缩小，固定模式保持4px（合法尺寸夹限除外）。现有边界1..512px不改。

按钮1000ms提示，保留重置仅来源与兼容。原模板无需升级旧库强制增加内置项，也不丢失已有库/基准。实际两色由工具起笔捕获，VBR不嵌入当前颜色。

验收：两模板默认字段、当前自定义预设不变/唯一ID/只一次发布、关闭编辑后重开完整重置/导出导入、1024上限原子拒绝；真实Qt点击并真实预览、压力0.5下主线与4px/2px边宽、交叉/回笔内部不混第二色、整笔低opacity不加深、单历史/undo/redo及独立导入客户端像素一致。仅相关最小回归，复合光标、非分隔绘制及湿混等继续后续。

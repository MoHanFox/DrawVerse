# 独立不透明度压感

尺寸、流量、不透明度是独立控制。BrushDynamics 新增 opacity 曲线及 pressure_opacity 开关，默认线性/关闭，旧预设保持行为。普通绘画/橡皮/蒙版每印章的压力响应限制局部整笔覆盖；较高压力可提升覆盖，后续较低压力不反向变浅，重复相同压力不会突破对应上限。流量控制向该上限靠近的速度；选区和颜色 alpha 在最终合成应用。涂抹保持强度语义，不套用此压力上限。

沿既有覆盖瓦片保存每像素已达到的响应，使用原始像素重建；与默认整笔不透明度共享事务、分页、取消和历史。不可变程序在起笔捕获开关与曲线，不读取在途 GUI 编辑。位置不变但压力变化时补一个参数印章，不推进间距相位；相同压力事件不引入喷枪式累积。

状态 v6 在 pressureDynamics 中增加可选 opacity 对象，含 curve/minimum/enabled；缺失默认关闭，显式 null/坏开关/旧版本携带新对象拒绝。保留关闭时编辑数据。VBR1.4 / behavior3 / opacity-pressure 能力仅在有新对象时输出；原1.3两控制对象保持行为2，旧格式不升级。ABI1.36新增能力位，无DTO布局变更，旧C参数编辑保留动态。Qt传递分类增加不透明度压感和共用曲线编辑器。

验收：真实压力升降、同压力往返、流量独立、像素/蒙版/擦除/图片/选区与取消历史，旧配置像素不变和在途快照；有界IO/旧版本拒绝/关闭数据保留/整包交换与原生准备，Qt开关、编辑、真实预览及VBR往返。未支持其余随机/设备动态及湿混仍按总体计划推进。

# 图层移动实时预览

## 目标与契约

移动工具和 Ctrl 临时拾取移动在按下时确定目标，拖动使用相对起点的绝对整数位移；更新不写历史，松手仅提交一次现有移动命令，Esc、失去输入抓取或窗口停用取消。空白拾取不移动先前活动层。保持位置锁、组/蒙版共同移动、画布外像素保留及原有撤销语义。

核心提供 begin/update/commit/cancel 会话，只捕获受影响层的原始外观元数据，避免为每次拖动复制所有图层瓦片表；预览偏移从不可变基线计算，全部目标校验成功才发布。取消恢复原始外观；提交先恢复再调用现有 move_layer，避免累积误差和重复历史。会话期间其他修改拒绝，保存也不能捕获临时状态。

## 共用呈现与输入

普通平面 Normal 图层栈复用液化的原图/下层/上层常驻纹理和 x/y/u/v 网格包，移动只需 2×2 网格，不读取或重采样像素。源纹理包含画布外瓦片和透明边界。组、蒙版、裁剪、特殊混合、置入图片和软件渲染采用 CPU 像素预览，保持功能一致。交互结束后保留最后预览，待最终像素帧接管。

ABI 1.63 增加移动会话操作、会话标记和通用 resident preview 查询；保留 ABI 1.62 液化入口和包格式。Actor 只合并相邻的绝对移动更新，提交携带最终位移并保留队列关闭屏障。Qt 在一帧中合并最新输入，快速按下/松开也能有序关闭。鼠标和平板使用同一链路。

共用源切分一次构造原图/上下层快照，避免三次克隆整个图层栈。后端能力读取当前窗口 `rendererInterface()->graphicsApi()`，窗口绑定与场景图初始化后通知 QML；不能把全局 `QQuickWindow::graphicsApi()` 配置当成软件场景图的实际后端。

GPU 用于纹理变换与合成，整数位移本身无需 wgpu 计算算子。CPU 与 GPU 共用文档偏移/历史语义；不将 GPU 输出回读用于交互。

## 最小验收

- 核心：更新可见而历史不变；提交单历史、撤销/重做正确；取消恢复；锁定拒绝；组/蒙版语义；画布外往返；四顶点常驻来源复用。
- ABI/Actor：有序 begin/update/commit/cancel，绝对更新合并，最终位移和容量查询，旧液化回归。
- Qt：松手前真实像素/常驻预览随动，松手单历史、Esc 恢复、Ctrl 拾取及软件回退；Windows Release 构建。
- 不以自动化运行时间代替实体鼠标/平板的持续手感结论，不运行无关全量测试。

## 代码入口与使用

- `core/crates/paint-core/src/document/tools/layer_move.rs`：基线、原子外观更新、提交和取消；`liquify_preview.rs::resident_source`：共用不可变源切分。`ResidentPreview` / `ResidentPreviewSource` 与旧液化类型保持兼容。
- `core/crates/paint-ffi/src/engine/session.rs`：移动操作、绝对更新尾合并、关闭屏障、共用常驻资产缓存和渲染调度；`document/layer_api.rs` / `liquify_api.rs`：ABI 会话/共用包查询。
- `ui/src/engine/PaintCoreClient.cpp`：16ms 最新输入槽、开始确认/最终关闭、共用资产与网格取帧；`ui/src/canvas/CanvasItem.cpp`：鼠标/平板、Esc/失焦取消；`LiquifyPreviewNode.cpp` 的材质供两个工具复用，未另建 shader。

使用 V 移动工具，或按住 Ctrl 点击可见内容后拖动。无需 GPU 计算开关，显示加速跟随 Qt 图形后端；设置中的 CPU 选项只控制 wgpu 算子，整数移动不派发计算算子。软件后端和复杂图层栈自动回退。

静态预览纹理按当前视口物理密度构建，最高2048px，之后同源复用；空显示切片可为1×1透明纹理。不是跨所有会话的永久缓存。该代理不得低于当前视口需求对应的清晰度，结束后普通视口帧接管。所有像素与置入图片原始模型保持；未把普通通用合成器改成 GPU 后端。

## 2026-10-22：移动源后台预热

移动首次读取三张常驻纹理时，普通合成器会先合成源区域再生成LOD；大图即使只需要视口代理，也可能遍历全部源像素。复用复杂移动已有的稀疏按行采样，按两个显示视口中较高的物理像素密度选择代理尺寸，并沿用最高2048px上限；空显示切片用1×1透明纹理。切换移动工具或目标图层/多选集合时，ABI1.80后台准备入口捕获不可变源并生成/解码三图包，Qt在正式拖动前预热同源纹理。准备结果严格绑定generation、revision、有界目标ID集合和请求ID，任一变化即失效。

首次按下时若预排已就绪，BEGIN只绑定源，后续拖动只更新四顶点，不重新合成或上传高成本资源；若尚未就绪，保留当前完整分辨率画布并立即接收输入，由普通完整帧路径更新，不能退回512px或其它模糊移动纹理。准备完成后不会把旧revision结果贴到当前拖动上。验收覆盖选择工具后直接拖动、首次拖动、组/蒙版、取消、提交、单条历史、软件/D3D11及2倍DPI；构建、预热和窗口抓图计时必须分别记录，均不得称为实体端到端输入延迟。

实际平台检查与限制见[验收](../validations/tools/layer-move-preview-validation.md)。


## 2026-10-20：完整根子树与连续多目标移动

当前移动会话的 CPU 已只改 appearance，但包含组、自身蒙版或多目标时，GPU 预览仍整体回退，每次位移重新合成画布。为移动单独提供完整子树常驻源：按归一化根目标抓取完整连续区间，包括所有子层和链接蒙版，一次合成带透明边界的静态源，拖动仍更新四顶点。原瓦片与层身份保持，最终只提交一次既有 metadata 历史。

只接受可独立 normal-over 合成的根区间：普通 Normal 根层；Normal 隔离组；所有后代采用 Normal/PassThrough 的透传组。Normal 隔离组内部非 Dissolve 的特殊混合/剪贴仍通过原 CPU 合成源，保持原语义；透传组若依赖区间外背景则回退。上方继续禁止剪贴及特殊混合，所有目标必须连续，不得把中间未选层一起移动。全部蒙版必须链接；解除链接的蒙版需保持固定坐标，不能预先合并后一起平移，因此回退。组内单子层、置入源、非连续多目标及依赖画布坐标随机数的 Dissolve 保留既有路径。

使用子树内非蒙版像素的绝对 bounds 合并源边界，含画布外瓦片；源快照内统一平移所有非组节点（包括蒙版）到局部坐标，保留组织与属性。下层/上层抓取完整区间外子树，CPU 参考与 Qt 渲染复用现有静态纹理协议，无新 ABI 或 GPU 计算算子。液化不会跟随复合蒙版变形，不能复用这项移动资格；自由变换另行适配。

验收：源静态合成与实际位移文档比较（含半透明/负坐标/组不透明度/内部剪贴与特殊混合/链接蒙版/连续双目标）；多次更新不改源身份、不复制目标像素；取消与提交/undo/redo保持。未链接、依赖背景透传、非连续、多目标组内及上方剪贴拒绝快路径。硬件真实窗口验证组/蒙版/连续多选跟随、软件仍走原像素路径；首次源构建与4K实体延迟另行测量。

## 2026-10-21：组内普通子层常驻

移动专用源可穿过可消去的祖先组：可见、100%不透明度与填充、没有自身蒙版/剪贴、Normal或PassThrough。Normal祖先的子树还必须全部为Normal/PassThrough且无剪贴，避免把隔离的特殊混合错误暴露到外部背景。在私有显示快照中将祖先设为不可见空壳，提升其直属子树；原图层结构、属性、瓦片与历史完全保持。索引和后序区间不变，复用已有完整子树切分、三纹理和四顶点协议。

两级组内的单层及其链接蒙版因此可以常驻；带有效组蒙版、半透明祖先或背景相关混合仍回退，以保持像素语义。此项不改变液化或自由变换资格、ABI与GPU算子。

上述复杂组合的移动回退已改用[有界CPU交互采样](layer-move-bounded-fallback-design.md)，避免每次拖动完整合成全部源像素；确认和取消后恢复普通完整显示。

2026-10-21后续：祖先消去现在抽为移动/变换共享的 `resident_hierarchy_source(ids, originals)`。移动传空覆盖，变换传会话原层，私有分割保留提升后的parent；不扩大液化资格，也不改变移动最终偏移/结构/历史。组内变换范围和回归见[变换设计](transform-resident-preview-design.md)及对应验收末节。

移动纹理不得以降低用户可见画质换取预热速度。视口物理密度低于2048时按实际密度生成，高于上限时才使用2048px；资源准备耗时与鼠标按下后的四顶点显示耗时分开测量。拖动期间与松手后的完整显示均使用原始层坐标、像素和历史模型。

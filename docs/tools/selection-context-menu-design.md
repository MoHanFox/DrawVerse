# 选区右键菜单（2026-10-30）

存在选区且文档空闲时，画布右键打开 GlassMenu。菜单绑定所属 CanvasPane 的 ownClient，浮动画布与多文档不通过全局活动客户端执行。仅接收右键，不截获绘画左键；编辑、文件操作及选区消失后关闭。右键本身不进入历史。

第一批实际接入取消选择、反向选择、自由变换、扭曲与透视；后三项进入原权威变换会话并设置现有控制层模式。参考图中羽化、通过复制/剪切创建图层、变换选区、填充与描边仍需核心事务，不能用整层复制或画笔替代，也不能用当前选区工具的羽化参数冒充已存在选区的羽化。

验收：无选区无菜单；有选区真实右键显示且不增加历史；取消选择执行核心操作并关闭菜单；变换沿既有会话/确认取消规则。新增 Qt 用例 selectionRightClickMenuUsesOwningDocumentAndDeselects；其余待补。

验证记录：qt_ui_tests Release 构建成功；offscreen/software 新右键用例通过（3 passed 含初始化和清理）。先前两种级联菜单行也通过。首次新增用例错误使用 QQuickItem::isEnabled() 检查 MouseArea 自有 enabled 属性失败，改读实际属性后通过，原日志 selection-context-validation.txt / selection-context-recheck.txt 保留在 build。最终日志 selection-context-final.txt。最终与调整画布一起复验软件及实际 D3D11 均通过；TapHandler 仅接收右键且不覆盖画布工具/空格导航光标。未做实体右键或参考图其余核心功能验收。

按用户后续要求移除右键“扭曲”和“透视”，保留取消选择、反向选择、自由变换。其余参考项仍待实际事务接入。

## 2026-10-30 选区事务与模态窗口

“调整”整体移到滤镜的第一项级联菜单，曲线、色阶、HSL 的入口、快捷键与原有调整会话保持同源。编辑→图像保留画布调整和旋转。

右键增加羽化、通过复制创建图层、通过剪切创建图层、填充、描边。每个 CanvasPane 创建自己的 SelectionEditWindow，绑定 ownClient 和所属 QQuickWindow，Qt.ApplicationModal、透明标题栏、拖动标题、相同面板配色；Escape、关闭和取消不提交。确认通过队列发送一个操作，等待回执关闭，失败保留窗口和错误。右键不包含扭曲和透视。

核心入口 Document::edit_selected_pixels：

- 羽化栅格化当前组合选区（包含减去、相交、反选与原羽化），对覆盖做三次可分离盒滤波近似 Gaussian，结果保留为单个渐变蒙版。仅修改当前选区，不修改后续选区工具的羽化设置。局部边界扩展三个滤波半径并裁到文档，沿用现有 16MiB 蒙版和 1MiB 文本编码预算。
- 复制/剪切建层作用于当前内容层，保留画布偏移和选区 alpha；剪切同时清除原层相应覆盖。完整前后图层森林用 LayerEdit 结果历史一次提交，ID 集合变化时恢复完整森林，普通像素结果仍按已有 ID 替换。复用已有分页结果和编码后备，不把复制与粘贴拆成两次历史。
- 填充使用前景/白/黑颜色、0–100% 不透明度，在预乘线性空间 source-over，仅修改选区覆盖；描边为内侧描边，宽度 1–1000px，使用可分离的精确平方欧氏距离场形成边带，同样支持颜色和不透明度。
- 当前要求普通内容层；独立组/蒙版拒绝，锁和预算失败发生在提交前。选区仍保留。置入层在内容修改后转为已有栅格结果，撤销恢复原始来源。

ABI 1.95 新增独立 paint_session_selection_pixels 异步入口、五个操作常量及历史标签 49–53，不改已有 DTO 布局。羽化属于仅选区发布；复制、剪切、填充、描边必须更新像素/图层发布，不能按仅选区优化跳过主画布刷新。

参考图的“变换选区”未属于本次五项接入，仍未增加。当前描边只有内部位置，未声称外侧/居中、混合模式和任意颜色拾取器已经支持。

完整森林 LayerEdit 在内部历史使用 tag 14，独立存储前后图层数量并验证两份森林，原 tag 11 同 ID 子集格式保持不变。冷页/低预算编码后备均可单步回退恢复新建层和原层内容。

# Ctrl 画布选层与临时移动

按住 Ctrl 左键点击画布，按真实像素覆盖命中最上方可见的内容图层；透明区域穿过、隐藏组不命中，蒙版与剪贴基底限制命中。组内命中具体子层。空白不改变选择，也不移动原选层。按下及释放均通过串行内核执行，释放时一次移动，生成一条既有移动历史；点击只选层不增加历史。锁定内容仍可选中但不移动。原工具参数和选区保持，液化、自由变换及空格平移优先。鼠标和数位笔共用，文档切换取消手势。

使用 ABI 1.24 的异步 pick-layer 请求（坐标与位移），避免在 UI 线程读取瓦片。沿用现有整数图层移动和撤销/重做，不复制像素或引入另一个移动系统。

同时修复图层面板异步 Loader 的焦点域：Loader 显式允许子控件获得活动焦点。自由变换数值字段复用图层数值字段的紧凑文本样式（20px、9px 字号），保留小数、负数及提交行为。

最小验收：核心测试透明穿透、隐藏组、蒙版、剪贴、锁定、置入图片、移动历史；FFI 测试真实排队选层/移动；原生 Qt 测试首次点击搜索输入、Ctrl 点击/拖动及工具恢复、变换紧凑输入与数值撤销。

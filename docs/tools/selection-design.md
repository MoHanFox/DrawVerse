# 选区第一模块：几何选区、历史与绘画约束（2026-10-09）

## 范围与方案

本模块实现矩形/椭圆、替换/添加/减去/相交、全选、取消及反选；选区约束笔刷、橡皮擦及像素蒙版绘制。自由套索、羽化、魔棒、选区变换另作后续模块，不放假按钮。

方案对比：整幅 alpha 蒙版不适合百万像素画布；稀疏蒙版适合自由选区，但几何选区仍会物化大量瓦片。首先采用不可变、有界几何步骤（最多 64 步），坐标为文档浮点像素，无逐画布分配。None 表示未启用、不约束编辑；启用但结果空表示禁止绘画，二者区分。新添或相交无已有选区视为替换；首次减去从全画布减去；无选区反选成为全选。替换重置步骤，取消清空。超过预算明确报错，旧选区/历史不变。

矩形覆盖为像素格交集面积，椭圆内部/外部快速分类、边界 4×4 固定采样；可关闭抗锯齿。覆盖添加用 max，减去 max(0,a-b)，相交用 min，反选 1-a，最终仅在文档内有效。笔触开始后选区不可修改；图层位移后仍用文档坐标约束。无选区保留原笔刷快速路径。

选区命令加入统一撤销历史，准备历史成功后才发布状态；无变化不增加历史。磁盘历史版本 DVH6 保存选区步骤。DocumentSnapshot 保存不可变选择身份，导出合成像素不受当前选区影响。ORA 扩展 v4 以有界文本保存选择并校验，读取 v1/v2/v3；载入不产生额外历史。其他阅读器可忽略该扩展，自有格式之后提供完整原生保存。

## ABI 与 Qt

ABI 1.8 增加能力位、独立 repr(C) 选区编辑/状态/步骤 DTO 和 FIFO 编辑、publication 一致性查询函数；原 DTO 和已有函数保持。编辑请求仅传几何数值，不传 Rust 容器；所有 caller-memory 走 pointers.rs，返回错误码与既有错误消息。cbindgen 生成头，新增 C/C++ 大小/偏移断言及异步回归。

Qt 只提交编辑并显示轮廓。M 为矩形，Shift+M 在矩形/椭圆间切换；拖动提交一次，Shift 添加、Alt/Option 减去、Shift+Alt/Option 相交，Esc 取消拖动，Ctrl/Command+A 全选、D 取消、Shift+I 反选。工具条和选择菜单可切换。输入坐标按画布变换映射到文档；通过 Rust 返回的步骤建立轻量 QPainterPath 轮廓，不接触内部像素。无选区时通过 Loader 完全不创建绘制项，避免额外纹理和场景图开销；无选区笔刷采用编译期专用循环。初期使用静态黑白虚线，避免全幅纹理按帧重画。预览拖动不改变文档，松手成功后才更新历史。

## 验收

1. 几何/抗锯齿/布尔组合/空与 None、百万画布有界内存、非法坐标/64 步上限及无变化历史。
2. 绘画/擦除/蒙版受约束，移动图层仍按文档坐标，撤销重做和磁盘历史故障不破坏旧状态，导出像素不受选择裁剪。
3. 既有 ABI 布局保留、1.8 新 DTO/查询、过期 publication、异步编辑次序及错误、ORA v4 回环和拒绝坏选择。
4. Qt 实际鼠标拖动、组合键、选区工具浮窗、缩放/DPI 轮廓与真实受限笔触回归，无 QML 警告。
5. 完整 check、原生视觉和无选区 600 点性能验证；通过后独立 commit/push。插件最后。

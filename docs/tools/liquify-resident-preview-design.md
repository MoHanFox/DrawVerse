# 液化常驻纹理预览

2026-10-19，分支 `feat/wgpu-support`。取代逐输入重采样、颜色读回、瓦片发布的主预览路径；原算子与最终采样规范见 [GPU 算子设计](liquify-gpu-operators-design.md)。结果见[验收](../validations/tools/liquify-resident-preview-validation.md)。

## 数据与职责

液化会话的原图和稀疏位移场仍是权威数据。新增显式选择的 deferred 会话：适用时输入只更新网格和网格历史，不生成预览像素瓦片。完成才执行全精度原图重采样、历史准备和原子采用。现有 ABI 的普通 begin 保持像素预览兼容，CPU、软件 Qt 或不支持的图层组合继续使用它。

Qt 场景图持有一次上传的原图、下层合成和上层合成纹理。核心发布不可变源描述及有界网格快照；ABI 使用 generation/revision/source 身份票据读取，不传递 Rust 或 GPU 指针。每次网格更新不上传源颜色、不从 GPU 读回预览颜色、不触发 CPU 视口渲染。网格位置固定在目标域，纹理坐标由同一逆向场计算；自定义片元着色器在线性预乘空间采样/合成，最后转换成显示 sRGB。纹理和几何只由场景图渲染线程创建、更新与释放。

第一阶段直接预览覆盖无选区、顶层正常混合的普通栅格栈（含图层偏移、不透明度、填充及隐式白底）。复杂组、蒙版、剪贴或非正常混合继续既有像素路径，不以扭曲整幅合成图冒充修改活动图层。焦点显示只切换静态上下层参与；CPU 显式设置、软件场景图始终可用。静态纹理采用有界代理，网格预览最多约 257×257 节点；预览近似不改变最终精度或会话源。

wgpu 执行共享 Elastic 算子，保留网格结果读回作为权威场、历史及发布；消除的是逐输入的颜色重采样/读回和文档像素物化，不宣称零数据回传。Qt 使用自身 RHI 设备和场景图渲染，未实现 Qt/wgpu 原生纹理或设备互操作，手动选择的计算设备不强制切换 Qt 显示设备。进入会话时用一个无颜色的恒等网格请求预热延迟编译；静态图片在后台一次生成，GUI 不承担像素复制。直接预览时后台轮询8ms、平时16ms，空闲不会重采样或持续要求 GPU 重绘。

RGBA8 源先解码为线性预乘，再进行双线性采样与正常 over，最终编码 sRGB，避免分别在 sRGB 空间叠图。源代理可降采样；网格三角插值近似权威双线性场，完成始终使用原始浮点源与完整场。现有全局细化和 8M 网格预算保持，跨大范围的精细编辑仍可能触达资源限制；没有宣称任意细节/画布/操作组合都具有固定成本。

画笔直径支持至 15000px，初始场间距可增至 128px，使大画笔节点数有界；小画笔细化保留旧场与历史。场保留画布外有符号坐标。最终输出只物化与原图可达域相交的场区域，避免大画笔为透明空区创建海量像素瓦片。

构建依赖 Qt ShaderTools 的 `qsb`，`tools/setup-qt.ps1` 会为同版本 SDK 补装该模块；着色器由 `qt_add_shaders` 生成并嵌入资源，不依赖运行时源码编译或 Qt 私有接口。

## 实施前验收条件

2026-10-21增补：选区不再全局关闭兼容普通根层的常驻预览。位移算子按原选区权重更新场，新增Selection::coverage_samples以规则间距按行计算覆盖，场节点和遮罩共用，避免逐节点重新遍历全部多边形边。

后台一次生成文档目标坐标下最长边2048的R8覆盖，ABI1.77的kind2读取，Qt按sourceId缓存并上传第四张静态纹理。片元在线性预乘空间按覆盖混合恒等源与变形源，再执行原上下层合成；焦点模式同样保护未选区域。原图UV的偏移/比例由源边界计算，选区始终在目标文档坐标采样。取消/局部历史只恢复场，确认才按原选区与完整源物化像素。

静态源、遮罩生成和首次上传仍有进入成本。软件后端、自身蒙版、组内及不支持组合继续像素回退。2048代理与覆盖是预览近似；原有粗场下远小于场间距的窄选区可能漏过节点，本轮没有改变该语义或无限细化。15000px仅为无选区用例，不据此声称任意微小选区精确响应。

- 2000px 和 15000px 输入在直接预览会话中不调用 Remap/RemapBlocks，不改变源/图层瓦片身份；完成才调用全精度采样。
- 会话 undo/redo/reset/cancel 恢复场，完成与像素路径产生相同最终像素和一条文档历史；负坐标原图保留。
- ABI 拒绝过期 generation/revision/source、容量不足不部分写入，读取是不可变快照。
- 真实 GPU Qt 最小用例验证纹理显示随网格改变、完成/取消恢复、15000px 输入及有界在途；软件场景图保留既有用例。
- 仅运行相关最小回归、必要生成头/编译和同机定向性能记录，不宣称全量、跨平台或手感验收通过。

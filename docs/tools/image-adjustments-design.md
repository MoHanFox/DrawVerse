# 曲线、色阶和色相/饱和度/明度（2026-10-28）

参考本机 `D:/PhotoCraft/photocraft-main` 的 `compose/src/adjust.rs`、`ui-egui/src/adjust_preview.rs` 与滤镜后台任务。该目录无 Git 元数据，不将其称为某个已核实提交或最新上游版本。独立实现 DrawVerse 的事务、算子和 Qt 窗口，沿用本项目的颜色、分页和历史契约。

## 交互与范围

图像→调整的三项打开独立 `Qt.ApplicationModal`、无边框 `Qt.Dialog` 窗口。复用 PanelWindow 的字体/调色板、Theme 浮窗顶栏和描边；标题栏仅调用系统移动，不连接 Workspace 的磁吸、停靠、几何保存。曲线复用 SpeedCurveEditor，可隐藏最低比例并调整图表高度，旧笔刷默认布局保持。

曲线有 RGB 总通道及红/绿/蓝通道，每通道 2–17 点，沿用直线/PCHIP 节点模式。先应用分通道，再应用总通道，编译 4097 个 RGB LUT 样本。色阶提供输入黑场/白场/中间调 gamma 和输出黑/白场。HSL 提供色相 ±180°、饱和度与明度 ±100%；明度先逐通道趋近黑/白，再计算 HSL 并旋转色相，正饱和度除以 `max(1-s,1/512)`，负值乘 `1+s`。不包含着色、分色范围、自动色阶、直方图、调整层或智能对象滤镜。

当前调整活动普通栅格层，保留自身/祖先蒙版、图层混合和剪贴关系；拒绝组、显式蒙版、置入图及全锁目标。像素 alpha 不变，允许锁透明；选区使用原画布坐标覆盖（含羽化），偏移和画布外内容保持。多选不批量修改，只调整活动栅格层。

## 核心与 GPU

Document 持有原图和候选层的不可变瓦片引用。每次更新从原图计算，完整候选成功后才发布，预览不写历史、不置 modified。确认只提交一次 LayerEdit 和具名历史；取消恢复原图。默认参数不生成历史。历史保存 before/after，撤销重做不重算调整。

CPU 文档仍为线性预乘 RGBA32F；调色时去预乘、转显示 sRGB，执行 LUT/HSL 后转回线性并恢复 alpha。选区混合在原线性预乘空间完成。CPU/GPU 共用数值请求和校验，GPU 是新增 wgpu 计算分支，沿用已有设备、失效禁用和 CPU 回退。统一计算硬件选择 CPU 时不执行 GPU 算子。

每批最多16个64×64瓦片；候选挂入原 PagePool 并 trim，不创建文档尺寸连续图。首版预览（下节修订前）也物化候选瓦片，GPU 每批有结果回读；当前仅 CPU 后备仍使用该路径。 不以功能接通推导端到端提速或大图实时门槛通过。当前驻留预览保留相同目标层/选区/混合语义及最终候选身份。

核心后备时 GUI 只保留一个待确认更新，期间合并到最新设置；确认先处理最终设置，异步失败不提交旧候选。取消等待在途批次完成，当前无批次内用户取消接口。活动调整期间核心拒绝其他业务修改，Qt 阻止绘画和其他编辑入口。

## 2026-10-28 拖动窗口及常驻预览修订

调整窗口保持应用模态且不参与磁吸管理；标题区域单独透明，使用全局坐标拖动。曲线独立控件绘制真实源直方图、灰阶带与方形节点；色阶使用直方图及输入/输出三角手柄，HSL 使用彩色轨道与着色。

参考本地 PhotoCraft adjust_preview.rs：通用 GPU 支持且无选区时，固定原 composition packet，在目标栅格采样后、蒙版/透明度/混合前执行显示 sRGB 调整；复用源纹理及合成资源，仅更新 LUT/uniform。组及剪贴沿原操作流运行。选区或设备/预算不支持时继续核心候选后备。确认才执行最终核心更新并生成单历史；保留本地预览到最终主画布采用，取消直接回原图。新预览身份拒绝旧读回/回调，设备丢失转核心后备。禁止把整个最终合成图调色替代活动层调色。

直方图在 BEGIN 的 worker 上从原层及选区扫描一次，以不可变 publication 提供有界 4×256 桶，不在 GUI 读取冷页。新增 ABI 1.88 直方图读接口与 HSL 着色参数语义，原结构布局保持。

补充：BEGIN 只准备中性的同源显示包，核心确认前不应用调色；源/视口资源准备一次后，持续调参复用页表、轴、uniform buffer 与 SRB。中性设置绕过颜色往返，保证原图显示。HSL 只更新 uniform；曲线/色阶仅在 LUT 内容变化时上传 4097 条查找值，不上传源瓦片，也没有生产预览读回。仍按 DrawVerse 原合成预算在完整文档分辨率执行，然后 LOD；未实现 PhotoCraft 的大图一次性低分辨率代理或可见区域调色。无选区且原通用合成支持的栈可用；有选区、软件后端、CPU 计算设置、设备/预算失败明确走原核心后备。

标题关闭按钮默认透明，hover 为不透明 #e81123，鼠标离开恢复；维持原取消语义。

## 2026-10-28 用户4096×2160拖动续修

用户实际为单栅格层4096×2160、GPU开启、无选区/蒙版；885万像素超过旧419万Qt通用合成前置限制，导致每次预览完整候选。扩展仅覆盖不超过9437184像素、每边4096的单节点栅格计划；其他大图/多节点保持CPU。沿用Rust原有4096瓦片/256MiB pin上限，Qt大图atlas按32列及瓦片数向上分配行（至少原1024槽），增长时失效缓存并重新上传，不越界复用。大图单节点payload上限512MiB，旧小图256MiB保持；进程含在途保守2GiB、CPU源512MiB、租约计账不变，能力/预算不足仍后备。全分辨率调色后LOD，不引入近似代理。

移除弹窗外轮廓。GUI只传有界控制点/五色阶值/HSL值；C++通过既有Rust纯曲线采样ABI编译相同4097项LUT，复用原提交/确认逻辑。调参通过Qt.callLater合并最新值，替代16ms轮询；CPU在途请求仍只合并最新，确认/取消等待回执。

验收：先保留原4096×2160无法取得GPU包的失败；同尺寸密集PNG实际模态拖动在释放前提交GPU，revision/历史不动、持续零源上传/资源重建，最终GPU预览与核心提交比对及撤销/取消保持。检查atlas跨原1024槽、增长后未改源不重复上传，复杂/超范围预算后备；保留原2K诊断与失败日志，不把GPU提交时间称物理显示延迟。

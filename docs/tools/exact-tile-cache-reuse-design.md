## 局部资格

缓存项保存的是合成 Mip。只在一个带显式不可变 Tile 的平面 Normal 层改变 offset、所有其他配置相同，固定贡献无显式瓦片且为空或画布内均匀隐式白时尝试映射。组、蒙版、剪贴、特殊混合、第二个非均匀背景或上层均拒绝。旧项必须在构建时有相同证书；源列表的 Weak 身份、顺序及有效 opacity 必须相同。Weak 保留分配身份，COW 编辑使旧身份失效，不能只比较 layer ID 或不受生命周期保护的裸地址。

按实际 TILE_SIZE 计算相对当前缓存配置的整数平移。旧/新瓦片必须完整位于同尺寸文档中，LOD/格式相同且 LOD 不超过瓦片 log2。采样相位和局部源窗口相同，均匀固定贡献不随位置变化；但数学证明不替代实际浮点/量化验证。保留原 CpuRenderer（零预算、没有可重映射旧项）的完整输出作精确参考，sRGB 字节和线性元素均不放宽断言。

缺项、部分边缘、新露出、越界、资格不明和非对齐位移精确重建。不把画面整体平移、不改变最终位置或参考算法。原 configuration、预算、取消、历史和正常完整帧关闭屏障保持。原项移入独立表避免键碰撞；取消时要么仍为旧表，要么空表/旧配置，要么仅已验证的新表，不提交混合状态。

## 本轮验证增量

补固定非均匀上层、移动后绘画及单独 fill 变化的完整像素/拒绝断言；对齐使用 TILE_SIZE，未按红色、4096 或场景号判断产品资格。原有两格式、代表 LOD、正负/连续移动、边缘/画布外、预算/淘汰、源编辑、蒙版/组和六个确定性取消边界继续验证。

共用原生宿主只增加一个按需非纯色夹具：满幅红色栅格上使用合法笔触生成六个不同颜色的圆斑，半径为尺寸的 0.075，中心比例为 x=0.2/0.5/0.8、y=0.2/0.7。核心图案另包含透明/半透明细节。S3 原 PassThrough 和链接蒙版不改变。共用工具先提交，并应用到准确合并后产品的独立对照工作树。

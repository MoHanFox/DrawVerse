## 局部资格

缓存项保存的是合成 Mip。只在一个带显式不可变 Tile 的平面 Normal 层改变 offset、所有其他配置相同，固定贡献无显式瓦片且为空或画布内均匀隐式白时尝试映射。组、蒙版、剪贴、特殊混合、第二个非均匀背景或上层均拒绝。旧项必须在构建时有相同证书；源列表的 Weak 身份、顺序及有效 opacity 必须相同。Weak 保留分配身份，COW 编辑使旧身份失效，不能只比较 layer ID 或不受生命周期保护的裸地址。

按实际 TILE_SIZE 计算相对当前缓存配置的整数平移。旧/新瓦片必须完整位于同尺寸文档中，LOD/格式相同且 LOD 不超过瓦片 log2。采样相位和局部源窗口相同，均匀固定贡献不随位置变化；但数学证明不替代实际浮点/量化验证。保留原 CpuRenderer（零预算、没有可重映射旧项）的完整输出作精确参考，sRGB 字节和线性元素均不放宽断言。

缺项、部分边缘、新露出、越界、资格不明和非对齐位移精确重建。不把画面整体平移、不改变最终位置或参考算法。原 configuration、预算、取消、历史和正常完整帧关闭屏障保持。原项移入独立表避免键碰撞；取消时要么仍为旧表，要么空表/旧配置，要么仅已验证的新表，不提交混合状态。

## 本轮验证增量

补固定非均匀上层、移动后绘画及单独 fill 变化的完整像素/拒绝断言；对齐使用 TILE_SIZE，未按红色、4096 或场景号判断产品资格。原有两格式、代表 LOD、正负/连续移动、边缘/画布外、预算/淘汰、源编辑、蒙版/组和六个确定性取消边界继续验证。

共用原生宿主只增加一个按需非纯色夹具：满幅红色栅格上使用合法笔触生成六个不同颜色的圆斑，半径为尺寸的 0.075，中心比例为 x=0.2/0.5/0.8、y=0.2/0.7。核心图案另包含透明/半透明细节。S3 原 PassThrough 和链接蒙版不改变。共用工具先提交，并应用到准确合并后产品的独立对照工作树。

有限原生比较：原 S2 三对独立进程；非纯色 S2、小 S1、(385,129) 非对齐 S2、S3 回退和关闭诊断各一对。保留 I/W、实际节奏、完整视口摘要、错误和历史异常，不用新的结果替换旧失败。只在测试/工具中生成场景，正式产品没有测试特殊分支。

## 当前预览验收协议（2026-10-23，测试/观测增量）

不改变缓存或呈现策略。目标仍是未准备移动按住时的 (384,0)、同一张图中原白/红采样，以及后续 Escape/单历史/完整帧契约。

- QWindow 入口改用同步发送的独立 QMouseEvent，登记具体对象与编号、窗口、坐标、按键和顺序；不移动 OS 光标。应用过滤器只将该对象在目标窗口的入口认作计划事件，Canvas 的转发交付不冒充独立来源。其他输入与生命周期事件仍传播，目标阶段出现时前提永久失效，不自动补发。
- GUI 内容/文档/视图状态变化递增代数，防止中途变化后恢复的 ABA。Canvas 另有按需启用的单槽、互斥保护观察，仅在 updatePaintNode 的同步阶段记录实际成功采用的 imageKey 或 resident source/revision、Canvas/窗口、区域及变换；失败发布 invalid，不读取额外的 GUI client 状态，不增加刷新。正常产品不启用观察器。
- 串行 grab 的 request/ready/complete/assertion 必须保持相同 GUI 内容、操作 sequence、输入/内容代数及 render 采用身份。请求之前节点必须已采用对应内容；图像归属于这次同 Canvas 的 grab，颜色坐标冻结在请求上下文。这里证明稳定节点区间中的 item 离屏抓图，不测物理显示延迟，不以 frameSwapped 或完成时 getter 代替关联。
- 保留原12项状态反例，增加旧 imageKey/revision、其他操作、输入/内容/呈现 ABA、取消、换文档/视图及其他 Canvas/grab 的确定性反例；允许新的有效目标通过。JSON判定回归仅证明拒绝条件，仍须有效原生窗口渲染才可形成当前合并建议。

验收只做 before 单独、after 单独、after 原三函数组合各一次；环境前提失效或关联不足时记录并停止盲目重跑。历史 after 缺现场的失败维持 unresolved，独立于当前 READY FOR REVIEW / BLOCKED / VALIDATION INCOMPLETE。不重跑核心/性能矩阵，不制作新运行包。

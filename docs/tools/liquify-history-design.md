# 液化会话撤销与重做

ABI 1.22 增加液化笔触开始/结束、会话撤销/重做操作。按完整笔触记录，重置也可撤销；空笔触不记录，新笔触丢弃会话 redo。步数沿用文档 max_history_commands。会话记录保存像素瓦片差异与位移场差异，位移场使用既有校验/内存预算/暂存盘 payload，像素使用既有分页瓦片，不保存整张图像。

文档正式 History 不变；发布时根据液化状态选择会话历史或文档历史。退出自动释放会话数据，取消完整恢复正式 undo/redo，确认只追加一条液化。历史面板进入时保存滚动位置并取消待回放目标，退出恢复原滚动位置；当前条目由文档正式历史恢复（确认时指向新液化）。不把临时记录复制到正式面板模型。

Ctrl+Z / Ctrl+Shift+Z 路由到当前历史域，输入框保留文字编辑。液化时 [ / ] 改液化直径（1–2000px），普通绘画改画笔半径。无新增菜单按钮。会话撤销重做是严格渲染屏障。

最小验收：核心整笔触/分支/步数限制/位移恢复/重置/正式历史隔离/暂存失败；FFI 新操作、会话历史发布和 ABI 版本；Qt 鼠标与快捷键、历史域恢复及 [ ]。保留现有液化回归。

# 框选与套索绘画/擦除性能验收（2026-10-11）

完成共用扫描线覆盖与文档内有界缓存：矩形/椭圆框选、自由/多边形套索的画笔、橡皮及蒙版使用同一路径。缓存最多 4096 个 64 像素行块，覆盖载荷上限 1 MiB，另有有界容器开销；不进入快照、历史或文件。选区编辑、初始化和历史恢复清空缓存，图层偏移按文档坐标查询。无 ABI/文件格式变化，保留原路径、奇偶规则、AA、羽化与组合算式。

## 同机 Release 对照

基线为 `ab2693a` 的真实源码检出，仅加入同一 `selection_performance.rs` 基准；构建目录与当前源码独立。1024×1024 透明文档，半径 32、间距 0.15、不透明度 0.5，120 次移动采样。套索为 4096 点圆形路径，羽化 8 像素。橡皮先在无选区文档绘制真实底图。每轮结束后撤销恢复相同像素；首轮包含覆盖冷缓存，后两轮重用缓存，表中总计为三轮合计。测量顺序执行，避开构建与 Qt 测试负载；这些数字是本机固定负载实测。

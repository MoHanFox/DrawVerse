# 选区常驻遮罩与 GPU 蚂蚁线

## 问题与职责

选区几何已从导航更新中分离，但原 QQuickPaintedItem 每 80ms 仍对整个复杂路径描两次边，缩放和平移也重复栅格化。CPU 继续负责选区发现、布尔路径和完整精度的选区数据；Qt GPU 负责已确认选区的视图变换、屏幕像素宽度边缘与黑白动画。

## 数据流

SelectionOverlay 增加静态 maskOnly 模式，只在选区/文档变化时将路径填成文档坐标的白色 alpha 遮罩。计时器只通知相位，不重画该遮罩。SelectionPresentation 通过既有 Qt ShaderEffectSource 机制保留纹理，片元 shader 按 documentRect 逆向定位，使用屏幕导数计算两档边缘带与 4px 黑白条纹。导航只更新 shader 参数，不改源项的文档几何；预览橡皮线继续复用原 CPU 小路径。

原选择覆盖率、灰度 alpha、撤销与文件不变；显示使用既有半覆盖几何，低倍缩放采用 mipmap 抑制密集细节混叠，不能把视觉简化解释为删掉选择细节，也不能把该显示机制称为魔棒核心 GPU 计算。

## 边界与预算

首版只在实际窗口 GPU 后端、宽高均不超过 4096 的文档启用，纹理大小显式为文档尺寸，不随 DPR 增大。软件或更大文档复用原向量路径。每个可见画布至多 4096² 遮罩及捕获纹理；隐藏画布卸载展示组件，避免每个后台文档保留大纹理。按 RGBA8 估算，4096² 的 CPU 绘制图、场景图纹理与含 mipmap 的捕获纹理合计约 213MiB（不含驱动额外分配），4096×2160 约 113MiB；这是显示预算上界，不是整程序占用。初始 mask 构建仍可能耗时，不宣称其已消除。

## 验收条件

软件路径、既有几何与相位回归保持；真实 D3D11 显示复杂 4096×2160 选区，动画有黑白边缘且中间透明。连续导航和相位推进期间 mask 的实际栅格化计数不增长，路径身份保持；灰度、孔洞/岛和大文档回退可复核。仅记录固定样本，不外推所有设备/输入延迟。

验收见[Windows 软件与 D3D11 回归](../validations/tools/selection-resident-ants-validation.md)。

# 大尺寸液化采样与基准

2026-10-19，处理[用户反馈](../planning/brush-feedback-execution-design.md)中的大尺寸液化卡顿。

先记录纯核心的固定输入基准，再记录Qt提交与帧完成耗时，不通过CPU/GPU占用推断原因。保持现有2000px尺寸、800万次单输入访问、8192位移瓦片、选择区/图层偏移/历史/失败原子性。不得用降低分辨率或减少采样替换像素等价优化。

当前每个像素对位移场和原图分别做双线性采样，四个相邻样本通常位于同一个64×64瓦片，仍重复计算坐标、查询缓存；原图缺失瓦片未缓存，在大片透明或隐式白底区域重复查询树。拟增加同瓦片四样本路径与缺失瓦片缓存，跨边界继续逐样本读取。保留原浮点混合顺序、原图分页固定上限和错误传播。

验收：与原四次读取的参考逐样本一致，覆盖负坐标、瓦片边缘、空瓦片、白底边界和分页；四工具/选择区/偏移/局部与总历史回归；固定2048×1536图案，半径128/512/1000与相同输入的时间和RGBA位摘要。Qt最大尺寸实际液化/帧发布/撤销重做与取消通过后才报告用户入口通过。实测见[专项验收](../validations/tools/liquify-large-brush-performance-validation.md)，阶段状态见[反馈验收](../validations/planning/brush-feedback-execution-validation.md)。

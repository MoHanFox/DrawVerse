# 长任务真实进度与延迟显示（2026-10-20）

范围：液化完成、自由变换完成和整图翻转，复用现有后台 actor、原子候选与64×64瓦片分页。短任务默认不弹出，超过设置中的延迟（默认1000ms，0–10000ms）才显示画布中央进度。每个文档及浮动窗口使用自身客户端，避免错显示其他文档的任务。

Rust核心提供可选线程安全 ComputationProgress；未接入时不增加瓦片锁或改变算法。实际采样/选区物化/历史比较循环按完成的瓦片或批次报告计数，阶段切换重置本阶段总数；准备、压缩历史等无法事先确定总量的阶段只显示不定进度。百分比明确为当前阶段，不合成虚假的全局百分比。计算仍使用原有有界瓦片/源缓存/紧凑GPU批次和临时存储，完成全部候选及历史写入后才提交；资源失败沿用原事务恢复和错误回执。

ABI增补独立只读的任务进度快照：任务序列、文档generation、任务种类、阶段、阶段序号、完成/总单位、实际运行毫秒、运行/成功/失败状态。它使用独立短锁，不等待actor完成或依赖已完成publication；调用者内存由指针边界层校验，失败清零。GUI后台轮询共享快照，依据任务耗时与偏好延迟显示；完成或失败立即隐藏，普通错误显示保持。既有液化无延迟不定进度移除。

延迟是Qt偏好，不写入绘画文件、state或VBR；偏好保存后同进程所有文档即时同步，重启保留。没有新增GPU职责：进度反映CPU/GPU共同任务的实际完成批次，不从GPU利用率推算。

验收：真实长计算期间可从另一线程读取中间计数，完成/失败状态正确；计数不超过总量、阶段内单调、无reporter的像素/历史一致；液化/变换/翻转低瓦片预算失败不破坏事务；短任务不显示、延迟设置0显示并保持GUI事件循环响应，完成/失败隐藏，多文档及浮动画布归属和偏好重启；四ABI、格式/生成头/Clippy及Release。分阶段进度不承诺严格总耗时估计或任意单瓦片完成时间。

偏好写入在GUI线程串行处理（仅用户修改设置时），各文档同步只恢复值、不重复写盘，避免不同后台线程的旧值覆盖最新选择。

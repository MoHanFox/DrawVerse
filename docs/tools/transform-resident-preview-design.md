# 自由变换与网格变形的常驻预览

2026-10-19。目标是解决拖动时画面滞后：交互只计算几何，确认才重采样原始像素；CPU与GPU职责分开，软件及复杂组合保留CPU像素路径。

参考 PhotoCraft `d95fdf3181c01ad41e95456091a394b105a9afb2` 的 `ui-egui/src/transform_tool.rs`、`transform_tex.rs`、`warp_preview.rs`：会话保留源纹理，控制点改变有界细分曲面，最终算法独立执行。DrawVerse 保留自己的4×4插值Catmull曲面与投影变换，不把液化Elastic位移场冒充控制点变形。

改造前 `Document::update_transform` 每次遍历目标像素；warp逐像素Newton求逆，代价随输出面积增长。Actor虽已合并相邻绝对更新，执行中的整图操作仍阻塞后续输入。

## 实施与边界

### 2026-10-21：变换框忽略附带蒙版

选择图层、组或多个图层时，初始控制框只合并被变换的非蒙版源内容；附带的图层/组蒙版不扩大框，也不以遮挡后的合成alpha缩小框。链接蒙版仍捕获为独立原始源，照常参与显示、确认与历史；解除链接仍固定。显式选择蒙版本身进行独立变换时仍使用该蒙版的内容边界，已有选区变换保持选区几何。常驻显示纹理继续保留合成外观，纹理边界与控制框通过现有世界坐标UV映射，不裁掉被遮挡的原图内容。

### 2026-10-20：无关组与蒙版不再关闭预览

共享 resident_source 的原判据要求整栈完全平坦，导致根层变换、液化、移动因任意无关组/蒙版退回逐帧像素计算。改为检查真实分割边界：移动目标仍为普通、无自身蒙版、非剪贴的 Normal 根层；其下的完整子树可整体缓存，其上的完整子树必须能表示成固定 Normal-over。此步允许上方 Normal/穿透组及蒙版，下方允许完整复杂栈；上方剪贴或特殊混合继续回退，目标在组内/带蒙版、多目标和选区仍另行接入。

不拆散组和蒙版，不改变最终物化/历史。以半透明嵌套组、图层/组蒙版的真实合成比较证明三张静态资产可重建原图；变换持续更新保持源与瓦片身份，确认像素对比原 CPU 路径，取消/历史保持。此项不声称所有组和蒙版变换性能已完成。

- 显式deferred开始入口；兼容单一普通Normal栅格/置入图片栈捕获原图、上下层，拖动只更改控制点及CPU正向细分网格。复用液化/移动的静态资产协议，不回读GPU预览。
- CPU使用现有 `TransformGeometry::map`，网格包含控制点分界，按曲面跨度有界细分。warp与液化仅共享呈现架构，算法仍独立。最终确认从原始源执行CPU取样（Warp使用共享三角面，非Warp使用逆矩阵），保持六种插值、原图、单历史、撤销/取消和资源失败语义。
- Qt以正向网格绘制原图到有界视口纹理，再在线性颜色空间与静态上下层纹理合成。透明像素、变形外区域和裁剪都要正确，不能只在变形三角形内显示上下层，也不能重复混合透明背景。静态纹理不随控制点更新上传。
- 更新只合并相邻绝对几何；checkpoint/undo/redo/commit/cancel必须保留顺序，确认采用最后一次已提交几何。预览保留至最终像素帧接管。
- 有选区、组/多选、蒙版/裁剪/特殊混合和软件显示保留像素路径。本轮不将通用图层合成器迁移至GPU，不启用wgpu计算来处理少量控制点。

## 验收条件

核心比较deferred与既有路径的最终像素/历史；检查拖动原始瓦片身份与源资产不变、控制点真实映射、取消/局部历史/画布外恢复/置入模型。原生覆盖异步包、容量和最终几何；Qt检查确认前真实画面、透明上下层合成、软件回退、撤销与取消。记录固定Release计算耗时，不以自动化等待耗时代替鼠标手感。完成Windows Release、最小回归及四ABI检查。

## 代码与调用

- `core/crates/paint-core/src/document/transform.rs`：继续定义几何、原图、局部历史和最终取样；新增状态只在deferred更新时绕过像素生成，确认临时退出deferred后调用同一个完整源取样器，失败保留会话可调整或取消。
- `transform_preview.rs`：`begin_transform_layers_deferred(ids)` 与 `enable_transform_deferred()`。后者接入置入图片自动打开的会话。`transform_preview()` 通过现有 `TransformGeometry::map(u,v)` 发布正向位置和源UV；包含每个1/3控制节点，轴向至多145点，共21025顶点。跨度细分受预算约束，不随原图像素数量线性增加。
- `tools/liquify_preview.rs::resident_source_layer`：与液化/移动共用静态源切分；置入图片采用保留的原始模型像素，不使用上一次变换生成的缓存作为下一次原图。三工具共用 `ResidentPreview`，正向/逆向语义显式区分。
- ABI1.64：新 `paint_session_begin_transform_layers_deferred`；已有会话通过 `paint_session_transform(...,PAINT_TRANSFORM_ENABLE_RESIDENT,null,...)` 请求接入。`focus` bit0仍为隔离源，bit1表示正向网格。旧入口默认像素路径，旧液化/移动包不改语义。
- `PaintCoreClient.cpp`：按实际窗口GPU显示能力选择入口，置入会话延迟到文件结果交付后接入；Actor继续合并相邻绝对更新，checkpoint和关闭不可越过；0/1视口在deferred期间停止CPU重采样。GUI保留末次预览直至最终帧接管。
- `LiquifyPreviewNode.cpp`：原图正向网格只绘制源，未使用的上下层采样器绑定1×1透明纹理；实际静态上下层由 `CanvasItem::previewPart` 共用图像节点提供。图像身份不变时不重新上传或主动重绘这些静态离屏层。
- `CanvasPane.qml` / `transform-composite.frag`：原图网格捕获至Qt layer，纹理尺寸每轴至多2048；静态上下层同坐标捕获，最终fragment在线性预乘空间合成后编码sRGB。画布外片元裁剪。Qt拥有纹理与生命周期，没有跨Rust共享GPU对象或GPU读回。

在硬件Qt窗口中照常 Ctrl+T 或置入图片，兼容目标自动使用该预览；不需要启用wgpu计算。性能设置选择CPU只控制wgpu算子，变换控制点本来就在CPU上，Qt硬件显示继续工作。软件场景图、有选区或复杂栈自动保留原路径。

PhotoCraft采用Bezier曲面与预览纹理/mip缓存；本实现保留DrawVerse插值Catmull节点与既有六种最终颜色插值；Warp的预览与最终取样共享三角覆盖，后绘制的面拥有像素，未移植其Bezier曲面或整个GPU合成器。预览是有界细分、RGBA8与2048静态代理，极端透视、放大细节、代理量化和采样核可能导致预览与最终像素有差别；不声称与Photoshop或PhotoCraft逐像素等价。首次代理准备与最终重采样仍有后台开销。

实测见[验收](../validations/tools/transform-resident-preview-validation.md)。

## 折叠网格一致性修复（2026-10-19）

用户截图显示确认后出现透明洞和跨区域换面。预览的前向三角形在折叠处仍有覆盖，而最终单一初值Newton反求既不保证收敛，也无法定义多根的遮挡关系；此前温和变形测试不能覆盖这一情况。

将Warp预览和CPU物化共用同一有界正向网格拓扑。CPU按目标瓦片分桶，三角形重心坐标确定源UV，不再用全局猜测反求Warp；共享边使用半开覆盖，退化三角跳过，按固定行序后绘制的面拥有覆盖像素。GPU正向源层在Qt有序透明绘制通道内使用One/Zero覆盖写入，避免不透明通道深度让第一面固定占据像素，也避免同一图层折叠导致alpha重复累加，完整上下层仍单独正常合成。非Warp透视继续使用精确逆矩阵；最终在原始源上执行已有六种颜色插值。

固定拓扑为预览近似与最终采样定义相同的表面，不能声称任意曲率下等于连续Catmull曲面精确求逆。目标输出/瓦片预算继续生效，三角-瓦片引用另设上限，失败不得发布部分结果。最小回归须覆盖强折叠多根区域、透明源、共享边、画布外及确认/撤销，并对比GPU预览与最终画面。

折叠修复的验证见[一致性验收](../validations/tools/transform-fold-consistency-validation.md)。


## 完整链接子树的变换预览（2026-10-20）

参考PhotoCraft `transform_tex.rs::read_surface` 在上传前对预览源应用蒙版，使用不可变预览纹理；最终仍由原始图层分别采样。DrawVerse复用完整根子树的常驻分割，捕获所选根ID及每个实际目标的原始Layer；支持根层的链接自身蒙版、完整Normal根组、独立的穿透根组以及连续根多选。预览只将完整子树合成为一张代理，沿整组选框发布同一CPU网格；原始分层/蒙版、局部历史和确认物化不改，允许延迟启用时仍读取会话原始层。

单层置入继续使用原始模型；复合源包含置入、固定蒙版、Dissolve、依赖外部背景的穿透混合、非连续多选、组内单层或选区继续回退。蒙版与所有者在最终阶段分别重采样，预览预合成及2048代理会在半透明边缘与非线性Warp局部细分产生近似差异，不能将预合成纹理写回图层或声称逐像素相同。必须验证最终像素与既有CPU路径完全一致、原始瓦片及静态源身份在多次更新中不变，取消/undo/redo及资源失败保留事务，真实D3D11确认前显示实际变化、软件路径保持。

核心状态保存 roots 与 preview_bounds：普通/置入源沿原图局部bounds计算UV，复合源沿会话初始世界坐标选框计算UV，避免带offset的蒙版/子层重复平移。resident_subtree_source显式验证所有非空目标均被会话捕获，直接单层入口未变换蒙版时不能误用完整子树。验证与固定组基准见[验收](../validations/tools/transform-resident-preview-validation.md#完整链接子树变换预览2026-10-20)。

## 大图局部选区常驻预览（2026-10-21）

核对PhotoCraft本地参考d95fdf3的transform_tool.rs：进入时split_selected生成移动像素和原位置余像素，预览文档保留余像素、源纹理按会话缓存。DrawVerse采用相同职责分离，保留自己的瓦片/选区、Catmull网格、CPU取样和历史，不移植完整egui合成器或mip链。

对无自身蒙版、Normal根层且图层opacity/fill均为1的单目标选区，进入时只对原选区覆盖到的瓦片各计算一次source×selection与source×(1-selection)，未触及瓦片共享身份；源带世界坐标与一像素透明边界。原图与原始选区留在会话，目标层的真实瓦片在拖动期间不变。移动的选中部分作为常驻纹理，余像素并入静态下栈，上栈按原可分割条件缓存。半透明像素和羽化覆盖不要求二值化。

初始几何直接使用另一个不可变资产，显示完整原图，避免source×selection over source×(1-selection)在羽化/alpha边界产生切缝。第一次离开原位切换到已捕获的移动资产，后续持续拖动复用同一sourceId和图像纹理；返回原位/局部撤销复用原位资产。两套初次显示可能各需一次代理创建/上传，不承诺首次拖动零开销。

拖动只改CPU网格，Qt负责显示；蚂蚁线在常驻变换期间隐藏，控制框展示实时边界，确认后一次生成高精度目标选区。最终仍从原始层/原始选区进行既有六种插值，余像素和历史按原事务物化，预览代理不写回图层。捕获失败的新会话取消并恢复原像素/选区/历史；延迟启用失败不发布私有候选。

软件、半透明图层属性、fill、固定/自身蒙版、组内、非连续多选、特殊混合及超过捕获瓦片预算的目标继续保留CPU路径，归T2及后续范围。像素alpha的半透明已支持，不能把它与图层opacity属性混为一项。2048代理/有界细分的显示近似保持，不把核心网格计时等同实体交互时延。ABI1.75、state45/VBR不变。

## 组内目标共享祖先分割（T2，2026-10-21）

变换复用移动已验证的私有祖先展平：祖先须可见、opacity/fill均1、无自身蒙版/剪贴，且为Normal或PassThrough；Normal祖先子树不得有特殊混合/剪贴。只在显示上下文提升子树并隐藏空组壳，真实组织与历史不改。完整目标及链接蒙版仍须被变换会话捕获；选区、固定蒙版、非连续目标、不可消去祖先继续回退。

共享入口接受会话不可变原层覆盖，延迟启用时用原始瓦片/属性，不采样上一次CPU变换结果；覆盖时保留私有显示上下文的parent，避免把目标放回已隐藏的祖先。拖动仍用既有世界选框/CPU网格/Qt纹理，确认逐层全精度物化。

验收要求：Normal/PassThrough两级祖先、同组静态兄弟、目标链接蒙版和偏移/alpha，初始分割合成等价；连续更新源及真实结构/瓦片身份不变；与CPU确认像素、局部/永久历史及取消等价；延迟启用和低预算确认失败可恢复；拒绝有蒙版/低opacity祖先及背景相关混合。Qt两后端需实际窗口显示组内目标跟随、兄弟不动并保持缓存身份，复核移动共享路径。

# 主线 C2-B — Guarded Tile Translation Reuse

基线 `eb3e2c2caf7c3c489cd03d7b3a269a6bdd19b757`，依赖未合并C1→C2-A。本轮只修改现有paint-render合成Mip缓存，不动交互/任务/质量/历史/ABI。

## 等价资格

第一版只证明一个有显式瓦片的平面Normal栅格层相对**当前缓存配置**改变offset。所有层顺序、ID、可见性、opacity、fill、blend、seed、parent、group、mask、clip、white几何不变；只有该层offset变化，差值两轴均为64的整数倍。组/蒙版/剪贴/特殊混合均拒绝。

其他层必须没有显式瓦片，且为透明默认层或offset=0、white_extent等于文档尺寸的隐式白层。顺序和alpha不变，所以同一旧/新完整画布瓦片内，固定贡献逐像素相同；半透明移动内容不会带走非均匀旧背景。非均匀静态背景保守拒绝，不尝试识别相同颜色。移动层white_extent必须为0。

每个缓存项构造时标记其单一栅格依赖资格（只存ID，不存强像素引用）。新配置必须获得相同资格。逐候选比较已有Weak源指针与新位置的所有实际源瓦片，数量、顺序和有效opacity必须完全相同；Tile写入遵循Arc COW/Weak身份退役，不只看层ID。冷/淘汰项不存在则不能复用。

新坐标=旧坐标+offset差/64。使用i64检查加减和u32转换，拒绝负坐标/越界；旧、新瓦片都必须完整在同尺寸文档内，部分边缘保守重建。只支持LOD≤6、相同LOD和像素格式；64平移保持2^LOD采样相位，Mip独立于视口blit相位。LOD>6仍原路径。新露出区域、原画布外没有旧Mip的区域保持精确重建。

## 生命周期

不删除configuration校验。资格不成立时原清空/重建；成立时从旧表生成独立新表，映射一对一，避免原地键覆盖。提交新表与新configuration之前检查取消；中途取消时缓存为空而仍为旧configuration，不混装新旧项。提交后取消只留下已证明有效的项；逐项重建沿用原取消检查，错误帧不返回。

预算不增、不强持有源像素、不预热、不保留额外图层纹理。只消费实际存在的Mip。原坐标hit、首次消费平移项、重建miss分开计数；已映射但未消费不计hit。资格/映射耗时按需诊断，原因明确。

## 验收

先增加完整像素对照（原CpuRenderer不改），小尺寸非均匀/透明图案、固定非均匀背景反例、正负/零/连续/返回、非对齐、非64边缘/画布外、预算/编辑/结构/组蒙版/两格式/代表LOD。使用仅测试编译的局部取消接缝确定性覆盖资格、映射、提交/重建边界，不增加产品等待。

共用测量先提交，两侧应用同一工具。独立worktree/CMake/Cargo target，S2对齐前后各3进程交替；非对齐/S3/关闭诊断各一对代表进程。保留I/W、所有失败及历史异常；不把特例收益外推任意拖动。

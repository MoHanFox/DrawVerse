# 共用选区与套索（2026-10-11）

矩形、椭圆、自由套索和多边形套索共用不可变 SelectionShape、四种组合运算、抗锯齿及羽化覆盖，沿用画笔/橡皮/蒙版的实际像素约束、原子历史和 ORA 选区存储。工具之间仅采集几何的方式不同，不复制选区引擎或参数栏。

多边形使用奇偶填充，支持凹形和自交；最多 4096 个有限坐标点，拒绝不足三点、退化及越界参数。抗锯齿仍用固定 4×4 边缘采样；羽化为文档像素半径（0–1000），使用到边界的有符号距离和对称 smoothstep 过渡，边界覆盖 50%。轮廓表示 50% 边界，羽化不改变该轮廓。无羽化保留原矩形/椭圆覆盖，路径不可变共享，覆盖查询不复制路径；64 个纵向桶索引排除不参与当前像素及羽化带的边段，索引大小随路径点数有界，与画布尺寸无关。每个选区总路径预算 4096 点。选区文本 v3 添加羽化和路径，继续读取 v1/v2；保留既有 ORA 容器和历史格式。

ABI 1.15 添加统一形状请求及 publication 一致的路径/羽化查询，不改变旧 DTO 大小；caller 点缓冲在返回前复制，所有指针访问集中在 pointers.rs。异步 actor 复用现有选区命令、历史和发布流程。自由套索与多边形套索分别记录真实工具标签。

Qt 共用选区参数状态和顶部参数栏：新建/添加/减去/交叉图标、羽化数值、消除锯齿；移除快捷键说明文字，保留既有组合键。工具栏套索可用，右键或详情下拉切换子类，记忆子类。自由套索按住拖动，松开自动闭合；多边形点击顶点、悬停预览下一边，双击或 Enter 闭合，点击起点闭合，Backspace 删除最后顶点，Escape/工具或文档切换取消。空格平移不提交选区，数位板与鼠标共用采集逻辑。

验收：真实覆盖（凹形、自交、AA、羽化、四种组合）、无效请求不改变状态、历史/ORA 往返、caller 缓冲立即复制；实际 Qt 鼠标/数位板及多边形完成/取消、参数和子类共用、DPI 轮廓、真实受限绘画；完整 tools/check.py，通过后部署、commit/push。

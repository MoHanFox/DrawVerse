# 复杂移动的有界交互采样

2026-10-21。带固定蒙版、半透明/蒙版祖先等组合无法平铺成三张静态纹理。旧回退在每次位移后先对所有源像素完整合成，再生成缩小预览；计算量仍随原图面积增长。

为这些移动预览单独提供 CPU 快速显示采样：输出最长边至多512，按像素中心最近邻取样，横向把相近源坐标合并为有界扫描行区段，复用核心完整组/蒙版/剪贴/混合规则。每输出行最多512个输出、每区段最多4096个源像素、总源样本不超过输出像素数的16倍。稀疏的大跨距退回短区段，不读取整个超大源行。支持负视口和画布裁剪，保留取消与存储错误，工作缓存只读。

仅移动会话的两个画布视口使用该路径；常驻源依然只更新四顶点，缩略图、普通绘画、导出和确认后视口使用既有完整渲染。会话结束屏障使低精度预览失效，再发布最终普通显示帧。Qt按帧的实际尺寸显示，软件与GPU显示后端均可使用，没有ABI/格式或wgpu算子变化。

交互帧的sRGB转换使用4097项只读表（约16KiB），与精确曲线最多相差一个8位色阶；线性帧保持精确。普通显示、物化和导出保留原转换。

预览允许细节消失/走样，确认后的原像素和历史不改变；这不是整个合成器已经迁移GPU。验证用CPU像素中心参考、有限工作量、取消、固定蒙版/祖先蒙版/混合、真实窗口松手前后和固定4K样本计时，不将算法耗时当作实体输入延迟。结果见[验收](../validations/tools/layer-move-bounded-fallback-validation.md)。

## 2026-10-21：只合成实际显示样本

前述区段方案仍会计算相邻显示采样点之间最多16倍的源像素。现在 `DocumentSnapshot::read_sampled_row(xs, y)` 接收非递减的画布横坐标（允许重复），与连续行共用 `RowSamples` 和原有普通、孤立组、剪贴、PassThrough合成器；没有复制一套简化的混合算法。所有依赖位置的溶解运算继续使用原始画布坐标。

稀疏层读取按有符号本地瓦片坐标分段，每段只pin一次所需瓦片，忽略没有采样点的中间瓦片；隐式白底、偏移、组/蒙版透明度与填充仍由同一规则处理。公开Rust读取先校验画布范围、非递减顺序及最多MAX_DIMENSION个样本；无序/越界返回错误，空行不访问存储。正常完整渲染仍使用连续行。

复杂移动输出每行至多512个采样坐标，每层只合成这些样本，不再有中间源像素的16倍开销；实际磁盘读以完整瓦片为单位，不能把512个颜色样本称为只读512个磁盘像素。每行检查取消并整理PagePool，存储错误继续上报。最长边512、最近邻和sRGB误差边界保持，结束后的完整渲染与原始像素/历史保持。本轮没有扩大GPU常驻组合或新增wgpu计算；GPU显示仍通过Qt完成。

这项坐标采样能力位于共享核心，后续其他代理预览可以复用。当前只接入复杂移动，液化/变换确认及导出不使用稀疏显示样本。首次静态资产、冷盘、层数/组深度及实体持续时延仍单独验收。

2026-10-22：共享判定对空蒙版或opacity=0蒙版保留常驻源，包括固定自身蒙版、可消去祖先蒙版；其内容、链接与最终高精度移动均保留。有实际覆盖的固定/祖先蒙版仍使用本有界CPU路径。详见[共享设计](transform-resident-preview-design.md#2026-10-22-无效覆盖蒙版共用常驻预览)。

# 统一调整画布（2026-10-30）

图像大小和裁剪合并为图像菜单中的“调整画布”。图层、图像、选择为编辑菜单开头的三级联入口。实现位于 `document/canvas_resize.rs`、`PaintCoreClient::resizeCanvas`、`CanvasResizeOverlay.qml` 和 `CanvasResizeOptionsBar.qml`。

## 交互

进入时显示白色八手柄边框，框内拖动改变裁剪原点，边角拖动改变边界；拖动时出现九宫格和 W/H 像素提示。像素模式输入最终宽高；比例模式 0:0 锁定进入时的当前比例，正数对指定比例，交换按钮互换方向。DPI 为整数 1–12000，仅改变元数据，不重采样。尺寸上限沿用核心 1,000,000，实际像素分配仍受文档瓦片和暂存预算限制。

默认不删除裁剪像素，图层及固定/链接蒙版整体平移原点，保留所有画外源；勾选删除时逐瓦片清除框外数据，隐式白色矩形物化为框内瓦片，置入图清除可编辑原始引用、保留裁剪后的栅格内容。隐藏/锁定层与组内节点同样处理，因为这是文档边界修改。确认后清除当前选区，撤销恢复原选区。

扩展区域实时显示白色或所选颜色，确认时捕获当前前景色并转线性空间。独立底层“画布扩展填充”仅写新增区域，原图范围透明，原内容及保留的画外内容置于其上；当前活动图层保持。失败不会更改文档；取消没有历史；确认的一次历史同时覆盖尺寸、DPI、图层与原选区。

进入时暂存面板图标折叠状态并收起列，沿用编辑期间浮窗隐藏机制；退出恢复原状态。提交期间阻止重复提交/取消，等待对应命令序号成功回执及其尺寸和 DPI 发布后结束；失败保持调整状态并显示错误，不能把尺寸未变的失败当作成功。多文档切换与主菜单操作在会话期间暂停。

## 边界与持久化

Rust 不依赖 Qt；UI 经 ABI1.93 的 `PaintCanvasResize` / `paint_session_resize_canvas` 提交，`paint_session_canvas_dpi` 与尺寸共享 publication 检查，旧 DTO 布局不变。历史 kind46 为调整画布；内部历史增加 Canvas 命令并支持内存/磁盘编码及历史跳转失败回滚。

ORA 使用有界 `drawverse/dpi.txt` 保存 DPI，旧文档缺省 72，文档图层格式不变；PNG 导出 pHYs 并在导入时恢复整数 DPI。JPEG/WebP 的既有编码路径未新增 DPI 元数据支持。

布局和显示沿用现有 Canvas 的轴对齐文档坐标与缩放，不进行图像插值。未声明大图端到端性能或实体输入延迟结论。


## 2026-10-30 调整会话独立历史与导航

调整草稿在所属 CanvasResizeOverlay 保存尺寸、原点、DPI、比例、裁剪开关与填充选择的有界快照。拖动松开记一步，连续输入合并 250 ms，修改历史位置后截断后续分支，最多 256 条并保留初始状态。复用现有工具条撤销/重做按钮、编辑菜单及快捷键，不新增历史列表或调整栏按钮。主菜单快捷键和浮动画布入口在调整期间仅访问草稿。导航不进入这份历史。取消销毁草稿效果，确认仍仅通过原核心 resizeCanvas 生成一条文档冷历史。

底层绘画仍被禁用；调整层处理滚轮缩放、中键拖动及空格加左键拖动，仅调用所属 CanvasItem 视图导航，不启动笔触或文档操作。禁用绘画时采用以视图中心为锚的即时缩放；平移停止旧惯性并更新视图，调整边框按原文档坐标同步投影。显现时同步取得焦点，避免延迟抢走输入框焦点。


## 2026-10-30 导航与越界遮罩纠偏

恢复原有 140 ms 缩放动画：调整模式通过 CanvasItem.resizeNavigation 显式允许禁用绘画时推进导航计时器，删除上一版即时缩放分支。底层禁用画布不再截获全局空格，调整覆盖层持有按键状态并在失焦/隐藏时释放，避免依赖底层物理按键轮询恢复。平移仍由调整层处理，绘画保持禁用。四块遮罩按视口裁剪后的边框边界分割，互不重叠；整个覆盖层裁剪到所属画布视口，消除负坐标导致的角落重复变暗。

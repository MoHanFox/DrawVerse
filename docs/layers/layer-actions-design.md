# 图层操作与编辑焦点

ABI 1.20。右键菜单和菜单栏共用 PaintCoreClient 操作：单选普通图层向下合并同级下一层；单选组合并整个组；多选合并所选子树（父子重叠只计一次）。复制、粘贴、复制图层保留完整子树、蒙版、属性和像素，分配新 ID；复制不修改文档，粘贴到当前目标之上、继承目标父组。系统剪贴板使用版本化私有 MIME，支持跨文档和重复粘贴。锁定目标父组拒绝插入。

合并将所选子树的内部混合、蒙版、不透明度和位置烘焙为普通像素层，放在共同父组的最高所选分支位置；未选内容保留。穿透组在合并时隔离栅格化，合并后不再穿透外部背景。输出按有内容的瓦片范围计算，遵守瓦片、层数、嵌套和剪贴板大小限制；失败不提交部分变化。复制与合并每次只有一条原子历史，历史存储保留新增及移除节点的像素。

行背景表示多选；白色焦点框仅显示在当前编辑的内容/组预览或蒙版预览外。Delete 删除当前蒙版或选中图层；组删除沿用现有保留内容/删除子树选项。Ctrl/Cmd+C/V 复制粘贴，Ctrl/Cmd+J 复制，Ctrl/Cmd+E 合并，Ctrl/Cmd+G 建组；文本输入有焦点时保留原生快捷键。右键已选行保留多选，右键未选行先单选。

拖放下边缘使用目标的真实 ID 和下方 placement，目标图层的父组是新父组；自己上/下边缘拖放是无变化操作，拖入自身/后代仍拒绝。禁止把下边缘定位成目标为自己的“下一行”从而产生 cycle 错误。

拷贝／粘贴图层和组仅保留 Ctrl/Cmd+C/V，不再显示于图层菜单或右键菜单；“复制图层”操作及 Ctrl/Cmd+J 保留。搜索与快捷键焦点详见 `layer-search-tools-design.md`。

## 图层剪切（2026-10-28）

Ctrl/Cmd+X复用复制的版本化私有MIME。无选区时剪切所选完整图层/组子树（父子重叠只计一次），保留蒙版、位置、属性；有选区时只剪切所选普通层/组内像素，保留层与选区及外部像素。显式蒙版复制仍拒绝，不能先删除再发现无法复制。文本编辑焦点保留原生剪切；编辑/笔触/文件任务期间不触发图层剪切。仅快捷键入口，快捷键列表增加说明。

ABI1.84为现有layer_action增加CUT=6/CUT_SELECTED_PIXELS=7。单Actor操作先完整编码成功再执行一次既有原子删除/清除，锁定、预算、历史或编码失败不发布新剪贴板、不改变文档；先取得会话剪贴板发布锁避免删除后发布失败。结果与命令sequence绑定，Qt worker有界读取后发布系统剪贴板。一次历史沿用删除图层/清除选区内容，不新增持久化编号或文档格式；撤销只恢复文档，不回退系统剪贴板。

# 蒙版、图层拖放与初始背景设计

本模块先确定交互和存储，再实现；插件仍最后实施。

## 模型与接口

选择稀疏的反向覆盖率蒙版：缺失瓦片代表白色（完全显示），存储 alpha 为隐藏量；比整图白色蒙版省内存，复用现有瓦片分页、笔刷和无损历史。蒙版是后序树中的专用节点，父节点必须是像素图层或组，每个父节点最多一个蒙版。它不参与普通颜色混合，而在父节点合成前乘以 `1 - hide_alpha`。蒙版关闭后不影响合成。锁定、子树移动和删除包含蒙版。

选中蒙版后笔刷以显示空间亮度绘制覆盖率（色板 50% 灰对应 50% 覆盖率，转换在笔触开始时完成）：黑隐藏、白恢复、灰色插值，压感控制半径和流量；橡皮擦恢复显示。预览显示真实黑白灰。增删、绘制、显隐和移动均进入已有历史；带蒙版的组禁止直接解组，避免静默丢失效果，可先删除蒙版。

已有 C ABI DTO 大小和旧命令语义不变。ABI 1.6 增加蒙版节点类型、蒙版/白色画布命令和带相邻节点位置的拖放函数；同步校验参数，异步执行结构事务。生成头仍由 cbindgen 负责。

## 拖放与呈现

拖到组行中部归组；拖到行上沿或下沿改变同级顺序，并可移到另一级；子树完整移动，循环和锁定由核心拒绝，失败不改变历史。组行保留眼睛和展开箭头，内容只显示名称。图层缩进按真实深度，蒙版在所属节点下再缩进一级。共享组件支持停靠和独立窗口。拖放由 UI 提交小命令，不在 UI 线程复制像素。

选中蒙版时，顶部混合/不透明度/填充/锁仍编辑所属图层；蒙版密度在蒙版工具行独立设置，避免把“图层不透明度”误变为蒙版密度。

## 默认画布

UI 新建默认一个名为“背景”的不透明白色像素图层。用有界隐式白色矩形加稀疏修改瓦片表示；擦除瓦片即使全透明也必须保留，撤销回到隐式白色。原有透明文档 ABI 保持兼容，UI 增加显式透明画布入口供测试和用户选择。后续默认名称为图层一、图层二……，编号独立于组和蒙版。

## 文件与性能

PNG/JPEG/WebP 导出合成后的蒙版效果。ORA 保存原始图层、蒙版节点和背景元数据；采用严格版本扩展，普通阅读器至少显示经过蒙版处理的兼容图层，同时 DrawVerse 读取原始像素以恢复可编辑蒙版。拒绝损坏、重复、循环和超预算输入；不把未实现的 PSD 当作已支持。

普通无蒙版绘画保留现有缓存快速路径。蒙版和背景是缓存配置/依赖的一部分，关闭蒙版避免读取冷页。隐式背景只枚举视口内瓦片。视口超过一百万源瓦片时使用有界中心采样预览，极端缩小可能漏掉细小笔触；常规画布继续精确平均，不分配整张超大画布。

## 验收条件

- Rust 验证黑白灰、压感、组蒙版、禁用、锁继承、撤销/重做、分页历史、背景擦除和不分配整图。
- 拖放验证同级排序、归组、移出、子树完整性、循环失败原子性和撤销。
- 文件回读保留可编辑蒙版、背景和顺序；扁平导出 alpha 正确。
- C/C++ ABI 布局和命令测试；Qt 验证默认背景、命名、深度、蒙版绘画及停靠/浮窗拖放。
- 完整 `python tools/check.py`、原生构建和绘画性能基准；记录实测限制，不宣称 GPU/PSD/沙箱已完成。


交互依据：[Adobe 图层组拖放](https://helpx.adobe.com/photoshop/desktop/create-manage-layers/get-started-layers/organize-layers-with-layer-groups.html)。该轮为图层/组的像素蒙版；后续并排显示与剪贴已见 clipping-design.md。剪贴只依赖当前图层 alpha，不需要选区/路径；矢量蒙版仍需路径模型。

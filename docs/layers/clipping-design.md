# 并排蒙版与剪贴蒙版设计

用户要求优先：像素蒙版不再占独立行，缩略图位于内容预览右侧。点击内容/蒙版预览分别选择绘画目标，白色边框标记目标；Shift 点击蒙版切换启用，菜单提供删除蒙版。组仍只显示组名及其蒙版，不请求组内容预览。停靠和浮窗使用同一组件。

剪贴采用独立布尔元数据，而非破坏性裁切或复制下层 alpha。连续剪贴层引用同一父级内最近的非剪贴基底，组可作为上层或基底。蒙版节点不参与相邻层判断。先合成基底及其像素蒙版，再在保留基底 alpha 的前提下合成剪贴链，最后一次性应用基底不透明度、填充和混合模式；剪贴层保留自身不透明度、填充和混合模式。隐藏基底关闭整条链，透明基底不显示上层。重新排序后依据当前相邻关系解析；移到最底部而无基底时剪贴层不可见，可直接取消剪贴。创建无基底的剪贴操作明确失败。

对比：显式绑定 ID 会在拖动后仍引用远处或另一个组，偏离用户要求的相邻层快捷操作；复制 alpha 无法随下层绘画和蒙版更新。因此选择动态同级关系。基础剪贴逻辑不依赖选区或路径，前轮文档所述的依赖在此纠正。

保留所有已有 C DTO 布局。ABI 1.7 增加独立 PaintLayerClipping（16 字节）查询/设置和能力位 2048。发布查询与 publication 精确对应，编辑经串行任务，继承完全锁，结构历史记录开关；分页历史版本 DVH5 保存新元数据。渲染配置包含剪贴标志，蒙版、基底与上层瓦片全部参与 Weak 缓存失效。未开启剪贴的现有快速路径保持不变。

ORA 扩展 v3 保存 dv:clipped，继续读取 v1/v2；有剪贴的工程使用现有原始栈+标准合成预览机制，其他阅读器仍可显示结果。PNG/JPEG/WebP 导出合成效果。数据损坏拒绝，不静默丢失剪贴关系。

交互：上层行底部（两层之间）Alt/Option 点击创建/取消；正常点击此区域仍选择图层，拖放继续工作。菜单提供创建/释放，Ctrl+Alt+G（macOS Command+Option+G）作用于当前层。缩进箭头表示上层剪贴，基底名称下划线；并排蒙版始终与所属行同层级。底层数据仍保留蒙版专用节点，保证历史和文件兼容。

验收：Rust 覆盖透明/半透明边界、连续链、隐藏/移动/父组/像素蒙版、混合/不透明度、撤销和冷历史；渲染验证缓存及多 LOD；IO 验证 ORA 回读、旧版本和扁平 alpha；C/C++ 静态/动态 ABI；Qt 验证真实 Alt 点击、缩略图目标切换、浮窗、拖放与两倍 DPI。完整 tools/check.py，原生截图和性能测量。

依据：[Adobe 剪贴蒙版操作及基底属性](https://helpx.adobe.com/photoshop/desktop/create-masks/layer-masks/create-and-manage-clipping-masks.html)。本轮不包含 Photoshop 高级混合选项中的全部开关，不改变当前隔离组策略，也不宣称矢量蒙版已实现。

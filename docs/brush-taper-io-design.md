# 起收笔预设与交换

2026-10-16。将已执行的distance-envelope-v1纳入不可变BrushSettings/BrushDefinition/BrushProgram，普通Rust起笔及湿混入口自动捕获预设；现有明确传参入口继续支持覆盖。无每文档可变全局参数，不把关闭配置丢弃。

state18新增strokeTaper，VBR1.22/behavior15在Preset顶层使用同一对象，要求drawverse.brush及stroke-taper能力。对象含model/enabled/start/end，各端lengthPx为0..4096的f64文档像素、size和opacity各含curve/minimum/interpolation（linear或pchip）。2..17个节点，先按f64验证范围/顺序/端值，再构造f32压力曲线，舍入导致重合也拒绝；四条曲线端值Y为0/1。所有字段完整，显式null/未知模型或字段拒绝。默认不写对象、不提升旧版本；关闭且非默认完整写入。包混合时取包含起收笔与所有来源需求的最高minor，降级拒绝。

原ABR记录与旧转换器基线不能表达起收笔，继续拒绝将非默认起收笔写入来源基线；当前用户预设仍可附带旧来源并独立保存新配置，原来源字节与记录不重算。与图片/纹理/单双流/双色/平滑/湿混组合需真实两笔像素、载色、历史与新目录交换一致。

当前ABI1.50与Qt只理解state17，所有既有原生准备和库包入口暂拒新增起收笔（包括完整关闭配置），防止旧镜像静默丢值。下一阶段新增明确支持的准备/包入口和Qt字段后解除保护。无C ABI版本变化，本阶段不展示参数控件。

验收：默认旧字节/版本保持、state18和VBR1.22严格范围与完整关闭往返、能力/行为/最高版本与降级/取消/原子写入、真实两笔及旧来源/图片组合、旧原生入口拒绝且目录/文件不变；Schema和合法非法示例同步，仅Windows及最小相关测试。

# 笔刷预览轮转与 ABR 双重笔刷间距

2026-10-18。ABR 导入后的笔刷结构已经由兼容层补齐，但异步预览仍可能被丢弃：Qt 使用双精度保存滑条值，Rust 状态使用 `f32`；例如湿混 `0.7` 往返后成为 `0.699999988079071`。`BrushLibrary::restore` 原先按 JSON 精确比较，判定状态变化并递增预览令牌，导致已经成功生成的预览回调因令牌不匹配被忽略。现在轮转比较按引擎实际精度递归比较数字，结构、字符串和数组仍要求一致；语义相同的状态保留预览、错误和令牌，真正变化的参数仍使旧预览失效。

预览临时状态版本也改为只升不降。传递抖动等较高版本字段存在时，后续双笔刷、平滑、湿混或起收笔不会把状态版本写低。

ABR 双重笔刷间距改从第二笔尖自己的 `dualBrush.Brsh.Spcn` 读取。实际画笔可能同时保存外层 `dualBrush.Spcn=100` 和内层 `Brsh.Spcn=30`，Photoshop 面板显示的 30% 对应内层值；此前读取外层会把 30% 错写成 100%。

# 自动平滑压力曲线

2026-10-14：所有压力编辑器（主尺寸/流量/不透明度、第二尺寸/流量）编辑节点后自动使用形状保持三次Hermite插值（PCHIP），经过原节点、C1连续、局部单调且不超出相邻节点范围。两点仍为直线，非单调节点的极值处导数为0；f64预计算归一化分段系数，保留极窄f32区间与默认恒等快路径。最低比例在曲线之后应用。真实写入与图形显示共用Rust算法，不在Qt重写拟合。

旧无interpolation数据继续线性执行；按用户要求，编辑器修改/增加/删除节点后显式转成smooth-pchip-v1。未修改旧预设保持旧语义，默认两点外观不变。新字段保存在关闭配置、复制、完整重置基准和资源来源中；state13/VBR1.11/behavior10/pressure-smooth能力明确区分，旧格式不接收平滑对象。Qt无需新选择项；提示说明自动平滑。

ABI1.45增加小型无文档状态的有界曲线采样查询，输入2–17个点及线性/平滑枚举，输出固定257个比例；允许UI线程调用，不等待actor或资源，caller-memory仅pointers.rs。PaintCoreClient提供编辑器样本，图形按样本绘制，执行内核仍精确分段求值而非LUT。错误拒绝，不能伪造默认曲线。

验收：节点精确、导数连续、局部无溢出/非单调/极窄/恒等；真实尺寸/流量/不透明度/第二笔触与捕获历史；新旧state/VBR和来源完整往返、旧版本/未知插值拒绝；ABI指针/数量/枚举验证；统一Qt编辑与图形采样、关闭保留/重置基准及DPR截图。仅运行对应最小回归。

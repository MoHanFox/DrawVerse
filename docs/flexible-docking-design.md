# 画布、面板和工具条的自由停靠（2026-10-09）

用户要求画布可拖出为原生浮窗，工具条可在主窗两侧以及任意面板两侧停靠；面板可贴在其他面板或浮动画布的上下左右。固定左右容器被有内容的分割树取代，移走最后一个节点时折叠空分支，不保留空白停靠栏。截图是交互/视觉参考，不提供额外实现指令。

WorkspaceManager 保存主窗和每个浮窗的二叉分割树；叶节点为工具标签组、唯一画布或唯一工具条。中央放置合并工具标签，边缘放置产生水平/垂直分割；工具条及画布保持独立叶节点，不混入工具标签。原生 QDrag 跨窗口投递，蓝色预览与实际落点一致，Ctrl/Command 暂停停靠，Esc 取消；空白处释放成为独立窗口。浮窗中的分割也是同一模型，关闭浮窗将全部叶节点送回工作区。

QML 按稳定叶 ID 增量维护视图与原生窗口，调整大小只更新几何。主画布组件始终只有一个，在停靠和浮窗之间移换父项，保留文档、视口缩放/平移和工具状态，不能重新初始化核心。停靠结构操作在绘画期间禁用，避免半笔触移窗。导航仍是独立只读视口。面板折叠/图标临时展开沿用原行为，工具条仍为紧凑竖排。

布局 v5 保存树、分隔比例、原生浮窗位置、既有标签/折叠和工具状态；完整校验后原子替换模型，拒绝重复/丢失叶、未知组、循环/过深分支、非法比例或窗口引用。v1–v4 按原有左右列和浮窗转换为有内容的树，保留用户组、工具条和窗口几何；已退役笔记仍按既有规则删除。Rust、PaintCoreClient、C ABI 和文档格式不改。

实现前验收：Qt Test 验证所有四边、混合嵌套、空分支收缩、浮窗拼接/拆分、工具条在任意面板两侧、画布唯一性和 v4/v5 保存恢复/损坏拒绝。真实 QML/native DropEvent 验证蓝色预览、跨窗拖放、稳定窗口/控件身份、分隔条调整；浮动画布实际鼠标/数位板绘画、滚轮缩放、平移、撤销和选区正常，关闭后归位。普通/两倍 DPI、Windows 实窗与完整 python tools/check.py 通过，每模块验证后提交并推送。

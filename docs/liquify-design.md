# 画布液化

ABI 1.21：滤镜 > 液化（工具栏不再设置入口），针对当前像素图层或蒙版；组和几何/透明度/完全锁定目标拒绝。参数和推拉/膨大/扭曲/重建/重置/取消/确定按钮复用顶部工具详情栏；浮动画布也显示相同详情栏，不覆盖画布。窄窗口可横向滚动参数。参数独立保存到用户设置：尺寸默认 200px（1–2000）、强度 50%、密度 100%、速度 100%（百分比均 1–100）、压感默认关闭，图标切换。速度只控制膨大、扭曲的持续时间变化；密度控制径向衰减，强度控制变形量，压感打开时乘笔压力。

Rust 原子液化事务保存原始层和稀疏逆向位移场。推拉沿路径改变取样位置；膨大作径向逆收缩，扭曲作逆旋转；重建将局部位移逐渐恢复为零。所有预览从原始像素双线性采样，避免反复重采样退化；保留层位置、混合、蒙版与选区限制。边缘取透明，白色背景隐式像素被真实采样。重建到零以及重置/取消恢复原始像素身份。按住膨大/扭曲时按经过时间持续变形，鼠标和数位笔共用输入。

预览不写历史，也不修改保存状态；确认所有预览一次提交真实“液化”历史，空确认无历史。取消撤回整个事务并保留既有 undo/redo。开始至结束冻结普通绘画、图层、选区、文件修改和文档切换；允许视口平移、缩放与当前原生窗口移动；期间禁止文档切换、创建和重新停靠。其他文档浮窗与浮动工具面板暂时隐藏，确认/取消后按原布局恢复。重置保持事务与详情栏，取消/确认关闭详情栏。失败不部分提交笔触；确认历史存储失败保留可取消的事务。

位移场最多 8192 瓦片（256MiB），一次输入最多 8M 像素访问、4096 插值点，源像素读取缓存有界；像素遵循已有驻留/暂存盘和逻辑瓦片预算。ABI 输入指针即刻复制，后台 actor 独占事务，使用 session flag 发布活动状态，不暴露 Rust 内存给 Qt。

“专注图层”默认关闭，仅在本次液化显示快照中隐藏其他层，保留目标和祖先/蒙版；不改真实可见性、不写历史。退出恢复合成。

液化时 Enter / 数字键盘 Enter 确定，Esc 取消。参数文本编辑时 Enter 先提交参数，不直接确认整个液化会话；结束参数编辑后可按确定或回到画布按 Enter。

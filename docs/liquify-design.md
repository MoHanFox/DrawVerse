# 液化系统（2026-10-10）

要在画布上直接操作，画布窗口底部有一个**不可移动**的悬浮面板，包含：工具按钮（推拉、膨大、扭曲、重建、重置、取消、确定）、尺寸、强度、密度、速度四组滑条（后三者 1–100%），并遵守"速度仅膨大/扭曲可用"。

## 交互模型

- 进入液化：图像菜单 → 液化…（新增），画布进入"液化模式"：底部出现悬浮面板，画布只接受液化手势，不绘画、不选区、不平移。
- 手势：在画布上按住拖动 = 应用当前工具；`[`/`]` 仍可调整尺寸（与笔刷一致）；Esc = 取消，回车 = 确定；面板上的按钮等价。
- 预览：所有形变先在**预览层**累积，确定时一次性提交为一条历史记录；取消丢弃，不产生任何历史。这与"无变化不生成假记录"一致。
- 重置：丢弃本次液化的全部形变（回到进入液化时的状态），仍留在液化模式。
- 重建：以当前形变为起点做局部平滑（把附近位移向邻域平均，强度按笔画路径衰减），用于修掉过度拉扯的痕迹。

## 内核方案

1. **形变场**：`WarpField { width, height, dx: Vec<f32>, dy: Vec<f32> }`，与文档同尺寸的位移图（每像素两个 f32 = 8 字节/像素；4K 文档约 66 MiB，超过 64 MiB 的就拒绝并给出明确错误，不做静默降级）。位移以"该像素的新位置 = 原位置 + (dx,dy)"表示。
2. **工具数学**（都以画布局部坐标运算，半径 `r = size/2`）：
   - **推拉 Push**：把 `[圆心, 圆心+delta]` 的位移按 `falloff(d/r)` 叠加到场上；`delta` 由鼠标增量、强度、密度共同决定。密度控制衰减曲线的陡度（density 越高，边缘衰减越快、作用越集中）。
   - **膨大 Bloat**：沿径向把像素往外推，`magnitude = strength * falloff * speed`，速度控制每帧推进量。
   - **扭曲 Twirl**：绕圆心旋转，`angle = strength * falloff * speed * 2π` 的很小比例，速度同样控制每帧转角。
   - **重建 Reconstruct**：把笔画经过处的 `(dx,dy)` 向 0 收敛（比例 = strength），并做一次 3×3 平滑，避免留下硬边。
3. **落笔**：`WarpField` 累积完成后，对本图层做一次**双线性重采样**：`out(x,y) = in(x + dx(x,y), y + dy(x,y))`，越界取透明；预乘 RGBA 线性插值天然正确，不会出现黑边。只写回受影响瓦片，保持稀疏，并走既有 `TileChange` 前后快照 → **一条历史**（新 `HistoryAction::Liquify`，显示"液化"）。
4. **ABI 1.13**：`paint_session_liquify_begin(core, session, layer)`（建立/重置场）、`paint_session_liquify_apply(core, session, kind, cx, cy, dx, dy, to_x, to_y, size, strength, density, speed)`（一次手势增量，只改场、不碰像素）、`paint_session_liquify_commit(core, session, out_sequence)`（重采样并提交历史）、`paint_session_liquify_cancel`。场只存在于会话 worker，UI 线程不持有大数组；所有参数有边界校验。
5. 组/蒙版/完全锁定图层拒绝液化（与画笔一致），笔画进行中返回 BUSY。

## 面板规格

- 位置：`DockWorkspace` 底部居中，**不可移动**（无拖动热区），宽度自适应内容，高度固定；`z` 高于画布与选择轮廓，但低于菜单。
- 工具区：推拉、膨大、扭曲、重建（单选，带图标与提示）+ 重置、取消、确定（按钮）。
- 参数区：尺寸（滑条，像素值可手填，范围 1–2000 且不超过文档较短边）、强度 / 密度 / 速度（滑条 + 可编辑数值，1–100%）。
- 可用性：**速度仅对膨大、扭曲可用**；推拉与重建时禁用并置灰（不做可点但无效果的假控件）。
- 面板与画布共享同一份参数状态（`LiquifyController`），面板不重复保存第二份。

## 验收

- Rust：推拉/膨大/扭曲/重建的场增量方向与幅度正确（含密度、速度影响）、重建收敛、越界透明、半径与强度边界拒绝、超大文档拒绝、提交后像素与"预览一致"且一次历史、取消不产生历史、重置回到进入时状态。
- FFI：非法 kind/参数/未开始时提交的拒绝，失败不产生半成品。
- Qt：进入液化后面板出现在画布底部且不可拖动、工具切换、速度在推拉/重建下禁用、`[`/`]` 调整尺寸、Esc 取消与回车确定各一条路径、确定后画布像素变化且 Ctrl+Z 一步还原、取消后像素与历史都不变。
- 全量 `python tools/check.py`（含两倍 DPI）后构建部署。

# 笔刷渐隐动态设计

2026-10-18。新增独立 `FadeDynamics`：按活动笔触产生的印章数量从完整响应渐隐到配置的最低比例，而不是用笔触距离近似。默认关闭，默认步数25；步数范围1–10000。

`FadeDynamics` 保存尺寸、流量和整笔不透明度三条压力曲线及各自最低比例。执行输入为 `1 - min(印章序号 / 步数, 1)`，因此第一枚印章为完整响应，达到步数后保持最低比例。它作为独立乘数作用于尺寸/流量/不透明度，不进入动态来源矩阵；压力、速度、倾斜等既有来源仍按原矩阵规则工作。

主笔尖、配对第二笔尖、干湿混和涂抹路径共享当前笔触的印章序号；散射子印章共享同一序号。该计数是 DrawVerse 的明确近似，尚未对 Photoshop 的散射/双笔尖步数做逐像素认证。

非默认渐隐写入 state34/VBR1.40/behavior26 和 `fade-dynamics` 能力；ABR `bVTy=1` 映射为渐隐，`fStp` 作为步数、`Mnm` 作为最低比例，`jitter` 继续报告未执行。converter10/handoff9；源记录 converter1..10，converter10基线必须包含 fadeDynamics。Qt“传递”页提供开关、步数和三条渐隐曲线。

# 画笔库预览、分组与拖拽交互修复

2026-10-18，修复画笔库的三个交互问题。

预览临时状态此前只把纹理标到 state 11。带 `minimumDepth`、`brightness`、`contrast`、`depthJitter` 或 `depthPressure` 的纹理需要 state 21，导致真实 ABR 导入后预览准备被 Rust 拒绝并显示“预览暂不可用”。现在纹理版本由 `BrushLibrary::textureStateVersion` 统一计算，保存状态和预览临时状态使用同一规则。

画笔组标题现在显示展开/收起箭头，点击组行切换折叠状态。搜索时忽略折叠状态，确保匹配项及其父组可见。列表模型重建前记录 `contentY`，重建后恢复，避免移动画笔后滚动条跳回顶部。

画笔库和图层列表增加拖拽期间的 `WheelHandler`。拖拽状态中鼠标滚轮直接调整 `contentY`。自动滚动改为使用最后一次拖拽坐标，画笔或图层靠近列表上缘时持续向上滚动，靠近下缘时向下滚动；离开单行进入空隙不再立即停止上缘滚动。

不改变画笔 state、VBR 或 C ABI 格式。组折叠状态属于当前画笔面板会话，不写入持久化格式。

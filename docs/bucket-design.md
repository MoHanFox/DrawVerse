# 油漆桶（2026-10-11）

2026-10-12 参数栏补充：最左侧显示与工具列/历史共用的 `bucket` 图标，17×17，与其他工具参数栏一致；图标后接原有不透明度参数。验收检查实际可见图标、名称和尺寸，并继续验证参数与填充行为。

按用户参考图提供单行参数；用户补充默认容差为 0：不透明度 100%（0–100）、容差 0（0–255）、消除锯齿勾选、连续的勾选、所有图层不勾选。油漆桶独立工具，使用当前前景色，G 激活；切换工具保留参数，不与画笔不透明度联动。鼠标和数位板按下只填充一次，拖动/抬起不重复；Alt 吸色和空格平移保持。主窗参数随活动文档显示，浮动画布使用同一 client。

核心：四邻接连续填充，关闭连续则匹配整个文档范围。种子与待比较像素来自填充前的不可变状态；所有图层使用可见合成，默认只比较当前像素图层（忽略该层显示 opacity/fill），写入始终只在当前层。颜色比较使用直通 sRGB RGB 和线性 alpha 的最大通道差，单位 0–255，完全透明统一为透明黑。消除锯齿在容差之外一个色阶的过渡带内线性降低覆盖，不改变满覆盖区域。选区覆盖参与目标权重，零覆盖阻断连续传播；羽化/AA 与选区共用。前景色在引擎内仍以线性源覆盖混合。

尊重组/祖先完全锁和透明锁；组本身不可填充。蒙版按黑白灰转换为隐藏覆盖，所有图层取样在蒙版目标上明确拒绝（不存在与场景色一致的取样语义）。图层偏移使用文档坐标，隐藏像素层可填充。发现和生成新瓦片完成后，准备单条“油漆桶”历史，再一次应用；取样/分页/历史/资源失败不留下部分像素或历史，完全无变化不创建历史。

工作量有界：连续模式访问至多 4096 个文档瓦片（16Mi 像素）；非连续超过 16Mi 文档像素直接报资源错误；不会按百万画布预分配整张图。位图记录访问，队列只加入首次访问点，匹配覆盖分瓦片保存，输出瓦片交给既有分页/历史存储。大范围超限明确报错，UI 不伪成功。异步串行 ABI actor 执行，UI 只提交请求并等待 publication，不在 UI 线程洪泛。

ABI 1.16 新增 sized PaintBucketFill（坐标、linear_rgba、opacity、tolerance、三 bool 标记及 reserved）、paint_session_bucket_fill 和 feature bit，旧 DTO/导出不变；历史编号 25。caller-memory 仅由 pointers.rs 访问，生成头由 paint-api-gen/cbindgen 更新。

验收先于实现：Rust 验证连续/全局不连通区域、容差/AA/不透明度、透明种子、所有图层只改当前层、偏移、选区/反选/羽化、锁/组/蒙版、单条历史撤销重做、无变化与资源失败原子性；FFI 验证 DTO 大小、空指针/参数拒绝及真实异步填充/history；C/C++ 静态/共享 smoke 调用新增导出；Qt 实际点击参数、鼠标与数位板、拖动不重复、独立工具参数与历史/帧、浮窗/DPI。最终默认包含 Qt 的 tools/check.py 完整通过，原生回归和 Release 部署后 commit/push。

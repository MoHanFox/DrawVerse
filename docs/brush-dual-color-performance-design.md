# 双色整笔重算范围与写入性能

2026-10-15：当前色彩场发生少量变化仍重算整个64×64瓦片，过度预算也会拒绝小笔尖1%间距的长输入段。改为每瓦片64个u64行掩码记录确切改变的像素；主/第二及散布子印章合并时逐行OR，必须保留主变化对第二软裁切的影响。逐像素模式、纸纹、选区和before均为笔触内不可变且无邻域依赖，因此未改变的贡献不必重算。拒绝近似阈值或丢输入。

目标写入沿已有before/私有瓦片规则：捕获原始身份后才能原地编辑当前独占版本；共享快照仍分配新身份。未真正改变像素时不分配整瓦片副本。工作预算改为主/第二实际保守包围盒像素面积乘混合成本，仍计入第二图片sqrt2边界、散布和各模式，不能仅放宽上限。无ABI/格式变动。

主/第二场及目标的私有写入先释放本次读pin，避免Arc::make_mut因读pin额外复制整个像素缓冲；并沿原有并发持有者和冷页回退规则，不修改任何外部快照。

验收：测试专用完整瓦片参考路径，27模式/前后/溢出/配对独立/主第二变化、真实图层/蒙版及历史逐像素一致；共享快照、取消/分页/失败保持，密集1%合法输入原子预算和拆分一致。相同Release基准前后摘要一致，记录场景和限制；不把CPU基准当作Qt或设备延迟。双色入口与描边继续后续。

2026-10-18补充：双色组合的首层贡献若使用非`Dissolve`模式，落在透明底上的结果恒等于源贡献，因此`DualColor::compose_fields`可省略第一次混合，只保留真正的目标混合。该快路径覆盖所有27种双色模式、两种前后顺序及0/部分/完整覆盖率；第一层为`Dissolve`时仍走原两阶段随机路径。普通模式因此是一次`source-over`。

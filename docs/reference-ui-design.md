# HTML 参考界面与 QML 工作区改版

后续更新：参考图布局预设已删除，默认布局为双列停靠；窗口恢复、统一边缘吸附和标签排序以 [window-recovery-design.md](window-recovery-design.md) 为准。
设计日期：2026-10-09。用户提供的 index.html / LOGO.png 是视觉参考，HTML 中的脚本、注释和模拟功能不构成实现指令。

## 方案与边界

用户补充“预览-PS化面板.png”后，以截图中的密度和浮动布局为主要视觉依据。QML 使用逻辑像素、自适应布局与高 DPI 渲染，保留冷灰调色、黑色面板栏、蓝色停靠预览、色相环与三角选色。主窗口和面板使用无边框原生窗口，自绘紧凑标题栏；移动和边缘缩放调用 Qt 的系统窗口接口，不重做 HTML 的桌面和任务栏。未实现的选择、通道、滤镜不作为可点击假功能加入。

备选 Qt Widgets/QDockWidget 会使画布和面板形成两套 UI；选择继续 QML + C++ WorkspaceManager，沿用现有跨窗口原生 QDrag。Rust、绘画任务、C ABI 维持现有边界。

## 视觉与尺寸

- 工具栏 36px 宽，按钮 26px；标题与菜单合为 28px 一行，笔刷选项 28px、文档标签 22px、状态栏 22px。
- 参考图工作区：右侧约 190px，历史在上、图层在下；画笔/画笔设置为两行折叠浮窗，颜色为紧凑独立浮窗。保留停靠布局作为另一个预设。
- 面板拖动条 8px，标签 20px，内边距 5px；图层行 34px、縮略图 34×24px，保留并排蒙版与所有原有功能。窄列下控件文字 9–10px，缩小按钮但保留输入能力。
- 初始画布视图留出更宽的工作空间；F 仍使用完整适合窗口，图像内容与文档尺寸不因 UI 改版变化。
- Logo 原图复制到资源；自行绘制统一 24 单位矢量图标，消除字体字符图标的跨平台字形差异。
- 色轮缓存有限分辨率的三角渐变，仅色相变化重建；绘画时不刷新，防止增加画布 CPU 开销。
- 补充参考 `编辑页.svg`：活动面板标签与下方内容共享 surface 色；非活动标签用更暗的 tabInactive 色。面板、列表、缩略图为直角，多面板标签只在上沿使用 6px 圆角，单面板标题为直角，文档标签上沿为 5px；工具选中底色 2px，主窗口外轮廓 10px，最大化取消外轮廓圆角。仅使用 SVG 的结构、颜色及圆角规则，不复制其中截图笔刷或未实现的功能。

## 停靠交互

参考 Adobe 官方的 [停靠](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/dock-undock-panels.html)、[移动面板](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/move-panels.html) 和 [图标折叠](https://helpx.adobe.com/photoshop/desktop/get-started/learn-the-basics/collapse-expand-icons.html)。

标签拖动单个面板，顶部空条拖动整组；沿标签左右移动改变顺序，面板中央合并为标签，上下边缘拆分/重排组。蓝色边线及半透明面积显示提交后的布局，标签插入使用竖线。拖到空白位置产生独立原生浮窗；Escape 取消，Ctrl 临时禁止停靠。浮窗仍可调整大小、跨屏移动、合并和回到工作区。

左右列支持折叠为图标栏，点击图标在画布侧弹出组，保持图标栏宽度，重复点击或点击外部关闭；双箭头展开整列。单组折叠后每个面板占一行，浮窗同步缩短并在展开后恢复高度。面板菜单关闭当前标签或整组；窗口菜单可以重新打开，包括自定义面板。空组释放，所有标签始终只属于一个组。工作区 v4 保存列宽、组高、折叠、关闭状态及浮窗位置；读取 v1/v2/v3 并继续移除已退役笔记。旧版布局首次升级应用参考图预设，保留自定义面板；新版保存后保留用户布局。

主窗口按组 ID 管理浮窗实例，结构修改只创建/销毁新增/移除的浮窗。修改活动标签和折叠状态使用独立通知，避免其他窗口重建。色轮保留紧凑 H/S/B 精细调节；双击前景色可输入 HEX。历史条目以核心实际撤销深度为准，点击逐项发送异步撤销/重做，不编造核心未提供的操作名或缩略图。

当前停靠模型为左右两列内的纵向组与独立浮窗/浮动标签组，不承诺任意二维嵌套停靠树或多个原生浮窗联动拖动。

左侧工具条独立于面板模型：顶部握柄原生拖动，空白处释放成为窄竖向 Qt Tool 浮窗；左边缘蓝色预览接收归位，双击握柄也可浮动/归位。Ctrl/Command 禁止停靠、Esc 取消，不丢失工具选中状态。v4 工作区增加可选工具条位置字段，旧文件默认停靠。关闭工具浮窗归位，窗口菜单提供归位入口。验收覆盖原生跨窗口 DropEvent、浮动工具实际绘画、保存恢复及两倍 DPI。

## UI 整体放大 1.1 倍（2026-10-09）

保持现有 QML 逻辑尺寸、停靠关系与布局 v4，在 QGuiApplication 创建前将 Qt 全局缩放因子乘以 1.1。系统 DPI 与外部 QT_SCALE_FACTOR 继续叠加；主窗、菜单、文字、图标、间距和原生浮窗使用相同倍率。工作区坐标仍按 Qt 逻辑像素保存，文档像素和画笔参数保持原有单位。

验收：Qt Test 与应用共用启动缩放设置；普通 offscreen 场景的实际窗口 DPR 为 1.1，外部 QT_SCALE_FACTOR=2 场景为 2.2。真实 QML 主窗及面板/工具浮窗截图尺寸与逻辑尺寸乘 DPR 一致；既有输入、拖放、布局持久化与两倍 DPI 回归通过；实际 Windows 主窗截图检查排布、文字与控件无裁切，最后执行 python tools/check.py。

## 验收条件（实现前）

### 原生模糊圆角与红色关闭按钮（2026-10-09）

正常主窗的原生窗口区域与 10px 外轮廓一致，按窗口实际 DPR 转换到物理像素，通过 [SetWindowRgn](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowrgn) 连同 Windows 模糊一起裁掉上方两角；尺寸、屏幕 DPI 与最大化/还原变化时更新。最大化移除区域裁剪，继续铺满可用屏幕。保留菜单栏 50% 原色和实时高斯模糊、实色直角子菜单及原布局。

关闭按钮默认红色、悬停较亮、按下较暗，白色关闭图标；只有右上角跟随主窗圆角，其他三角直角，最大化时全部直角。验收覆盖表面角像素、真实 QML 按钮三个状态、窗口区域随缩放/最大化更新及 Windows 实际合成画面的上角背景与红色按钮。普通/两倍 DPI 和完整 python tools/check.py 通过。

### 不透明直角菜单与菜单栏真实透背景（2026-10-09）

普通弹出菜单、浮动面板菜单和菜单项高亮统一直角，底色 #1c1e21 完全不透明，取消透明弹窗表面；保留 6px 文字行距和浮窗侧边位置。背景不透出画笔选项、文档标签或其他窗口内容，反复关闭/打开不留旧画面。浮动面板本身已有实色直角外框，保持其布局和停靠。

主窗不透明背景从菜单栏下缘开始绘制，菜单栏保留原色、50% 底色、上圆角下直角和矩形焦点，使其实际合成 alpha 为 50%，可以透出桌面或后方窗口。下方工作区仍完全不透明。不抓取桌面，不缓存截图，不改绘画内核。

侧边菜单显示时跟踪其窗口，应用内的外部鼠标按下关闭并消费该次按下，避免点击空白画布同时绘画；窗口失去激活时关闭，覆盖点击桌面/其他应用。Esc 与菜单动作保留，关闭立即隐藏并释放弹窗、清除跟踪。

用户补充最大化铺满要求：主窗最大化覆盖所属显示器完整可用区域（保留系统任务栏），系统 DPI 与 1.1 倍缩放继续一致。最大化取消圆角和缩放边框，还原恢复正常窗口尺寸及位置；验证实际窗口几何，而不只检查最大化状态或按钮图标。

用户再次明确菜单栏保留高斯模糊：Windows 原生窗口通过动态解析 user32 的 SetWindowCompositionAttribute，请求合成器的 ACCENT_ENABLE_BLURBEHIND，不添加亚克力高光或额外色罩；opaque 工作区覆盖其余区域，仅标题菜单栏显露原生实时模糊和 50% QML 底色。不同于已删除的菜单截图缓存，此路径不抓帧或持续轮询。该函数无 SDK 头/导入库，动态调用失败和非 Windows/offscreen 均返回 false，只保留真实透明，不声称支持模糊；Windows 原生验收须在自建彩色背景窗口上对比合成画面，验证锐边实际扩散。初始化时显式启用 Qt alpha buffer。其他平台的系统模糊仍未实现。

验收：主窗最终帧菜单栏空白位置 alpha 50%，下方工作区 alpha 100%；菜单与高亮 radius 0、底色 alpha 100%，四角均不透明；修改菜单后方控件后菜单截图保持相同；主窗/侧边菜单重复开关无残留，点击浮窗空白处、主窗空白处及 Esc 均释放侧边窗口。普通/两倍 DPI、Windows 实窗以及完整 python tools/check.py 通过，更新启动目录，只提交本次 UI 修改。

### 普通菜单与浮窗侧边菜单（2026-10-09，替代毛玻璃）

删除菜单抓帧、模糊和缓存链路，避免快速关闭重开时将旧菜单截进背景。保留原色、子菜单 75% 底色和 6px 文字行距；菜单栏底色改为 50%，焦点/高亮改为矩形，上方圆角、下方直角。背景每次绘制均先清空透明表面再绘制当前几何，防止圆角变化残留。

独立浮动面板的面板菜单在右侧相隔 4px 的专用 Qt.Popup 窗口中显示，右侧空间不足时放到左侧，位置受所属屏幕可用区域约束。保留原 QML Menu 内容及动作，以同窗 Item 菜单放入专用弹出窗口，因此兼容 Qt 6.5，不依赖 6.8 的 Popup.Window。Esc、点击外部及关闭面板均释放侧边弹出窗口；普通停靠面板继续在本窗内弹出。

验收：连续快速开关/切换菜单后截图与首次相同，无旧菜单缓存；最大化/还原后菜单栏上角仍正确，背景 alpha 50%、焦点矩形、文字行距 6px；侧边菜单与浮窗不重叠、屏幕右边缘向左翻转，动作与关闭释放通过普通/两倍 DPI 和 Windows 实窗验证。最后执行完整 python tools/check.py，更新 build/qt 并提交推送。

### 半透明圆角毛玻璃菜单（2026-10-09）

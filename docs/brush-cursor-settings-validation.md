# 笔尖光标偏好验收

2026-10-13：全局轮廓/简化圆形/中心十字/仅悬停/1–3像素线宽/内外轮廓颜色已实施。默认实际笔尖形状、黑白双线、无中心十字；独立于 VBR 和预设。光标编辑不使笔触预览失效；液化/CapsLock/临时工具保持优先级。

多文档笔刷状态同步并只经一个后台 worker 顺序保存，写入者关闭后排空保存队列再移交，最近快照供新文档继承。修复不同文档保存旧副本覆盖全局参数的可能性。

验证：Release Qt 构建与生成头检查通过；六项相关原生 Qt 测试通过（8 pass 含初始化/清理）：新增光标偏好持久化/非法原子恢复/不进入 VBR、轮廓和中心、绘画时隐藏恢复、CapsLock、简化圆形、多文档实时共享、关闭首文档后写入移交/第三文档继承/重新启动恢复；既有数位笔悬停、真实笔尖像素/预览、旧预设、画笔橡皮共用、跨窗口面板测试继续通过。

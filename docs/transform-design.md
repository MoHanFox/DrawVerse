# 置入图片、自由变换与栅格化

ABI 1.23。图片图层保留不可变原始像素和绝对变换描述，显示瓦片仅为派生缓存；重复缩放和网格变形从原图取样，栅格化明确移除源图，可撤销。图片源随文档嵌入保存，复制、删除、历史与 ORA 恢复不能丢弃源。

Ctrl+T / 编辑菜单进入自由变换，八个方形控制点与外侧旋转区域；默认保持比例，Shift 临时反转比例约束，Alt 围绕中心，Shift 旋转按 15 度吸附，Ctrl 角点自由扭曲、Ctrl+Shift 边点斜切、Ctrl+Alt+Shift 角点透视。顶部提供 X/Y、相对 W/H、比例链接、旋转、水平/垂直斜切、六种插值、自由变换/网格切换、重置、取消、确认。网格采用 3×3 单元的连续曲面，可拖动网格节点。Enter / 双击确定，Esc 取消；Ctrl+Z / Ctrl+Shift+Z 撤销重做每次调整，步数沿用历史设置，确认只有一条正式历史。

源数据、变换描述、取样与提交分离，为 CPU/GPU 后端共用操作描述。CPU 预览和最终结果使用相同取样器，后台执行；资源失败不修改旧预览或历史。文档会话期间阻止其他编辑，保留视口平移缩放。原始 RGBA32F 不经 PNG 回写；文件中兼容预览和原始模型分别存储。

实现前验收：原图缩小再放大精确恢复、栅格化撤销、自由变换控制与会话历史、六种插值真实区分、透视/网格/翻转、锁和失败原子性、复制与 ORA 原始源恢复、FFI 边界/异步顺序、Qt 主窗及浮动画布快捷键与控制点。

交互参考 Adobe 自由变换说明：https://helpx.adobe.com/photoshop/using/free-transformations-images-shapes-paths.html 。以当前默认保持比例的操作方式为准，不采用旧版 Shift 才保持比例。

组与多选使用统一边界和共享变换，逐个保留原始图层、图片源、蒙版与层次，不先合并栅格化；生成全部目标预览后原子替换。提交与撤销以完整目标集合形成一条历史，取消恢复原集合。验收增加组/多选缩放与取消、图片源保留、整集合撤销。

普通栅格层存在选区时仅变换选区内像素，残余像素留在原位置，选区灰度覆盖随变换移动；局部与正式历史同时保存像素和选区。图片层及组/多选保持整体变换。选区运算沿用 16MiB 覆盖上限，超过上限明确报错。验收包括选区内移动、外部像素不变、取消与撤销恢复选区。

# 第二笔尖独立路径调度

在现有 paired-dab-v1 上新增显式 path-coverage-v1 模式：SecondaryTip.with_spacing 接受直径比例0.01..1，间距只由第二标称直径决定。没有 spacing 的已实现配置仍使用配对印章，不默默切换旧配置。后续界面默认独立路径；两个模型在交换中必须明确区分。

笔触捕获独立的第二距离余量、序号和上一印章。每个输入段按弧长合并主、第二事件；相同距离先生成第二印章，随后主印章读取覆盖。第二动态使用自己的事件序号和固定随机域，不受主间距或主散布数量控制。原地第二有效压力响应变化触发第二更新，主不透明度变化不重复沉积第二流量。释放时补第二终点和必要的主终点读取。

第二覆盖用稀疏64px瓦片并集，存于目标图层局部坐标；分页、暂存盘和瓦片上限复用现有 PagePool。主写入按瓦片读取第二覆盖，不做逐像素哈希查询。每个散布子印章只走自己的矩形，避免远距离散布的大空矩形。关闭/配对模式不分配此场。第二覆盖只在笔触内存在，完成/取消释放，不进入文档或历史，历史仍只保存最终图层像素。

起笔、每段与终点均预检主/第二事件最大展开数和两者采样工作量之和，段拒绝不推进任何距离/随机状态；存储失败或覆盖瓦片超限回滚整个笔触。主边界、选区与锁沿原写入规则；第二字段不是文档选区，不能额外合成到画布。

验收：第二间距真实改变印章图案、主间距改变不重采样第二序列、不同输入拆分逐像素一致；转弯/终点/原地压力与设备、独立散布随机；程序/图片/旋转及偏移；画笔/橡皮/蒙版/涂抹、整笔上限/历史/取消；单瓦片驻留冷页、字段上限和最大密度两流预检原子性。旧 paired 回归和旧IO拒绝保持。保存/原生Qt以及真实PS兼容核验仍待后续，无ABI变化。

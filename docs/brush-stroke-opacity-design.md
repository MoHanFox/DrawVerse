# 独立笔刷尺寸与整笔不透明度

用户新规则覆盖此前工具全局尺寸断言：活动预设的 radius 是实际像素半径，选择预设恢复自己的大小；大小编辑进入该预设、原生准备、复制与交换。旧状态 toolRadii 仅接受并校验，不覆盖预设尺寸。画笔/橡皮使用活动预设尺寸。

普通绘画、擦除和蒙版把 opacity 作为整条笔触上限，tip.flow 和流量压感控制笔触内的覆盖累积。每个触及瓦片保存未乘整笔不透明度的覆盖，使用起笔前不可变像素重建结果；选区覆盖在累积之外应用，避免反复擦拭突破羽化边缘。只为 opacity 小于 1 的笔触启用额外瓦片；瓦片进入既有驻留/暂存池，结束或取消释放，不分配整张画布。颜色自身 alpha 同样在最终合成应用。涂抹仍保留运输强度语义。

这是用户要求的全局行为修复，旧状态 opacity/VBR dabOpacity 对普通画笔现在解释为整笔上限；历史命令保存最终像素，无损撤销重做。现有压力控制仍是尺寸与流量，独立不透明度压力控制继续后续，不能将流量压感声称为不透明度压感。

数位板位置优先于绘画中到来的鼠标/悬停事件，避免合成事件覆盖笔位置。真实 TabletMove 更新轮廓，笔释放后恢复鼠标路径。

验收：低不透明度密集笔尖及往返不超过上限、第二笔累积、低流量逐渐达到上限、选区与蒙版/擦除/锁、取消/撤销/重做；每个预设尺寸编辑/切换/持久化/原生起笔；真实数位板按下移动时鼠标与悬停不会覆盖位置，释放后鼠标恢复。仅跑相关最小回归。

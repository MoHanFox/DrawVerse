# 二维湿混涂抹

2026-10-15。独立 R 涂抹工具在预设启用湿混后使用已有二维载体；关闭时保持旧涂抹逐位行为。预设选择不切换工具，不新增格式字段或 ABI。湿混 Erase 和双色仍拒绝。

涂抹使用自己的所有图层取样开关（覆盖预设中供画笔使用的 allLayers）、强度和强度压感。强度乘现有流量、覆盖、纹理、选区一次，不采用普通画笔的整笔沉积账本。每印章先从当前位置读出画布，再准备二维拾色/混合/消耗，随后以线性预乘 RGBA 插值替换目标；透明颜色可被搬运，不将涂抹误作前景色 over 沉积。透明锁保持目标 alpha。蒙版拾取可见灰度，写回隐藏量，透明载色不改变蒙版；所有图层取样仍不能编辑蒙版。

自动清洗策略不变；涂抹只有开启手指绘画时才执行自动前景色载入。关闭手指绘画不清除手动或之前保留的真实载色。每笔是否保留由 autoClean/autoLoad 策略决定。首印章和原地输入也允许拾色/沉积，不能沿用旧涂抹的原地跳过使准备好的载体丢失。颜色动态作用于实际输出，不能直接改写保留载色。

复用现有 WetTool 租约、配置起笔、预算、分页和结束采用；取消/失败不采用私有载体并恢复真实像素，撤销只影响文档历史。Qt 提示说明涂抹参数优先级；预设底部预览仍演示画笔模式的湿混，工具切换不改变预览。

验收先覆盖真实像素：前景色自动载入受手指开关控制、保留载色、二维拾色搬运、强度/压感、透明底/透明锁、选区/蒙版与合成取样、颜色动态、取消/失败/undo/redo；原生 actor 对照核心并验证载色采用。Qt 实际 R 工具落笔及旧普通涂抹回归。不以这些用例代替完整硬件/跨平台、性能、双色和收尖等总体验收。

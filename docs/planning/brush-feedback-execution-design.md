# 2026-10-18 用户反馈执行顺序

反馈来源为用户提供的桌面文本；其中的现象是待复现线索，性能原因和 Photoshop 对比不是已经确认的实现事实。本清单按依赖与回归风险排序，每个可独立验收的修改在最小测试通过后单独提交。

| 顺序 | 工作 | 最小验证及边界 |
| --- | --- | --- |
| 1 | [预览缓存与参数批处理](../brush/performance/brush-library-parameter-batching-design.md)：大小/流量/不透明度不触发标准预览，逐项更新预览，避免重建整个列表与重复全库查询 | Qt 信号/真实异步预览与大目录参数写入；保持绘画参数实际生效，不代替大包导入和滚动验收 |
| 1c（待完成） | 大笔刷包导入及导入后列表滚动性能：用户已明确“几乎滑不动”是滚动严重卡顿 | 分别测量导入阶段界面响应、首次滚动和预览缓存后的滚动帧耗时；覆盖图片笔尖/纹理/双笔刷资源，区分预览生成、图片加载、列表委托和整库同步开销，修复前后使用相同输入对比 |
| 2 | 设置面板按分类延迟创建，补选择框短标题、统一图片透明度滑条，隐藏相对尺寸下的绝对尺寸，收敛数值显示 | Qt 真实分类切换/布局/参数回写；不改变文件语义 |
| 3 | 曲线拖动保持鼠标抓取；[Ctrl 点击节点切换直线/曲线](../brush/dynamics/brush-curve-node-modes-design.md) | Qt 快速越界拖动；节点模式需要核心/IO支持后才能宣称完成，不能用整条曲线模式冒充 |
| 4 | 画布外起笔与库/图层自身落点屏蔽，双击笔刷改名 | Qt 外部起笔进入/边缘覆盖/单历史与真实拖放/改名 |
| 5 | [光标零宽细线、复杂轮廓简化、简化轮廓亮度设置](../brush/ui/brush-cursor-bounded-outline-design.md) | 核心轮廓边界与 Qt 光标偏好往返；独立于真实绘画像素 |
| 6 | [笔刷上限 2000px](../brush/core/brush-size-limit-design.md)，[扁平图片笔尖间距](../brush/core/brush-image-spacing-design.md) | 核心尺寸/预算与真实图片笔触、IO/ABR/Qt范围往返；避免仅放开控件上限 |
| 7 | [双笔刷相对百分比与 ABR 自动换算](../brush/dual/brush-dual-ratio-design.md) | 核心尺寸、旧像素偏移语义保留、state/VBR与ABR往返、Qt显示 |
| 8 | [起收笔相对/独立长度、头尾透明选择](../brush/wet/brush-taper-relative-length-design.md) | 核心像素/历史，IO关闭值与往返，Qt按模式显示；保留小数精度，仅规范显示 |
| 9 | [笔尖/纹理缩略图与已有资源选择](../brush/library/brush-resource-picker-design.md) | Qt资源切换与真实笔触、保存重开；引用已有资源，不重复导入 |
| 10 | [双笔刷选择已有笔刷并快照继承大小/间距/散布/数量](../brush/dual/brush-dual-existing-preset-design.md) | 核心/IO/Qt；选取时复制参数，不引入库循环引用 |
| 11 | 自身/已有笔刷/纹理描边 | 用户已明确：整条笔触轮廓，外/中/内可选，勾选后取色轮第二颜色；核心像素/IO/Qt，不能用第二覆盖模式冒充完整描边 |
| 12 | 大尺寸液化性能 | 固定文档/半径/输入基准及像素等价测试，区分核心计算、帧发布和界面开销；单独记录实测 |

## 执行规则

- 复用现有源码职责、contracts 和 `python tools/check.py`；不新增通用 Agent 框架。
- UI行为补 Qt 测试，数值/像素语义补 Rust 测试，跨格式修改覆盖旧值与新目录往返。每步只执行相关最小测试，不将它们写成全量通过。
- 新持久化语义先设计与验收条件，再实现核心→IO→原生→Qt；VBR继续为1.0，ABI/state/behavior独立演进。
- 性能修复记录可复现输入与结果；不从CPU/GPU占用推断瓶颈，不把用户对一种场景的验收外推到所有组合。
- 完成状态与实际命令记录在[验收记录](../validations/planning/brush-feedback-execution-validation.md)。

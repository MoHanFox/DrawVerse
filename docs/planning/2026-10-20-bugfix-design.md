## 排序

1. 严重：空图层自由变换失败、取消或 Esc 后界面无法退出。
2. 普通 1、18、20：初始背景乱码、无效变换拖动、微小套索误报。
3. 普通 2–9、14：资源/分组闪烁、多选保持、组与名称编辑、整数参数和紧凑控件。
4. 普通 15、16、19：整图翻转、多层移动、蒙版链接。
5. 性能 1–5：移动启动、选区变换、重复魔棒与复杂蚂蚁线导航。
6. 普通 10、11、17：最近八笔参数快照、工具隔离、涂抹独立采样。
7. 普通 12、13：旧描边纹理与算法命名、新增 SDF mask 描边，以及笔刷 GPU 说明。
8. 严重：长计算的可配置延迟进度和分步执行。必须接实际任务进度与资源失败，不能用动画冒充计算进度。

## 当前设计：自由变换状态闭合

Qt 在提交开始时乐观打开会话；原生拒绝空内容或成功取消后，元数据会将 transformActive 改回 false。原通知条件仅检查修改后的 true，遗漏 true→false；QML 因而保留工具覆盖层与快捷键。比较修改前后的 active 和 busy，并在任一转换时发 stateChanged，沿用原生错误与事务语义。

验收：空图层开始失败后覆盖层关闭、非空图层取消和真实 Esc 都关闭、无多余历史，且之后可继续绘画/变换。状态和几何分别使用既有通知，不改变 ABI。

结果见[验收记录](../validations/planning/2026-10-20-bugfix-validation.md)。

## 普通 1：背景名称

构造白色文档时使用明确 UTF-8 的“背景”，不迁移或改写用户已有图层名称。检查 4096×2160 初始化后名称正确、隐式白底仍不分配瓦片、未产生修订。

## 普通 18：拒绝无效拖动而不打断会话

继续使用原生几何校验作为单一判据。仅在交互 UPDATE 因退化/交叉四边形被同步拒绝时静默返回 false，保留上一有效控制点；坐标范围、资源等其他错误仍正常报告。后续有效拖动必须继续成功，取消不增加历史。保持变换期间原有状态修订通知，并补全关闭/忙碌转换。

## 普通 20：微小套索

客户端提交套索前识别不足三个点、全重复、全共线的有限路径，返回未提交，不改变选区和历史。按核心共线阈值 1e-9 检查，而非按有向面积检查，避免误拒绝合法的自交套索。非有限或超范围输入仍由原生校验报告。

## 普通 14：自由变换紧凑菜单

变换右键菜单复用既有 GlassMenu / GlassMenuItem，统一紧凑间距与主题，不另建菜单组件。回归检查实际装配的菜单行高度与取消项。

## 性能 3–5，第一步：选区几何与导航分离

选区布尔路径使用明确的文档像素尺寸作为裁剪域，独立于 viewport 的 documentRect / zoom。导航只重绘，不重算并集、差集和蒙版边界；避免 QML 分别更新 rect、zoom 时拿暂时不一致的比例反复裁剪复杂选区。保留未指定文档尺寸的旧调用行为。复杂蚂蚁线逐帧栅格化与消除锯齿效果另行检查，此项不宣称全部性能问题解决。

## 普通 7：后台同步保留多选

原生目录同步只更新执行参数，保留仍有效的 Qt 笔刷/组多选。restore 默认仍按文件的活动笔刷恢复；只有 applyNativeCatalog 请求保留临时选择，并按新目录过滤失效 ID。400 个预设样本模拟同步参数变更后，多选和禁止绘画状态必须保持。

## 普通 9：工具参数同排滑条

油漆桶不透明度和涂抹强度在标题与现有百分比输入间放置常驻整数滑条，滑动立即赋值；保留百分比文本编辑和既有设置持久化。滑条与输入必须双向同步，不修改画笔不透明度。

## 普通 4：紧凑图层组

组行高度 24px，普通像素行保留 34px；组不显示和请求合成内容缩略图，展开按钮、可见性、名称与可选蒙版仍可用。

## 普通 5：图层/组原位改名

双击名称原位显示输入框，Enter/失焦确认、Esc 放弃；空白名称不提交。Rust 复用结构历史保存名称变更，支持 undo/redo 且不复制像素；同名操作无历史。ABI 1.65 在现有 PaintGroupRequest 增补 RENAME_LAYER=4（同时支持像素层和组），复用 UTF-8 所有权和异步队列，DTO 布局不变。Qt 仅经 PaintCoreClient 提交，禁止在 QML 伪改模型文字。

## 普通 8：整数参数编辑

所有笔刷设置标量以整数显示单位提交（px、%、角度、数量、时间）；内部半径和归一化比例仍按现有契约换算，导入参数不因打开面板被改写。共用 ParameterSlider 根据精度吸附、量化提交，笔刷面板精度统一 0；独立大小和起收笔滑条同样取整，起收笔输入使用 IntValidator。曲线编辑器不变。

## 普通 3：笔刷组展开稳定列表

保留 groupedModel 供范围选择使用，显示模型改为有稳定 kind/id 的 ListModel，折叠/展开通过插入、移动、删除行更新。未变化的行保留 delegate 与 Image，避免整个 JS 数组重新赋值导致所有预览销毁、重建而闪烁。搜索和目录变化走同一更新路径。

## 普通 2：资源缩略图抗缓存淘汰

每个可见缩略图保留已获取的不可变内容身份图片，后台 64 项 LRU 淘汰不清空正在显示的图片，也不因全局完成信号反复重排队。复用 delegate 更换身份时才清空、请求新图。64px 缩略图在后台已生成，显示端同步解码，避免再次异步加载造成空帧。

## 普通 6，第一步：笔刷组创建与改名

创建组直接使用首个未占用的“笔刷组N”，有选择时复用原子 groupSelectedItems，无选择时创建空组。组行单击只选择，三角按钮独立折叠；双击名称原位编辑，Enter/失焦确认、Esc 放弃。保留根目录投放区但删除提示文字。多选拖动另行实现原子组织操作。

## 普通 6，第二步：多选原子拖放

拖动已选中项保留多选，目标统一调用一次 moveSelectedItemsToGroupAt。按组织树显示顺序提取最高层选中项（已选组的后代不重复移动），先检查目标及环，再从候选树移除、修正同父插入位置、批量插入，最后仅一次 applyOrganization；失败保留原树。沿用现有 MIME，只有操作成功才接受 drop。

## 普通 17：涂抹独立密集采样

涂抹沿位移路径使用笔尖尺寸/短轴决定的 0.25–2 文档像素采样步长，忽略主/副笔刷预设间距；第二笔尖在相同力场采样位置配对，不另开稀疏印章流。复用现有分页预算、不可变笔尖形状、压感/强度与像素传输。普通画笔和橡皮保留原间距。采样是有界离散近似，不声称数学上的零间隔或所有大笔刷性能已解决。

## 普通 12，第一步：独立描边纹理入口

已有算法标注为“建路径”。选择纹理来源先进入仅 UI 的待选状态，即使整笔描边已启用且主纹理为空，也可展开资源库或直接导入；选择合法资源后才发布有效描边配置，不向核心发送缺资源的启用纹理。导入复用已有后台资源解码，通过 role=3 应用到捕获的目标预设，不修改主笔纹理；切换预设后完成仍回填原目标。SDF 算法及自身笔触纹理扩展属于下一阶段。

## 性能 3，第二步：重复魔棒的幂等合并

魔棒默认 Add；原路径每次点击都追加相同 mask，增加历史、序列化与 Qt 布尔路径工作。Selection 在连续 max/Add 或 min/Intersect 段内发现相同完整形状时返回原身份，包含段起点 Replace；跨 Subtract/Invert/其他组合不去重，保持灰度减法语义。判定包含所有几何和 alpha 字节，不以边界或指针近似。无修订时继续沿用现有历史/显示不刷新路径。独立复杂蚂蚁线渲染与 AA 专项仍未完成。

## 性能 4–5，下一步：常驻遮罩显示

见[选区常驻遮罩与 GPU 蚂蚁线设计](../tools/selection-resident-ants-design.md)。复用 CPU 选区数据与软件显示，GPU 仅接管有界文档的常驻选区渲染和动画。

## 普通 15：完整图像翻转

在 transform 模块内增加整数镜像路径，复用自由变换的不可变源取样和 LayerEdit 原子历史；覆盖所有图层与蒙版（含隐藏/锁定层），不受当前选区限制。整数翻转无需插值：稀疏瓦片按镜像坐标读写、逐瓦片分页，保留隐式白底与画布外像素；置入图片仅镜像局部几何并保留原源图。蒙版与图层均按各自绝对画布位移镜像（现有蒙版并非父节点相对坐标），选择几何/灰度遮罩同步镜像。全部候选及历史成功后才发布，失败不改文档。ABI 1.66 在现有 transform kind 增补水平/垂直整图操作，不更改 DTO。

验收包括非 64 对齐的奇数尺寸、负坐标/半透明、白底透明擦除、蒙版/组/隐藏锁定层、置入模型、选区、双次翻转恢复、单历史 undo/redo、资源失败原子性和真实 Qt 客户端提交。

## 普通 16，第一步：多图层原子移动

现有绝对位移会话接受多个 ID，按最高层子树归并，组/子层/蒙版不重复移动；开始和更新先验证所有目标及祖先位置锁。预览只改 appearance，松手从基线一次提交结构历史，Esc/失败恢复全部基线。Ctrl 拾取沿用单目标，普通图层工具提交当前多选。ABI 1.67 增补复制 ID 数组的 begin-layer-moves 入口，UPDATE/COMMIT/CANCEL 复用原协议。

本小项先完成所有组合的 CPU 像素回退；单目标沿用原常驻 GPU 路径，多目标常驻显示及首次移动性能另行优化，不以功能通过代替性能验收。验证多选实时外观、重叠子树、锁拒绝原子性、最终绝对坐标/单历史、取消、原生数组所有权及 Qt 客户端。

## 普通 19：蒙版链接状态

蒙版记录独立的 mask_linked，默认 true；链接按钮提交核心属性历史，解除后移动/变换所有者不会带动蒙版，显式选中蒙版仍可单独移动。组内逐蒙版遵守同样规则，锁检查只覆盖实际目标。蒙版坐标本来就是绝对画布坐标，修正自由变换重复加所有者位移的旧路径。

状态通过结构历史、复制/粘贴及 ORA 保存恢复。二进制旧 mask 字节 0/1 保持，3 表示解除链接的蒙版，其他位组合拒绝；普通 ORA 原版本4/带置入源版本5不变，出现解除链接时分别写版本6/7，XML mask-linked 标志默认1，7保留置入源二进制。旧读取器显式拒绝新版本，避免静默丢失链接。ABI1.68 增补 group kind5 设置与按 publication 查询，不改已有 DTO。

## 性能 2，第一步：CPU 选区变换有界物化

选区原图中心覆盖边界用扫描行算子查找，避免复杂套索逐像素遍历边。对零位移且内容完全在画布内的普通栅格，保留原瓦片及隐式白底，仅重采样原选区边界与目标几何边界的并集；边界瓦片先保留原像素，再覆盖工作区，透明洞相对隐式白底必须写出。其余源保留既有全图路径。缩放的插值参数沿用原参考范围，不借优化改变采样行为。变换后的选区遮罩只编码目标在画布内的包围框，越界时为空遮罩，保持灰度和三角覆盖规则。

本项先解决 CPU 重复扫描/物化整张白画布，不引入 GPU 或改变最终算法；测试对照保留的全图实现，比较全部插值、变形/仿射、边界/半透明/羽化、撤销与瓦片身份，固定4K套索样本记录优化前后，不将核心计时当作UI帧延迟。常驻选区预览另行接入。

## 普通 11：三个工具的参数隔离

偏好新增不隔离（默认）、仅大小/不透明度/流量、完整隔离。BrushLibrary 管理三个工具上下文；部分隔离对每个预设分别记住三项标量，其他参数及活动预设共用；完整隔离分别保存预设参数、活动笔刷和混合模式。目录身份、名称、分组、导入资源与重置基线共用，切换工具不回滚组织、不复活删除项。更改隔离级别以当前设置初始化三套，禁用时保留当前工具参数作为共用值。

参数配置复用现有预设编码/校验，仅 UI 偏好持久化，不扩展 VBR/核心格式或 ABI；每套最多1024项/2MiB，三套加原状态有界。活动配置在 snapshot 时覆盖旧快照，原生异步规范化保留隔离偏好。工具切换仍经 PaintCoreClient；涂抹直接进入自身上下文，避免先进入画笔再覆盖；导航/选区工具不写入三个绘画上下文。参数相同的预览保留身份，避免切换重建整库缩略图。

## 普通 10：最近八个笔刷参数快照

起笔捕获单预设参数、双笔刷编辑来源和混合模式，收笔按End序列等待核心实际成功且产生变更的回执；取消、失败、无像素变更不记录。原生在publication内保留最多4096条成功End序列（共享不可变队列），ABI1.69按准确publication及after序列增量查询；不从最新历史深度猜测多笔异步结果。Qt待确认快照最多4096项/16MiB，已记录快照按完整参数去重、最近优先保留8项，同一笔刷不同尺寸独立保留。

偏好保存独立version1的八条单预设快照（每项≤2MiB，总偏好输入≤32MiB），复用原预设严格校验，不递归嵌入目录。点击恢复该笔刷参数及混合模式，保留当前工具、全局颜色和目录组织；原预设删除时创建新的自定义副本（不复活旧身份）。八格显示捕获的笔尖形状/图片及实际直径，无记录时为空。图片复用资源64px缩略图，不依赖图片光标开关。最近记录仅失效UI偏好缓存，保持执行目录缓存，不重复准备相同参数。VBR/state格式保持。

## 普通 13，第一步：SDF 与遮罩算子

见[SDF 遮罩描边设计](../brush/core/brush-sdf-outline-design.md)。先建立有界距离场、等距线弧长采样、max印章及遮罩布尔的CPU参考；旧建路径复用平方距离变换，保持现有行为。新算法的灰度形状缓存、笔刷取样、序列化、设置入口与独立自身纹理另行接入，此步不宣称UI完成或GPU加速。

## 普通13，完成实际接入

SDF描边已从通用算子接入灰度形状瓦片、不可变A/距离场/遮罩缓存、实际笔尖与独立纹理采样、单历史像素写入和QML算法选择；旧建路径默认保留。state43/behavior35、ABI1.71及VBR1.0按实际模型交换，预览和绘画共用版本辅助与核心入口。笔刷CPU/GPU范围及代码示例已补充到[GPU说明](../platform/gpu-acceleration-design.md#笔刷的-gpu-范围与-sdf-用法)。性能和资源近似边界见SDF设计，不将功能接入视为所有复杂图像性能达标。

# 时间平滑与稳定器内核

完整目标包括位置/压力平滑、稳定器、起收笔曲线和有界笔尾回算；本阶段先建立共用时间路径处理，不以平滑代替收尖或湿混。

## 不变量与模型

BrushSmoothing为验证后的不可变预设参数：enabled、positionMs/pressureMs（0..250）、speedResponse（0..1）、stabilizerPx（0..128文档像素）。默认关闭，位置12ms/压力8ms/速度响应0.5/稳定器0；关闭仍保留参数。三个实际通道全部零时走原始路径。主笔刷捕获一份路径定义；第二笔尖沿处理后的同一路径调度，没有第二套过滤器。

固定4ms时间网格，原始线性轨迹插值后按时间计算指数响应；位置响应随固定步进速度提升，压力独立平滑。稳定器采用文档像素拖绳圆域，低于半径保持位置、超过则跟随边界。相同带时间轨迹的线性拆分在固定网格取样相同，不能按事件数滤波。设备角度/倾斜等仍采用既有短角度插值，不用位置过滤器覆盖设备能力。无时间进展的输入明确使用直接通道并重置过滤相位；逆时拒绝且不改状态。

输入每次最多4096个网格点，配置和时间算术有界；生成在局部副本，所有主/第二印章工作量累计预检后才更新状态或写像素。材料/存储失败恢复整笔快照。结束时最多512个固定步进释放滞后，停止稳定器位置约束，最后连接真实终点；只处理尚未写出的笔尾，不重放全笔。不模拟压力归零，不把预测写入历史；取消不补尾。一次笔触仍只有一条历史。

Rust Document共用画笔/橡皮/涂抹/蒙版/选区路径，分页覆盖与随机序列按最终处理路径工作。没有Qt算法或ABI改动。本阶段旧state/VBR/来源基线编码明确拒绝非默认新配置，避免静默丢失；下一阶段接状态/VBR、原生桥、PS分类和真实预览，再推进起收笔缓存。

## 验收条件

关闭及启用零参数逐像素旧路径；同一带时间直线路径不同事件拆分一致；独立压力过滤、速度响应和稳定器；逆时/等时/极长时间与溢出拒绝有界且原子；真实两流、四类写入/选区/蒙版/偏移/压力上限/取消/分页与历史；在途捕获不受外部参数更改影响；结束精确终点；旧IO拒绝非默认关闭配置。相关Rust/IO回归与clippy，不宣称实体数位板手感或完整系统通过。

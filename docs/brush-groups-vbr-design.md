# VBR分组清单与副本身份

2026-10-17，接state20的ordered-tree-v1 DTO。VBR1.24在manifest新增可选organization，沿用完整roots/groups结构；旧groups保留为空的兼容槽，非空一律拒绝，避免两套组织源。有组织字段必须minor≥24；实际无组可规范为旧平版本，存在空文件夹仍是有组。预设的behaviorVersion/能力只描述绘画算法，不因目录元数据升级。

ImageBundle增加独立组织快照和显式with_organization构造，原Package仍表示平预设数据，旧调用方不改结构。所有构造、编码和解码均检查组织DFS预设顺序与Package/manifest刷子引用完全一致；manifest预检在读图片/来源前完成。继续256组/8层/1280节点和原JSON、ZIP及资源预算，不新增组文件，不放宽条目限额。平包不写新字段、最低版本和字节行为保持；纯程序但有组不能走旧1.0快路径。

副本重映射作为ImageBundle的原子元数据操作：调用者给新包UUID及完整预设/组映射，必须完整、唯一、规范且与原包身份集不重叠，两个角色及包身份也不互相冲突。先验证全部候选Package和新树，最后一次采用；取消或映射错误不改变原包。保留名称、顺序、全部当前参数和关闭值，资源/来源哈希和原ABR/记录字节不改、不重新编码或克隆大资源。目标库现有ID冲突仍由目录导入验证，不把映射的本地唯一性冒充全局UUID分配。

旧四类原生package_read在安装任何资源/返回平Package JSON前拒绝有组包，required清零；旧写入口的严格平Package JSON保持拒绝新增组织字段。新原生整树交接和Qt尚未接，不宣称用户导入已完成。

验收：纯程序/图片、空组/嵌套/同名和顺序VBR1.24往返；降级/未知模型与字段/legacy groups冲突/引用或顺序歧义拒绝，公开可变Package被改坏后保存不能覆盖目标文件；完整映射/缺失多余/冲突/取消原子性，资产和来源不变，真实当前两笔像素/载色和历史；Schema及旧平包最低版本保持、四旧读入口无资源安装。Windows必要回归/Release/ABI与旧Qt，硬件手感用户验收，跨平台后置。分组状态原生/Qt与库目标合并、重置基准全链仍待后续。

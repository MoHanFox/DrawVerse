# 面板收起后的尺寸保持（2026-10-11）

收起一列时，仅该列变为图标宽度；工具栏和其他展开面板保留收起前的宽高。浮动宿主按新的内容宽度收窄，保持左上角与高度，展开恢复各列原来的宽度。纵向腾出的空间显示背板，不分给其他面板；主工作区的腾出空间交给画布，保持已有画布像素定位机制。

工具栏的固定宽度规则优先于图标列紧凑分配，仍为用户选择的 36–72 逻辑像素。折叠前由共享布局计算记录展开叶面板的宽高；横向尺寸作为布局 v6 的可选 retainedWidths 保存，缺失时兼容旧布局。取消拖动恢复这些尺寸，显式窗口调整/分割线拖动解除相应方向的保持，允许用户重新安排尺寸。

旧布局未记录展开叶宽度时，从保存的展开宿主尺寸重建缺失值，再规范化已折叠浮窗宽度；已经记录的尺寸不覆盖。工具栏旁边都是图标列时，调整工具栏宽度也调整宿主宽度，不能把图标空间挤掉。

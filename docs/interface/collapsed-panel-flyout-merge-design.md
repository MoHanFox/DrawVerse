# 折叠列弹出面板的标签合并

## 交互与顺序

折叠面板列弹出的浮面板接受其他面板拖入。内容区追加为标签；标签栏按落点插入。拖入的面板与目标属于同一持久化组，因此折叠栏图标顺序直接采用组内标签顺序，拖动标签换序后同步更新，保存工作区后保留。

原生窗口拖动与 Qt MIME 拖放使用相同组内合并逻辑。单面板、整组，以及包含多个组的整列均可拖入；整列依来源组顺序、每组标签顺序合入目标，不拆成新的纵向面板。Ctrl 禁用吸附及 Esc 取消保留现有恢复快照。工具条与画布不成为内容区合并标签。

## 实现

- WorkspaceManager 为弹出面板单独记录可见合并目标，保留主停靠栏的独立几何。原生拖动优先命中实际可见浮面板，沿用 Windows 遮挡判断；不把弹出几何写回折叠栏目标。
- PanelGroup 提供 `mergeBeforePanelAt`，Qt 拖放和原生窗口拖动共用标签位置计算。dragBeforePanel 同时驱动插入线与最终合并，内容区为空锚点即追加。
- 原生拖动结束时，弹出目标的每个来源组都执行 merge，而普通整列停靠保持既有分组行为。
- 合并复用既有 dockPayload 与 group.panels；没有新增工作区格式或语义类型分类。这里的「同一类」是同一标签组。
- DockTile 在成员变化时更新各图标到同一浮面板窗口的映射，避免新合入图标再次创建重复窗口；PanelFlyout 同步组内当前标签。注册目标销毁时按对象身份注销，不移除新实例的目标。

没有新增 GPU 算子、Rust/ABI/state/VBR 修改。Qt 使用原有软件或硬件显示后端。

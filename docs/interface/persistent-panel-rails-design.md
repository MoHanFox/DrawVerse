# 常驻图标面板列（2026-10-10）

后续分组行为与仅顶层透明规则由 [panel-categories-design.md](panel-categories-design.md) 取代：同组标签/并列整窗展开，不同组可多开；下方栏不透明，正文内容共用。

后续 [面板状态与紧凑信息栏](panel-presentation-design.md) 将同图标再次点击改为收回，并增加面板尺寸/侧边位置保存与样式；本文的多开、空白不关闭、独立调整大小及列归位状态规则继续适用。

本次“面板列”指收起为图标的列，包括主窗停靠列与独立浮动列。用户要求取代此前唯一临时窗、点击空白/失焦收回的行为。每个图标可独立打开一个常驻面板，同列及不同列可同时打开；点击已打开图标将该面板置顶，不关闭其他面板。空白处和失焦不关闭，只有面板收回按钮、该面板上的 Escape、展开来源列、移走/删除来源等显式操作关闭。

打开的面板独立选择内容，不随同组其他图标活动状态变化；图标栏顺序继续由原标签组保持，普通展开组的标签拖动交换仍保留。每个图标窗口仅呈现该图标内容，其标题导航可沿列侧边滑动；浮动列仅要求导航靠列，面板底部不与列底部齐平，不用短列高度压缩内容。窗口有真实可拖动边框，宽高独立可调整，保持侧边锚定并受屏幕可见范围约束。最近点击的面板通过原生 raise/requestActivate 置顶，重叠时可切换前后。

主窗和浮动列的图标与空白区域均使用 Theme.surface (#1C1E21)。布局输出为紧凑图标节点补充独立列背景矩形，图标仍紧挨排列；浮动图标列保留原高度并允许调高，不缩成图标总高度。

整个浮动列在主窗侧边归位保持自身展开/图标状态，以独立列插入；窗口返回工作区保留树结构与组状态。明确插入另一列内部或合并标签仍沿用接收列状态，单图标拖出仍形成展开工具窗。布局继续 v6，无 Rust/C ABI 修改。

验收：同组及不同组图标同时打开、内容独立、最近点击置顶、空白/失焦保持、显式收回与 Escape、源图标拖出/展开生命周期；主窗和浮动空白背景像素相同；短浮动列打开高面板，导航靠列且底部独立，侧边滑动与宽高调整；整个展开/收起列经菜单和实际边缘拖动归位保持状态，保存重开保持状态；原正常标签排序及菜单外部关闭保留。普通/两倍 DPI Qt Test、Windows 实窗及完整 tools/check.py 后 commit/push。

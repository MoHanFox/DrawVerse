# 平滑画布导航与自适应笔尖轮廓

日期：2026-10-19。GPU 总体规则与代码入口见 [GPU 加速](../platform/gpu-acceleration-design.md)；验收见 [最小回归](../validations/interface/canvas-navigation-adaptive-cursor-validation.md)。

## 行为与约束

- 滚轮与缩放快捷键采用约 140ms 的对数缩放动画，保持输入时的文档锚点；连续输入累积目标倍率。100% 与适合窗口保持精确定位。开始绘画、拖动、切换文档、窗口失活或隐藏时停止惯性与动画，避免输入坐标漂移。
- 中键/空格拖动与笔输入拖动直接跟手；释放后根据最近的屏幕速度指数减速，长时间静止后释放不启动惯性。速度、帧步长与持续时间有上限。
- 高分辨率视口增加屏幕像素计量的周边预取和运动方向前瞻；仍受现有 4M 像素/4096 边长限制。整图概览复用 view 1（导航器），不存在概览请求时由主画布请求最长边 512 的概览。概览只填充高分辨率区域之外，避免半透明颜色重复叠加。旧纹理保留到新帧采用，跨文档代数清空。
- Qt 场景图变换常驻纹理实现显示加速；CPU 合成和任务调度保持现有职责。不宣称普通绘画、全图图层合成已迁移 GPU。
- 取消简化圆形的亮度控件。所有已显示的笔尖轮廓沿实际几何按显示背景逐像素选黑/白，带相反色的细保护边；主副笔尖几何、图片轮廓和液化圆形共用着色机制，不新增副笔尖溢出语义。当前灰度双笔刷仍裁到主覆盖，退役的双色溢出不会重新显示。半透明笔尖图片和中心十字保持独立。
- 自适应着色用 Qt ShaderEffect。仅截取轮廓可见包围区域的背景与轮廓 alpha 到有界 GPU 纹理，不读回 CPU、不捕获整张文档、不包含自适应输出自身。背景包括棋盘格、当前视口与液化网格。纹理尺寸不超过窗口物理尺寸与 2048 边长/4M 像素；无光标时停止离屏更新。巨大椭圆完全包住窗口、轮廓本身不在窗口内时跳过离屏捕获。
- Qt 软件渲染器不支持 ShaderEffect，显示黑白双线轮廓回退，不宣称软件后端有逐像素 GPU 自适应。计算设备选择与 Qt 显示后端独立。

## 验收条件

Qt 最小用例覆盖：缩放中间帧、最终倍率与锚点、连续缩放目标、惯性与中断、不写历史；预取覆盖可见区且受界限、透明概览不重复叠加；真实 GPU 捕获验证同一笔尖跨黑白背景具有相反亮度，光标移动/隐藏与液化显示不污染文档。软件回退与已有液化预览各执行最小用例。Release 构建必须通过；不运行全量或跨平台/实体输入测试。

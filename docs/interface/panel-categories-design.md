# 面板列与面板组（2026-10-10）

用户明确区分面板列和组：列沿整个侧边停靠；列内上下排列的块是不同组，以居中的灰黑横线分隔图标。标签合并和左右并列构成同一组，例如左边导航、右边历史/颜色标签构成一组。点击任一图标打开整组，保持标签和左右结构；点击当前活动图标再次收回，点击同组其他图标切换对应活动标签并置顶。不同组仍可多开，空白/失焦不关闭。

工具分割树的水平节点增加可选 role=row 表示同组并列，普通水平分割表示独立列；垂直工具树表示列内不同组。布局 v6 保留并验证此可选角色，旧布局水平分割继续解释为独立列，不猜测重组用户旧结构。列与组均从树推导，不另存可能失配的第二棵树。组边的垂直插入针对完整组；内侧水平插入为同组，最外侧水平插入针对完整列生成独立列，整列边缘发光。折叠列的空白区域同样属于完整侧边；24px 范围内先选鼠标指向的边，鼠标无目标时再用拖动窗边缘接触判定，避免宽窗口另一侧抢占目标。主工作区左右边仍可归位，文档/工具隔离不变。图标折叠把一组的左右树摊成单列图标；展开窗使用同一组树布局，完整组记住宽高与侧边偏移，整个列归位继续保留状态。

浮出组双击顶部只收回该窗，不展开来源图标列。整列展开由图标列顶部按钮明确触发；普通展开列双击顶部仍折叠列。

导航器删除底部尺寸/百分比/适合窗口/实际像素和空白区域，预览填满内容区。红色细框映射活动画布可见文档区域，画布平移、缩放、调整大小、文档切换与独立文档浮窗焦点变化均同步；裁剪到文档边界，未显示文档或没有交集时隐藏，纯视图变化不写入像素/历史。缩放与适配继续使用主底栏及视图菜单/F。

用户继续要求历史面板去掉底部撤销/重做按钮；历史条目点击跳转保留，编辑菜单/快捷键与工具条的撤销/重做不变。主窗、独立浮窗及侧边展开使用同一 PanelContent 和 PanelGroup；浮窗共用 PanelWindow 的字体/调色板，避免容器默认样式造成白按钮和深色按钮差异。

浮动列仅最上方拖动/标签栏背景保持 75% 不透明，下方组的标签栏使用不透明 #05080A；顶栏之后整列统一不透明正文背板，任何空白、分隔和下方组都不透出画布。侧边展开窗是一组，保留其顶层半透明背景。

验收：外侧整列吸附与内侧同组并列、上下不同组、标签合并、结构/折叠/取消/保存恢复；折叠列组间居中线、同组整窗与标签切换、多组并存、再次点击/双击收回不展开列、宽高记忆；导航红框在真实视口变换及多文档切换下位置/大小正确，旧下方控件消失。Qt Test 普通/两倍 DPI、Windows 实窗和完整 python tools/check.py 全通过后提交推送 origin/master；Rust 与 ABI 不变。

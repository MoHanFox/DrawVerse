# 无文档欢迎工作区

## 行为

正常启动不注册画布文档。没有任何文档时，菜单栏和背景保留，中央显示「欢迎来到DrawVerse」。引擎准备期间显示实际加载阶段的小字；引擎、偏好和当前笔刷执行资源准备成功后，替换为蓝色「新建画布」及浅亮背景、白色描边的「打开」胶囊按钮（126×34，圆角为高度一半）。按钮复用原来的新建与文件打开对话框。

主工作区、工具条、工具详情与状态栏随文档列表整体隐藏；浮动停靠面板和浮动工具条通过独立 workspaceHidden 条件隐藏，保留窗口对象及持久化布局。打开或新建后恢复；关闭最后文档、初次打开失败后返回欢迎页。文档命令与快捷键增加文档存在条件，避免操作初始化客户端的内部会话。

## 边界与实现

`DocumentManager::configure` 默认只登记应用服务客户端，不把内部默认会话加入用户文档列表。服务保留笔刷资源、偏好及后端初始化，所有用户文档走原有独立客户端生命周期。`Main.qml` 首个 CanvasPane 显式绑定真正的首文档客户端，后续文档继续独立创建。预览、基准及现有编辑器测试显式设置 createInitialDocument；正常程序启动不设置它。

加载完成由真实信号决定：brushLibraryReady 表示偏好已恢复；ready 表示绘画引擎可用；新增 Qt 只读 brushCatalogPrepared 表示工作线程收到当前 preparation 的成功结果。等价目录也会报告完成，过期票据及失败不冒充成功。欢迎文字按实际状态显示阶段，没有伪造百分比或固定时间。错误显示在欢迎区，首选项仍可用于修正存储设置。

这里只改变 Qt 应用启动和显示，Rust/ABI 1.74、state44、VBR 不变。内部服务仍有核心会话；本次不等同于消除所有冷启动计算或把全部初始化搬离 GUI 线程。

按用户补充，移除“文件操作完成”这一通用成功通知：文件成功回执清空旧通知，保留失败提示和“保存期间又有修改”的关闭保护。不能只隐藏欢迎页所有错误。验收新建白底/透明画布、实际保存、关闭最后文档后欢迎区无成功文字；实际打开失败仍显示错误。

## 2026-10-21：面板异步创建的窗口生命周期

PanelContent 的 Loader 只在内容可见、实际宿主窗口可见且当前客户端未关闭时激活。隐藏原生窗口不会自动清除子项的 visible，因此仅检查子项不足以阻止欢迎页隐藏浮窗继续创建图层面板。切换来源或卸载时，如果 Loader 仍在 Loading，先将 asynchronous 设为 false，完成已开始的控件 deferred 创建，再同步卸载；避免外层取消后 Qt 6.8 控件内部创建计数遗留。LayersPanel 到自身 Component.onCompleted 后才填充 ListView，避免外层未完成时再启动子委托。再次打开窗口按原选择恢复内容。保留图层面板异步创建和持久化布局，不以等待或屏蔽警告处理退出诊断。验证欢迎页往返、隐藏浮窗零激活 Loader、关闭客户端零孵化对象以及真实跨窗口编辑。


浮动面板窗口始终使用透明 surface，图标栏仍由原背景矩形填色；展开/折叠不再在已创建的交换链上切换是否需要 alpha。验证原生拖动合并三种来源，以及原图标列展开后的背景与位置。


跨窗口画布迁移先将 CanvasPane 隐藏，使自适应轮廓/选区的 ShaderEffectSource 解绑，再改变 parent，最后显示并恢复焦点。原来的 park 先改变 parent，GPU纹理源仍持有旧窗口，会阻止子树正确迁移并在后续标签激活时停留在主窗口。保留Canvas实例、客户端、缩放与平移；回归用当前Ctrl+Shift+Z、实际缩放动画完成及通过静止中键停止惯性验证状态，不用固定等待。

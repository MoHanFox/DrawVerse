# 自定义快捷键

命令目录由 ShortcutSettings 定义，QML 菜单与画布读取同一份有效绑定。仅命令快捷键可编辑；空格平移、修饰键手势、确认/取消和方向微调保持固定。

单个按键组合通过 Qt QKeySequence 规范化；拒绝无效输入、固定交互键以及命令冲突（包括前缀）。允许清除绑定和恢复默认。录入期间暂停所有可配置绑定，Esc 取消录入。配置保存到独立 QSettings 分组，不改文档或 ABI；保存失败回滚内存。默认保持现有行为。浮动画布共用配置，原有焦点和可执行条件保持。

套索命令：L 激活并沿用上次套索子类；Shift+L 在自由套索与多边形套索之间切换。两项均可自定义，浮动画布共用；只在画布获焦且未绘制、未液化、未自由变换时触发。工具提示随有效配置更新。

新增默认键与用户已有显式配置冲突时，保留已有配置，新命令保持未绑定，避免重置用户快捷键。

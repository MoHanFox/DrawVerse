# 当前画笔与画笔设置（2026-10-09）

用户明确：画笔面板选笔刷，画笔设置只编辑该笔刷，不需要设置页的第二个笔尖网格。按此拆分为共享 BrushLibrary 状态、画笔列表和设置页；所有停靠/浮窗/自定义画笔参数面板读取同一状态。

## 方案

本轮不复制 PS 截图笔刷，也不添加没有核心实现的纹理/散布/硬度开关。内核已经支持圆形压感笔刷的半径、不透明度和间距；库以这些真实参数提供圆笔预设，可保存为自定义预设。大小显示直径，提交核心时除以二；间距界面以直径百分比显示，核心以半径分数表示，范围 2.5–50%。橡皮擦为工具状态，与选中笔刷独立。

BrushLibrary 是 UI 设置模型，不访问 Rust 内部；PaintCoreClient 将活动预设的参数快照提交既有 C ABI。设置按预设保留，切换不串改其他预设。后台读取/保存有版本及范围校验的 JSON，最多 64 个预设，名称最多 80 字符；坏数据保留默认库。删除内置画笔禁止，删除当前自定义预设回到默认笔刷。颜色仍为独立前景色。

预览经 PaintCoreClient 的后台 worker 建立独立 Rust 异步 session；使用真实圆笔压感、opacity、spacing 绘制白色波形到透明 240×60 文档，按可读范围缩放半径。与当前文档、图层、历史、脏标志隔离。串行请求，每个预设只保留最新 token；结果过期不覆盖。界面请求用单次 debounce，仅可见列表与设置请求，主画布绘画期间延后预览。不在 UI 主线程生成笔触，不按绘画帧刷新模型。退出先停止预览 session，再销毁核心。

## 验收

1. 不同预设参数独立，切换、修改、保存副本、重命名、删除、持久化及非法 JSON/数值测试。
2. 画笔列表选择后，设置页名称/大小/不透明度/间距同步；设置页无第二套预设网格；浮窗与停靠共享选择。
3. 后台真实引擎预览可见、有 alpha、修改 opacity 后像素变化；过期结果拒绝；预览不改变主文档 revision/history/modified。
4. 实际绘画验证 spacing 与透明度生效，鼠标/数位板、蒙版/剪贴/IO、Qt 两倍 DPI 全部回归。
5. 完整 check、原生截图、600 点绘画性能复核后独立 commit/push。Rust/ABI 本轮不改，不创建虚假 pytest。

# 笔旋转动态

2026-10-18，新增预设级笔旋转动态，模型为 `rotation-v1`。输入使用 `InputPoint::rotation` 的整圈角度，按 `rotation.rem_euclid(360) / 360` 归一化到 0..1；设备没有旋转能力时按 0 处理。曲线在整圈边界存在方向不连续，使用时应把曲线端点视为同一角度附近的配置。

参数包含启用开关和尺寸、流量、整笔不透明度三条独立曲线。每条曲线使用 2–17 个严格递增节点、0–1 最低比例及可选 `smooth-pchip-v1`；默认关闭、三条曲线恒等线性。曲线编辑复用 `SpeedCurveEditor`，设置/重置回调指向旋转对象。

尺寸因子乘到主笔尖实际半径，并乘到配对第二笔尖的独立/相对跟随尺寸；相对固定边宽继续以已缩放主尺寸为基准。流量因子乘到印章流量，不透明度因子乘到压力/起收笔形成的整笔上限。旋转因子与压力、速度、切向压力、距离、倾斜因子在同一印章计算中相乘；随机序列、选区、蒙版、锁和历史边界不变。第二笔尖自身不保存旋转动态，由主预设统一下发。

保存使用 state28、VBR1.34、behavior23 和 `rotation-dynamics` 能力。VBR `parameters.rotationDynamics` 完整保存 `model/enabled/size/flow/opacity`，关闭状态也保留；旧 state27/VBR1.33 不携带该对象，低版本夹带明确拒绝。预设复制、完整重置、导入导出和重启恢复使用同一对象。

本阶段只覆盖笔旋转角；ABR 旋转/渐隐来源、任意来源到任意参数的动态矩阵、实体设备手感、跨平台和 GPU 仍未完成。

# 工具列、稳定视口与画笔交互（2026-10-10）

本轮按用户 18 项反馈调整 Qt/QML，Rust/C ABI 保持。工具列侧向吸附针对整个工具面板列，成为从顶到底的独立邻列，不插入某一个短面板。工具列正文宽度范围 36–72 逻辑像素（浮窗含两侧边框 38–74），高度可调整；停靠分隔和浮窗边框均可调整宽度，布局 v6 可选 toolWidth 保存。从混合浮窗移走最后一个普通面板后，剩余纯工具列立即约束宽度，保留高度，避免继承整个混合窗的宽度。工具列不被面板折叠。

吸附提示采用非交互、不抢焦点的独立透明工具窗，沿目标边缘向外绘制窄高亮。主窗边缘、独立列侧边和浮窗边都使用同一提示；它不参与停靠命中/遮挡判定。提示只在拖动期间存在，不覆盖窗口正文；Ctrl 抑制、取消和释放均删除提示。

交互画布在工作区布局改变时保持文档像素在所属窗口中的绝对位置与缩放，区域缩小仅裁剪。CanvasItem 记录文档原点的场景坐标；DockWorkspace 更新叶几何前捕获、布局完成后恢复同窗口同文档位置，布局期间视口尺寸改变补偿中心变化。用户显式适配/缩放/平移、切换文档或移至另一窗口仍按各自行为处理。导航缩略图继续自动适配。

文档标签使用上方圆角、底边平直的 10px 圆角形状，留顶部 3px 间隔；独立单文档窗保留一行标题及原生拖动能力。工具详情栏高由 28 改 36，控件垂直居中。

画笔和橡皮各自保存活动直径，同一工具换任意预设均保留该工具直径；形状、间距与不透明度仍由共享预设提供。BrushLibrary 保留旧预设 radius 字段用于旧设置验证，但活动 radius 改为工具大小槽，设置 JSON v1 增加可选 toolRadii，旧配置用所选预设半径初始化两个槽。半径修改不使列表预览失效，所有预设预览均用固定适中半径；不透明度/间距修改仍生成真实异步预览。错误预览不会伪装成功。

颜色块单击交换前景/第二颜色，双击弹出对应颜色的 HEX 输入，延迟单击避免双击先交换；第二颜色初始白色，并由同一 PaintCoreClient 维护，预览、色轮、绘画使用当前前景色。截图指示的是色块，色轮拖动继续调 HSV。

未开启 CapsLock 时，绘画画布显示按实际工具半径和缩放计算的圆形笔刷轮廓，黑白双线可见，移出画布隐藏。CapsLock 显示精确十字；移动、选区及 Space 平移保持相应光标。Windows 同步真实 CapsLock 初始/重新激活状态，其他平台按应用内按键更新。圆形笔尖是当前实现的实际支持笔尖；不伪造尚未支持的形状。

验收在 Qt Test 覆盖工具整列吸附、混合窗拆分、宽度边界/缩回/保存恢复、外侧提示窗及取消、左右列展开收起的像素绝对坐标、标签圆角与详情高度、两工具大小与跨预设继承、固定真实预览、颜色单双击、鼠标/CapsLock/工具切换轮廓。普通/两倍 DPI 和 Windows 实窗验证后运行完整 tools/check.py，每个完成模块提交推送 origin/master。

原生窗口检查还覆盖标题栏单击/双击不提前进入系统移动：普通窗口同样越过拖动阈值后才 startSystemMove，最大化恢复跟随行为保持，避免双击第一下进入原生移动循环。

Windows 全屏的排队系统移动消息经过全局原生过滤器；Qt 消息分发可能不给 result 指针，因此所有过滤返回值写入先检查非空，避免消息队列路径崩溃。原生回归使用 PostMessage 验证真实队列处理，不以绕过过滤器的同步 SendMessage 进入移动循环后人工退出作为通过。

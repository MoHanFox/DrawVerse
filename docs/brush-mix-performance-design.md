# 混合与双笔刷性能、菜单和预览修复

2026-10-14用户反馈工具混合与双笔刷都慢。先保留可重放release基准，覆盖普通/混合/独立双流/配对/组合与128/256px，记录真实像素摘要和End历史。优化保留间距、AA、压感、颜色动态、选区、蒙版、分页和事务；不提高间距、不丢输入。不宣称本轮解决所有性能问题。

圆形程序笔尖对保守内圈/外圈作平方距离判定，距离边缘至少0.5px的区域返回与原式相同的0/1，边缘和椭圆仍用原hypot与软边算式。主/第二共用。整笔覆盖达到当前压力上限后，在目标操作稳定、文档纸纹未启用时，不重算已不再变化的颜色混合；不能跳过会变化的纸纹、工具翻转或未达到上限的颜色贡献。优化前后真实像素必须相同。

用户补充：工具详情下拉须高优先级跨原生面板置顶。工具选项CompactComboBox使用Qt6.8窗口Popup，Qt6.5/测试强制fallback使用已有原生浮窗规则的独立Qt.Popup/置顶窗口；普通面板下拉维持当前行为。Esc和外部点击关闭，关闭后返回原父项，反复打开和浮动画布仍正确。真实窗口渲染/点击回归，而非只断言z值。

笔刷预览固定正常，不跟随工具模式；移除混合底色/额外模式预算，不因模式切换失效或重做所有预览。真实笔触仍捕获工具混合模式，颜色动态/双笔刷等预设内容仍生成真实正常预览。保存工具模式与预设完全分离。对应回归覆盖预览像素/缓存/在途请求保留、实际混合/历史、菜单跨窗口及DPR1/2，性能以同一固定输入和像素摘要对比。先修复本轮反馈，双色扩展与平滑IO/Qt等全系统范围仍继续后续。

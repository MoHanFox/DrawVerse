# 搜索与快捷键焦点修复

2026-10-13 补充：面板保持打开时，搜索→工具按钮或画布外部空白→搜索必须允许反复恢复输入；不得依赖重新创建面板。回归用真实点击和键盘输入验证，不能用测试代码直接 forceActiveFocus 代替用户点击。

图标展开的 `PanelFlyout` 是可编辑的独立原生窗口，必须允许激活，不得设置 `WindowDoesNotAcceptFocus`。搜索点击同时恢复控件焦点和所属窗口激活；工具点击回到画布。输入回归同时覆盖停靠及图标展开窗口，并向操作系统当前焦点窗口发送按键验证，不直接向失活窗口注入按键。

图层名称按去除首尾空白后的不区分大小写子串匹配。命中子图层时保留祖先组；命中组名时显示该组子树。搜索期间临时展示命中内容，不修改组折叠状态；清空后恢复。无结果显示明确提示，不修改选择或文档。

图层与画笔搜索编辑期间字母、Delete、Ctrl+C/V 留给文本控件。Enter 结束输入并保留查询，Esc 清空查询并结束输入；点击工具将焦点交回当前画布，工具和图层快捷键立即恢复。工具栏不再提供液化入口，保留滤镜入口及液化详情栏。液化 Enter/数字键盘 Enter 确定、Esc 取消；参数输入框编辑数字时 Enter 先完成输入。

拷贝／粘贴图层仅保留 Ctrl/Cmd+C/V，移除菜单栏和右键菜单入口；复制图层 Ctrl/Cmd+J 保留。

最小验收：Qt 原生窗口验证搜索名称/空白/大小写/无结果/折叠组祖先与恢复、搜索文字快捷键隔离、点击工具后的工具和图层快捷键、移除菜单与工具栏入口；液化回车提交与 Esc 取消。无 Rust 或 ABI 修改，不运行核心全套。

快捷键焦点判断只识别 QQuickTextInput / QQuickTextEdit。画布也有 cursorPosition 属性，不能用属性存在与否判定文本输入，否则画布获得焦点后所有图层快捷键均被错误禁用。

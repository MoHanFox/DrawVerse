# 实时笔尖姿态与光标

ABI1.38：独立可重复绑定的Pose句柄，create/bind_prepared/read/clear/destroy。绑定准确准备记录、预设ID与本笔半径，不等待编译；read仅try_result，未准备返回Busy并清空输出。准备完成只保留所选不可变预设，释放整目录ticket，不长期钉住全部图片。句柄每文档最多悬停/绘画各一个，跨笔触复用，避免每笔消耗不可复用ABI token。可以在库销毁后保留已捕获姿态，错误/并发绑定不产生混合配置。

原生Core pose和绘画共用每印章几何/尺寸响应，输出半径/角度/圆度。输入压力是否已知和方向向量显式标记，未知悬停压力返回名义半径，缺失旋转/倾斜仍走预设回退。Qt只映射输出，不实现压力/倾斜算法。GUI读取不做文件IO/资源扫描；冷准备仅排后台任务，等待时显示基础轮廓并16ms重试。

起笔绑定与BeginPrepared相同记录；绘画期间保存基础回退几何及图片轮廓身份，不用后来编辑的预设替换。鼠标/数位板/悬停更新输入和已知方向，释放/失活重置；视口只做显示变换。图片既有归一化轮廓与双线DPI宽度沿用。简化圆按原偏好保留名义大小；真实轮廓在落笔时用已知压力大小，压力为零时隐藏轮廓。

验收：原生尺寸/角度/圆度与真实绘画一致、Busy/错句柄/坏输入清输出、重复绑定/库关闭/在途独立持有、旧静态光标兼容；Qt真实TabletHover/Press/Move/Release、鼠标方向、图片轮廓、编辑期间捕获、缺能力与DPI/缩放，无QML警告。最小测试后提交推送，未实现其余动态湿混仍记录。

先复用快捷键、重复 Press、离笔、窗口悬停和菜单专项，以 Windows 原生可见 Release 窗口建立基线。新增测试先在未修改产品代码上执行，保存失败断言和事件序列至忽略的 `artifacts/issue-2-main-b1/`。

## 调查与修改边界

- 将已按下的笔手势归属与悬停光标归属分开。多个 CanvasItem 的应用过滤器不能抢走另一画布已接纳的 Move/Release；设备身份也必须匹配。
- 应用级 proximity loss 只收尾该设备在本画布接纳的笔手势，不能结束其他文档或鼠标笔触。
- 笔切换窗口/画布时，释放前一归属的原生光标和 QML 悬停显示。继续隔离 Quick 缓存鼠标 Hover，真实鼠标仍可明确接管。
- 隐藏、禁用、取消交互、换窗口/客户端或销毁时，复用已有取消路径释放本画布已接纳的笔接触，避免新的接触归属阻塞后继画布；不提交被取消笔触的历史。
- 菜单与普通按钮先通过实际 QML 行为、动作计数核对。没有失败证据的路径不作猜测性修改。
- Space 的缺失 Release 与 Ctrl/Alt 一样，通过现有 16ms 轮询的连续两次物理松开恢复；只恢复已接纳的按键，不通过轮询取得 Space。笔悬停归属存在时，其他画布不抢先消费 Space。

保留既有快捷键显示快照/笔尖姿态采样分离、输入后端选择和 WinTab/wmpointer 设备策略；在画布及菜单处理入口前执行同一拒绝判断，避免过滤器安装顺序影响结果。不增加计时器或点击时间去重，不改变压感、方向、绘画数据、ABI、依赖或配置格式。

原生光标释放时同步发布 QML 的悬停结束；保存的 Blank 若来自同一画布旧鼠标轮廓，不恢复已经失去归属的隐藏光标。保留普通 Wait 等已有窗口光标的恢复。

CanvasItem 的派生成员先于 QQuickItem 基类析构；实测基类析构仍发布一次 `windowChanged`。析构入口断开自身信号到自身的构造期回调，避免回调再次访问/启动已析构的计时器。连续销毁后建立新窗口的同进程专项覆盖此边界。

新增显式 `--profile-dir` 测试接入，统一隔离正式 Release 的输入偏好、笔刷资源和工作区；不传此参数保持原启动行为。`tools/run-tablet-input-check.ps1` 校验完整部署、排他创建会话目录、临时配置原生窗口与缓存/暂存路径，保存启动元数据后恢复父进程环境。没有新增逐事件日志或系统键盘监听；原有诊断默认仍关闭。

## 专项验证与交付

新增受控 Qt 事件用例覆盖多画布接触移动、非所属设备离笔、窗口悬停交接；复用实际按钮/菜单、快捷键与文本焦点、重复笔触/失抓/异常离笔、真实像素/历史/撤销重做、帧发布及颜色路径专项。合成设备命名不构成真实驱动验证；OS SendInput 与 Qt 合成输入分开报告。

部署完整 Release（含 Qt DLL/QML 插件），提供隔离配置启动方式与学生实体复测清单。方向噪声留待 B2；状态断言不能证明肉眼无闪烁。验收记录见 [专项验收](../../validations/brush/input/tablet-input-cursor-ownership-validation.md)。

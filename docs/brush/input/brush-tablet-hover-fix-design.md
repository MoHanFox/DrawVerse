# 数位笔直接进入与悬停光标修复

移除双色绘制页两个自动描边预设创建按钮，保留既有预设与底层模板能力。

Qt 可能在非落笔阶段只发送带数位笔设备的 Quick Hover，旧代码直接忽略这类事件。改为更新当前位置，保留最近 Tablet 样本的设备几何，悬停压力未知；落笔期间仍由 Tablet 输入独占位置，避免伴随鼠标/悬停覆盖真实绘画位置。

仅数位笔位于交互画布时设置对应原生窗口光标，解决未经过鼠标进入时仅设置 Item 光标不生效。全应用至多一个画布持有窗口光标；离开、设备离开感应范围、鼠标接管、窗口失活、隐藏/禁用/换窗/销毁恢复原窗口光标。无 ABI、预设或文件格式变化。

验收：无先前鼠标进入的数位笔 HoverEnter/Move、Tablet 窗口/Item 入口、笔触后悬停位置、鼠标接管、离开与光标恢复，保留倾斜/旋转与真实笔触历史；双色页按钮缺失，已有描边像素/历史/VBR回归。Release 和最小 Qt 测试，环境缩放1/2。

# 主线 B2 — Cursor Pose Continuity & Direction Diagnosis

基线为 B1 PR #5 合并提交 `a844abe8797e286af36d429c2533b10496eace22`。本阶段只调查和修正轮廓显示状态；不修改送入核心的绘画样本、方向阈值、滤波、ABI 或依赖。B1 运行包与历史证据保留。

## 先验证的边界

1. 已绑定的在途笔触使用捕获的不可变姿态；后续偏好保存或下一笔的参数准备，不应使其暂时显示基础轮廓。通过原生可见窗口、真实 CanvasPane QML、同栈参数变化观察，避免 QTRY 等待掩盖中间回退。
2. 悬停方向只能由同一画布、文档、输入设备且连续拥有输入的两个位置计算；新设备或离开后重新进入的首个位置不是移动向量。视图变换后的基准必须属于新的文档坐标系。
3. 真实微小位移、真实转弯及 ±180° 表示单独观察；不把数值跨界等同于可见椭圆跳变，不从合成轨迹推导驱动噪声或新滤波参数。

先在未改产品代码上保存失败断言，再选择最小修改。若不能证明缺陷，则只交付诊断，不增加猜测性缓存。

## 验收条件

- 已接纳笔触的姿态在偏好 pending 时仍按捕获参数和当前有效样本更新；结束后立即由新上下文接管。无有效绑定或真实错误仍回退，不无限保留旧姿态。
- 切换设备、离开/重新进入、文档变化不会用旧位置算首个方向；不沿用其他笔的倾斜/旋转几何。真实转弯无新增滞后。
- 记录输入位置、设备/画布、pending、动态 ready、最终角度/半径/圆度及 QML 值；有界内存收集，操作结束后统一导出。
- 同一有效输入序列的实际绘画像素、历史及撤销/重做保持；定向复用压力/倾斜/旋转、简单/动态轮廓、B1 生命周期/窗口/快捷键及一个颜色专项。
- Windows native 可见 Release、复用现有工具链与测试；原始证据在忽略的 `artifacts/issue-2-main-b2/`。合成 Qt 输入、OS 键盘注入与实体设备分开报告。

最终范围、失效规则、复现与限制见[对应验收记录](../../validations/brush/input/cursor-pose-continuity-validation.md)；不以状态断言声称肉眼无抖动或输入到显示延迟改善。

## 已证实缺陷与实现规则

未修改产品基线的新回归共 5 行失败：捕获姿态在修改下一笔参数时从 60°/.35/半径7.2回退为0°/.35/半径12；另四行的首次输入都被旧位置计算为约 −161.565°，预期无方向时0°。颜色变化同栈本身没有触发该回退，不能将此失败写成颜色即时显示缺陷。

- `PaintCoreClient::brushCursorPose` 先使用已成功绑定的在途 `m_strokePose`，只有非绘画悬停路径继续等待偏好提交及目录 source/preparation 匹配。沿用现有捕获句柄，无最后姿态缓存、不引入新的重试。结束/取消笔触后按原逻辑切回当前笔刷；未就绪、关闭、液化、缺失绑定和 native read 错误仍返回基础姿态。
- `CanvasItem` 的**显示用**位置历史增加 pointing-device 身份和文档 generation；Press、设备/笔尖工具变化、换 client、离开悬停、窗口/显隐/交互生命周期及文档变化清除该历史。接触越过边缘时仍保留当前接触的方向，悬停交接不改变笔触捕获。
- 同一设备的 Quick Hover 可继承最近原生笔样本几何；另一设备或另一笔尖不能继承旧压力能力、倾斜或旋转。下一个真实样本立即接管。
- 视图变化沿用原有 documentPoint 重定位；不修改方向阈值 `1e-9` 或真实微小位移的方向响应。±180° 数值及椭圆模180°等价性分别记录。
- 原有有界、默认关闭 InteractionTrace 仅补显示输入上下文、方向、半径/圆度、可见性、pending/captured 字段；仅测试显式启用，结束后一次导出。没有普通文本或系统键盘采集。

悬停期间涉及新笔刷/尺寸/形状的准备仍立即采用当前基础轮廓；不会为掩盖回退而显示旧笔刷。真实设备中这类必要准备变化是否可见，及真实微小输入的噪声分布仍待采集，不在本轮推导滤波参数。

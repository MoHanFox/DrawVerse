# Document真实输入分页

依赖原始输入调度器。新增明确的begin_stroke_input / continue_stroke_page / begin_stroke_finish入口；旧同步入口仍保留原预算。一次准备只推进一次原始滤波，保存原始段印章事件；页面不是新输入点，不增加中间终点。输入及结束未完成时禁止新输入/旧End，取消清除整笔及在途页。

事件页直接调用现有主/第二写入算子。实际像素、几何及双RGBA贡献、二维载色、随机计数和选区/锁均沿用现有Stroke状态，不克隆整笔瓦片。失败恢复笔触before，并丢弃输入状态。输入完成不增加历史；结束页完成后只提交一条历史、返回完整WetInk。

起收笔不能在页边界无条件重放整条笔触：只重放既有活动尾，拆分准备/按预算执行/采用。恢复尾快照一次，主副事件仍按原始次序逐印章执行，跨重放页保存检查点和日记。单个重放页继续受原8M/8192预算；页完成后可继续，End不能越过重放。旧同步起收笔路径复用同一重放执行器并保持累计预算拒绝规则。

验收：实际像素/完整载色与旧同步/已知终点一次性参考比较，页大小不影响结果；主副配对/独立、随机/压力/设备/时间平滑、图片/纹理、湿混/涂抹/蒙版及选区/偏移锁；原64px超预算输入在新Document入口完成。可见进度、取消/非法输入/页预算/瓦片与暂存失败整笔回滚、单历史及撤销重做、结束忙碌和不重复滤波。Actor尚未接时明确不能宣称Qt问题已修复。Windows必要代码回归，整体硬件手感由用户验收。

分页输入的512M访问/131072估算印章总上限也累计调度与活动笔尾重放，每页先按剩余额度收窄，不允许靠反复重放绕过整输入上限。没有输出采样点的平滑输入只采用滤波状态，不触发重放或可见修订。无独立第二路径时保留旧正无穷间距哨兵，仅在该路径关闭时接受。

# 密集笔刷输入有序分页

2026-10-16用户恢复推进，优先处理湿混双色Qt验收发现的单次64px密集图片输入预算回滚。目标不是提高原8M像素访问预算、减少印章或人为插值鼠标点，而是以有界任务页执行同一个原始输入段。

## 语义

保留原输入段起终点、原始压力/倾斜/旋转和时间语义；位置及设备插值继续使用现有InputPoint::interpolate（现有时间戳语义保持，不借此引入另一种时间模型）。印章序号、累计弧长、主第二独立间距余量、同时印章第二流优先、原地压力的副后主顺序保持。配对第二笔尖仍属于同一个主操作，不拆开成不同的取样顺序。零印章段也必须完成其边界状态。

调度器持有有界输入段和小游标，不建立整笔印章数组或克隆贡献瓦片。prepare_page不修改游标，产生有界事件及after状态；执行成功后才adopt，旧页/异实例页不能采用。失败不前进调度位置。分页边界不能变成新的用户输入点。

每页仍受8192印章/8M估算访问及8192个事件上限约束；页可缩小预算供调度公平性使用，不允许放大既有限制。单原子印章超页预算明确拒绝，不能偷偷拆散湿混的先读后写操作。单输入最多4096个滤波段、131072个调度印章及512M累计估算访问，限制异常长输入，不预分配全部事件。工作权重从原Document预算计算提取，共用同一估算，不以低估消除报错。

## 分阶段接入与验收

1. 数值调度/共用预算：完整主/副事件、设备插值、静止压力、弧长/余量及事务页。独立旧循环参考逐事件精确核对，页尺寸不改变序列；严格边界/整段预检/过期及异实例页拒绝。旧Document预算分类和真实笔触回归保持。本阶段尚不宣称修复画布的大跨度输入。
2. Document真实执行：原始滤波一次捕获、按页调用既有写入算子、保持起收笔检查点/活动尾、可见中间页/单历史、失败与取消整笔回滚。旧同步入口的预算保护保留，通过明确新入口接分页。
3. Actor调度：页之间让出任务，Move/End不能越过未完成页，Cancel/New/stop可终止且不采用载色；完成序列不能提前宣称输入完成。渲染发布和共享WetTool所有权保持。
4. 原生/Qt真实64px单输入复现及复杂组合、像素与载色/历史、取消/预算/暂存失败验证。无需更改ABI布局、state或VBR；准确记录仍存在的超大原子印章/总输入上限。

Windows最小相关验证，跨平台后置；不修改Qt绘画算法，不恢复试画。只有第2至4项实际接通并通过后才能移除剩余清单中的大跨度输入限制。

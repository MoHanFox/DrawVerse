# VBR 程序笔刷包阶段

基于 VBR 总体草案，首个可执行子集只包含已实现的程序笔尖与压感/流量。ZIP 包包含 manifest.json 与 brushes/<UUID>.json；不接受未实现的资源/分组/行为模块，明确报不支持，不替换为圆笔。

预设保留稳定 UUID、名称、profile/behaviorVersion、必需能力；参数使用 diameter（像素）、spacing（直径比例）、dabOpacity（当前印章沉积语义）、hardness/roundness/angle/flow/pressureSize/pressureFlow。前景色、工具临时大小和涂抹工具状态不进入 VBR。内置预设使用固定导出 UUID，自定义预设复用自身 UUID。

解析与验证在 Rust paint-io，执行验证调用 paint-core。Qt 只将已验证参数发布到库；导入整个包成功后一次更新，不覆盖同 ID 已有预设（冲突生成副本 UUID），不修改文档与历史。IO 在后台线程执行，界面提供导入/导出当前预设。首期 UI 库上限仍64，导入超过剩余容量整体拒绝。

限制：压缩128MiB、展开256MiB、条目4096、预设1024、单 JSON 2MiB；无落盘解压。所有路径/大小/压缩方式、重复及大小写冲突、符号链接、加密、缺失/多余条目、版本/能力、参数范围严格检查。保存同目录临时文件并同步后原子替换；错误和取消保留旧文件。JSON Schema 描述已实施子集，不宣称完整资源与 ABR 支持。

验收：跨包参数与身份往返、最低间距、非法参数/版本/路径/重复/预算、坏文件原子性、取消保存保留旧文件；FFI 长度/输出/数据复制；Qt 导出后导入、已有库/文档不被失败请求修改、预览与实际笔触有效。

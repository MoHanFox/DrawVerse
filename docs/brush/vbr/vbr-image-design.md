# VBR 图片笔尖资源

扩展可执行容器到1.1：manifest assets包含id/path/sha256/kind，kind仅tip-mask，路径固定assets/<sha256>.png。预设可选tipResource，只有drawverse.brush/behaviorVersion=1加image-tip能力能执行。标准资源仍是灰度×alpha覆盖，不进行显示色彩转换；完整PNG字节校验SHA-256，不能重编码后保留原身份。1.0程序包继续读取和写出。

资源归档先在Rust整包验证：所有逻辑路径、重复/别名/类型/压缩、尺寸/展开预算、JSON/预设/资源引用/PNG与哈希、所有实际定义编译成功后才返回。图片资源在包内去重，禁止缺失或无引用资源和未知资产种类。完整包保留原PNG字节与不可变编译覆盖，资源驻留总量限制128MiB；输入128MiB/展开256MiB/最多4096条目沿用有界容器规则。

程序旧API没有资源仓库，遇到图片包明确拒绝；后续独立库资源读写接口在完整验证后写内容寻址文件、返回小JSON，并由现有原子目录发布流程接入Qt。单个内容寻址文件不覆盖且原子写入；若后续整包发布失败，可能留下未引用资源文件，不能把磁盘资源写入宣称为可回滚目录事务。

原生ABI1.31的库级package_read/write处理资源仓库与小JSON。read容量不足/空指针先拒绝且不写资源；旧无库接口明确拒绝图片。导入交接支持多个不可变资源，直到准备采用它们；Qt沿用完整草稿恢复和冲突副本，预设tipResource映射v3 maskResource，导出按资源身份获取字节。Schema：`contracts/vbr-image-v1.1.schema.json`。

验收：程序兼容、图片包身份/资源字节/参数往返与真实孔洞像素、共享同资源、坏哈希/路径/种类/引用/彩色冒充/缺资源/额外条目/版本拒绝、取消保存保留原文件。全新Qt资源目录导入且删除源端文件后真实绘画/预览，重复导入冲突副本。ABR/高级动态另行继续。

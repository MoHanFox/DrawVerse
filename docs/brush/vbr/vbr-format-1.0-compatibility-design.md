# VBR 1.0 固定版本与缺项补全

2026-10-18，VBR manifest 的运行版本固定为 `1.0`。写出端始终写入 `major: 1, minor: 0`；读取端接受任意 `major: 1` 的历史或未来 minor，并以实际存在的预设字段执行。历史版本号只用于解释旧文件来源，不再作为拒绝预览、导入或执行的条件。

读取预设时先递归合并完整的默认配置形状。对象已存在时，缺失的标量、布尔、数组和嵌套对象字段补默认值，已有值保持不变；可选功能对象整体缺失时继续视为关闭，显式 `null` 同样视为关闭，不会因为补全默认形状而自动启用双笔刷、纹理、湿混或其他功能。双笔刷的 `paired-dab-v1` 与 `path-coverage-v1` 在合并后校正 `spacing` 的必要形态。

补全完成后，`behaviorVersion`、`requiredCapabilities` 和必要的 `engineProfile` 按当前实际字段重新归一化；已正确的内容及能力顺序保持不变。写出和手工构造对象仍通过严格校验，保留 UUID、名称、数值范围、资源身份、引用完整性、数量预算和可执行编译检查。缺字段兼容只发生在读取入口，不会放宽损坏资源或非法参数。

manifest 的 `version.minor`、`groups` 和 `assets` 缺省分别为 `0`、空数组和空数组，旧包不再因缺少这些结构字段失败。ZIP 条目预算与 6144 图片资源上限同步。

同一轮修正了画笔库中禁用第二笔刷的路径：规范化为默认值的空 `dualBrush` 现在表示已关闭的有效配置，可在导入后正常关闭；旧包中缺失或过期的行为版本元数据不再阻断 Qt 导入。禁用菜单项的级联展开计时器只在菜单项启用且悬停时运行，因此没有目标组时“移动到组”不会因鼠标经过而展开。

# 确定性散布内核

先完成统一印章内核，后续接版本化状态/VBR/原生Qt设置；本阶段不宣称已有界面。不可变ScatterDynamics：enabled、amount（名义直径的0–10倍）、bothAxes、count（1–16）、countJitter（0–1）、seed(u64)。关闭仍保留合法参数。单轴沿路径法线，双轴在文档坐标独立偏移；首个无方向印章以水平路径为基准。偏移范围为±amount×名义直径，压力尺寸不改变散布范围。

计数器散列基于配置seed、文档已接受散布笔触序号、逻辑印章序号、子印章及独立通道；不采用设备事件频率或全局随机状态。每笔不同，同种子/笔触序号/路径完全可复现；分段拒绝不消耗随机序号，取消已接受笔触后下一笔使用新序号。撤销重做恢复已生成像素，序号不回退；运行时序号不进入工程或VBR。数量抖动只减少至ceil(count×(1-jitter))（至少1），在此与count之间均匀选择。

逻辑路径间距不变，多个子印章共用方向及输入通道，分别经过真实笔尖、选区、锁、蒙版和写入算子。涂抹独立记住上一个实际子印章，用其位移搬运；首个普通涂抹印章不凭空载色，手指绘画只在首个子印章带入前景色。默认关闭沿旧路径，像素不变。

数量上限参与输入段与首印章工作预算（包括图片旋转和涂抹取样成本），超限先拒绝/整笔回滚，不静默删点、提高间距或减数量。瓦片/分页与历史仍走既有事务。旧IO遇到任何非默认散布配置明确拒绝，不能丢字段保存；原始converter1基线同样不冒充支持。

验收：固定种子真像素/共线输入拆分/数量与抖动/单轴双轴、每笔变化和历史精确恢复；图片/选择/擦除/蒙版/涂抹共用、首笔预算拒绝与后段拒绝保持状态、默认兼容。IO边界回归。实时光标仍展示基础笔尖姿态，散布包络显示与随机尺寸/角度/颜色等后续范围另行实现。

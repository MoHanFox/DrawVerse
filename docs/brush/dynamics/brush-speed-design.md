# 速度动态

2026-10-18，新增预设级速度动态，模型为 `speed-v1`。输入速度来自文档像素距离除以同一输入段的时间，单位为 px/s；零距离、零时间或反向时间不产生速度响应，保持通道原值。曲线横轴为 `speed / maxSpeed` 的归一化值并裁剪到 0..1，纵轴为输出比例。

参数包含启用开关、1–100000 px/s 的速度上限，以及尺寸、流量、整笔不透明度三条独立曲线。每条曲线使用 2–17 个严格递增节点，端点为 `(0,0)`/`(1,1)` 范围，带 0–1 最低比例；编辑时使用 `smooth-pchip-v1`，旧值缺省为线性。默认关闭、上限 2000、三条曲线均为恒等线性响应。

尺寸因子乘到主笔尖实际半径，也乘到双笔刷配对第二笔尖的独立/相对跟随尺寸；相对固定边宽继续以已缩放的主尺寸为基准，避免重复缩放。流量因子乘到每个印章的流量；不透明度因子乘到压力/起收笔共同形成的整笔上限。速度因子不改变随机序列、选区、蒙版、锁或历史边界。指针涂抹按现有流量语义使用流量因子，湿混继续走同一印章尺寸与上限路径。

Qt 在“传递”分类提供开关、速度上限和三条曲线。界面只读取简单的启用/上限/曲线/最低值属性；曲线使用专用 `SpeedCurveEditor`，避免把整张嵌套 `QVariantMap` 绑定到多个子组件。预览仍固定白色和正常模式，速度只在真实绘制输入上执行。

保存使用 state24、VBR1.30、behavior19 和 `speed-dynamics` 能力。VBR `parameters.speedDynamics` 完整保存 `model/enabled/maxSpeed/size/flow/opacity`；关闭状态也完整保留。旧 state23/VBR1.29 不携带该对象，字节和版本保持不变；带速度对象写入低版本或从低版本读取该对象明确拒绝。预设复制、完整重置基准、导入导出和重启恢复沿用同一对象。

本阶段不把速度来源接入 ABR 导入、ABR 导出或任意来源到任意参数的动态矩阵；不新增 C ABI DTO，也不改变现有导出签名。跨平台和实体数位板手感仍由后续验收覆盖。

# 笔触距离动态

2026-10-18，新增预设级笔触距离动态，模型为 `distance-v1`。输入使用当前印章在活动笔触中的累计文档距离，按 `distance / maxDistance` 归一化并裁剪到 0..1；每条笔触从 0 重新开始。距离单调递增，因此分页和回笔不会产生非线性负值。

参数包含启用开关、1–100000 px 距离上限，以及尺寸、流量和整笔不透明度三条独立曲线。每条曲线使用 2–17 个严格递增节点、0–1 最低比例及可选 `smooth-pchip-v1`；默认关闭、上限 1000、三条曲线恒等线性。曲线编辑复用 `SpeedCurveEditor`，但设置/重置回调指向距离对象。

尺寸因子乘到主笔尖实际半径，并乘到配对第二笔尖的独立/相对跟随尺寸；相对固定边宽继续以已缩放主尺寸为基准。流量因子乘到印章流量，不透明度因子乘到压力/起收笔形成的整笔上限。距离因子与速度、切向压力因子在同一印章计算中相乘；随机序列、选区、蒙版、锁和历史边界不变。第二笔尖自身不保存距离动态，由主预设统一下发。

保存使用 state26、VBR1.32、behavior21 和 `distance-dynamics` 能力。VBR `parameters.distanceDynamics` 完整保存 `model/enabled/maxDistance/size/flow/opacity`，关闭状态也保留；旧 state25/VBR1.31 不携带该对象，低版本夹带明确拒绝。预设复制、完整重置、导入导出和重启恢复使用同一对象。

本阶段只覆盖文档距离；ABR 距离/渐隐来源、任意来源到任意参数的动态矩阵、实体设备手感、跨平台和 GPU 仍未完成。

# 统一压力曲线与最低比例

完整动态的首个控制模块，先实现Rust验证/编译/真实写入，再接ABI持久化和PS分类面板。BrushDynamics与BrushTip分离，尺寸和流量各有PressureControl：2–17个(x,y)控制点、x严格递增并含0/1端点，xy有限且在[0,1]，允许非单调y；minimum比例[0,1]。按原始输入插值后在每印章计算：minimum+(1-minimum)*curve(p)。只有相应压感开关启用才生效；涂抹流量目标由独立强度压感开关控制，不与画笔flow开关合并。

编译预计算有界分段系数，实际曲线按定义分段精确求值，不用稀疏LUT抹掉窄变化。f64系数避免极近f32横坐标产生无穷斜率，输出有界；线性曲线/最低0编译成无附加控制，直接返回原压力，不增普通笔刷逐像素分支。程序和图片笔尖、画笔/擦除/涂抹及图层蒙版共用；已有选区、事务、间距、输入分段逻辑保持。

旧定义默认无变化，当前BrushTip与C DTO不扩展；后续经原生准确修订及新状态版本接入曲线。未接新IO前，旧状态/来源捕获遇非默认动态明确Unsupported，避免默默丢参数；ABR基础转换默认动态，不能宣称已经映射PS形状/传递动态。

验收：数量/有限值/顺序/端点/比例验证，非单调及极窄区间正确，独立尺寸/流量、开关/最低值与真实像素，图片/擦除/蒙版/涂抹压力生效且旧像素完全相同，起笔快照不随后续修改变化；旧IO拒绝未支持动态、旧状态/ABR/VBR回归。阶段后续必须完成编辑曲线/默认恢复/数值输入、状态和VBR往返及原生预览，不能用内核完成替代完整动态完成。

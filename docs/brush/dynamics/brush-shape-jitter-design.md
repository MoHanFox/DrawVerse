# 确定性形状抖动内核

新增不可变ShapeJitter：enabled、size（0–1）、minimumSize（0–1）、angle（0–1，最大偏移±180°）、roundness（0–1）、minimumRoundness（0.01–1，相对基础圆度）、seed（u64）。大小在[max(minimumSize,1-size),1]均匀取样，圆度同理，最终圆度至少0.01。顺序是压力大小/设备几何后再施加随机缩小与角度偏移，不放大名义外边界。关闭和全部零抖动保持旧像素。

基于accepted随机笔触序号、逻辑路径印章序号、散布子印章序号和独立通道生成固定随机值。复用散布计数器的混合函数但使用独立域，不以设备事件、像素访问顺序或流量改变随机序列。未启用新随机模块时，散布的既有随机序列不变。一次散布的不同子印章分别取样。无每印章分配、不保存无界随机序列。

几何沿共用覆盖用于程序和图片笔尖、绘画/擦除/蒙版/涂抹；图片旋转范围和LOD依实际随机几何。路径间距保持名义尺寸，不能因随机缩小改变间隔。预算保留名义最大尺寸和数量预检，失败不消耗序列；取消还原真实像素。光标保持输入位置的基础/设备姿态，不跳到随机样本。尚未接状态/VBR/Qt时明确拒绝非默认新配置保存，禁止丢字段。

验收：范围/非法浮点、独立随机通道、分段一致/不同种子、散布子印章变化，关闭/零配置的旧像素；压力设备组合、非方形孔洞图片完整覆盖；四类写入、整笔透明度、选区、取消及精确历史；失败重试序列与名义预算；未接IO必须拒绝。此模块无ABI变化，状态/界面与ABR映射后续接入，不宣称完整PS兼容或完整系统完成。

# 颜色动态内核

不可变ColorDynamics：enabled、foregroundBackground/hue/saturation/value（0–1）、perTip、seed(u64)。背景颜色属于本笔工具Brush，不进入预设。关闭/全零保持旧像素；默认背景白色，后续原生工具接口接用户当前背景。颜色在独立随机域按accepted笔触、逻辑印章、散布子印章取样；perTip=false整笔固定，true每实际印章变化。关闭模块不消耗随机序号。

前景/背景按均匀随机比例0..foregroundBackground在线性直RGB混合；色相在线性RGB的HSV中偏移±hue/2圈，饱和与明度加减最大设置值后裁剪。色相循环。保持前景alpha；透明背景没有可恢复直RGB，回退前景色，不制造黑边。此语义显式定义，不宣称PS/感知HSV完全一致，后续ABR映射必须报告差异。

颜色仅用于画笔、蒙版画笔及涂抹首印章手指载色，橡皮不改变颜色。涂抹后续仍搬运画布颜色。共享程序/图片覆盖。随机前景不改变光标；起笔捕获两色与配置。

整笔透明度的分页覆盖Tile在颜色动态启用时，用RGB保存直线性颜色的覆盖贡献、alpha保存覆盖量。新增贡献按本次覆盖增量加权累加；无增量时不改颜色，不随原地重叠加深。归一化累计色后按原始像素和整笔透明度重建。保留旧关闭路径像素，无额外整图缓存/第二套瓦片；压力更高可以加入新贡献，降低压力不使已画变浅。选区在累积后限制最终贡献，透明锁与蒙版沿既有写入规则。

验收：非法参数/透明色、各通道/两色混合/整笔与逐印章、独立随机通道/分段一致、真实多色覆盖且透明度上限、压力/图片/选区/蒙版/透明锁、手指载色与搬运、精确取消历史和分页、预算重试。原生/UI/IO暂未接时拒绝保存非默认模块，不能丢字段。全系统仍含纹理/双笔刷/平滑/湿混与完整ABR等后续范围。

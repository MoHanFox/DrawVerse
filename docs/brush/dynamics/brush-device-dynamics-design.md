# 设备与路径笔尖动态内核

先完成统一内核几何，后续再接有版本的状态/VBR/ABI/Qt配置和实时光标。不将仅有内核能力宣称为用户功能完成。本阶段无ABI变化，IO遇到非默认新动态明确拒绝，不能静默保存成静态笔尖。

不可变 TipDynamics：角度来源 Fixed/Direction/PenRotation/Tilt，倾斜圆度开关与最低圆度比例（0.01–1）。角度在预设角度上相加。路径方向来自累计采样路径的文档坐标切线；第一个没有方向的印章使用基础角度，静止保持最后有效方向。旋转需设备能力4，倾斜需能力2；缺失或倾斜零向量回退预设，不将缺失能力当真实零通道。倾斜角度采用两个Qt倾斜角通道的方位 atan2(y,x)；倾斜圆度以两通道合成幅度（上限90°）的余弦乘基础圆度，再限制最低比例及内核0.01下限。这是明确的DrawVerse参数语义，不宣称复制PS专有笔尖模型。

每印章计算一份小型几何（sin/cos/roundness），不克隆资源或重编译曲线，图片边界/LOD与程序覆盖使用同一份数据；画笔/橡皮/蒙版/涂抹共享。默认静态笔尖沿原算术保持像素，图片完整旋转边界不裁切。旋转插值走最短周期路径，缺失能力采用目标样本通道和预设回退。时间、压力验证与跨段间距保留不变。

验收：默认像素精确兼容，程序/非方形图片真实旋转和倾斜边界、鼠标路径方向、缺失能力、跨360°插值、急转方向及分段输入一致、选择/蒙版/擦除/涂抹共用、起笔不可变与历史；IO非默认新配置必须拒绝。真实设备、界面、VBR保存和动态光标是后续交付，不以本轮核心测试冒充。

# 压力动态状态与VBR

状态v5增加可选pressureDynamics（size/flow各有curve坐标对数组和minimum比例）。Serde有界读取最多17点，在构造类型时调用Rust核心验证；无可变未验证内核状态。旧1–4缺字段默认线性，不自动升级；非默认编辑结构保存为v5，包括语义线性但多控制点的数据。图片/来源行不能把v5回退。动态与工具/光标偏好仍分离。

VBR1.3新增pressure-curves能力及drawverse.brush行为2，与原有行为1区分。parameters.pressureDynamics使用同一经过验证的类型；启用/关闭仍由原pressureSize/pressureFlow（涂抹强度工具开关）控制，关闭时数据也保留。无动态包保持1.0/1.1/1.2，包含曲线则即使没有图片来源也使用1.3；旧容器版本含曲线、行为/能力不匹配须拒绝，不悄悄忽略。完整原始来源快照converter1仍不接受曲线，原始ABR基础转换不伪造压力动态映射；用户编辑的当前定义和原来源分离。

先完成IO/原生准确准备，再接Qt曲线编辑与真实预览，ABI随后声明能力。验收：v5恢复/规范化/旧状态不升级、非法顺序/数量/NaN/范围整包拒绝、当前动态真实像素及复制/快照；VBR1.3行为能力/版本/源图片共存/跨包/拒绝降级及旧格式回归；原生准备正确捕获动态，不把内核IO阶段当完整界面完成。

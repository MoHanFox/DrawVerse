# 湿混与颜色动态

2026-10-15。解除湿混对有效ColorDynamics的临时拒绝，复用既有linear-hsv-v1及完整种子/逐印章或整笔频率。先读取并更新原始二维载色，取样沉积RGBA后再应用颜色动态，之后进入既有RGBA贡献账本与工具blend。输出alpha保持，背景色只参与RGB；全透明沉积不会凭背景产生油墨。颜色动态不直接改写载体，但后续印章拾取已画颜色属于正常反馈。

ColorDynamics增加内部不可变ColorTransform，按既有随机域/逻辑序号/散布child与背景快照每实际主印章准备一次。整笔频率复用index0/child0，逐印章沿用主流调度序号；双重灰度笔刷的独立覆盖流不另调颜色。普通笔刷sample也复用prepare/apply；既有算法作为cfg(test)独立旧实现逐位核对，不能改变旧普通像素或state/VBR版本。背景透明时回退当前沉积RGB，HSV仍是明确的线性RGB规则，不声称光谱颜料混合。

载色保持只读准备/成功提交，清洗和装载不执行颜色动态；0流量/0opacity仅拾色时不变色。尺寸/压力/散布/图片/纹理/灰度双路径共用，蒙版在动态后转换可见灰度，透明锁保持精确alpha，opacity/选区仍只作用一次。饱和湿混贡献仍允许新颜色，不使用普通画笔的饱和跳过。计入额外每像素HSV工作与每印章准备预算；不在像素循环内重复生成随机数。有效双色湿混组合继续明确拒绝；IO/ABI/Qt入口尚待完整接通。

验收：旧sample与准备变换在完整种子、两种频率、多个两色alpha/灰度/色相及逻辑序号的f32位级一致；普通颜色动态原像素保持。真实湿混单印章与纯载色参考/蒙版/锁、动态RGBA变化与alpha不变、原始载色不被直接变色、整笔与逐印章差异、关闭值保持；散布/图片/纸纹/灰度双路径/分页/输入拆分/压力/平滑与真实历史、取消和存储失败。参数及版本不增加，仍不宣称Qt湿混或完整系统完成。

# 湿混统一设置与起笔载色规则

2026-10-15。将已实现的WetMix纳入不可变WetSettings：enabled（默认false）、allLayers（false）、autoClean（true）、autoLoad（true）及六项WetMix。关闭时保留完整值，但不改变普通笔刷；前景/背景实际颜色与载体网格属于工具状态，不属于预设。BrushSettings、BrushDefinition和编译BrushProgram传递同一快照。

新增Document配置湿混起笔方法，显式接收可选上一笔成功返回的载体。每笔在私有副本上重置路径，按新标称尺寸重采样二维载色并应用新WetMix；改load仅改变下一次装载量，不缩放已持有油墨。先autoClean，再autoLoad（使用起笔前景色）；初次没有载体时为空，autoLoad关闭则只拾取画布。成功结束返回下一笔载体；失败/取消不得修改调用方持有者。两笔位置间的空中移动不产生距离消耗。手动清洗/装载继续使用既有载体方法，不改变预设。

为避免绕过预设策略，普通起笔明确拒绝启用湿混，旧显式载体起笔拒绝启用配置并提示使用配置入口；默认配置的旧显式方法保持行为。配置入口只接收启用预设。启用湿混的非Paint和有效双色组合在编译时拒绝，关闭的组合可保存编辑。实际取样/选区/蒙版/锁/颜色动态/纸纹/散布/平滑/历史仍走已有湿混内核。

本阶段不分配JSON/VBR/ABI版本；旧state编码和原ABR来源基线显式拒绝非默认WetSettings，防止关闭参数丢失。Qt无入口不显示控件。后续文件格式再表达完整参数与关闭值，桥/Qt执行同一配置起笔规则，不另建Qt湿混算法。

验收：默认与关闭值不影响普通像素；真实两笔干载色/拾色、四种清洗装载组合、起笔颜色与设置捕获、跨笔路径重置和尺寸/混合参数重配；原载体不变、取消和失败、真实撤销重做；普通/旧显式入口和无效组合准确拒绝；旧IO非默认拒绝而默认字节保持。只验证对应层，不宣称完整湿混用户入口完成。

笔刷定义新增配置后，异步Operation::Begin改为Box持有定义，避免扩大每个Move等队列命令；调用方依旧立即拥有捕获的定义，工作线程解包执行，不改变ABI或排序。

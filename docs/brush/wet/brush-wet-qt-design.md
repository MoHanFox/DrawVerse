# 湿混 Qt 镜像、执行与参数页

2026-10-15。在已有BrushLibrary中增加完整wetMix映射，默认关闭、六比例与三个策略开关，关闭数据可编辑/保存；state17/VBR1.15/behavior14、复制/导入/原始来源与独立resetState基准完整传递。QML不计算载色或像素。湿混与有效双色组合双向拒绝，防止产生无法执行的修订；纯覆盖双笔刷允许组合。

PaintCoreClient最低ABI1.50及WET_BRUSH能力，主库准备/文件接口切换显式wet入口。共享BrushCatalogConnection持有一个工具句柄，所有文档创建会话后绑定同一工具，最后worker结束时释放。预览用独立工具/文档并清洗，不修改主工具/历史；有色底样使用真实Rust普通笔触建立，湿混仍走实际prepared入口，工具预览混合固定正常。实际工具颜色在需要时捕获，参数改变使旧token预览失效。

设置页新增末尾“湿混与载色”分类，沿用通用复选框、紧凑百分比输入和滑条；六比例0..100%，开关启用/所有图层取样/自动清洗/自动装载，解释统一悬停1秒。手动清洗/载色只操作主工具，异步反馈准备或占用失败，不产生画布历史。保持来源与兼容页唯一重置按钮。

验收：Qt严格模型/关闭值/默认旧版本、独立基准/复制重置与持久重开/VBR；真实参数页输入、有色预览失效但主文档历史不变；真实起笔捕获与两笔载色/手动控制、取消及undo/redo、文档共享与关闭寿命；相关旧模式/预览/持久化回归。未完成的双色湿混、湿混Smudge/Erase、收尖、非分隔和高级ABR等范围继续明确记录，不声称整个系统完成。

窄面板参数行约束最小宽度，数字框保留66px，标题独占一行、复选框文字换行；清洗/载色按钮纵排，不把参数列撑出滚动视口。湿混预览每次清洗独立载体、使用红蓝有色底样，再按自动载色策略试画，不读取主画笔的保留颜色；提示明确说明这一点。数值显示为整数百分比，原生f32回传采用相应显示容差验证。

手动操作等待本会话已提交的前序编辑序号完成，再检查工具占用；等待准备采用非阻塞轮询和3秒错误反馈，不把原生End仍在排队误报为工具冲突。操作等待期间禁止本会话开始新笔触，跨文档冲突仍由共享工具原子拒绝。

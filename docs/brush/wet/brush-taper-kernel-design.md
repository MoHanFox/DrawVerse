# 起收笔曲线与有界笔尾调度内核

2026-10-16。完整起收笔按数值/笔尾调度、Document瓦片回算与历史、参数IO/原生/Qt三段推进。本阶段实现独立可执行Rust内核，不显示未接入的UI，不宣称画布已支持起收笔，也不往旧BrushSettings加入无法保存的字段。

模型distance-envelope-v1。起笔和收笔各有0..4096文档像素长度，尺寸和整笔opacity各自使用既有PressureControl曲线/最低比例（自变量是该端距离比例，不是修改设备pressure）；线性或PCHIP曲线端值必须0/1，中间可非单调且仍限制0..1。开关关闭或某端长度0时该端因子为1，完整关闭配置仍可持有。起笔因子按累计处理后弧长计算，收笔因子按当前处理后终点减该印章弧长计算；两端重叠取min，尺寸与opacity独立，不把opacity当作流量。单点可以因两端最低值为0而完全透明，不添加虚构距离。

TaperRecord保留全局单调id、累计弧长、主/第二流和完整InputPoint；保留原设备能力、时间与随机调度身份，不生成新原始终点。流共享同一累计弧长，之后集成应将尺寸因子乘实际印章直径，将opacity因子应用整笔贡献上限，压力和第二相对尺寸语义不能被覆盖。

TaperBuffer只保留距离终点不足收笔长度的记录，超过窗口的前缀冻结；起笔曲线始终基于全局距离，不因窗口滑动重启。prepare_append只读，完整验证单调距离/id/时间/通道及资源限制后生成计划，commit只接受相同基础身份的计划。计划的replay包括旧活动笔尾与新记录，retired前缀用于推进调用方瓦片检查点，其余作为临时尾部；结束只冻结当前笔尾，不延伸轨迹。空输入也可推进真实处理后终点（末印章之间距离）；相同终点空输入为无重绘计划。

每个buffer容量由调用方指定，1..65536记录；单批最多65536，完整重绘计划最多容量+单批。预检剩余活动尾部而非总笔触长度，已冻结前缀不保留；不通过提高印章间距、截断路径或丢压力来满足预算。最多同时持有旧窗口、重绘列表和新窗口，记录驻留有硬界；图像资源和之后的瓦片/载体检查点另走各自预算。调用方如保留多个准备结果也承担它们的内存，过期结果不能提交。

Document下一阶段必须恢复旧活动尾部覆盖的瓦片/覆盖场/私有载体到检查点，再应用replay，在retired边界推进检查点；实际提交像素成功后才能采用调度状态。随机/颜色/第二路径状态随检查点捕获，结束只重绘有限窗口，不能重放整笔。存储/预算失败仍回滚整笔。当前不宣称这些Document能力已完成。

验收：独立曲线/最低值/关闭/零长度/端点/重叠与数值范围；主第二流/完整设备通道、一次整批与分批最终命令相同、逐次预览与全轨迹参考一致；长笔触只保留有限尾部、空输入推进与相同终点不重绘、零距离印章数量预算、舍入前非法数据/逆时/重复id原子拒绝、异源/过期/取消未采用及结束后拒绝继续。只运行对应Rust测试和Clippy，无ABI/格式/UI发布。

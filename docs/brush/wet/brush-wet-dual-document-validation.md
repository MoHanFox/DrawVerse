# 湿混双色 Document 验收

2026-10-16，Windows。对应[设计](brush-wet-dual-document-design.md)。

新增 Rust `begin_configured_dual_wet_brush_stroke` / `end_wet_ink_stroke`，实际执行并返回完整 WetInk。旧单载体结束入口对双色明确拒绝且保留笔触，旧普通预设编译仍拒绝该组合；只有明确的 Document 入口使用内部成对编译。当前 Engine、IO/ABI/Qt组合尚未接通，不会因仅修改内核而让旧调用者丢失第二载色。

真实主、第二印章分别拾色/写入/提交载色；配对先主后第二，独立流沿既有调度。两张几何场与两张RGBA场分别分页，湿混颜色饱和后继续更新；软裁切使用几何比例，前后/27模式复用干双色的同一最终合成函数。整笔opacity/选区/纸纹一次应用，before及原历史路径保持。主动态只影响沉积，不改两套原始载色。尺寸沿既有相对/固定边宽映射并限制在合法1–512 nominal域。

起收笔标量检查点包含双载体，新增RGBA场使用首次写入瓦片日志，恢复四场及图层；不克隆整张增长场。工作预检加入两角色采样及额外场成本，取消、分页、图层预算或历史暂存失败整笔回滚。

验证结果：

- 10项新Rust用例分别通过（`wet_dual`主日志6项、几何补充1项、extra最终日志2项、预算1项）。常量载色的27模式×两路径×前后×溢出共216组实际图像与干笔对照（RGBA误差<2e-6）。真实低整笔opacity反复回笔上限、前后颜色、外部保留两色、单历史与undo/redo均通过。
- 图片主/第二笔尖、软边/低流量、两路径、选区/蒙版/偏移和透明锁共8组分页起收笔，完整最终像素及两载体采样/revision与已知终点的一次执行参考精确相等；撤销恢复原图、重做恢复实际图像。
- 主墨透明时第二半透明墨仍在主几何范围内显示；溢出开关控制外侧，证明未以主颜色alpha替代几何。几何覆盖饱和后回笔继续混色；0写入仍真实拾色；所有图层取样及蒙版不允许合成取样的规则保持。无拾色配置中，颜色动态产生不同像素而两原始载体一致，含相对固定边宽配置。
- 取消、瓦片暂存失败、图层预算失败及独立历史暂存失败均恢复原像素和历史深度，外部两载体不变，无半笔提交；历史失败使用合法最小预算及六瓦片非均匀底图实际触发存储失败。预算按两载体实际网格分别计算，新增4阶到64阶第二载体成本差的精确断言；修正后预算/暂存回滚用例再验证通过，未按小主载体乘二低估大第二载体。
- 既有 `brush_wet_document` 12、`brush_wet_pair` 5、`brush_wet_color` 5、`brush_wet_smudge` 6项通过；旧起收笔10项及干双色精确变化像素对照完整瓦片的648组矩阵（1函数）通过，共39项旧函数回归。
- paint-core全目标Clippy（-D warnings）通过；Windows Release/生成头一致性及四项C/C++ static/shared ABI通过。Qt6.8.3 windows / software Quick / 环境倍率1：原有双色控件/像素/交换和湿混涂抹强度/手指/历史两项通过（初始化清理共4 passed、0 failed）。未创建尚未开放的组合Qt假测试。

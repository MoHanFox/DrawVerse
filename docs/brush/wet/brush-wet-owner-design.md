# 湿混共享工具载色与原生会话

2026-10-15。WetSettings属于不可变预设；WetTool是可克隆的共享工具所有者，持有可选上一笔成功载体。每次起笔取得独占WetLease；快照借给Document配置起笔，只有文档end/历史成功才consume lease提交新载体。取消/任意错误/队列取消/会话丢弃只drop lease，保留旧载色并释放busy。租约不能clone，序号不回绕；工具锁内不执行Document或外部回调，不持锁等待笔触。

手动清洗、按当前WetMix/尺寸/颜色重载和闲置快照通过同一所有者。占用期间返回Busy，避免设置或其他文档改写在途载体。手动动作不生成画布历史；清洗未初始化载体为无操作，重载可以创建初始载体。大小/设置变化沿用已完成reconfigured语义，所有失败先保留原状态。工具本身不是文档历史内容，Undo/Redo不改载色。

原生Session增加带WetTool的构造入口，普通构造建立独立工具；未来应用可把同一工具交给多个文档。Engine在Begin的wet.enabled分支取得lease并走配置湿混入口，End成功后提交，Move/End错误和Cancel释放，New/文件替换/stop丢弃未提交租约但保留共享工具已完成载色。重复Begin的Busy不得取消当前笔触/释放它的租约。跨会话在工作线程取得占用，冲突通过现有异步任务状态报告Busy。

本阶段完成原生执行/所有权基础，不新增C ABI，不解除ABI1.49的湿混prepare/package临时拒绝；外部句柄、共享工具C接口与完整Qt设置/有色预览/基准下一阶段接入，不能声称UI湿混已可用。

验收：共享工具独占和跨线程/取消/重载失败、清洗与空载/保色、租约提交/drop；真实异步原生两笔与Rust参考像素/返回载色一致，Undo/Redo不改工具、取消/错误/双Begin和两文档Busy保持、New及stop释放。原有普通笔刷/原生准备拒绝回归保持；验证后记录范围并提交。

# 湿混接入文档笔触

2026-10-15。当前阶段开放Rust Document.begin_wet_brush_stroke(definition,first,&carrier,all_layers)及end_wet_brush_stroke返回(像素是否变化,新载体)。普通起笔/结束保持不变，湿混必须用自己的结束入口，避免无意丢弃工具载色。输入载体不可变克隆，成功后由调用方采用返回值；取消、输入段预算/分页/写入/历史失败不改变原载体。clean/reload仍由工具拥有者调用，文档不自动覆盖外部工具状态；撤销重做只恢复文档像素。

BrushDefinition/BrushSettings/ABI/state/VBR暂不加湿混字段，无旧读写静默丢失；后续完整IO/桥/Qt阶段再开放产品入口。复用现有形状/图片/设备/压力/散布/纹理/灰度双笔刷/平滑路径。当前只允许Paint，拒绝橡皮输入、旧Smudge、有效双色双笔刷及颜色动态的未定义组合（包括中途橡皮输入）。这些组合继续后续，不能默默换模型。

每个实际主印章完整读取二维格点后写入，之后提交该印章载色，下一印章可读前一次结果。目标层原始RGBA或可见合成双线性取样，世界像素中心为i+0.5，越界透明；所有图层只写目标且mask目标明确拒绝合成取样。蒙版单层取样转换可见灰度到不透明灰色。取样权重复用真实形状/图片与灰度双笔刷、局部纹理，输出选区/不透明度/纸纹不限制取样。选区只在最终合成应用一次，透明锁保留精确alpha。0尺寸不接触并重置路径；0流量/0不透明度仍允许拾色，无文档改动；画布外印章读取透明并消耗载色。

湿混使用分页RGBA整笔贡献账本，复用stroke.coverage瓦片（本笔语义固定）。每像素source alpha q=ink.alpha×几何覆盖×流量，cap=max(之前贡献alpha,当前不透明度压感上限)，Cnext=Cold×(1-q)+ink×(覆盖×流量×cap)。最终Cnext×整笔opacity×选区×纸纹与起笔before按工具模式合成。透明变化只计一次，低opacity不会突破上限；已饱和贡献仍可改变颜色，不使用普通笔刷的饱和跳过。蒙版按最终贡献可见灰度/alpha处理，alpha锁按已有精确锁路径。该模式不声称与普通干笔多次覆盖完全同像素。

源/下一/输出载色有界64阶；预检为每实际散布印章增加格点采样、图层组合和贡献混合加权工作量，滤波路径/分段/终点都计入。写入与账本沿用Tile/PagePool原子回滚，失败释放在途载色。Mask/图片/纹理/双路径与偏移使用同一文档坐标。

验收：真实两色拾取/移动/透明底及下一印章读上次结果；取样选区独立、层/合成/蒙版/偏移、透明锁、低整笔opacity与pressure ceiling/27工具模式、图片/纹理/散布/双路径/平滑、单历史/undo/redo/取消、成功返回载色与无像素拾色、页预算/存储及历史失败；原普通画笔/涂抹/混合性能回归。Qt/VBR/ABI仍待接入，实体硬件/跨平台与性能不冒充通过。

补充：湿混stroke_to的无效点/段预算等错误也整笔回滚，普通笔刷错误策略保持。静止压力输入仅在实际启用大小/流量压力或opacity压力时生成额外印章；滤波预检与执行使用同一判定。双线性零权重邻点与零覆盖拾色格点不读，图像覆盖计划与绘画复用。

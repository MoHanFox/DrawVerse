# 原生预设来源引用与状态

BrushPreset新增可选来源记录ID（64字节小写SHA），与BrushSettings/BrushProgram分离，起笔不读来源或增加像素循环分支。编辑参数、改名、副本保留引用，显式清除/替换是原子目录修改；已捕获Arc修订保持原值。

状态v4新增可选sourceResource，v1–v3无变化；只在有来源时写v4，否则继续原版本。需要来源时由显式SourceStore上下文校验记录与完整原始身份，缺失/坏数据整包拒绝，不能默默移除来源。恢复批次去重记录与原始hash，每个原始文件只读取/校验一次，避免共享包的1000个预设重复扫描同一大文件；原始字节逐文件释放，验证结果仅保留身份/版本。

先实现Rust目录/状态层，原生准备桥/Qt仍不接收带来源的草稿；没有可操作但不执行的UI入口。后续原生共享资源上下文接SourceStore，再读来源报告与ABR导入；VBR来源范围另设计。

验收：身份非法/不存在预设拒绝且revision/Arc不变、编辑/改名/副本/删除/恢复来源保留、参数与像素不受来源影响、v4与v1–v3往返、没有上下文/缺失/损坏/取消整包拒绝、共享原始来源批次验证。无C ABI布局变化。

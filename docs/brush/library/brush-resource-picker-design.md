# 已导入覆盖资源选择

2026-10-18，对应[反馈顺序](../../planning/brush-feedback-execution-design.md)步骤9。

笔尖、纹理和第二笔尖使用同一不可变覆盖资源库。选择器展示已导入库中的资源，包括当前未被预设引用但仍保存在库中的PNG；切换只修改引用，不重新导入、不删除共享文件。来源PNG文件名不可靠且不一定存在，以内容身份的短前缀区分。

原生后台入口返回有序、去重、最多4096项的64位十六进制身份列表，不解码整库图片、不改变预设或修订。仅枚举资源目录直接普通PNG文件，排除目录、链接和其他名字；损坏覆盖文件在实际读取时由既有哈希/PNG校验拒绝。ABI增加独立资源清单能力，state/VBR不变。缩略图按需要复用已有白色覆盖PNG后台入口，缓存有界，防止大ABR一次生成全部缩略图。

Qt在设置资源分类打开和导入成功后异步刷新清单；各导入按钮旁显示当前资源缩略图，下拉可复用任一覆盖资源。资源切换前后台验证，捕获目标预设ID，失败保持原引用；预览和实际绘画使用相同资源身份。多文档共享资源库，重新打开仍可列出未引用资源。

实施前验收：IO清单的排序、过滤、上限、重开和只读；ABI容量探测/错误清零/不改修订；Qt缩略图、主副/纹理切换、失败保留、实际像素、重开与新目录VBR交换。结果写入[分步记录](../../validations/planning/brush-feedback-execution-validation.md)。

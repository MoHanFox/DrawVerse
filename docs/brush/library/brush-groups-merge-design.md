# 分组目录原子合并

2026-10-17，接VBR1.24整树身份重映射。BrushCatalog新增import_organized，接收已编译预设、有界不可变组织树、目标组（或根）和插入位置。预设数组必须与输入树DFS投影完全一致；不自动重排、不猜测名称关联，不允许以导入覆盖已有ID。输入组和预设身份必须与目标的两种身份都不冲突。

先验证数量、完整投影、目标位置、全部跨角色身份、合并树深度/容量及共享资源预算，再在私有候选目录中采用。一次成功仅推进一次revision，现有预设Arc与旧树快照不变，首个导入预设被选中；只有空文件夹时保留原选择。完整空输入是经目标位置验证后的无变化操作。失败包括revision耗尽时不改变选择、组织、预设和revision。根条目作为一个连续序列插入，子树内部顺序/空组/同名保持，插入目标可能让原合法子树超出8层，合并后仍必须拒绝。

旧import/import_into_group继续原先的非空平预设语义，委托同一事务，减少不同入口验证分叉。VBR读入和UUID映射不直接修改库；后续原生事务在准备资源/预设后调用此入口。资源文件暂存/清理、原生完整交接和Qt仍是后续工作，本阶段不把Core内存事务当成完整文件导入。

ImageBundle提供import_into_catalog内存桥，复用真实definition绑定主/副/纹理资源及全部动态、湿混、起收笔和平滑，保留来源ID，逐预设检查取消；候选目录完成合并后再次检查取消再采用。平包构建平组织，分组包使用已验证组织；不在此方法写资源/来源文件，耐久原生入口须在发布可保存目录前保证资源落盘。本阶段通过真实包接Core，而不新增不完整C ABI。

验证覆盖根/嵌套插入及DFS、同名/空组、真实预设捕获保持、空输入无变化、双向跨角色冲突/投影/目标/深度/组数/预设数/资源预算失败原子性；相关旧目录与IO回归、Windows Release/ABI及必要旧Qt回归。无ABI/state/VBR版本变化。

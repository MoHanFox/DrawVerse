# 原生来源准备桥与校验凭据

ABI1.32连接共享资源仓库的来源目录与v4状态准备，并提供后台来源记录查询。初次解析验证记录/原始字节；持有的ValidatedSource只保存身份凭据，不持有大型原ABR，也不作为执行参数。SourceStore同一命名空间的Weak缓存只复用仍由当前修订或在途ticket持有的凭据，不能跨新store/重启假装冷恢复已验证。

普通显式decode_with_sources仍执行冷校验；准备专用decode返回catalog和凭据，ticket/current持有。当前发布后复制凭据持有，闲置记录释放资源时不破坏当前持有；库销毁后在途ticket仍存活。Weak索引最多4096，失败不替换当前合法状态。元数据修改不触碰笔触执行资源。

凭据代表曾捕获的不可变身份，磁盘外部篡改不改已捕获修订；来源查看使用完整新读取，仍会发现损坏/缺失，不能显示伪造成功。新store冷恢复必须重新拒绝损坏文件。验证每批次原始文件去重，不重复读取同一包。

来源查询返回原JSON字节（最多2MiB），原始ABR不进caller JSON/GUI；IO不持有全局注册表锁，GUI只能后台调用。Qt接收v4/报告查看与ABR用户导入仍作为下一接入阶段，现有程序/图片参数旧流程保持。验收：v4准确准备、重复准备凭据复用、当前/在途/退役生命周期、冷坏来源拒绝、共享store与source-info buffer/error、旧ABI C/C++兼容。

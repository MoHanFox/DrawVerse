# 画笔导入导出保留分组

2026-10-18，Qt 画笔库的导入和单笔刷导出补齐组组织信息。通过文件导入画笔时，导入操作的调用方从文件名生成外层组名，并把本次导入的所有预设放入该组；ABR 本身没有 DrawVerse 分组信息，因此 ABR 导入同样统一使用文件名创建外层组。

`BrushLibrary::importPackage` 和 `BrushLibrary::importAbr` 增加可选组名参数。组名非空时，先按原有流程完成预设 ID 映射和来源校验，再创建新的外层组，把本次导入的根节点放入其中。VBR 的 `ordered-package-v1` 仍先重映射内部组 ID 和预设引用，之后把完整内部组树嵌入外层组，因此组名、层级、空组和顺序保持；旧平包没有组织树时，所有导入预设直接进入文件名组。

单笔刷导出从只写预设改为在存在父组时写 `ordered-package-v1`：`organization` 只保留当前预设所在的完整组路径，组 ID 与预设引用和导出画笔一致。没有父组时继续写旧的平包格式。导出全部画笔仍保留完整组织树。ABR 与旧平包无法携带 DrawVerse 组信息，导入时只能获得文件名外层组。

导入组名复用现有 80 字符上限，空文件名回退为“导入画笔”。不改变 C ABI、state 或 VBR 版本，也不要求旧包升级。

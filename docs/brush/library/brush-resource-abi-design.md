# 原生共享图片资源 ABI

ABI 1.29 为独立笔刷库绑定一次持久资源目录，并允许隔离预览库共享同一 ResourceStore。目录IO、PNG转换与mip编译仅在后台运行；状态准备读取v3哈希引用，开始笔触捕获完整资源，不访问原始导入路径。

导入文件接口选择标准覆盖/alpha/反向亮度，返回64字节资源ID与16位量化标记，暂存一个导入交接Arc供随后准备使用。资源ID是数据，不是图层状态；文件失败不修改库或文档。原目录不能在库仍使用资源时随意换成另一目录。

历史准备记录最多64条；图片记录在无在途消费者时可释放重资源，保留不可变JSON/资源目录配方，查询时后台重新准备。被文档捕获的记录不释放；当前目录继续持有当前资源。重新读取仍验证哈希，错误明确拒绝，不替换圆笔。此机制避免64条无用设置记录把旧大笔尖永久钉在内存中。

验收：目录绑定/共享、原生PNG导入/错误解释拒绝、v3准备/真实孔洞绘画、原文件删除、库销毁及资源快照、无消费者的旧资源释放与准确配方重建；旧程序API与DTO保持兼容。Qt图片控件/VBR资源包/ABR仍作为后续接入。

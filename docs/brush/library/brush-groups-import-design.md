# 画笔分组包副本树导入

2026-10-18，在完整范围导出和 ABI1.55 `package_read_groups` 基础上接通 Qt 导入。所有 VBR 导入现在先由 Rust 返回完整 `ordered-package-v1` handoff（平包生成显式平根），Qt 再决定如何合并；不再把分组包退回旧平包拒绝路径。

`BrushLibrary::importPackage` 识别 wrapper 后校验 package/organization 投影及全部输入预设 ID。导入预设全部获得新的本地 ID；导入组也生成不冲突的新组 ID，组织中的预设/子组引用同步重映射。输入根树连续追加到当前根目录，组记录追加到当前组织；当前已有同名组和空组保持不变，不按名称猜测合并。最终用全部本地预设重新规范化，组数、8 层深度、空组、顺序和跨角色 ID 冲突在候选采用前检查。

平 handoff 没有组记录时按 package 顺序追加到根目录；有组记录时保留 DFS 顺序、层级、空组和同名。一次成功只改变画笔目录并保持单次持久化；失败保持原 catalog、组织、选择和资源。导入第一个新预设作为选中项。

`PaintCoreClient` 新增 `brushLibraryReady` 状态：画笔偏好恢复完成前发起的导入会排队，恢复后自动继续，避免启动阶段导入被随后到达的偏好覆盖。设置页仍通过既有导入按钮选择 VBR/ABR；ABR 路径不变，VBR 路径使用分组读入口。

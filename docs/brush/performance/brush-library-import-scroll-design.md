# 大包导入与滚动性能

2026-10-19用户明确：“几乎滑不动”是导入后滚动严重卡顿。导入阶段与导入后列表滚动分别测量，不用参数批处理结果代替验收。

先通过真实Main窗口导入许可ABR样本三次，形成448项、含图片资源与来源的目录。记录导入总耗时和GUI心跳最大间隔，以及首次和重复滚动时的同步派发耗时/心跳。样本内容不等同用户34MB/485项/304资源包，不外推设备帧率。增加有界委托数量检查和无整库通知检查。

定位后按独立瓶颈优化，保留资源验证、导入原子性、实际绘画参数、来源和重置基线。滚动时的缩略图任务应有界且优先当前可见项，避免离屏任务持续积压；缓存命中不得重复生成。任何预览近似必须单独说明并验证，不能改变画布笔触。

最小验收和实测见[分步记录](../../validations/planning/brush-feedback-execution-validation.md)。

首步：列表委托不再创建即提交预览，停止滚动75ms后只请求实际可见行；已有图片缓存立即显示。离屏请求按原token撤销，后台移除尚未开始的同token任务，正在计算的至多一个任务完成后结果被旧token拒绝。选中笔刷的设置预览继续保留；取消不清空已缓存图片，不改变预览像素算法。

第二步：分段计时显示448项校验约22ms，发出presetsChanged后的QML同步刷新约1.68s。QML对QObject序列属性逐项遍历会重新读取属性，旧presets()每次构建全部行，导致目录规模放大。新增presetRows()按方法返回值序列；库面板仅在结构通知时获取一次副本，搜索/分组/签名复用JS查找表。删除按钮查单项，不再在每次设置变化时遍历整个属性。现有笔刷选择框也使用值序列，结构变化时显式刷新。公开绘画契约和持久化格式不变。

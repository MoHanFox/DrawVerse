# 大目录参数调整与列表通知

2026-10-19，补齐[反馈顺序](../../planning/brush-feedback-execution-design.md)步骤1的大目录部分，先于整笔描边实施，以减少新增复杂参数后的重复开销。

当前每次参数写入都广播presetsChanged，QML重新查询整库、构建查找表和组签名；客户端还在settingsChanged中立即生成包含重置基线的完整快照，再重复生成保存快照。原生准备本身已有异步任务，不将其误称为同步核心执行。

参数写入和settingsChanged保持即时。目录增删、重排、改名仍通知整个列表；普通参数只通知受影响行。标准预览仍忽略大小/流量/不透明度，其他参数仅清除当前行预览。连续更改合并为一次延迟保存/准备，起笔、湿混动作、创建共享目录的新文档、关闭/销毁前显式冲刷最后状态，不能画旧参数或丢失最后一次编辑。已有纯查询snapshot/catalogSnapshot始终返回当前值。

光标在新状态准备完成前继续使用已有基础回退，不在每次设置通知中立即序列化整库。原生返回与Qt在f32实际精度等价的状态直接采用执行身份，不重建界面目录；真正不同的状态仍通过既有严格restore。

先用512项合成目录记录同机连续大小/流量/不透明度写入耗时及信号数量，再验证行对象/滚动位置保持、标准预览不丢失、复杂参数只更新当前行、立刻起笔捕获最终值、立刻关闭/共享文档与保存重开。许可ABR样本仍用于导入回归；合成目录不能替代用户34MB包全部场景的验收。

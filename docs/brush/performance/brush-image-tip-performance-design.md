# 非完全覆盖图片笔尖性能

2026-10-18。图片笔尖的软边像素不能使用完全覆盖跳过，因此保留逐像素覆盖采样；本阶段在 `MaskDab` 上预计算旋转后的比例倒数，并对轴对齐笔尖跳过旋转乘法，同时把边缘判定拆成内部快速分支。覆盖采样仍使用原双线性/多级 mip 和原透明度账本，不改变完全覆盖跳过、选区/蒙版/历史或图片资源。

固定基准 `brush_image_tip_performance`：2048×2048、256×256 软边图片、半径128、1%间距、240个8px输入、普通混合/整笔opacity100%，3次中位数约3.34秒；同机程序笔尖对照约2.37秒。该差异主要来自图片覆盖采样，不能外推所有图片/Qt/设备。

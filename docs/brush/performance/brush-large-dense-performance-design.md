# 大笔刷密集笔触性能

2026-10-18。大尺寸、不透明、普通混合画笔在高密度输入下，每个印章都会重复计算覆盖并重写已完全着色的像素。普通全不透明路径此前没有 coverage 饱和跳过，因此大笔刷连续移动时像素访问量随印章数线性重复。

本次只在可证明结果稳定的条件启用重复印章跳过：普通混合、无湿混/涂抹/图层蒙版、无透明度锁、无起收笔、整笔不透明度和有效流量均不低于1；画笔还要求颜色 alpha 为1，橡皮不要求颜色 alpha；颜色动态关闭；双笔刷必须关闭彩色贡献。纹理、图片笔尖和灰度双笔刷只有实际达到完全覆盖的像素会记账，部分覆盖和纹理孔洞仍按原公式继续累积。满足条件时，活动笔触的 coverage 本地账本标记已完全覆盖的像素；后续印章在计算覆盖率前跳过这些像素。整笔不透明度为100%的普通硬橡皮也使用同一账本，已清零像素后续不再重复计算。

coverage 账本只属于活动笔触，不进入图层、历史、保存或导出；失败/取消仍使用原整笔回滚。该跳过不改变印章顺序、随机序列、选区、预算、历史或最终像素。彩色双笔刷、湿混、涂抹、混合模式、起收笔、蒙版和低不透明度/流量路径保持原执行。

基准使用`brush_large_dense_performance`：2048×2048、硬圆笔尖半径128、1%直径间距、240个8px输入、普通混合、整笔opacity1，含Begin/End和单历史，不含Qt视口。优化前后最终像素摘要相同；这是固定CPU输入场景，不外推所有笔刷、设备输入或GPU呈现。

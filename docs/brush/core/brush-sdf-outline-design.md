# SDF 遮罩描边

2026-10-20，对应问题清单普通12/13。旧“建路径”保持现有模型及结果，新算法分步接入；[验收](../../validations/brush/core/brush-sdf-outline-validation.md)记录实际完成范围。

## 算子边界

`paint-ops::sdf` 不拥有文档、颜色、笔刷资源或 GPU。输入为不可变灰度 alpha A；距离场以 A≥128 的 50% 几何计算，内部负、外部正，二值相邻像素中心离边界各0.5px。灰度 A 单独保留，在最终布尔遮罩中使用，不能提前二值化后丢弃。边界外为透明；全透明场返回有限正距离，全实心场按透明外边界计算。这是像素栅格欧氏距离近似，不是连续 alpha 的精确曲线距离。

二维平方距离变换使用按列、按行的抛物线下包络，各维线性；旧描边复用同一算子，保留原运算顺序和半像素约定。新距离场可随描边形状修订缓存；算子本身不猜测修订身份。

等距线使用 marching squares，格点位于像素中心。共享边使用整数身份连接，不按浮点坐标哈希；鞍点按双线性渐近判定，恰好相等时固定分离正区域。边界上可返回开放线，调用方必须提供足够透明 padding 才能保证闭合。闭合线不重复末点；等长弧长重采样避免闭合接缝重复印章，短小轮廓至少一个采样。每个采样发布中心、切线、朝 SDF 增长方向的法线、半径和纹理角度。

外/内/居中中心线分别为 +W/2、−W/2、0，半径W/2，目标步长0.4W；整数采样数使实际步长略小，小轮廓允许低于0.3W。独立印章遮罩在同层取max，不使用颜色叠加。采样回调复用上层笔尖/纹理；默认圆形覆盖使用约1px smoothstep。不同遮罩提供max、概率并集、乘积交集、a*(1−b)差集。外描边 D*(1−A)，内描边 S*A*(1−erode(A,W))，其中内缩遮罩由距离阈值和原A限制；居中描边用±W/2的距离带裁剪。之后由文档层一次着色、保持预乘alpha。

## 资源与失败

每个 raster 最多8Mi像素，线段最多262144、印章最多262144，印章包围盒采样合计最多6400万次。尺寸、有限值、覆盖率、步长、半径及计数预检；所有大数组使用 fallible reserve，超限返回错误，不发布部分遮罩。距离变换直接修改的工作数组在全部校验/临时分配成功后才开始运算，其余接口返回独立候选。距离变换峰值为一个f64栅格、一个f32场和按最长边的两个f64/usize/f64行缓冲；极窄图行缓冲仍受像素上限限制。提线另需约两倍像素的u32边索引及有界线段/点数组。

不强制 GPU：先保留可执行 CPU 参考；只有实际集成、正确性与传输收益验证后才能报告 GPU 加速。新设置、灰度形状缓存、独立自身纹理、UI/序列化和真实笔触属于后续接入，第一步不能视作用户可用算法完成。

## 自身描边的独立纹理

先在现有建路径接通 `source:{model:"self-brush",texture:{...}}`，复用现有完整纹理参数和内容身份资源；没有 texture 的旧对象编码保持不变。核心以独立纹理调制描边覆盖，主笔触的纹理不改写。启用/禁用、资源、空间和深度随描边配置保存，纯参数和含资源VBR、最近快照、隔离配置复用同一编码。

仅使用该扩展时提升state42、behavior34，并要求`outline-self-texture`；旧自身/已有/纹理来源仍是state41/behavior33。state41携带新字段须拒绝，VBR1.0按实际字段重算能力。异步导入捕获目标预设和角色4（自身描边纹理），角色3保留独立纹理来源；切换来源后完成仍按捕获角色应用，不改主纹理或其他预设。绘画/预览都通过同一C ABI准备，ABI次版本记录支持范围，无DTO改动。

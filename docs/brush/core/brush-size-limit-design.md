# 2000px 笔刷尺寸范围

2026-10-18，对应[反馈顺序](../../planning/brush-feedback-execution-design.md)步骤6a。

主/第二笔尖名义直径上限统一为2000px（半径1000）。Rust Brush验证为权威范围；同步Qt编辑/恢复/导入、ABR钳制、原生姿态和湿混准备入口以及大小快捷键，避免界面接受、核心拒绝。

既有小尺寸参数保持；VBR维持1.0，ABI布局不变。不扩大单印章/分页/整笔预算，不将“可选2000px”解释为所有湿混/图片/文档组合均已通过性能验收。ABR超2000的来源值保留，执行值钳制并报告。

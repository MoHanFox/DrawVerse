# 复刻主体落笔的描边（2026-10-20）

用户新要求覆盖旧建路径/SDF方案：描边跟随主体已经确定的实际印章位置、压力尺寸、方向、散布与起收笔回放；不重新沿轮廓建立路径或等距盖章。主体和描边颜色分离，重叠印章的几何覆盖取max，最后一次写入颜色并保存单笔历史。

每个实际主体印章在当前中心按 placement 计算两个半径：Outside为(r+w,r)，Center为(r+w/2,max(0,r-w/2))，Inside为(r,max(0,r-w))。同一不可变笔尖采样器分别以这两个尺度复刻，并将覆盖max合入整笔外/内遮罩；最后计算 max(outer-inner,0)。颜色、目标已有像素和历史都不参与形状计算，避免自交叠加成粗块。宽度是半径方向的大小差；非圆形笔尖按相同比例放大/缩小，不承诺恒定欧氏轮廓距离。

描边来源可用主体、主体加独立纹理、现有笔刷快照或纹理。来源采用主体已经确定的落笔动作，不使用新建轮廓路径或独立路径间距。独立来源另外复刻自身覆盖；默认用主体同尺度外/内差裁剪，允许溢出时保留来源差的完整形状。允许溢出仅影响该几何裁剪，不突破画布、当前选区、锁透明或瓦片预算。主体来源的两个遮罩可以复用，开启溢出不会凭空扩大其范围。

第一步为 paint-ops::replay_outline 的纯CPU算子：64×64有界瓦片，每像素四个u8覆盖（主体外/内、来源外/内），共享来源只采样两次；更新在私有输出上完成，非法参数、取样失败或分配失败不修改原遮罩。允许每次合成至多8Mi像素，完整笔触范围和总采样预算由上层检查。算子不持有文档、颜色、Qt或GPU资源；CPU参考可直接使用，尚未增加GPU实现。

后续实际笔触接入必须复用既有印章几何/纹理/双笔刷取样、尾部回放捕获和单笔事务，缓存四通道遮罩并有界发布；UI只保留新描边与允许溢出，旧格式只能读取迁移，不能把新模型伪装成旧behavior。预览和真实笔触使用同一路径，state/VBR/资源包按新实际字段校验并验证保存重开。

## 实际笔触算子接入（2026-10-21）

新增核心Replay执行路径，在主体dab几何、双笔刷、纹理与随机动作已经解析后复用原采样闭包，四通道瓦片max合并与整笔差集直接生成覆盖。独立来源在起笔时编译不可变笔尖程序，按主体实际尺寸/标称尺寸同比响应，并复用主动作的中心、角度随机样本与尾部尺寸；不另排间距/散布路径。主体与来源外/内通道由既有尾部日志统一捕获、恢复，预览沿既有单笔覆盖事务发布，确认一次历史；允许溢出只放宽主体包络裁剪，选区/锁透明/画布和配额仍在最终写像素时生效。

该小项暂通过核心显式入口启用，旧路径/SDF用于兼容对照；IO、Qt设置和旧入口移除继续接入，尚不标记O1全部完成。CPU路径，不新增GPU。

## 设置、预览和交换接入（2026-10-21）

Qt新建/编辑描边统一使用 `stroke-replay-v1`，删除算法选择和独立建路径间距/散布设置，增加“允许溢出”。已有来源捕获其形状及纹理快照，大小相对主体标称大小缩放；动作中心、散布位置及收笔尺寸来自主体，不另外运行来源的间距/散布调度。主颜色和第二颜色沿用原事务，标准预览与实际笔触共用执行路径。

state45要求布尔allowOverflow；VBR保持1.0，实际字段重算behavior37和stroke-outline-replay能力。ABI1.75/bit63声明支持，DTO不变。旧state先按原schema严格校验，Qt再保留颜色/宽度/位置/来源资源迁移为新模型，默认不溢出；视觉会按新算法改变。原生IO及核心旧Path/Sdf仍保留兼容读取/参考执行，不能称旧算法代码已经完全删除。

本次接通用户可操作链路。仍限干画笔普通像素层及既有8Mi像素、瓦片配额；未新增GPU计算，未覆盖任意独立来源动态组合、湿混/涂抹或实体设备持续输入。完全移除原生旧执行路径需另行明确兼容策略，继续在O1跟踪。

## 旧原生执行删除（2026-10-21）

删除outline_brush/outline_sdf执行模块、二值轮廓/距离场band生成和缓存，移除核心OutlineAlgorithm选择接口；StrokeOutline默认及唯一模型为Replay。纯数值通用SDF算子仍供其他数值功能使用，与退役描边执行无关。尾部恢复直接恢复四通道遮罩，不再维护旧缓存。旧算法专属测试改为新两尺度独立参考与灰度AA语义，保留选区/偏移/锁透明、取消、分页/尾部、资源失败及单历史断言。

旧state/VBR的模型名仅在IO格式边界接受：按原版本和字段严格校验后，bind统一产出Replay，默认不溢出；从核心写回state45。VBR原始参数可按其旧字段转存，核心永远不运行旧算法。VBR缺项补全使用原始轮廓默认字段，不能用新allowOverflow污染旧对象；显式新模型缺此字段仍拒绝。历史像素结果不改，只影响旧预设再次起笔的算法，与上一步Qt迁移的视觉变化一致。

# 普通画笔混合模式

2026-10-14：按用户更新的双色扩展设计，先实现工具详情栏“模式”下拉，再接双色贡献与自动描边。颜色写入内核已完成阶段实现，见 [验收](../../validations/brush/core/brush-blend-validation.md)；原生入口和工具栏尚未接入，不提前添加可点击但不执行的入口。

## 行为与架构

模式作用于笔刷颜色与当前目标层像素的写入，不修改图层混合模式，也不对可见合成画面做取样。复用Rust线性预乘RGBA的BlendMode/blend_pixel，包括26种非正常模式及正常；组专用穿透不能进入菜单。空目标层遵守现有透明底合成语义，不能拿白色或合成底替代透明目标。

这是画笔工具状态，与实际前景/背景色一样在起笔时捕获；保存工具偏好，不把当前工具模式自动写入所有预设或VBR。现有无模式入口仍为正常，以新版本化入口显式传入，不能改变旧DTO布局或把值塞进reserved。预设重置不改变此工具状态。主/第二灰度组合先执行，再应用画笔颜色与目标的混合，不能把目前双笔刷的灰度模式重新解释为颜色模式。

普通画笔的正常模式保留精确旧路径。非正常模式分别累积笔触贡献，并基于起笔前目标重算混合，防止1%间距和原地重叠把整笔不透明度反复应用、导致颜色无限变深。流量及颜色动态仍可累积贡献，透明度压感使用已有局部整笔上限；不能把动态关闭或间距变大当作混合实现。对不同笔触再次混合应真实改变画面。溶解使用捕获的确定性笔触种子及稳定坐标，不随帧或事件频率重新抽样。

蒙版沿用既有mask_tone的显示灰度解释（线性颜色先转显示亮度），对可见灰度而非内部隐藏量计算，再映射回隐藏覆盖；透明锁保持原alpha并仅混合有效颜色。选区/AA/羽化、图层偏移和祖先锁不变。橡皮/涂抹保持其现有写入语义，不自动继承画笔的颜色混合模式；新入口对不支持的组合明确校验，UI按当前工具显示有效参数。

Rust捕获/瓦片/历史为权威，UI只提供选择和持久工具状态。实时预览与真实笔触都用同一Rust路径。失败/取消恢复整笔，单笔一条历史，撤销重做不依赖当前混合模式。

## 与双色扩展衔接

双色贡献模式各自决定颜色合成；工具栏模式提供默认，贡献模式显式覆盖对应默认值。实现双色前进一步固定继承表示和上下贡献求值顺序，避免先对各贡献混合、再用相同工具模式把最终结果混合第二遍。分隔渲染开启时基于before重算整笔，自动描边预设默认开启；关闭的逐印章双色行为必须独立建模并验收，不能悄悄走同一算法。现有用户编辑的扩展原文保留，详见 [brush-dual-color-extension-design.md](../dual/brush-dual-color-extension-design.md)。

## 先行验收条件

实际27模式透明/不透明/半透明底及已存在BlendMode公式参考，正常旧像素不变；正片叠底加深/颜色减淡提亮，不改目标层appearance。单笔密集/稀疏/不同事件拆分/原地回擦不重复施加整笔透明度，下一笔再次施加；压力上限、流量/颜色/纹理/图片/双覆盖组合。灰度蒙版/透明锁/选区羽化/偏移/分页与预算/存储失败、取消及真实历史。FFI大小/reserved/模式/工具校验、捕获与旧入口兼容；Qt真实模式选择、两色/工具/预设切换、重开保存、隔离预览、DPR1/2及ABI/生成头检查。记录线性工作空间与PS逐像素尚未核验的边界，不以图层混合模式的测试代替画笔写入测试。

## 本阶段内核边界

BrushDefinition/BrushProgram新增不可变write_blend工具捕获字段，BrushSettings仍不拥有它，旧定义和C ABI入口默认正常，不改state/VBR/ABI。非正常绘画使用覆盖账本重算before目标；混合工作量加入现有预算估计。非正常模式与擦除/涂抹组合以及组穿透在编译时拒绝。透明锁用不透明颜色参考混合后恢复原alpha精确位值；溶解稳定坐标采用图层偏移后的文档坐标，笔触序号只在成功起笔后采用。

后续原生/Qt入口须显式复制并验证模式，保留旧入口正常行为，工具栏状态/持久化/跨文档同步和真实预览一并接入。预览非正常模式需要明确有色底样，不能用透明底结果宣称所有模式均有差异。

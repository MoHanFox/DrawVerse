# 程序笔尖第一阶段

统一笔刷系统的第一项实现：在原圆笔路径上加入编译后的笔尖覆盖，画笔、橡皮、蒙版和涂抹共用。`BrushDefinition` 持有旧基础参数与 `BrushTip`；`BrushProgram` 在开始笔触前验证并缓存角度变换，每像素不重复计算三角函数。

参数：硬度 0–100%，圆度 1–100%，角度 -180–180°，印章流量 0–100%，大小压感、流量压感。旧入口使用硬圆、100% 圆度与流量、原大小/流量压感，像素计算保留原路径。涂抹强度压感仍由涂抹工具开关决定，独立于画笔流量压感。

不透明度当前仍是旧的印章沉积语义，整条笔触不透明度将在后续独立实施，不在界面伪装为已完成。图片笔尖、纹理、ABR、VBR、稳定器与湿混也属于后续模块。

验收：旧入口与默认新定义的像素一致；软笔中心/边缘、旋转椭圆、压感开关与流量有效；非法参数在笔触/历史改变前拒绝；擦除、选区、蒙版、涂抹与事务撤回继续使用同一覆盖。每个阶段记录真实测试结果后提交。

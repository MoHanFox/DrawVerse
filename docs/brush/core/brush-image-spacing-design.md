# 扁平图片笔尖间距

2026-10-18，对应[反馈顺序](../../planning/brush-feedback-execution-design.md)步骤6b。

图片笔尖的名义直径取图像长边；旧排布仅用该直径计算步长，导致极薄横条在沿短边移动时仍按长边间距排印章。资源构造时缓存非零覆盖的包围盒尺寸，编译后的主/第二图片笔尖以`min(有效宽, 有效高×静态圆度)/图像长边`缩放原步长。缩放不受静态旋转影响，减少快速转向造成的间距跳变；空图保持原步长，程序笔尖保持原算法。

这是一项图片排布纠正，沿长边的排布也会更密；不声称任意带孔纹理完全连续。源像素、资源哈希、存储参数、单印章形状不变，无新持久化字段，state/VBR/ABI版本保持。薄图增加印章数，现有单页/总输入预算与取消回滚继续生效；不增加无界循环。

实施前验收：矩形资源及带透明边的方图沿短边绘画无大间隙；0/90度、主/第二独立流、一次输入/分段/实际分页RGBA一致；圆图/程序笔尖既有回归保持，撤销重做仍单历史。运行结果记入[分步记录](../../validations/planning/brush-feedback-execution-validation.md)。

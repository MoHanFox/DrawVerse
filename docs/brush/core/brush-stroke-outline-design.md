# 整条笔触描边

对应[本轮反馈](../../planning/brush-feedback-execution-design.md)。用户要求对整条笔触轮廓描边，支持外／中／内，宽度为相对名义直径百分比或独立像素，可选色轮第二颜色；来源为自身、已有笔刷快照或纹理（文档／局部）。

## 几何和事务

描边建立在当前笔触独立覆盖的并集上，不能用目标图层与起笔前像素的差值：相同颜色继续绘画也必须有轮廓。覆盖合并完成后使用50%等值区域建立距离带，保留孔洞、分离区域和闭合笔触；相邻印章重叠处不生成内部接缝。该阈值用于覆盖形状，不将整笔不透明度当作形状阈值。

宽度指完整带宽，外描边全部向外，居中各一半，内描边全部向内；亚像素宽度使用一像素过渡覆盖。相对宽度在起笔捕获名义直径，绝对与相对值均保留，上限2000px。无描边时不增加覆盖或距离场工作。

距离计算使用两次可分离平方距离变换，逐行／列扫描，时间随栅格面积增长，不逐像素遍历宽度平方邻域。首阶段单次栅格最多8Mi像素，分配失败或超限明确失败，不偷偷缩小图像或截断轮廓；文档接入时需在包含外描边余量的局部区域预检，失败回滚整笔。该限制不是允许整幅大文档每次分配距离场；后续接入应优先按受影响区域执行。

当前几何输入是独立覆盖，不是光标轮廓；既有光标简化阈值、段数与图像资源不变。图层偏移、选区、透明度锁、蒙版、起收笔回放与分页输入均由Document事务负责。最终主笔触和描边合为一个撤销命令，取消或失败均恢复起笔前状态。

## 来源与保存

自身使用当前笔刷捕获的形状与纹理；已有笔刷使用支持参数的不可变快照，允许大小、间距、散布（两轴）和数量，不递归引用源预设。纹理复用已有资源及文档／局部坐标模型。第二颜色在起笔时捕获色轮背景色，之后切换颜色不改变在途笔触。自动预览继续遵守白色预览规则。

按核心几何→Document真实像素与历史→IO／原生→Qt逐步接入。新增持久化对象时独立演进state、behavior与ABI，VBR继续1.0，按实际字段读写；已关闭对象的值和资源也必须往返，旧准备入口不得静默丢失新对象。

## 验收

见[分阶段验收](../../validations/brush/core/brush-stroke-outline-validation.md)。几何阶段使用独立逐像素最近邻参考比较，覆盖三种位置、亚像素宽度、孔洞、边缘、单像素、空输入、重叠无接缝和资源限制。Document阶段验证相同颜色底图、图片笔尖、纹理、起收笔、分页与普通路径一致、实际选区／偏移／锁和单历史、取消及失败回滚；IO与Qt阶段验证关闭值、新目录资源交换、真实异步预览、控件和保存重开。未完成阶段不能报告整项反馈已完成。

# 笔刷来源与报告界面

Qt保留v4/sourceResource，在编辑、改名、副本、图片替换、共享文档状态与设置恢复中不丢弃来源。sourceResource是不可变导入时报告身份，不属于绘画参数；预览使用当前参数，报告展示导入时快照，不能把报告当作当前效果。

PS分类面板新增“来源与兼容”。通过PaintCoreClient在后台查询ABI1.32来源记录，显示原名称/格式与版本/转换器、基础参数快照、逐项映射/近似/未执行说明。普通程序/PNG预设显示无ABR来源。默认按需读取，不自动对每次参数变化读原文件；切换预设/来源使过期结果失效，刷新再次校验。文本只按纯文本显示，有界原JSON，不将原ABR传到GUI。

VBR1.1尚无来源格式，因此有来源预设导出必须明确拒绝，避免静默去掉来源；后续完成选择性来源导出再解除。向现有v4库导入VBR图片不能将库降到v3。来源损坏使冷恢复失败并保留原设置文件，查看显示真实错误。

验收：v4准确保存/恢复/改名/副本/切换程序/图片与来源共存；异步真实查询、导入时参数不随当前编辑变化、切换时清空/旧响应拒绝、刷新损坏报错、旧v2/v3与VBR图片导入不回退、来源导出显式拒绝；Qt最小测试与Release构建。本阶段不实现ABR用户导入、VBR来源资源或动态湿混。

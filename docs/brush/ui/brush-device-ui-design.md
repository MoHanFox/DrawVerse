# 设备动态设置与原生入口

ABI1.37增加DEVICE_TIP_DYNAMICS能力，无DTO布局变化。旧package入口解除新几何临时拒绝，Qt接受state7/VBR1.5/behavior4/tip-dynamics；每预设保存tipDynamics对象，与压力控制分离，大小/资源/来源/复制/关闭圆度控制保持既有状态。默认配置可规范化为空，不升级旧数据。

形状动态分类添加角度来源（关闭/方向/笔旋转/笔倾斜）、倾斜圆度开关和最低圆度1–100%；采用通用紧凑输入和1秒提示。Qt只校验参数，不执行倾斜或方向算法。真实预览沿隔离原生目录与笔触，只有开启设备动态的预览提供明确合成倾斜/旋转能力与通道，旧预览输入不变。

验收：真实界面选择/开关/最低比例，保存恢复/复制与默认回退、坏字段原子拒绝、VBR原生往返/来源与图片保留；从UI参数准备的真实设备笔触与鼠标方向，起笔后编辑仍使用捕获配置、无QML警告、生成头/C ABI检查。轮廓目前仍是基础笔尖，本阶段先启用设置与实际绘画；实时设备光标需要独立原生pose查询，下一阶段完成，不能由Qt复制一套算法。

# 画笔菜单与展开组落点修正

2026-10-18，补齐画笔右键菜单、拖拽作用域和展开组落点。

画笔 DropArea 的空区和 footer 原先把 `drop` 当作隐式注入参数，运行时会进入错误作用域并产生 `root is not defined`。现在全部改为显式 `function(drop)`，列表项和根级回调通过预先保存的 `panel` 引用访问面板状态，拖动期间不再依赖动态解析根 id。

画笔右键菜单设置 `topLevel`，使用独立 Window 弹层，位置和外观与顶部菜单栏一致。“创建分组”只在多选时通过 `Instantiator` 动态插入，不再用不可见静态项占位，因此首项与菜单顶部不再出现额外空隙。菜单文案改为“导出该组笔刷 / 导出该笔刷 / 导出选中笔刷”；没有组时“移动到组”子菜单禁用并显示为灰色。

画笔和图层列表采用同一展开组落点规则。组展开时，落到组标题上三分之一的元素放在组前，落到其余部分会合并进组并成为第一个子元素；组收起时保留上、中、下的组前、组内、组后三段落点。画笔通过索引 0 插入，图层使用 placement 0 的原生首子项插入语义。

2026-10-21按用户截图移除列表尾部固定24px、带底色边框的根目录拖放条，不再占据内容高度。现有列表自然空白处的透明DropArea仍可把笔刷/组放回根目录；指针实际拖入时才显示落点反馈。列表内容填满时仍可通过末项下半部或右键菜单移到根目录。

# 双色双笔刷原生与Qt入口

2026-10-18补充：新增 `interleaved-stamp-v1` 逐印章模式下拉，见[逐印章设计](../dual/brush-dual-stamp-design.md)；本文保留整笔分隔阶段的入口记录。

2026-10-15：ABI1.48公布PAINT_FEATURE_DUAL_COLOR_STROKE，不改变DTO/导出签名。解除准备与库包临时拒绝，既有准确state16/VBR1.14/behavior13完整捕获两色配置。Qt严格镜像color完整对象，默认省略、关闭保留、副本和完整重置基准/共享偏好/最高版本/VBR保持。

双笔刷分类新增“双色绘制”子页：启用、使用第二颜色、允许溢出、前后顺序、主/第二贡献各27模式。当前为separated-stroke-v1整笔隔离合成，说明底贡献在透明笔触内混合及整笔opacity一次；非分隔模式不能假装已支持。所有开关和紧凑下拉使用通用控件/1000ms说明，关闭仍可编辑。灰度模式与配置保留，双色开启时不执行旧覆盖组合。

双色真实预览捕获当前工具前景/背景RGBA，只对启用双色的预设随两色变化失效，颜色不写入预设或resetState。普通预览维持旧白色/颜色动态例笔触及工具正常模式，不跟随工具writeBlend；主/第二自己的贡献模式仍属于真实预设内容。相对尺寸用于预览的标称范围和采样密度估计。实际几何/色彩/裁切仅Rust执行，起笔后改参数或交换两色不影响当前笔触。

验收：严格字段和旧state15拒绝、关闭值/副本/基准重置/最高版本；真实Qt子页/开关/模式/窄列DPR1/2、两色预览和旧请求拒绝、工具模式缓存保持、VBR/独立客户端实际像素与两色起笔捕获/历史、保存关闭重开；公开原生准备/库包写入恢复。自动描边预设及复合光标继续下一阶段，橡皮/涂抹双色未定义，维持明确拒绝而非静默改模型。

重置入口只在“来源与兼容”（分类8）参数末尾显示；它仍恢复完整预设基准，与来源刷新含义不同。其他分类不重复显示。验收实际切换分类、按钮可见性和点击恢复参数。

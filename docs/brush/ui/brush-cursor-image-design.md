## 数值与资源阶段

BrushMask生成固定256×256 straight RGBA8显示图，RGB恒为255，alpha来自实际覆盖。以长边作为单位直径、保持原始宽高比并居中透明留边，与既有轮廓坐标一致。对基础双线性覆盖（边界样本重复）做整数有理面积积分；不是放大后呈方块的源像素常量格平均。薄线/孔洞按覆盖面积参与，不因目标像素中心未落入极薄资源而整图消失。覆盖是有限分辨率的基础资源表示，不宣称等价于某个实际屏幕尺度的mip印章或随机/纹理组合覆盖。

每轴预计算分段线性基函数的整数积分权重，奇数居中留边也不引入浮点坐标误差。使用u64累计面积与最近舍入；最大4096源边和256目标边下，每轴权重项不超过源边+512，二维访问不超过4608²；最坏归一化分母约7.04×10¹³、255倍分子仍在u64内。输出256KiB，不使用整图浮点积分缓存。任何覆盖为零仍输出白色RGB/零alpha。原资源、mip、绘画像素和历史均不修改。

ResourceStore后台生成并编码PNG，按不可变资源ID缓存，最多8项/4MiB、单PNG最多512KiB；缓存仅持有编码结果，不钉住BrushMask/mip。缓存命中复用已验证的显示结果，未命中从内容校验后的实际资源生成；读取错误/取消不安装半成品。沿用任务取消的前后检查，单次数值生成有明确上限，不宣称内部逐像素可取消。

## C ABI阶段

ABI1.53增加PAINT_FEATURE_BRUSH_CURSOR_IMAGE(bit48)和paint_brush_library_tip_cursor_png，接口形状沿用outline：库句柄、UTF-8内容ID、调用者buffer/capacity/required；PNG固定256边，无新DTO，无state/VBR变化。背景线程调用，不保留调用者内存，不持有全局句柄锁做生成。容量查询返回BUFFER_TOO_SMALL及完整required，不复制部分结果；失败清零required，足够容量下空buffer拒绝；已有调用方/轮廓接口保持。Qt尚未消费时明确记录未完成。

验收：正方形/非方形/透明及中间alpha、奇数纵横比边缘面积、4096×1薄资源及高频平均、覆盖不变；PNG解码全像素等于内核输出、解释方式、LRU及弱引用/无资源驻留、取消/非法ID/损坏未命中拒绝；公开ABI能力/头生成、容量哨兵及错误、共享资源库独立生命周期。Windows Release/C/C++ ABI和最小既有Qt绘画回归；整体硬件手感由用户验收。下一阶段必须接实际界面、全局保存和在途身份方可移除剩余清单中的用户入口限制。

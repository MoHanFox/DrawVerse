# 工具详细栏的传递参数

画笔与橡皮共用当前活动笔刷的流量、不透明度及两个独立压感开关；工具详细栏直接绑定 BrushLibrary，与设置页、预设切换、保存和在途捕获复用既有链路。不透明度是整笔上限，流量是逐印章累积速度，不新增工具私有副本。两个滑块各自紧跟对应压感复选框，使用通用紧凑控件及一秒悬停说明。

涂抹图标后的预设下拉框改为细分隔线，仍从画笔面板选择共用预设，保留涂抹强度及独立强度压感。

验收：真实键盘调整两个滑块、鼠标切换两个压感开关，在画笔和橡皮均更新活动预设；反向修改设置与切换预设后控件同步，关闭压感保留原曲线，保存快照恢复一致。涂抹不再有下拉框，保留尺寸、强度、压感与真实绘画回归。仅做 Windows 相关最小 Qt 验证，无 ABI 或格式变化。

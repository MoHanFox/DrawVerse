# 纹理原生与 Qt 入口

ABI1.42 表示原生库包读写与 Qt 已完整保留 state11 / VBR1.9 的 texture 对象。不改变 C DTO 布局，PNG 导入复用覆盖资源接口；后台任务捕获预设 ID 和纹理/笔尖目标，不随当前选择改变。包导出收集当前笔尖、纹理与来源基线 PNG 并集，删除旧临时拒绝，仅保留无资源上下文的旧程序包限制。

BrushLibrary 每个预设保存独立 texture 对象，严格校验模型、字段、范围和哈希；resource=null 必需且只允许关闭。关闭可编辑并保留引用；默认关闭无引用可规范化省略。复制、恢复、准确原生准备和独立真实预览保留所有字段；最高目录版本不能被后面的旧预设降低。

PS 风格设置新增纹理分类，提供启用、导入/移除纹理、三种 PNG 解释、文档纸纹/笔尖局部、比例、角度、深度、反相和 X/Y 偏移。没有图片时禁用启用开关并明确提示。移除引用同时关闭，其他参数保留；原始 ABR 来源不改写。使用统一控件与 1 秒注释。纹理只改变覆盖，光标沿用笔尖轮廓。

验收：实际点击设置与关闭编辑、导入捕获目标和已删除目标、预览/真实纹理绘画及在途设置快照、历史、state11 跨库恢复、VBR1.9 纹理独占/同源/来源并集交换、错误对象及旧版本拒绝/原子性、旧颜色和图片入口回归。运行对应 Rust/Qt 最小回归和生成头/ABI smoke，不把局部结果声称完整笔刷系统验收。

# 整笔描边 Qt 与参数镜像

2026-10-19。沿用[核心设计](../core/brush-stroke-outline-design.md)、state41、ABI1.60 和 VBR1.0；Qt 同时要求整笔描边与分组能力。

BrushLibrary 完整镜像 strokeOutline，包括关闭值、绝对/相对宽度、自身/已有笔刷快照/纹理及资源。预设复制、重置、持久化、原生目录、导入导出和白色异步预览使用同一配置。来源快照复用第二笔尖字段，不引用可变预设，不递归引用描边。

设置新增“整笔描边”页，提供开关、外/中/内、第二颜色、宽度方式和三类来源；已有笔刷可调整大小、间距、两轴散布与数量，纹理可选已有资源、坐标与深度。尚不支持的湿混/蒙版等组合遵循核心拒绝，不伪装成功。

最小 Qt 验证覆盖关闭值与非法输入原子性、复制重置、真实预览、两色笔触和单历史、资源包进入新目录、保存重开；验收独立记录，不称全量通过。

# 半透明图片光标Qt接入

2026-10-17，接ABI1.53已验证的白色PNG，不在Qt重做覆盖算法。光标与预览页添加默认关闭“半透明笔尖图片”和1–100%透明度（默认25%），1000ms提示。全局cursor.image/imageOpacity严格验证/旧配置缺省，与现有共享保存一致，不进入预设/resetState/VBR、不触发绘画预览或历史。简化圆形模式隐藏图片。

PaintCoreClient保留最多当前/在途主副4个需求身份，后台逐个调用PNG接口，Busy有界轮转，结果按仍有效的内容身份采用，失败不反复请求同一身份。关闭/简化时清空后台需求和Qt结果；只保留当前需求的有限数据URL，QML图片关闭全局解码缓存。切换设置不改起笔捕获的主副身份和副角色资格；绘画中重新打开开关也能重建原资源显示。

主图片独立于轮廓开关；副图片仅复合光标、双色有效溢出和绘画工具允许时显示。图像按原生实时姿态/圆度/旋转及文档缩放变换，单位直径正方形含透明留边；不可套原图宽高比两次。轮廓在线宽不变的上层显示。CapsLock、吸色、平移、Ctrl移动、液化、变换、仅悬停、窗口隐藏和Windows Ink位置路由继续接管显示；程序笔尖沿用既有几何。图像就绪前维持可见轮廓/系统指针回退，不能只隐藏系统光标而无定位提示。

最小验收：偏好默认/严格值/缺省/复制重置和重启多文档共享，不污染VBR或真实预览；真实QML开关/滑块及白色alpha图像、独立轮廓和透明度、姿态/缩放/工具优先、主副不同图片与在途切换/关闭重开及过期结果、失败回退和Qt缓存上限，窗口实际合成截图。Windows必要Qt回归及Release/ABI；硬件手感用户验收，跨平台后置，无新ABI或state/VBR版本。

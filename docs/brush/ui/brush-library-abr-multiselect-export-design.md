# ABR 大包兼容、画笔多选与选中导出

2026-10-18，画笔库补齐大体积 ABR、组/画笔混合多选和右键导出。

ABR 转换不再把 Photoshop 允许但超出 DrawVerse 原生范围的参数当成损坏文件。主笔刷直径按 ABR 合法范围读取后钳制到 512 px；主笔刷间距读取到 1000% 后钳制到原生 50%，第二笔刷间距钳制到 100%；0% 圆度钳制到原生 1% 下限。第二笔刷数量和当前笔刷一致，同时接受 Photoshop 的整数或整值 Double。钳制会在来源报告中标为近似，而不是静默丢弃。纹理 `normal` 在进入画笔库时归一化为 `multiply`，预览和保存共用 `textureStateVersion` 处理深度字段与高级模式。

画笔库选择由单个 `selectedId` 扩展为有序项目列表，项目可以是画笔或组。普通点击单选，Ctrl/Command 切换项目，Shift 按当前可见树范围选择。多选或只选中组时，`brushSelectionBlocksPainting` 为真，`PaintCoreClient::beginStroke` 拒绝开始绘画。搜索、折叠和拖动时选择仍按稳定 ID 保存。

底部组按钮和多选右键菜单都能把当前选择创建为新组。若选择中包含组，会连同整棵子树一起移动；已位于所选组内的画笔不会重复搬出。导出按钮从工具栏删除，改为画笔右键“导出该笔刷”和组右键“导出该组”；多选时统一显示“导出选中项”。导出使用 `ordered-package-v1`，选中组包含全部后代，选中画笔位于未选组时作为根画笔导出，纯画笔多选生成显式平根组织。右键菜单使用现有紧凑 `GlassMenu`/`GlassMenuItem`。

没有组时也会临时构造平根组织来完成画笔根级重排，不再要求预先创建组。画笔 DropArea 回调通过行内 `panel` 引用根状态，避免运行时的 `root is not defined`。导出和选择不改变 state、VBR 或 C ABI 版本。

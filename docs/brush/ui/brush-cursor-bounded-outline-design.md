# 光标细线与有界图片轮廓

2026-10-18。本轮[反馈顺序](../../planning/brush-feedback-execution-design.md)步骤5。

## 行为与边界

- 全局光标线宽支持0，默认0；0表示单条1界面像素细线，隐藏第二条内线。已有1–3设置继续保留。
- 简化圆形始终显示单条细线，以HSB的B选择1–100%灰度亮度；不修改前景色、资源、笔触或导出包。
- 精确图片轮廓算法与原有严格复杂度接口保持；显示资源改用独立有界轮廓。小资源且不复杂时保留精确结果，复杂/大资源使用最多128边的保守覆盖降采样，超过2048段继续降低采样边长；保持闭合与原图长宽比，允许丢失显示分辨率下的细节。
- 降采样只用于轮廓显示，不改变源遮罩、mip、图片光标或绘画像素。ResourceStore沿用后台工作与8项缓存，避免鼠标移动时重新计算。

## 实现前验收条件

核心：简单轮廓不变；高频大图结果有界且闭合；极扁资源保持正确长宽比和非空轮廓；源覆盖不变。IO：真实资源生成/缓存继续通过。Qt：0宽和亮度持久化、非法值原子拒绝、普通/图片/简化主副光标的单线宽度与显隐；最小真实图片光标回归。所有测试结果写入[分步验收](../../validations/planning/brush-feedback-execution-validation.md)，不外推实体设备手感或所有GPU。

# 压力曲线编辑入口

ABI1.35声明压力动态，原生package读写解除临时边界。Qt接受v5/parameters.pressureDynamics/行为2/pressure-curves，原始来源仍独立；本地只验证输入及绘制曲线图，不执行笔触算法。修改生成准确原生准备与预览，旧预设没有曲线字段仍用线性默认；复制/改名/共享/恢复/导出都保留曲线和最低比例。

PS分类增加“形状动态”，尺寸压感及曲线在此；“传递”包含流量压感和流量曲线。编辑器2–17点、图上选择/拖动、双击增点、按钮增删、选中点X/Y百分比数值和最低比例、恢复默认；端点X固定0/1，Y可编辑。关闭压感不丢编辑数据且仍可编辑，执行是否生效沿内核开关；涂抹流量曲线受涂抹强度压感控制。浮点精度由数据保留，不因显示取整而改节点，非法编辑保持原值。

未修改配置时旧状态/vbr行为版本和像素不变，编辑后v5/VBR1.3；恢复默认且没有其他动态可规范化回旧格式。原生预览使用同一动态定义和真正的压力序列，界面不画假笔触。Tooltip沿1秒规则。

验收：面板实际鼠标编辑/端点/增删/数值/重置与最低比例、无QML警告、准确真实预览变化和起笔在途快照、鼠标/笔输入像素；共享状态及关掉压感仍保留配置、重开/VBR往返/来源图共存、坏压力状态保持配置，旧最小界面/ABI回归。完整其余动态/湿混仍继续后续。

用户后续要求独立预设尺寸与整笔不透明度，普通低不透明度笔触的旧像素兼容声明由 `brush-stroke-opacity-design.md` 覆盖。

# 颜色动态原生Qt入口

ABI1.41新增COLOR_DYNAMICS能力和24字节PaintBrushBackgroundDesc，以及带背景的prepared起笔入口。旧ToolDesc/入口布局不变，旧入口使用白色背景。新入口同时复制前景ToolDesc与背景DTO、验证size/reserved/RGBA，sequence失败归零；后台操作持有Pixel背景值，等待准确准备后捕获完整预设与两色，不在GUI等待编译。caller读写仅pointers.rs。

Qt接受state10/VBR1.8/behavior7/color-dynamics，颜色动态分类含启用、逐笔尖（关闭为整笔）、前景背景/色相/饱和度/明度抖动。通用百分比输入/滑动条与1秒提示；关闭后参数仍可编辑而不激活模块；同样修正散布和形状抖动禁用父组。关闭配置、完整seed/model、复制、目录/批量导入最高版本保持。起笔传当前两色并捕获，中途换色不影响本笔。真实隔离预览使用固定红/蓝示例，原有无颜色对象预览保持；Qt不执行HSV/随机算法。解除库package临时拒绝，启动至少ABI1.41。

验收：新DTO/C ABI边界与实际后台笔触、旧入口白色行为；Qt真实分类/输入/开关、预览、多色覆盖及透明度上限、起笔后换背景/关闭仍保持、精确历史、VBR恢复与重开、图片来源组合保持，DPR1/2、生成头和相关静态检查。实体设备/跨平台和PS真实颜色兼容仍需后续，完整系统不能按本阶段宣称完成。

# 笔刷预览刷新规则管理

2026-10-26，用户要求列明无需刷新预览的设置并完成代码，规则须独立管理，不能在单个判断中堆叠。

## 无需刷新条件

| 设置 | 条件 |
| --- | --- |
| 散布、纹理、双笔刷、湿混、平滑、起收笔、描边、颜色/形状及速度/切线/距离/倾斜/旋转/方向/衰减动态内部参数 | 对应功能关闭 |
| 大小/流量/不透明度压感开关、压力曲线及最低值 | 标准预览固定使用线性大小/流量压感，不启用不透明度压感；包含副笔尖及描边来源笔尖 |
| 最低倾斜圆度 | 倾斜圆度关闭 |
| 描边备用宽度 | 像素模式下百分比不生效；百分比模式下像素值不生效 |
| 程序硬度 | 使用图片笔尖，含副笔尖和描边来源笔尖 |
| 随机种子 | 形状/颜色抖动强度为零，或散布偏移与数量抖动为零 |
| 喷枪开关、间隔 | 当前标准预览不模拟停留喷射；本项不代表喷枪效果已获得预览支持 |
| 大小、流量、不透明度、前景/背景色、光标设置、绘画混合模式、名称/组织及选择等元数据 | 标准预览使用固定大小/流量/不透明度、示例色及普通混合，继续保持原有免刷新行为 |

关闭状态的参数仍校验、保存、同步到执行笔刷；除标准预览固定的压感和喷枪外，开启后必须用最新保存值刷新。正在生成的预览与错误状态在有效参数不变时保留，旧任务仅在有效参数改变后失效。

2026-10-27补充：按用户要求压感开关也免刷新。标准压感规则同时用于缓存键和实际生成参数，避免只跳过失效通知导致重试、冷加载时图像改变。压感曲线和最低值也采用固定示例值，实际绘画及保存仍保留用户的开关、曲线和最低值。

## 实现约束

独立BrushPreviewPolicy以具名规则注册表管理：关闭功能、压感、笔尖、随机种子、描边宽度、喷枪分别处理。统一生成规范化有效参数；缓存比较、实际预览请求及恢复/跨工具复用共用这份参数。setter不再各自清缓存；真实笔刷参数和持久化不规范化、不丢失关闭值。规范化数据只进入独立预览会话。

颜色动态仅按enabled启用预览示例色，修正参数对象非空就改变示例颜色的问题。保留实际影响预览的间距、圆度、角度、有效动态等。未知字段默认保留比较，避免未来新增功能被静默免刷新。

无Rust/ABI/state或文件格式变化，按用户要求只做与规则、有效切换、异步回包、保存恢复和实际预览有关的最小验证；交付build/bin/Release/drawverse.exe。

## 2026-10-28 滑条拖动预览事务

笔刷设置内共用 CompactSlider 在按住期间继续发布真实参数，但 BrushLibrary 保留预览输入、图片及 token，并暂停请求；释放或控件销毁时比较最终有效参数，按原策略失效并请求一次。键盘和输入框沿用即时更新。

# 笔尖角度与圆度控制器

参考用户提供的 PhotoCraft 截图：左侧圆形方向盘、椭圆轮廓和两个短轴手柄，右侧角度与圆度数值。复用 DrawVerse 现有笔尖参数与真实预览，不复制第三方代码，不改变 ABI、state 或 VBR。

同时核对 PhotoCraft 源码 `crates/ui-egui/src/brush_sections.rs` 的 `ellipse_grab`、`ellipse_drag`、`ellipse_widget`（本地参考提交 d95fdf3181c01ad41e95456091a394b105a9afb2）：优先命中短轴手柄、沿短轴投影、否则按指针方位求角度。DrawVerse 保留自身顺时针角度约定、整数交互和主题，使用 Qt 图元而非 egui；屏幕旋转符号不照搬。

## 交互与边界

- 主笔尖与可编辑的第二笔尖共用一个 QML 控件，替代原角度、圆度的两条滑条。已有笔刷来源继续继承原笔刷，不另外修改其笔尖。
- 方向盘拖动角度，零度朝右，正角度顺屏幕坐标顺时针，与核心取样一致；角度范围 -180° 至 180°。
- 上下短轴手柄拖动圆度，沿当前旋转后的短轴投影，保持角度不变；圆度限制 1% 至 100%。压扁到 1% 仍可恢复。
- 数值采用现有整数输入、加减与验证；只在用户输入或拖动时提交，打开面板不量化已有导入参数。外部参数变化同步显示，不因拖动破坏绑定。
- 手势按下后捕获，离开圆盘仍可拖动，释放后移动不再修改。界面预览表示几何方向与比例，图片笔尖仍由既有资源/真实笔刷预览展示。

## 验收

通过真实 Qt 鼠标事件检查角度、旋转后的圆度手柄、1%/100% 限制、释放后停止；检查右侧输入、外部参数同步、主/第二笔尖独立、已有来源隐藏、保存恢复后保持参数；构建 Release。结果见[验收](../../validations/brush/ui/brush-tip-shape-control-validation.md)。

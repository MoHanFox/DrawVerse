# 双笔尖覆盖内核

第一阶段执行 paired-dab-v1：每个实际主印章生成一个第二笔尖簇，先计算主覆盖，再与第二簇覆盖组合，再进入现有纹理、流量、整笔不透明度、选区和四类写入。第二簇最多16个散布子印章，按覆盖并集合成；只在主笔尖非零区域参与，第二笔尖不能扩大主笔尖边界。

DualBrush 是不可变配置，包含开关、覆盖组合及共享 Arc<SecondaryTip>；默认配置由 OnceLock 共享，避免扩大原生任务队列枚举或每次默认构造重复分配。SecondaryTip 独立拥有半径、BrushTip、图片资源、大小/流量曲线、设备几何、散布与形状抖动；不包含递归双笔尖，不执行第二颜色或第二整笔不透明度，构造时拒绝这些配置。第二动态使用独立随机域与实际主/子印章计数，调用拆分不改变结果。关闭保留完整配置及资源，执行编译后不进入像素循环。普通写入在原地改变有效第二压力响应时生成更新印章，固定曲线响应不变时不重复沉积；涂抹保持原有移动运输触发规则。

覆盖模式显式定义为 multiply=a*b、darken=min(a,b)、lighten=max(a,b)、subtract=a*(1-b)、difference=abs(a-b)、screen=a+b-a*b；a=0时统一返回0，仅作用于主笔尖边界。此模型不是PS输出逐像素兼容声明。第二簇流量在并集之前应用，不承担第二颜色沉积。蒙版/橡皮和涂抹复用相同组合后的覆盖。

第二图片与主图片、纹理源按Arc身份去重计入目录预算，包括关闭配置。每个主印章编译第二簇的几何/mip，像素循环不分配；最大展开数量和最坏图片采样费用进入起笔/段预检，拒绝时不修改像素或历史。主印章范围仍有效，较大/非方形/旋转第二图片完整采样但裁切在主区域。

本阶段不提供尚未执行的第二路径间距。独立路径调度、state/VBR/原生Qt与兼容报告在后续阶段继续；旧state保存遇到非默认DualBrush明确拒绝，绝不丢弃配置。ABI保持1.42，光标仍为主笔尖轮廓。

验收：模式数值和边界、程序/图片及孔洞/旋转、独立压感与设备/形状/散布、输入拆分和主散布子印章随机域、关闭像素兼容与资源保留；真实绘画/擦除/蒙版/涂抹、选区与锁、整笔上限/取消/撤销重做；共享预算、捕获快照、工作量预检原子性；IO显式拒绝。完整双笔刷功能不能仅以此阶段宣布完成。

# 第二笔尖选取已有笔刷

2026-10-18，对应[反馈顺序](../../planning/brush-feedback-execution-design.md)步骤10。

在启用双笔刷下选择“自定义 / 现有”。选择已有预设时复制其主笔尖的名义尺寸、实际间距、图片/硬度/圆度/角度/流量、大小/流量压力、笔尖设备、散布与形状抖动参数，形成原双笔刷模型的独立快照；不复制其第二笔刷，也不持有源预设引用，因此源修改、改名、删除和自选不会递归改变快照。第二覆盖仍是灰度覆盖组合，来源的颜色、湿混、起收笔、纹理等整笔处理不成为第二笔尖处理。

已有模式只显示选取列表、大小、间距、散布开关/幅度、双轴和数量；其他参数从快照继承并保持。首次选取采用独立尺寸，后续只改变这几个可编辑值；切回自定义可编辑完整快照。选择模式尚未选取时不改变执行参数。

快照执行值沿用已有state/VBR模型，不增加格式或行为版本。编辑器模式和来源显示名称作为Qt个人设置存于根级dualEditors，保持复制/重置基线和重开；原生目录准备不接收这些显示偏好。VBR只交换可执行快照，导入后以自定义方式编辑，来源不在目标目录中也能完整执行。

实施前验收：Qt复制所有支持字段、单位换算、自选/删除源/修改源保持、开关和只显示允许字段；已有IO原生入口实际捕获/预览/像素/新目录VBR与重开，复制重置和旧自定义回归。结果写入[分步记录](../../validations/planning/brush-feedback-execution-validation.md)。

# 第二笔尖相对尺寸内核

2026-10-14，实施双色扩展的尺寸基础，不提前展示未完成的双色入口。既有六种灰度覆盖模式不变。新增不可变 DualSizing，独立/相对模式、直径偏移[-511,511]px、跟随压感/固定宽度规则；独立尺寸和关闭模块配置均保留。默认独立、偏移0、跟随，旧笔触不变。

相对标称直径为主标称直径加偏移，最终夹在[1,512]px。跟随规则再执行第二大小压感与大小抖动。固定规则使用当前主实际半径加偏移/2，再夹到[0.5,256]，不再次执行第二大小压感或大小抖动，第二角度/圆度/散布/流量仍有效。保留第二大小配置。尺寸只改变第二采样，灰度模型仍限制在主覆盖内；自动外描边须后续双色与溢出合成。

配对采用当前主子印章实际尺寸。独立路径采用最近已发出的主子印章大小抖动样本，压力使用第二取样点的压力重新计算主尺寸响应；起笔尚无主印章时采用主序号0/子序号0的真实形状样本。此规则定义了独立双流对应关系，不虚构主随机序号，也不承诺独立散布/不同几何均匀描边。固定模式的静止压力更新使用主尺寸响应，不能只检查被忽略的第二尺寸曲线。第二步长按有效标称直径，工作预算按最大有效尺寸保守计算。

本阶段无ABI/state/VBR变化。旧DualParameters.from_core对任何非默认尺寸配置（包括关闭/独立模式保留的非默认值）明确拒绝，防止保存丢失。后续显式格式版本、原生捕获与Qt设置完整接通才公开。

验收：正负零偏移/尺寸夹限/非法非有限值，配对实际尺寸与压力规则、独立步长与分割一致，主形状抖动起笔映射，完整真实像素及单笔历史/撤销重做，旧覆盖测试，旧IO非默认拒绝与默认往返。运行对应核心与IO回归、Clippy及应用构建。

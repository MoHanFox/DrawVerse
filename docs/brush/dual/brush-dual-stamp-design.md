# 逐印章双笔刷双色模型

2026-10-18，在 `separated-stroke-v1` 整笔隔离双色之后增加 `interleaved-stamp-v1`。它保留双色配置的启用、第二颜色来源、溢出、前后顺序和两种贡献混合模式，只改变双色贡献进入笔触的时机。

## 执行模型

每个主印章先生成自己的主覆盖，并在配对模式下生成同一位置、带独立动态/散布/图片/相对尺寸的第二覆盖。主色使用起笔捕获的颜色动态样本；第二色按 `useBackground` 取起笔捕获的背景色或前景色。主/第二覆盖都以当前压力不透明度上限和收尖系数限幅。

单组印章先在透明像素空间按 `second-behind` 或 `second-in-front` 合成主、第二贡献；不溢出时继续使用 `min(second, primary)` 的软裁切。随后把该组结果以 source-over 写入笔触内的 `stamp_field`。这一写入发生在下一组印章之前，所以后一个第二印章可以覆盖先前主印章，回笔和交叉也按实际印章顺序累积。

笔触结束时，`stamp_field` 从起笔 before 快照重新复合到文档：整笔不透明度只乘一次，图层写入混合模式、选区、羽化、蒙版、透明锁、图层偏移和文档纸纹仍作用于最终贡献。这样逐印章顺序与现有整笔事务、历史、分页和 taper 回放共用同一套边界。

## 约束

该模型要求配对笔尖（`paired-dab-v1`）。独立第二路径（`path-coverage-v1`）没有单一的主/第二配对顺序，明确拒绝启用。橡皮和未开启手指绘画的涂抹会忽略颜色模块并按原工具执行；开启手指绘画的涂抹在第一笔沉积阶段使用双色，之后按涂抹搬运。湿混下的双色涂抹/橡皮没有实际意义，保持不处理并移出待办。关闭双色时仍保留该模型值，允许切回独立路径或湿混，但重开时不得把它当成可执行组合。

带 taper 的尾段回放把 `stamp_field` 与主、第二覆盖和图层 before 一起记入期刊；取消、预算失败和存储失败恢复整条活动笔触。分页仍以 64 像素瓦片为单位，单印章和总输入预算沿用既有调度上限。

## 保存与版本

颜色对象的 `model` 从 `separated-stroke-v1` 扩展为 `separated-stroke-v1`/`interleaved-stamp-v1`。state22 才允许后者；VBR1.28 才允许后者，behavior17，能力名为 `dual-color-stamp`。旧 state21/VBR1.27 读取到该模型必须拒绝，避免旧执行器把它退回整笔分隔而静默改变像素。

ABI1.56 公布 `PAINT_FEATURE_DUAL_COLOR_INTERLEAVED`（bit51），复用既有双色 DTO、准确准备和库包入口，不改变结构布局。Qt 新增“整笔分隔合成/逐印章交织”下拉，关闭状态保留，路径组合在设置层拒绝。双色开启后第二色固定使用背景色，不再提供“使用第二颜色”开关；加载旧配置时 UI 规范化为使用背景色。

颜色对象字段的机器可读校验见 [dual-color-stamp-v1.28.schema.json](../../../contracts/dual-color-stamp-v1.28.schema.json)。

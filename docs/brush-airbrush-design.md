# 时间喷枪

2026-10-18，新增预设级时间喷枪，模型为 `time-interval-v1`。它不是把设备事件频率当作流量：Qt 在笔按住且位置不变时按固定毫秒间隔提交一次专用 `AirbrushTick`，Rust 在文档上执行一次印章沉积。移动输入仍走原路径，不会与定时器重复注入移动点。

参数为启用开关和 `intervalMs`（1–1000ms，默认50ms），随预设保存到 state23/VBR1.29，behavior18，能力名 `airbrush`。只支持干画笔和橡皮；普通涂抹与湿混不支持喷枪。手指绘画涂抹的双色语义不改变。

每次 tick 在 Document 内以当前输入位置、压力和时间为准，复用同一笔触、随机序号、动态、选区、图层锁、蒙版和单一历史。为使低不透明度喷枪能逐 tick 累积，airbrush tick 使用当前文档像素作为合成底，并按流量、整笔不透明度和压力上限应用贡献，不跳过已达到覆盖上限的像素。普通距离印章仍保持原有饱和跳过。

Qt 定时器只在绘画期间运行，结束、取消、丢笔、切换文档和关闭客户端都会停止。定时器间隔取起笔时捕获的预设值，中途编辑不影响在途笔触。ABI1.57 新增 `PAINT_FEATURE_AIRBRUSH`（bit52）和专用 `PAINT_COMMAND_AIRBRUSH_TICK`，不改变既有 DTO 或入口签名。
